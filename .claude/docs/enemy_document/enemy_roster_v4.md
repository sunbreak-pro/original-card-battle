# 敵ロースター v4.2 — 80% 用 9 体と 100% 用 10 体 + エクストラボス枠（属性 / 特性 / 状態 / 適応）

> **Status**: DRAFT v4.2（2026-09-20）。`battle_core_v4.md` の §16 / §17 / §18 に合わせた全面改訂です。位置（近間 / 遠間）を持つのはボスと精鋭だけになり、投入量は 1 行動 1 コストに変わりました。数値は叩き台で、§10 の試験台で測って直します。**2026-09-21**: ボス 2 体の固有カード 6 枚を `swordsman_cards_v4.md` の #44〜49 に結びました（#38）。
> **入力**: `battle_core_v4.md` §16（近間 / 遠間の決定）、§17（コスト・決定木・状態・予兆）、§18（K1〜K8 の目盛りとバランス）。同書の §0〜§14 は古いので従いません。
> **v4.1 からの差分**: 共有の距離（近 / 中 / 遠）と 3 段の補正、空振り回避、`effectiveRange`、`minInvest`、`shift` を廃止しました。通常敵は位置を持ちません。`tiers` は列 1〜4 になり、列番号がそのままコストです。状態はスタック制で、「軽足」は「俊敏」へ、敵側の「手薄」は「無防備」へ改名しました。

## 0. 目盛り（v4.2）

| 項目                             | 値                                                                                     |
| -------------------------------- | -------------------------------------------------------------------------------------- |
| プレイヤー HP                    | 50                                                                                     |
| 敵 HP                            | 通常 50〜70 / 精鋭 90〜110 / ボス 160〜200 / エクストラボス 240〜260 / 取り巻きの犬 32 |
| 最大スタミナ                     | 通常 10 / 精鋭 12 / ボス 14 / 犬 8                                                     |
| 毎ターンの回復                   | プレイヤー 3（§18.2 K1）/ 通常 2 / 精鋭 3 / ボス 4 / 犬 2                              |
| 1 フェーズの出力（平常時の目安） | 通常 7〜13 / 精鋭 10〜16 / ボス 13〜20 / エクストラボス 16〜24                         |
| 出血 / 再生                      | HP −2 × 残スタック / HP +2 × 残スタック                                                |
| 構え                             | 残 3 以上で Guard +3                                                                   |
| 特性の威力加算                   | +3 か +5                                                                               |

プレイヤーのカードの目盛りです（`battle_core_v4.md` §18.2 の K2 / K8）。列番号がそのままコストで、1 枚は 1 列だけを持ちます。

| 面               | 列 1 | 列 2 | 列 3 | 列 4 |
| ---------------- | ---- | ---- | ---- | ---- |
| 単属性アタック   | 6    | 13   | 21   | 30   |
| 単属性ガード     | 4    | 9    | 15   | 22   |
| 二属性アタック面 | 4    | 8    | 14   | 20   |
| 二属性ガード面   | 3    | 6    | 10   | 14   |

敵の面は、同じ列のプレイヤーの約 6 割に置きます。プレイヤーは 1 ターンに 2 枚以上出す前提（§18.4）ですが、敵は 1〜2 行動しか出しません。1 フェーズの出力を上の目安に収めるため、1 行動あたりの値をこの比率にします。

| 面               | 列 1 | 列 2 | 列 3 | 列 4 |
| ---------------- | ---- | ---- | ---- | ---- |
| 単属性アタック   | 4    | 8    | 13   | 18   |
| 単属性ガード     | 3    | 6    | 9    | 13   |
| 二属性アタック面 | 3    | 5    | 9    | 12   |
| 二属性ガード面   | 2    | 4    | 6    | 9    |

出力の目安は、プレイヤーが「主に咎める側」を外しているときの値です。咎める側に居続けると位置の特性が乗り、1.5 倍ほどまで上振れします。上振れは予兆で見えるので、読んで外すのがプレイヤーの手になります。

**ターン数は測り直します。** v4.1 の狙い（通常 6〜10 / 精鋭 10〜14 / ボス 12〜24 / エクストラボス 22〜28。ボスの内訳は 瘴気の司祭 12〜18、深淵の釣り人 14〜20、歪みの根 18〜24）は、プレイヤーの 1 ターン平均 8〜10 を前提にしていました。新しい目盛りではプレイヤーの平均が 15〜20 へ上がるので、HP を据え置くとターン数は半分近くまで落ちます。HP を上げるか目盛りを下げるかは §10 の試験台 1 で測ってから決めます。

## 1. 記法

### 1.1 スキーマ

```
EnemyDef {
  id, name, rank: normal | elite | boss
  maxHp, maxStamina, recover            // recover は毎ターンの固定回復
  hasRange: bool                        // 位置を持つのはボスと精鋭だけ（§17.3）
  startRange?: close | far              // hasRange が true のときだけ定義する
  mainSide: close | far                 // 主に咎める相手の側
  floors: [min, max]                    // 出現する階層
  actionsPerPhase: 1 | 2                // 精鋭とボスは 2
  omenDepth: 1 | 2                      // 2 なら「次」と「次の次」を見せる
  actions: EnemyAction[]
  decisionTree
    // hasRange が false: { foeClose: id[], foeFar: id[] }             2 枝
    // hasRange が true : { selfClose: { foeClose, foeFar },
    //                      selfFar  : { foeClose, foeFar } }          4 枝
  adaptations?: Adaptation[]            // ボスだけ
  escorts?: { id, count }[]             // 取り巻き
  journal: { close, far, weakness }     // 手記の頁（開示度 2 で全部見える）
}

EnemyAction {
  id, name
  attributes: (A | G | St | Sk | M)[]   // 1〜2 個
  column: 1 | 2 | 3 | 4                 // 列番号 = コスト
  power?, hits?                         // hits 2 なら 1 撃ずつ Guard に当てる
  guard?
  selfMove?: close | far | flip         // 位置を持つ敵だけ。自分の位置を変える
  push?: flip                           // 相手の位置を反転する。敵だけが持つ
  breakStamina?                         // 崩し
  statuses?: { name, stacks, target: self | foe | ally }[]
  stance?: { kind, value, when? }       // when は「相手が遠間のターン開始」のような条件
  trait?: { condition, param, effect }  // 1 つまで
  omen: { kind, side? }                 // 種別 + 咎める側の一字
}

Adaptation {
  id
  condition: string       // 手記に書ける文（例: 「アタックを 3 回続けて受けると守りに入る」）
  watch: string           // 何の履歴を数えるか
  effect: string          // 決定木か行動の差し替え
  until: string           // いつ元に戻るか
}
```

### 1.2 共通規則（v4.2）

- **1 行動 1 コスト**です。決定木を上から見て、払える最初の行動を取ります。どれも払えなければ休みになり、そのフェーズは回復だけで終わります（§17.2）。予兆に出した技が払えなくなったときも休みです。予兆のコミットは崩しません。
- **予兆は「種別 + 咎める側の一字」**です。種別は属性の主（攻撃 / 守り / 技 / 構え / 動）で、効果が乗る側を「近」「遠」の一字で添えます。側を読まない行動には一字を付けません。
- **位置を持つのはボスと精鋭だけ**です。通常敵と取り巻きは位置を持たず、決定木はプレイヤーの位置で 2 枝に分かれます。位置を持つ敵は自分と相手の組で 4 枝です。
- **敵にも構え（残 3 以上で Guard +3）とスタンス枠 1 が働きます。** スタンスの行動は 1 戦闘で 1 回だけ使え、使うと決定木から外れます。状態の種類に上限はありません（§17.5）。
- **崩しと相手に付ける状態に距離の条件はありません。** v4.1 の「diff 0 のときだけ」は距離の廃止で役目を終えました。側を読む技は、相手がその側にいるときだけ効果が乗ります（外して避けられます）。
- **`push` は相手の位置を反転します。** 近間の相手は遠間へ、遠間の相手は近間へ動きます。プレイヤーの Guard では減りません。`shift` は廃止しました（§18.3）。
- **`selfMove` は自分の位置を変えます。** 位置を持つ敵だけが持ちます。

### 1.3 精鋭とボスの 2 行動

- 1 フェーズに 2 手を続けて取ります。1 手目の後の位置で決定木を引き直します。
- 予兆 2 段は次のフェーズの 2 手を両方見せます。開示度 0 では 1 手目の種別だけです。2 手目は「予定」として出し、1 手目の後に変われば「予定変更」と見せます（§17.6 F11）。
- コストは 1 手ずつ払います。回復が 3〜4 なので、2 手目は自然に列 1〜2 へ落ちます。

### 1.4 複数体の戦闘

- 位置を持つのは長だけです。取り巻きは位置を見ません（§17.3）。プレイヤーの位置は 1 つで、長との組だけが判断の材料になります。
- 各敵が自分の予兆を持ち、決定木を引きます。行動順は EnemyDef の並び（長 → 取り巻き）です。
- 単体攻撃は受け皿で対象を選びます。`targets: all` のカードは全員に当たります。全員の HP が 0 で勝利です。

### 1.5 ボスの適応

- 適応は「条件（手記に書ける文）→ 決定木の差し替え」の組で持ちます。条件は行動履歴を数えるだけで判定でき、乱数を使いません。
- 適応中は予兆バナーに小さく印を出します（開示度 1 以上）。開示度 2 では条件そのものが手記の頁に書かれます。

### 1.6 特性（敵で使うもの）

| 条件         | 敵での意味                                           |
| ------------ | ---------------------------------------------------- |
| 連動         | 同じフェーズに指定の属性を実行済み（2 行動の敵だけ） |
| 位置（自分） | 自分が指定の側にいる（位置を持つ敵だけ）             |
| 位置（相手） | 相手が指定の側にいる                                 |
| 温存         | 使用後の残スタミナが閾値以上                         |
| 死力         | 現在スタミナが 2 以下                                |
| 崩し後       | 相手（プレイヤー）のスタミナが 3 未満                |
| 無防備       | 相手の Guard が 0                                    |
| 相手の状態   | 相手に指定の状態が付いている                         |
| 自分の状態   | 自分に指定の状態が付いている                         |

| 効果  | 意味                                |
| ----- | ----------------------------------- |
| 威力  | +3 か +5                            |
| Guard | +3 か +5                            |
| 回復  | 次のターン開始の回復 +1             |
| 追撃  | 次のアタック面の威力 +5             |
| 転換  | 現在の Guard の半分を次の威力に足す |
| 状態  | 指定の状態を 1 スタック付ける       |
| 崩し  | 崩しを +1                           |

予兆 / 初手 / 締め / 連打 / 手薄 はプレイヤー側の条件で、敵には使いません。敵側の「相手の Guard が 0」は **無防備** と呼びます（§17.6 F1）。カード側の「手薄」（プレイ後の残り手札 1 枚以下）とは別の語です。重撃はプレイヤー側の効果で、敵には使いません。

### 1.7 状態の書式

状態はスタック制です（§17.5）。文面は「<状態名> を n 付与する」に揃えます。敵には状態の種類の上限を置きません。

- **使うと減る型**（効果が出るたびに 1 減る）: 強化 / 脆化 / 集中 / 見切り / 威圧
- **ターンで減る型**（付いた側のターン開始に 1 減る）: 出血 / 再生 / 俊敏 / 鈍足 / 疲労
- 強化は ×1.5、脆化も ×1.5 です（§18.2 K4）。
- 「軽足」は **俊敏** へ改名しました。効果は「有効なターンの開始時に近間 / 遠間を選べる」です。
- 威圧は「相手の次の行動の威力と Guard を 3 下げる」です（§17.2）。

## 2. 通常 6 体（位置を持たない）

主に咎める側は 近間 3 / 遠間 3 です。HP 50〜70、最大スタミナ 10、回復 2、1 行動、予兆 1 段。決定木はプレイヤーの位置で 2 枝に分かれます。

### 2.1 長柄の歪み兵（polearm_warped）— 遠間咎め、階層 1〜2

v3 からの検証用の敵です。「遠間に居続けると薙ぎ払いが伸びる、近間へ入ると石突きで押し返される」の押し引きが基準になります。状態は使いません。

- HP 60 / 最大スタミナ 10 / 回復 2 / 位置なし / 主に咎める側 遠間 / 階層 1〜2

| id           | 名前             | 属性  | 列（コスト） | 効果                         | 状態 | 特性                                  | 予兆     |
| ------------ | ---------------- | ----- | ------------ | ---------------------------- | ---- | ------------------------------------- | -------- |
| sweep        | 薙ぎ払い         | A     | 2            | 威力 8                       | —    | 位置（相手 遠間）: 威力 +3            | 攻撃・遠 |
| shove        | 石突きの押し込み | A + M | 2            | 威力 5、相手の位置を反転する | —    | 無防備: 相手の Guard が 0 なら威力 +3 | 攻撃・近 |
| reach_thrust | 穂先の突き       | A     | 1            | 威力 4                       | —    | —                                     | 攻撃     |
| guard_up     | 柄で受ける       | G     | 1            | Guard 3                      | —    | 温存: 残 4 以上で次の回復 +1          | 守り     |

決定木: 相手 近間 → shove / guard_up / reach_thrust。相手 遠間 → sweep / reach_thrust / guard_up。

列 3 を持たないのは階層 1 の敵だからです。回復 2 と列 2 が釣り合うので、毎ターン 8〜11 を刻み続けます。

手記: 近間「石突きで遠間へ押し返す。Guard が無いと重い」。遠間「薙ぎ払い。遠間に居続けると +3」。弱点「近間に入れば薙ぎ払いが軽くなるが、1 ターンで押し返される。押し込みの予兆が出たターンに鈍足を付けるか、Guard を残して受ける」。

### 2.2 影走りの犬（shadow_hound）— 近間咎め、階層 1〜2

速くて脆い敵です。近間の相手に噛みついて出血を残し、遠間へ逃げられると跳びかかって引き戻します。「間合いを外す」を最初に教えます。

- HP 50 / 最大スタミナ 10 / 回復 2 / 位置なし / 主に咎める側 近間 / 階層 1〜2

| id       | 名前         | 属性  | 列（コスト） | 効果                         | 状態         | 特性                         | 予兆     |
| -------- | ------------ | ----- | ------------ | ---------------------------- | ------------ | ---------------------------- | -------- |
| bite     | 噛みつき     | A     | 2            | 威力 8、出血を 2 付与する    | 出血（相手） | —                            | 攻撃・近 |
| lunge_in | 跳びかかり   | A + M | 2            | 威力 5、相手の位置を反転する | —            | 位置（相手 遠間）: 威力 +3   | 攻撃・遠 |
| crouch   | 身を低くする | G     | 1            | Guard 3                      | —            | 温存: 残 4 以上で次の回復 +1 | 守り     |

決定木: 相手 近間 → bite / crouch。相手 遠間 → lunge_in / crouch。

出血 2 スタックは翌ターン −4、その次 −2 です（ターンで減る型）。

手記: 近間「噛みつき。出血が 2 スタック残る」。遠間「跳びかかって近間へ引き戻す」。弱点「HP 50。遠間へ逃げても 1 ターンで戻される。跳びかかりの予兆が出たターンに Guard を置き、噛みつきの予兆で遠間へ抜ける」。

### 2.3 錆びた鎧の亡者（rusted_revenant）— 近間咎め、階層 2〜3

重くて遅い敵です。開幕に「鉄の身」を置いてから近間の相手へ大振りを振るいます。大振りはコスト 3 なので、回復 2 では 2 ターンに 1 度しか出せません。

- HP 58 / 最大スタミナ 10 / 回復 2 / 位置なし / 主に咎める側 近間 / 階層 2〜3

| id          | 名前     | 属性  | 列（コスト） | 効果                         | 状態 | 特性                                   | 予兆     |
| ----------- | -------- | ----- | ------------ | ---------------------------- | ---- | -------------------------------------- | -------- |
| iron_body   | 鉄の身   | St    | 2            | 毎ターン開始に Guard +3      | —    | —                                      | 構え     |
| heavy_swing | 大振り   | A     | 3            | 威力 13                      | —    | 崩し後: 相手のスタミナ 3 未満で威力 +3 | 攻撃・近 |
| press       | 押し込み | A + M | 1            | 威力 3、相手の位置を反転する | —    | —                                      | 攻撃・遠 |

決定木: 相手 近間 → heavy_swing / iron_body / press。相手 遠間 → press / iron_body。

鉄の身の毎ターン +3 は目盛りを上げません。毎ターンの Guard は戦闘の長さに直接効くためです。大振りと押し込みを交互に出すので、平均の出力は 8 前後になります。

手記: 近間「大振り。こちらのスタミナが少ないと重くなる」。遠間「押し込みで近間へ戻される」。弱点「鉄の身を置く前の 1 ターンが最も柔らかい。置いた後は崩しでスタミナを削り、大振りを出させない。遠間へ抜けても押し込みで戻されるので、戻された直後の 1 ターンで叩く」。

### 2.4 弩の狩人（crossbow_hunter）— 遠間咎め、階層 2〜3

遠間の相手へ重い一射を撃ち、威圧を乗せます。近間へ入られると退き撃ちで押し返します。

- HP 54 / 最大スタミナ 10 / 回復 2 / 位置なし / 主に咎める側 遠間 / 階層 2〜3

| id       | 名前       | 属性  | 列（コスト） | 効果                         | 状態         | 特性                       | 予兆     |
| -------- | ---------- | ----- | ------------ | ---------------------------- | ------------ | -------------------------- | -------- |
| bolt     | 弩の一射   | A     | 3            | 威力 13、威圧を 1 付与する   | 威圧（相手） | —                          | 攻撃・遠 |
| backstep | 退き撃ち   | A + M | 2            | 威力 5、相手の位置を反転する | —            | 温存: 残 4 以上で Guard +3 | 攻撃・近 |
| brace    | 盾を構える | G     | 1            | Guard 3                      | —            | —                          | 守り     |

決定木: 相手 近間 → backstep / brace。相手 遠間 → bolt / brace。

威圧は使うと減る型で、こちらの次の行動の威力と Guard を 3 下げます。

手記: 近間「退き撃ちで遠間へ押し返す」。遠間「弩。威圧が付いて次の一手が 3 下がる」。弱点「近間で粘れば弩は撃てず、退き撃ちと盾だけになる。押し返された次のターンに戻れるよう、ムーブ面を 1 枚は手札に残す」。

### 2.5 靄の射手（mist_archer）— 遠間咎め、階層 3〜4

遠間の相手へ矢を放ち、疲労で回復を削ります。近間へ入られると靄に溶けて相手を遠間へ弾き、また矢の間合いを作ります。「押し返される側が出す答え」を教える敵です。

- HP 56 / 最大スタミナ 10 / 回復 2 / 位置なし / 主に咎める側 遠間 / 階層 3〜4

| id         | 名前       | 属性  | 列（コスト） | 効果                          | 状態         | 特性                                      | 予兆     |
| ---------- | ---------- | ----- | ------------ | ----------------------------- | ------------ | ----------------------------------------- | -------- |
| mist_arrow | 靄の矢     | A     | 3            | 威力 13、疲労を 1 付与する    | 疲労（相手） | 位置（相手 遠間）: 威力 +5                | 攻撃・遠 |
| fade       | 靄に溶ける | G + M | 2            | Guard 4、相手の位置を反転する | —            | 無防備: 相手の Guard が 0 なら次の回復 +1 | 守り・近 |
| scatter    | 散り矢     | A     | 1            | 威力 4                        | —            | —                                         | 攻撃     |

決定木: 相手 近間 → fade / scatter。相手 遠間 → mist_arrow / scatter / fade。

疲労はターンで減る型で、1 スタックにつきそのターンの回復を 1 削ります。回復 3 が 2 になると、1 ターンに出せる列が 1 つ下がります。

## 6. 最終ボス: 歪みの根（distortion_root）— 遠間咎め、開始 遠間、階層 5、3 段階

ダンジョンの底で瘴気を生んでいる本体です。撃破がクリア条件になります（`vision/concept-v3.md` §12-15）。3 段階を持ち、段階ごとに違う問いを出します。段階 1 は位置を問い、段階 2 はコストを問い、段階 3 は両方を同時に問います。HP 200 のボスです。

- HP 200 / 最大スタミナ 14 / 回復 4 / 位置あり / 開始 遠間 / 主に咎める側 遠間 / 階層 5 / 2 行動 / 予兆 2 段 / 撃破条件: HP 0

| 2    | 133〜67  | 回復が細る中でどの列を選ぶか | 枯らし          | 列 1 の札を混ぜて 1 ターン 2 枚を保つ。構え圏（残 3）を守る            |
| 3    | 66〜0    | 両方を同時に                 | 両方 2 スタック | 位置を入れ替えながら列 1〜2 で削る。1 フェーズの被害を 18 以下に抑える |

段階ごとに違う問いを出します（同じ問いを重くする案は取りません）。1 体で長い戦いを持たせるので、同じ判断を 3 度繰り返させると長さが退屈に変わります。属性 5 つへの適応（§6.4）は 3 段階を通して常に働き、段階はその上に「どちらの軸を締めるか」を重ねます。

**本体の位置も段階で動きます。** 段階 1 は遠間に根を下ろし、段階 2 で近間へせり上がり、段階 3 は 1 フェーズごとに反転します。歪みの根は自分の位置を変える行動を持たず、段階の適応だけが動かします。

### 6.2 専用の状態（2 つ）

## 7. エクストラボスの枠

クリア後に挑めるボスの枠です。ラスボスより強く、負けても本編が壊れない位置に置きます。最初の 1 体は竜（Issue #39）で、本節は枠だけを決めます。

ボスなので位置（近間 / 遠間）を持ちます。開始位置と「主に咎める側」は、1 体目を作るときに決めます。

### 7.1 位置づけとループ上の場所

「生と継承」のループ（`vision/concept-v3.md` §9）では、階層 5 でラスボスを倒すか、その手前で「この生を終える」を選ぶかで生が閉じます。エクストラボスはその**閉じる直前**に置きます。階層 5 の最深ノードの隣に「根の裂け目」ノードが出て、入ると 1 戦だけ行います。

```
階層 5 到達 → 歪みの根（撃破 = クリア）
              └→ [解禁済みなら] 根の裂け目 → エクストラボス → 生存ルートで生を閉じる
```

### 7.2 解禁条件

**歪みの根を一度でも撃破していること。** 撃破の記録はキャラクターではなくプレイヤー（ゲーム外）に残るので、次の生から「根の裂け目」が見えます。`concept-v3.md` §9 の「キャラクターの永続成長は無い」を破らないため、解禁が与えるのは**挑戦の機会だけ**にし、数値のボーナスは一切付けません。

挑戦は **1 つの生で 1 回**です。勝っても負けても、その生でもう一度は挑めません。

### 7.3 負けたときの扱い

エクストラボス戦での敗北は**死亡として扱いません**。挑む前の時点で到達階層・手記・遺産の候補は確定しており、敗北するとそのまま生存ルートで生が閉じます。

こうすると「せっかくの生を捨てるかもしれない」という躊躇が消え、挑戦が本編の判断を歪めません。代わりに、挑戦を選んだ時点で**その生の探索は終わる**ので（刻限の残りは使えません）、まだ潜れる生を閉じる分のコストは払います。

### 7.4 報酬

継承の仕組み（死ぬと成長が消える）と噛み合わせるため、報酬は**次の生へ渡せる形のものだけ**にします。新しい軸は足しません。

| 報酬                 | 中身                                                            | 継承のどこに乗るか                                         |
| -------------------- | --------------------------------------------------------------- | ---------------------------------------------------------- |
| 固有カード 3 種      | 他のボスと同じく撃破で習得する                                  | 遺産の候補に並ぶ（`concept-v3.md` §8.3、段をそのまま継ぐ） |
| 手記の頁 1 枚        | そのエクストラボス専用の頁                                      | 遺産の候補に並ぶ                                           |
| 生存者ボーナスの延長 | ツール枠 +1 / デッキ上限 +5 が、次の 1 生ではなく **2 生** 続く | `concept-v3.md` §14 の生存者ボーナスの期間だけを伸ばす     |

永続のスキルツリーも、恒久的な枠の拡張も置きません。3 つとも既にある仕組みの上に乗ります。

### 7.5 強さの目安

ラスボス（HP 200）より上に置きます。HP 240〜260、1 フェーズの出力 16〜24 です。狙いのターン数は §0 と同じく、目盛りが確定してから測り直します。専用の状態は他のボスと同じく 2 つまでです（`battle_core_v4.md` §17.5）。適応は歪みの根の 5 + 2 を上限とし、超える場合は段階を増やす方向ではなく 1 つの適応を重くする方向で調整します。

## 10. 試験台で見る点

1. **目盛りと HP の噛み合い**（最初に測る）。プレイヤーの 1 ターン平均出力を出し、通常敵が何ターンで落ちるかを数えます。3 ターンを切るなら、敵 HP を 1.5 倍にするか `battle_core_v4.md` §18.2 の K2 を下げます。どちらを動かすかは、精鋭とボスのターン数も一緒に見て決めます。
2. **正解の間合いが敵ごとに違うか**。各敵について、プレイヤーが近間に居続ける方針と遠間に居続ける方針の 2 つで勝率を出し、差が 15 pt 以上あること。差が無い敵は、位置の特性か押し返しの技を直します。
3. **押し返しが効きすぎないか**。プレイヤーが主に咎める側へ戻される回数を数えます。1 戦で 3 回を超えるなら押し返しの行動を決定木の下へ下げ、0 回なら上へ上げます。
4. **通常敵の 1 フェーズ出力**が 7〜13 に収まるか。位置の特性が乗ったときだけ上振れし、外していれば目安に収まること。外しても上振れするなら特性の条件を見直します。
5. **精鋭の 2 行動が理不尽でないか**。番人の「兜割り（列 3）+ 盾打ち（連動）」が 1 フェーズ 20 を超えないこと。超えるなら連動を +2 にします。
6. **ボスのコスト繰りが読めるか**。回復 4 に対して列 3 + 列 1 が続くので、スタミナが細ると列 1〜2 の行動に落ちます。落ちた状態が 3 フェーズ以上続くならボスの回復を 5 にします。逆に一度も落ちないなら 3 に下げます。
7. **2 体戦で全体攻撃が必須にならないか**。群れの長に対して単体攻撃だけのデッキでも勝率 40% 以上。
8. **瘴気纏いの重さ**。最大スタミナ −2 の状態で勝率が 30% を切るなら、瘴気の儀の予兆を 2 段前から見せます。
9. **適応の見え方**。turtle / breaker / pusher の各条件が 1 戦で 1 回以上発火し、手記の文だけで読めるか。発火しない条件は閾値を下げます（breaker の Guard 9 は単属性ガード 列 2 相当）。
10. **出血の重さ**。犬の噛みつき（威力 8 + 出血 2 スタック = 翌ターン −4、次 −2）を 2 回受けたとき、HP 50 が半分を切るか。切るなら出血を 1 スタックにします。
11. **鉤爪が逃げ道を塞ぎすぎないか**。鉤爪 2 スタックを受けた状態で勝率が 30% を切るなら、鉤縄が付けるスタックを 1 のままにし、第 2 段階の 2 スタックを外します。
12. **深みと枯らしが別物に見えるか**。釣り人の深み（近間で回復 −1）と歪みの根の枯らし（常に回復 −1）で、プレイヤーの 1 ターンのプレイ枚数の内訳を取ります。2 体で同じ内訳になるなら片方を作り直します。
13. **3 段階が違う問いに見えるか**。段階 1 / 2 / 3 でプレイヤーが使うカードの属性と列の内訳を取り、段階ごとに最多が変わること。3 段階とも同じなら、段階 2 の枯らしを重くするか段階 1 の根張りを軽くします。
14. **属性 5 つの適応が全部発火するか**。root_a / root_g / root_st / root_sk / root_m の各条件が 1 戦で 1 回以上発火し、手記の文だけで読めるか。発火しない条件は閾値を下げます（root_a の 4 枚、root_sk の通算 2 つが候補）。
15. **段階 3 の 1 フェーズの被害**が 20 を超えないか。「根を張る（列 2）→ 薙ぎ払い（列 3 + 根張り）」が上限の 18 で、これを超える組み合わせが出るなら薙ぎ払いの特性を +3 に落とします。
16. **休みの頻度**。崩しでスタミナを削ったとき、敵が休みになる回数を数えます。1 戦で 3 回を超えるなら崩しが強すぎるので、崩しの値か敵の回復を見直します。

## 11. 変更履歴

### 2026-09-20 v4.2

`battle_core_v4.md` の §16 / §17 / §18 に合わせて全面改訂しました。共有の距離（近 / 中 / 遠）と 3 段の補正、空振り回避、`effectiveRange`、`minInvest`、`shift` を廃止し、位置（近間 / 遠間）を持つのはボスと精鋭の 5 体だけにしました。通常敵 6 体と取り巻きは位置を持たず、決定木はプレイヤーの位置で 2 枝、位置を持つ敵は自分と相手の組で 4 枝になりました。投入量をやめて 1 行動 1 コストにし、`tiers` を列 1〜4 へ置き換えて列番号をそのままコストにしています。目盛りは K2 / K8 の 4 列へ差し替え、敵の面をその約 6 割に置き直しました。状態はスタック制に揃え、「軽足」を「俊敏」へ、敵側の「手薄」を「無防備」へ改名し、崩しと状態付与の「diff 0 のときだけ」を外しました。深淵の釣り人と歪みの根は、近間 / 遠間の 2 値とコスト制で成立するように作り直しています。

数値は全て叩き台です。特に敵 HP を据え置いたままプレイヤーの目盛りが上がっているので、ターン数は §10 の試験台 1 で測ってから、HP と目盛りのどちらを動かすか決めます。
