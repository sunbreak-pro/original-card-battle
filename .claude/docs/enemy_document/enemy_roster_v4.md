## 1. 記法

### 1.1 スキーマ

```
EnemyDef {
  id, name, rank: normal | elite | boss
  maxHp, maxStamina, homeRange: close | mid | far
  floors: [min, max]                    // 出現する階層
  actionsPerPhase: 1 | 2                // 精鋭とボスは 2
  omenDepth: 1 | 2                      // 2 なら「次」と「次の次」を見せる
  actions: EnemyAction[]
  decisionTree: { close: id[], mid: id[], far: id[] }   // 優先順。払える最初の行動を取る
  adaptations?: Adaptation[]            // ボスだけ
  escorts?: { id, count }[]             // 取り巻き
  journal: { close, mid, far, weakness } // 手記の頁（開示度 2 で全部見える）
}

EnemyAction {
  id, name
  attributes: (A | G | St | Sk | M)[]   // 1〜2 個
  effectiveRange?: close | mid | far    // A の面と、相手に付ける Sk の面が持つ
  minInvest: 0 | 1
  tiers: [T0, T1, T2, T3]               // 面ごとの性能。min 1 なら T0 は —
  moveFirst?: bool                      // A + M で「動いてから斬る」なら true
  trait?: { condition, param, effect }  // 1 つまで
}

Tier {
  power?, hits?           // hits 2 なら 1 撃ずつ Guard に当てる
  guard?
  shift?                  // 自分の移動。負で詰め、正で退き
  push?                   // 相手を押す矯正。+1 で相手を 1 段階遠くへ
  breakStamina?           // 崩し。diff 0 のときだけ
  statuses?: { name, stacks, target: self | foe | ally }[]   // foe は diff 0 のときだけ
  stance?: { kind, value, when? }       // St の面。when は「遠にいるターン開始」のような条件
}

Adaptation {
  id
  condition: string       // 手記に書ける文（例: 「アタックを 3 回続けて受けると守りに入る」）
  watch: string           // 何の履歴を数えるか
  effect: string          // 決定木か行動の差し替え
  until: string           // いつ元に戻るか
}
```

### 1.2 共通規則（v4）

- 投入量は「実行後に残スタミナが 3 以上になる最大」。残りが 3 未満なら最低投入。最低投入すら払えないときは決定木の次へ進み、全て払えなければ休み（回復のみ）。
- 予兆は行動の種別（属性の主）と狙い間合い。実行時に diff 2 なら攻撃を捨てて `homeRange` へ 1 段階移動する（空振り回避）。
- 敵にも構え（残 3 以上で Guard +3）、スタンス枠 1、状態の上限 4 が働く。スタンスの行動は 1 戦闘で 1 回だけ使え、使うと決定木から外れる。
- 敵の Sk が相手（プレイヤー）に状態を付けるときも diff 0 が要る。狙い間合いは予兆で見えるので、外して避けられる。
- `push` はプレイヤーを押す矯正。プレイヤーの Guard で減らない。端では止まる。

### 1.3 精鋭とボスの 2 行動

- 1 フェーズに 2 手を続けて取る。1 手目の後の距離で決定木を引き直す。
- 予兆 2 段: 次のフェーズの 2 手を両方見せる。開示度 0 では 1 手目の種別だけ。
- 投入量は 1 手ずつ「残 3 以上」の規則で決める。2 手目は自然に低投入になる。

### 1.4 複数体の戦闘

- 間合いは敵ごとに持つ。プレイヤーのムーブは全ての敵との距離を同じ方向へ 1 段階動かす（端で止まる）。（2026-09-14 見直し中 → `battle_core_v4.md` §16.4）
- 各敵が自分の予兆を持ち、決定木を引く。行動順は EnemyDef の並び（長 → 取り巻き）。
- 単体攻撃は矢印で対象を選ぶ。`targets: all` のカードは全員に当たる。全員の HP が 0 で勝利。

### 1.5 ボスの適応

- 適応は「条件（手記に書ける文）→ 決定木の差し替え」の組で持つ。条件は行動履歴を数えるだけで判定でき、乱数を使わない。
- 適応中は予兆バナーに小さく印を出す（開示度 1 以上）。開示度 2 では条件そのものが手記の頁に書かれる。

### 1.6 特性（敵で使うもの）

条件 12 / 効果 10 の語彙のうち、敵で使うもの。

| 条件       | 敵での意味                                           |
| ---------- | ---------------------------------------------------- |
| 連動       | 同じフェーズに指定の属性を実行済み（2 行動の敵だけ） |
| 位置       | 指定の間合いで使った                                 |
| 温存       | 使用後の残スタミナが閾値以上                         |
| 死力       | 現在スタミナが 2 以下                                |
| 崩し後     | 相手（プレイヤー）のスタミナが 3 未満                |
| 手薄       | 相手の Guard が 0                                    |
| 相手の状態 | 相手に指定の状態が付いている                         |
| 自分の状態 | 自分に指定の状態が付いている                         |

| 効果  | 意味                                |
| ----- | ----------------------------------- |
| 威力  | +3 か +5                            |
| Guard | +3 か +5                            |
| 回復  | 次のターン開始の回復 +1             |
| 追撃  | 次のアタック面の威力 +5             |
| 転換  | 現在の Guard の半分を次の威力に足す |
| 状態  | 指定の状態を 1 段付ける             |

予兆 / 初手 / 締め / 連打 はプレイヤー側の条件で、敵には使わない。重撃（投入 +1 で威力 +6）はプレイヤー側の効果で、敵には使わない。

## 3. 精鋭 2 体

HP 90〜110、最大スタミナ 12、1 フェーズ 2 行動、予兆 2 段、スタンスを持つ。1 ターンの出力 10〜16。狙い 10〜14 ターン。

## 7. エクストラボスの枠

クリア後に挑めるボスの枠である。ラスボスより強く、負けても本編が壊れない位置に置く。最初の 1 体は竜（Issue #39）で、本節は枠だけを決める。

### 7.1 位置づけとループ上の場所

「生と継承」のループ（`vision/concept-v3.md` §9）では、階層 5 でラスボスを倒すか、その手前で「この生を終える」を選ぶかで生が閉じる。エクストラボスはその**閉じる直前**に置く。階層 5 の最深ノードの隣に「根の裂け目」ノードが出て、入ると 1 戦だけ行う。

```
階層 5 到達 → 歪みの根（撃破 = クリア）
              └→ [解禁済みなら] 根の裂け目 → エクストラボス → 生存ルートで生を閉じる
```

### 7.2 解禁条件

**歪みの根を一度でも撃破していること。** 撃破の記録はキャラクターではなくプレイヤー（ゲーム外）に残るので、次の生から「根の裂け目」が見える。`concept-v3.md` §9 の「キャラクターの永続成長は無い」を破らないため、解禁が与えるのは**挑戦の機会だけ**にし、数値のボーナスは一切付けない。

挑戦は **1 つの生で 1 回**。勝っても負けても、その生でもう一度は挑めない。

### 7.3 負けたときの扱い

エクストラボス戦での敗北は**死亡として扱わない**。挑む前の時点で到達階層・手記・遺産の候補は確定しており、敗北するとそのまま生存ルートで生が閉じる。

こうすると「せっかくの生を捨てるかもしれない」という躊躇が消え、挑戦が本編の判断を歪めない。代わりに、挑戦を選んだ時点で**その生の探索は終わる**（刻限の残りは使えない）ので、まだ潜れる生を閉じる分のコストは払う。

### 7.4 報酬

継承の仕組み（死ぬと成長が消える）と噛み合わせるため、報酬は**次の生へ渡せる形のものだけ**にする。新しい軸は足さない。

| 報酬                 | 中身                                                            | 継承のどこに乗るか                                         |
| -------------------- | --------------------------------------------------------------- | ---------------------------------------------------------- |
| 固有カード 3 種      | 他のボスと同じく撃破で習得する                                  | 遺産の候補に並ぶ（`concept-v3.md` §8.3、段をそのまま継ぐ） |
| 手記の頁 1 枚        | そのエクストラボス専用の頁                                      | 遺産の候補に並ぶ                                           |
| 生存者ボーナスの延長 | ツール枠 +1 / デッキ上限 +5 が、次の 1 生ではなく **2 生** 続く | `concept-v3.md` §14 の生存者ボーナスの期間だけを伸ばす     |

永続のスキルツリーも、恒久的な枠の拡張も置かない。3 つとも既にある仕組みの上に乗る。

### 7.5 強さの目安

ラスボス（HP 200 / 18〜24 ターン）より上に置く。HP 240〜260、1 ターンの出力 16〜24、狙いは 22〜28 ターン。専用の状態は他のボスと同じく 2 つまで（`battle_core_v4.md` §5）。適応は歪みの根の 5 + 2 を上限とし、超える場合は段階を増やす方向ではなく 1 つの適応を重くする方向で調整する。

## 10. 試験台で見る点

1. **正解の間合いが敵ごとに違うか**。各敵について、プレイヤーが近 / 中 / 遠に居続ける 3 方針の勝率を出し、最良と最悪の差が 15 pt 以上あること。差が無い敵は決定木か矯正技を直す。
2. **通常敵のターン数** が 6〜10 に収まるか。犬（HP 50）が 4 ターンで終わるなら HP を 56 に、亡者（HP 58 + 鉄の身）が 11 を超えるなら鉄の身を T2 上限にする。
3. **精鋭のターン数** が 10〜14 に収まるか。番人（HP 90 + 鉄壁 +4）が 14 を超えるなら鉄壁を T2 上限（+3）にする。群れ（合計 127）が 14 を超えるなら犬の HP を 26 にする。
4. **精鋭の 2 行動が理不尽でないか**。番人の「兜割り T3 + 盾打ち（連動）」が 1 フェーズ 16 を超えないこと（現状 12 + 4 = 16 が上限）。超えるなら連動を +2 にする。プレイヤー HP 50 に対し 3 フェーズで落ちる出力は出さない。
5. **2 体戦で全体攻撃が必須にならないか**。群れの長に対して単体攻撃だけのデッキでも勝率 40% 以上。
6. **ボス戦が 12〜18 ターン** に収まるか。2 行動で投入量が枯れて T0 / T1 に落ちるのは仕様だが、6 ターン目以降にボスの出力が 6 を切るなら、ボスだけ回復 +1（体格）を足す案を試す。20 を超えるなら帳の T3 を +3 に戻す。
7. **瘴気纏いの重さ**。最大スタミナ −2 の状態で勝率が 30% を切るなら、儀式の狙い間合いを予兆でより早く（2 段前）見せる。
8. **適応の見え方**。turtle / breaker / closer の各条件が 1 戦で 1 回以上発火し、手記の文だけで読めるか。発火しない条件は閾値を下げる（breaker の Guard 9 は単属性ガード T2 相当）。
9. **空振り回避の頻度**。靄の射手で 1 戦に 1〜2 回。0 回なら 2 段詰めの手段（軽足、詰め 2 のカード）が初期デッキに足りない。
10. **出血の重さ**。犬の T3（10 + 出血 2 段 = 翌ターン −4、次 −2）を 2 回受けたとき HP 50 が半分を切るか。切るなら T3 の出血を 1 段にする。

11. **第 2 ボスが 14〜20 ターン** に収まるか。釣り人（HP 180）が 20 を超えるなら引きずり込むの T3 を 17 に、14 を切るなら HP を 200 にする。
12. **鉤爪が逃げ道を塞ぎすぎないか**。鉤爪 2 段を受けた状態で勝率が 30% を切るなら、2 段目の「ターン開始に近へ 1 段階」を外して 1 段目と同じ効き方にする。
