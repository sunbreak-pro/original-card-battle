# 敵ロースター v4 — 80% 用 9 体と 100% 用 10 体（属性 / 特性 / 状態 / 適応）

> **Status**: DRAFT v4.0（2026-09-13）。戦闘コア v4（属性 5 つ、状態 10 語、スタンス枠 1、5 枚ドロー）に合わせた敵の正本。数値は試験台（`docs/reports/2026-09-13-battle-100-inventory.html` §7）で測って直す前提の叩き台。
> **入力**: `battle_core_v3.md` §6 / §8（予兆、空振り回避、決定木、長柄の歪み兵）、`docs/reports/2026-09-13-battle-100-inventory.html` §3 / §6、こうだいさんの決定（2026-09-13: 敵 9 体で 80%、状態 10 語 + ボス専用、連戦の試験運用）。
> **v3 からの差分**: 敵の行動が 1〜2 の属性を持つ（プレイヤーのカードと同じスキーマ）。行動に特性を 1 つまで付けられる。通常敵の半数が状態を使う。精鋭は 1 フェーズ 2 行動と予兆 2 段、スタンスを持つ。ボスは行動履歴で決定木を切り替え、専用の状態を 2 つ持つ。複数体の戦闘（間合いは敵ごと）を精鋭 1 体で導入する。

## 1. 記法

### 1.1 スキーマ

```
EnemyDef {
  id, name, rank: normal | elite | boss
  maxHp, maxStamina, homeRange: close | mid | far
  floors: [min, max]                    // 出現する階層
  actionsPerPhase: 1 | 2                // 精鋭とボスは 2
  omenDepth: 1 | 2                      // 2 なら「次」と「次の次」を見せる
  actions: EnemyAction[]
  decisionTree: { close: id[], mid: id[], far: id[] }   // 優先順。払える最初の行動を取る
  adaptations?: Adaptation[]            // ボスだけ
  escorts?: { id, count }[]             // 取り巻き
  journal: { close, mid, far, weakness } // 手記の頁（開示度 2 で全部見える）
}

EnemyAction {
  id, name
  attributes: (A | G | St | Sk | M)[]   // 1〜2 個
  effectiveRange?: close | mid | far    // A の面と、相手に付ける Sk の面が持つ
  minInvest: 0 | 1
  tiers: [T0, T1, T2, T3]               // 面ごとの性能。min 1 なら T0 は —
  moveFirst?: bool                      // A + M で「動いてから斬る」なら true
  trait?: { condition, param, effect }  // 1 つまで
}

Tier {
  power?, hits?           // hits 2 なら 1 撃ずつ Guard に当てる
  guard?
  shift?                  // 自分の移動。負で詰め、正で退き
  push?                   // 相手を押す矯正。+1 で相手を 1 段階遠くへ
  breakStamina?           // 崩し。diff 0 のときだけ
  statuses?: { name, stacks, target: self | foe | ally }[]   // foe は diff 0 のときだけ
  stance?: { kind, value } // St の面
}

Adaptation {
  id
  condition: string       // 手記に書ける文（例: 「アタックを 3 回続けて受けると守りに入る」）
  watch: string           // 何の履歴を数えるか
  effect: string          // 決定木か行動の差し替え
  until: string           // いつ元に戻るか
}
```

### 1.2 共通規則（v4）

- 投入量は「実行後に残スタミナが 3 以上になる最大」。残りが 3 未満なら最低投入。最低投入すら払えないときは決定木の次へ進み、全て払えなければ休み（回復のみ）。
- 予兆は行動の種別（属性の主）と狙い間合い。実行時に diff 2 なら攻撃を捨てて `homeRange` へ 1 段階移動する（空振り回避）。
- 敵にも構え（残 3 以上で Guard +2）、スタンス枠 1、状態の上限 4 が働く。スタンスの行動は 1 戦闘で 1 回だけ使え、使うと決定木から外れる。
- 敵の Sk が相手（プレイヤー）に状態を付けるときも diff 0 が要る。狙い間合いは予兆で見えるので、外して避けられる。
- `push` はプレイヤーを押す矯正。プレイヤーの Guard で減らない。端では止まる。

### 1.3 精鋭とボスの 2 行動

- 1 フェーズに 2 手を続けて取る。1 手目の後の距離で決定木を引き直す。
- 予兆 2 段: 次のフェーズの 2 手を両方見せる。開示度 0 では 1 手目の種別だけ。
- 投入量は 1 手ずつ「残 3 以上」の規則で決める。2 手目は自然に低投入になる。

### 1.4 複数体の戦闘

- 間合いは敵ごとに持つ。プレイヤーのムーブは全ての敵との距離を同じ方向へ 1 段階動かす（端で止まる）。
- 各敵が自分の予兆を持ち、決定木を引く。行動順は EnemyDef の並び（長 → 取り巻き）。
- 単体攻撃は矢印で対象を選ぶ。`targets: all` のカードは全員に当たる。全員の HP が 0 で勝利。

### 1.5 ボスの適応

- 適応は「条件（手記に書ける文）→ 決定木の差し替え」の組で持つ。条件は行動履歴を数えるだけで判定でき、乱数を使わない。
- 適応中は予兆バナーに小さく印を出す（開示度 1 以上）。開示度 2 では条件そのものが手記の頁に書かれる。

### 1.6 特性（敵で使うもの）

| 条件   | 敵での意味                                           |
| ------ | ---------------------------------------------------- |
| 連動   | 同じフェーズに指定の属性を実行済み（2 行動の敵だけ） |
| 位置   | 指定の間合いで使った                                 |
| 温存   | 使用後の残スタミナが閾値以上                         |
| 死力   | 現在スタミナが 2 以下                                |
| 崩し後 | 相手（プレイヤー）のスタミナが 3 未満                |

予兆 / 初手 / 締め はプレイヤー側の条件で、敵には使わない。

## 7. 試験台で見る点

1. **正解の間合いが敵ごとに違うか**。各敵について、プレイヤーが近 / 中 / 遠に居続ける 3 方針の勝率を出し、最良と最悪の差が 15 pt 以上あること。差が無い敵は決定木か矯正技を直す。
2. **通常敵のターン数** が 6〜10 に収まるか。犬（HP 30）が 4 ターンで終わるなら HP を 34 に、亡者（HP 45 + 鉄の身）が 12 を超えるなら鉄の身を T2 上限にする。
3. **精鋭の 2 行動が理不尽でないか**。甲冑の番人の「兜割り T3 + 盾打ち」が 1 フェーズ 12 を超えないこと（現状 9 + 3 = 12 が上限）。超えるなら盾打ちの連動を +1 にする。
4. **2 体戦で全体攻撃が必須にならないか**。群れの長に対して単体攻撃だけのデッキでも勝率 40% 以上。
5. **ボス戦が 12〜18 ターン** に収まるか。2 行動で投入量が枯れて T0 / T1 に落ちるのは仕様だが、6 ターン目以降にボスの出力が 4 を切るなら、ボスだけ回復 +1（体格）を足す案を試す。
6. **瘴気纏いの重さ**。最大スタミナ −2 の状態で勝率が 30% を切るなら、儀式の狙い間合いを予兆でより早く（2 段前）見せる。
7. **適応の見え方**。turtle / breaker / closer の各条件が 1 戦で 1 回以上発火し、手記の文だけで読めるか。発火しない条件は閾値を下げる。
8. **空振り回避の頻度**。靄の射手で 1 戦に 1〜2 回。0 回なら 2 段詰めの手段（軽足、詰め 2 のカード）が初期デッキに足りない。
