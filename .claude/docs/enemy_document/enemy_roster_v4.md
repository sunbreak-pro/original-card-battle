**届く間合いは、敵の値を動かしません。** カードは幅で威力を動かします（`swordsman_cards_v4.md` §1.4）。敵の行動は、実行の時点で相手が届く間合いの外にいれば空振りします（`battle_core_v4.md` §6）。広い届く間合いは空振りを減らすだけで、カードのように「どこからでも出せる」値打ちにはなりません。値は上の目盛りのまま置き、届く間合いは敵の役（得意な間合い）で決めます。釣り合いは §10 の 17 で空振りの回数を数えて見ます。

出力の目安は、プレイヤーが敵の得意な間合いを外しているときの値です。得意な間合いに居続けると間合いの特性が乗り、1.5 倍ほどまで上振れします。上振れは予兆の狙うマスで見えるので、読んで外すのがプレイヤーの手になります。

**ターン数は HP で合わせました（v4.4、#204）。** v4.1 の狙い（通常 6〜10 / 精鋭 10〜14 / ボス 12〜24 / エクストラボス 22〜28。ボスの内訳は 大黒蛇 セルク 12〜18、獄竜 ガルド 14〜20、歪みの根 18〜24）は、プレイヤーの 1 ターン平均 8〜10 を前提にしていました。新しい目盛りではプレイヤーの平均が上がり、HP を据え置くと通常敵は貪欲な打ち手で 4〜6 ターン、先読みの打ち手で 3 ターン前後で落ちていました。§10 の 1 に従い、目盛り（`battle_core_v4.md` の持ち物）ではなく敵 HP を動かしています。

- **通常**: HP をおよそ 1.5 倍にしました。貪欲な打ち手の中央値が 6〜9 ターンに入ります。錆槍の竜兵だけは 60 のままです。縦切りの試験が HP 60 を前提に組まれているためで、上げるときは battle と一緒に直します
- **精鋭**: HP を通常より上に置き（110 / 120）、重い 1 撃（兜割り・引き裂き）を列 3 から列 2 へ下げました。1 フェーズの出力が目安の 10〜16 に収まります
- **ボス**: 回復を 4 から 3 へ下げ（§10 の 6）、重い 1 撃を列 2 へ、自分に付ける再生を 1 スタックへ下げました。HP は大黒蛇 セルクだけ 160 から 140 にし、ほかは据え置きです。先読みの打ち手で 12〜14 ターンかかり、勝率はおよそ 6 割です
- **測り方**: 11 体 × 打ち手 4 種（左端 / ランダム / 貪欲 / 1 ターン先読み）× ランダムデッキと既定デッキで、各 60 戦です。ボスは適応と段階を外したデモの形で測りました。適応と段階が入ったら（#50）測り直します

## 1. 記法

### 1.1 スキーマ

```
EnemyDef {
  id, name, rank: normal | elite | boss
  maxHp, maxStamina, recover            // recover は毎ターンの固定回復
  size: 1 | 2 | 3                       // 使うマスの数。2 以上は押す / 引くを受けない
  startGap: number                      // 開始の間合い。既定 3。開始のマスは プレイヤーのマス + startGap + 1
  favoredGap: string                    // 得意な間合い（例: "0" / "1〜2" / "2 以上"）
  floors: [min, max]                    // 出現する階層
  actionsPerPhase: 1 | 2                // 精鋭とボスは 2
  omenDepth: 1 | 2                      // 2 なら「次」と「次の次」を見せる
  actions: EnemyAction[]
  decisionTree: { gap0: id[], gap1to2: id[], gap3plus: id[] }   // 間合いの帯 3 枝
  adaptations?: Adaptation[]            // ボスだけ
  journal: { gap0, gap1to2, gap3plus, weakness }   // 手記の頁（開示度 2 で全部見える）
}

EnemyAction {
  id, name
  attributes: (A | G | St | Sk | M)[]   // 1〜2 個
  column: 1 | 2 | 3 | 4                 // 列番号 = コスト
  reach?: [min, max]                    // 届く間合い。相手向きの面（アタック / 相手に付ける状態 / 押す / 引く）を持つときだけ
  power?, hits?                         // hits 2 なら 1 撃ずつ Guard に当てる
  guard?
  move?: forward n | back n             // 自分のマスを動かす（n は 1〜2）
  push?: n, pull?: n                    // 相手を n マス押す / 引く
  breakStamina?                         // 崩し
  statuses?: { name, stacks, target: self | foe }[]
  stance?: { kind, value, when? }       // when は間合いの境目（例: 「相手との間合いが 2 以上のターン開始」）
  trait?: { condition, param, effect }  // 1 つまで
  omen: kind                            // 種別。狙うマスは reach から出す
}

Adaptation {
  id
  condition: string       // 手記に書ける文（例: 「アタックを 3 回続けて受けると守りに入る」）
  watch: string           // 何の履歴を数えるか
  effect: string          // 決定木か行動の差し替え
  until: string           // いつ元に戻るか
}
```

v4.2 の `hasRange` / `startRange` / `mainSide` / `escorts` / `selfMove` と、`push: flip`、`omen.side`、状態の `target: ally` は廃止しました。

### 1.2 共通規則（v4.3）

- **1 行動 1 コスト**です。決定木を上から見て、払える最初の行動を取ります。どれも払えなければ休みになり、そのフェーズは回復だけで終わります（§17.2）。予兆に出した技が払えなくなったときも休みです。予兆のコミットは崩しません。
- **全ての敵がマスを持ちます。** 開始のマスは、プレイヤーのマス（既定 2）から開始の間合いぶん空けた先です。大きさ 2 以上の敵は、近い端のマスから右へ続けてマスを使い、間合い N は近い端から数えます（`battle_core_v4.md` §7.2）。
- **1 つのマスに敵は 1 体です**（2026-09-23 の決定）。取り巻きと群れは置きません。同時に出る敵は、それぞれ別のマスに立つ個体です（§1.4）。
- **決定木は間合いの帯 0 / 1〜2 / 3 以上の 3 枝です。** 枝を選ぶ N は、予兆を決める時点の値です。どの枝にも、その間合いで意味のある行動を 1 つ以上置きます。3 以上の枝には、前へ出る行動か、間合い 3 以上に届く行動を必ず置きます（`battle_core_v4.md` §6.1）。各枝の末尾には列 1〜2 の行動を置き、スタミナが細っても枝が空にならないようにします。
- **得意な間合いと居続け対策**: 敵ごとに得意な間合いを持たせます。詰め続ける相手を咎める行動と、離れ続ける相手を咎める行動を、各敵に 1 つ以上置きます。どの行動がどちらを受け持つかは、各敵の決定木の下に書きます。
- **届く間合い**: アタック面・相手に付ける状態・押す / 引くを持つ行動は、届く間合いを持ちます。既定は 0〜1 です。**実行の時点で相手が届く間合いの外にいたら、相手向きの面は空振りします。** コストは払い、ガード・ムーブ・自分に付ける状態は解決します（`battle_core_v4.md` §6）。v4.2 の「相手が遠間なら〜を付与する」は、その状態の届く間合いで書き直しました。
- **予兆は「種別 + 狙うマス」です。** 種別は属性の主（攻撃 / 守り / 技 / 構え / 動）です。狙うマスは、敵のいまのマスから数えて届く間合いに入るマスで、床に出します。敵が動いたり押されたりすると、狙うマスも一緒にずれます。自分にだけ効く行動は狙うマスを持ちません。行動が間合いの境目を読むときは、境目を満たすマスを濃く出します。v4.2 の一字（近 / 遠）はやめました。
- **動く**: 「前へ n」はプレイヤーの側へ、「後ろへ n」は右の端へ動きます（n は 1〜2）。端や入れないマスの手前で止まります。敵はプレイヤーのマスより左へ行けず、敵どうしは行き先に空きがあればすれ違えます。アタック + ムーブの行動は、当ててから動きます（解決順は A → M。`battle_core_v4.md` §2.2）。
- **押す / 引く**: 押すは相手を自分から遠ざけ、引くは近づけます。Guard では減りません。押されて動けなかった 1 マスにつき 3 の壁のダメージが入ります（Guard で減ります。引くには無い）。撃つ側に鈍足が付いていると 1 マス減ります（`battle_core_v4.md` §5）。プレイヤーのカードも押す / 引くを持ちますが、大きさ 2 以上の敵は受けません。
- **敵にも構え（残 3 以上で Guard +3）とスタンス枠 1 が働きます。** スタンスの行動は 1 戦闘で 1 回だけ使え、使うと決定木から外れます。状態の種類に上限はありません（§17.5）。
- **崩しと相手に付ける状態は、届く間合いの中なら付きます。** 間合いの境目を読む特性は、実行の時点の N で判定します。

### 1.3 精鋭とボスの 2 行動

- 1 フェーズに 2 手を続けて取ります。1 手目の後の間合いで決定木を引き直します。
- **同じフェーズに同じ行動を 2 度は取りません。** 引き直した枝の先頭が 1 手目と同じ行動なら、次の払える行動を取ります。v4.2 では 1 手目で位置が反転して枝が替わりましたが、v4.3 では同じ帯に留まることが多く、同じ行動が 2 度続くと予兆 2 段が読み合いにならないためです。
- 予兆 2 段は次のフェーズの 2 手を両方見せます。開示度 0 では 1 手目の種別だけです。2 手目は「予定」として出し、1 手目の後に変われば「予定変更」と見せます（§17.6 F11）。
- コストは 1 手ずつ払います。回復が 3〜4 なので、2 手目は自然に列 1〜2 へ落ちます。

### 1.4 複数体の戦闘

- **同時に出る敵は、それぞれ別のマスに立つ個体です。** 1 つのマスに敵は 1 体で、長と取り巻き、群れの形は作りません（2026-09-23 の決定、`vision/world-v1.md` §2.1）。どの敵も自分のマス・予兆・決定木・フェーズを持ちます。味方に状態を付ける行動も持ちません。
- 80% で 2 体が同時に出るのは、§9 の組（錆槍の竜兵と灰弩の竜兵）だけです。行動順は組の並び（手前の敵から）です。
- **手前の敵が奥の敵をかばいます。** 規則ではなく、届く間合いの結果です。手前の敵と間合い 0 のとき、その奥のマスの敵とは間合い 1 なので、0 にしか届かない札は奥へ届きません。追い越しはできないので、プレイヤーは手前の敵の先へ出られません。
- 単体攻撃は受け皿で対象を選びます。`targets: all` のカードは届く間合いの中の全員に当たります。全員の HP が 0 で勝利です。

### 1.5 ボスの適応

- 適応は「条件（手記に書ける文）→ 決定木の差し替え」の組で持ちます。条件は行動履歴を数えるだけで判定でき、乱数を使いません。
- 適応中は予兆バナーに小さく印を出します（開示度 1 以上）。開示度 2 では条件そのものが手記の頁に書かれます。

### 1.6 特性（敵で使うもの）

| 条件       | 敵での意味                                           |
| ---------- | ---------------------------------------------------- |
| 連動       | 同じフェーズに指定の属性を実行済み（2 行動の敵だけ） |
| 間合い     | 実行の時点で相手との間合い N が指定の数以下 / 以上   |
| 温存       | 使用後の残スタミナが閾値以上                         |
| 死力       | 現在スタミナが 2 以下                                |
| 崩し後     | 相手（プレイヤー）のスタミナが 3 未満                |
| 無防備     | 相手の Guard が 0                                    |
| 相手の状態 | 相手に指定の状態が付いている                         |
| 自分の状態 | 自分に指定の状態が付いている                         |

| 効果  | 意味                                |
| ----- | ----------------------------------- |
| 威力  | +3 か +5                            |
| Guard | +3 か +5                            |
| 回復  | 次のターン開始の回復 +1             |
| 追撃  | 次のアタック面の威力 +5             |
| 転換  | 現在の Guard の半分を次の威力に足す |
| 状態  | 指定の状態を 1 スタック付ける       |
| 崩し  | 崩しを +1                           |

予兆 / 初手 / 締め / 連打 / 手薄 はプレイヤー側の条件で、敵には使いません。敵側の「相手の Guard が 0」は **無防備** と呼びます（§17.6 F1）。カード側の「手薄」（プレイ後の残り手札 1 枚以下）とは別の語です。重撃はプレイヤー側の効果で、敵には使いません。v4.2 の「位置（自分）」「位置（相手）」は、v4.3 で「間合い」の 1 つにまとめました。

### 1.7 状態の書式

状態はスタック制です（§17.5）。文面は「<状態名> を n 付与する」に揃えます。敵には状態の種類の上限を置きません。

- **使うと減る型**（効果が出るたびに 1 減る）: 強化 / 脆化 / 集中 / 見切り / 威圧
- **ターンで減る型**（付いた側のターン開始に 1 減る）: 出血 / 再生 / 俊敏 / 鈍足 / 疲労
- 強化は ×1.5、脆化も ×1.5 です（§18.2 K4）。
- 「軽足」は **俊敏** へ改名しました。効果は「有効なターンの開始時に、1 マスだけ無料で前か後ろへ動ける」です（v4.3）。
- 鈍足は、付いた側が自分で動くマスと、自分が押す / 引くマスを 1 減らします（下限 0）。相手が撃つ押す / 引くは減りません（`battle_core_v4.md` §5）。
- 威圧は「相手の次の行動の威力と Guard を 3 下げる」です（§17.2）。

## 7. エクストラボスの枠: 竜神

クリア後に挑めるボスの枠です。ラスボスより強く、負けても本編が壊れない位置に置きます。この枠に入るのは住処の主である **竜神** です（`vision/world-v1.md` §5.2 / §8、Issue #39）。系譜の頂点で、全ての敵の親玉にあたります。本編では姿を見せないので、本節は枠だけを決めます。

**大きさは 3 で、上限の 3 を使うのは竜神だけです**（§1.8）。姿の条件「本編で見たどの竜よりも大きいこと」（`vision/world-v1.md` §8）を、マスの数でも見せるためです。本編の竜ガルドは大きさ 2 です。開始の間合いは既定の 3 で、場は 8 マスが要ります（§0）。得意な間合いは、中身を作るときに決めます。

### 7.1 位置づけとループ上の場所

「生と継承」のループ（`vision/concept-v3.md` §9）では、階層 7 でラスボスを倒すか、その手前で「この生を終える」を選ぶかで生が閉じます。エクストラボスはその**閉じる直前**に置きます。階層 7 の最深ノードの隣に「根の裂け目」ノードが出て、入ると 1 戦だけ行います。

```
階層 7 到達 → 歪みの根（撃破 = クリア）
              └→ [解禁済みなら] 根の裂け目 → エクストラボス → 生存ルートで生を閉じる
```

### 7.2 解禁条件

**歪みの根を一度でも撃破していること。** 撃破の記録はキャラクターではなくプレイヤー（ゲーム外）に残るので、次の生から「根の裂け目」が見えます。`concept-v3.md` §9 の「キャラクターの永続成長は無い」を破らないため、解禁が与えるのは**挑戦の機会だけ**にし、数値のボーナスは一切付けません。

挑戦は **1 つの生で 1 回**です。勝っても負けても、その生でもう一度は挑めません。

### 7.3 負けたときの扱い

エクストラボス戦での敗北は**死亡として扱いません**。挑む前の時点で到達階層・手記・遺産の候補は確定しており、敗北するとそのまま生存ルートで生が閉じます。

こうすると「せっかくの生を捨てるかもしれない」という躊躇が消え、挑戦が本編の判断を歪めません。代わりに、挑戦を選んだ時点で**その生の探索は終わる**ので（刻限の残りは使えません）、まだ潜れる生を閉じる分のコストは払います。

### 7.4 報酬

継承の仕組み（死ぬと成長が消える）と噛み合わせるため、報酬は**次の生へ渡せる形のものだけ**にします。新しい軸は足しません。

| 報酬                 | 中身                                                            | 継承のどこに乗るか                                         |
| -------------------- | --------------------------------------------------------------- | ---------------------------------------------------------- |
| 固有カード 3 種      | 他のボスと同じく撃破で習得する                                  | 遺産の候補に並ぶ（`concept-v3.md` §8.3、段をそのまま継ぐ） |
| 手記の頁 1 枚        | そのエクストラボス専用の頁                                      | 遺産の候補に並ぶ                                           |
| 生存者ボーナスの延長 | ツール枠 +1 / デッキ上限 +5 が、次の 1 生ではなく **2 生** 続く | `concept-v3.md` §14 の生存者ボーナスの期間だけを伸ばす     |

永続のスキルツリーも、恒久的な枠の拡張も置きません。3 つとも既にある仕組みの上に乗ります。

### 7.5 強さの目安

## 10. 試験台で見る点

1. **目盛りと HP の噛み合い**（最初に測る）。プレイヤーの 1 ターン平均出力を出し、通常敵が何ターンで落ちるかを数えます。3 ターンを切るなら、敵 HP を 1.5 倍にするか `battle_core_v4.md` §18.2 の K2 を下げます。どちらを動かすかは、精鋭とボスのターン数も一緒に見て決めます。
2. **正解の間合いが敵ごとに違うか**。各敵について、プレイヤーが詰め続ける（間合い 0）/ 離れ続ける（3 以上）/ 出入りする の 3 方針で勝率を出し、最良と最悪の差が 15 pt 以上あること（`battle_core_v4.md` §13）。差が無い敵は、間合いの特性か押す / 引くの行動を直します。
3. **押し返しが効きすぎないか**。プレイヤーが敵の得意な間合いへ戻される回数（押す / 引く / 敵が自分で寄る）を数えます。1 戦で 3 回を超えるなら、その行動を決定木の下へ下げ、0 回なら上へ上げます。
4. **通常敵の 1 フェーズ出力**が 7〜13 に収まるか。間合いの特性が乗ったときだけ上振れし、外していれば目安に収まること。外しても上振れするなら特性の条件を見直します。
5. **精鋭の 2 行動が理不尽でないか**。門竜の「兜割り（列 3）+ 盾打ち（連動）」が 1 フェーズ 20 を超えないこと。超えるなら連動を +2 にします。
6. **ボスのコスト繰りが読めるか**。回復に対して列 3 + 列 1 や列 2 + 列 2 が続くので、スタミナが細ると列 1〜2 の行動に落ちます。落ちた状態が 3 フェーズ以上続くならボスの回復を 1 上げます。逆に一度も落ちないなら 1 下げます。v4.3 は回復 4 でボスがほぼ落ちずに 2 行動を続け、プレイヤーが勝てなかったので、v4.4 で 3 に下げました（#204）。
7. **2 体の組で全体攻撃が必須にならないか**。錆槍の竜兵 + 灰弩の竜兵に対して、単体攻撃だけのデッキでも勝率 40% 以上。
8. **瘴気纏いの重さ**。最大スタミナ −2 の状態で勝率が 30% を切るなら、瘴気の儀の予兆を 2 段前から見せます。
9. **適応の見え方**。turtle / breaker / pusher の各条件が 1 戦で 1 回以上発火し、手記の文だけで読めるか。発火しない条件は閾値を下げます（breaker の Guard 9 は単属性ガード 列 2 相当）。
10. **出血の重さ**。走竜の噛みつき（威力 8 + 出血 2 スタック = 翌ターン −4、次 −2）を 2 回受けたとき、HP 50 が半分を切るか。切るなら出血を 1 スタックにします。
11. **鉤爪が逃げ道を塞ぎすぎないか**。鉤爪 2 スタックを受けた状態で勝率が 30% を切るなら、鉤縄が付けるスタックを 1 のままにし、第 2 段階の 2 スタックを外します。
12. **深みと枯らしが別物に見えるか**。ガルドの深み（隣で回復 −1）と歪みの根の枯らし（常に回復 −1）で、プレイヤーの 1 ターンのプレイ枚数の内訳を取ります。2 体で同じ内訳になるなら片方を作り直します。
13. **3 段階が違う問いに見えるか**。段階 1 / 2 / 3 でプレイヤーが使うカードの属性と列の内訳を取り、段階ごとに最多が変わること。3 段階とも同じなら、段階 2 の枯らしを重くするか段階 1 の根張りを軽くします。
14. **属性 5 つの適応が全部発火するか**。root_a / root_g / root_st / root_sk / root_m の各条件が 1 戦で 1 回以上発火し、手記の文だけで読めるか。発火しない条件は閾値を下げます（root_a の 4 枚、root_sk の通算 2 つが候補）。
15. **段階 3 の 1 フェーズの被害**が 20 を超えないか。「根を張る（列 2）→ 薙ぎ払い（列 2 + 根張り）」が上限の 13 です（v4.4）。これを超える組み合わせが出るなら薙ぎ払いの特性を +3 に落とします。
16. **休みの頻度**。崩しでスタミナを削ったとき、敵が休みになる回数を数えます。1 戦で 3 回を超えるなら崩しが強すぎるので、崩しの値か敵の回復を見直します。
17. **空振りの回数**。敵ごとに 1 戦の空振りの回数を数えます。1 戦で 3 回を超える敵は、狙うマスが読まれ過ぎているので届く間合いを 1 広げます。0 回の敵は狭めます（§0 の「届く間合いは敵の値を動かさない」の確認）。
18. **右端に立つ敵が崩れないか**。開始の間合い 3 の場で、右端に立った灰弩・燐弓が下がれずに崩れるかを見ます。その敵へのプレイヤーの勝率が、同じ層のほかの敵より 20 pt 以上高いなら、その層の場を 1 マス広げるよう #168 に返します。
