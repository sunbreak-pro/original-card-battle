## 2. 要素の選別

「80% 版」は、出立 → 階層 1 → 戦闘 → 次の階層 が Unity で 1 周通る版を指します（#94 の Definition of Done）。判断の基準は 2 つです。**ループの 5 要素（習熟 / 間合い / スタミナ / 手記 / 瘴気）のどれかに直接つながるか**と、**無いと 1 周が成立しないか**です。

### 2.1 残す（13 件）

| 要素                 | 形                                                                                        | 残す理由                                             |
| -------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 通常戦闘ノード       | 踏むと 1 戦。刻限 1                                                                       | 階層の主成分。これが無いと探索が移動だけになる       |
| 精鋭ノード           | 寄り道に置く。報酬が厚く、HP とスタミナを多く削る                                         | 「安全に通すか、削られても取るか」の分岐を作る       |
| 階層ボスノード       | 階層の出口。撃破すると次の階層へ                                                          | 階層の区切りが無いと刻限の予算が意味を持たない       |
| 休息ノード（階層内） | HP 15% 回復 / スタミナ全回復 / 最大スタミナ +2。瘴気は濃度分たまる                        | HP の持ち越しに対する唯一の階層内の答え              |
| 習熟訓練             | 休息ノードの二択の片方。指定した 1 枚に刻み 1                                             | 探索から習熟へ届く唯一の線。§14 で決定済み           |
| 情報収集ノード       | 手記の開示度を 2 段目へ上げる。対象はこの階層の敵 1 種                                    | 手記を探索側から動かす。戦闘の予兆の精度に直結する   |
| イベント 3 種        | 泉（HP 回復）/ 重い宝箱（貴重品 + 最大スタミナ -2）/ 特殊な食事（最大スタミナ +1 + 代償） | 探索の選択が戦闘の数値を変える例を、最小の数だけ持つ |
| 階層間の休憩         | HP 30% 回復 / スタミナ全回復 / 瘴気はたまらない                                           | 階層の切れ目。ここで次へ潜るか生を閉じるかを選ぶ     |
| 死亡地点の痕跡       | 前の生の遺産を回収する。1 つの生で 1 件                                                   | 継承のループが探索に現れる唯一の点                   |
| 刻限                 | 階層ごとの行動予算。尽きるとその階層の行動が終わる                                        | 探索の圧力そのもの                                   |
| 瘴気                 | 行動ごとに濃度分たまる。最大スタミナへ効く                                                | 生の長さ。戦闘へ効く経路が既に決まっている           |
| ノードの段階開示     | 遠い = 種別アイコンだけ。隣接 + ホバー = 中身（敵名 / 脅威度 / 回復量）                   | 選ぶ材料が無いと、ノードの分岐が運になる             |
| 消耗品 3 枠          | 拾ったらその場で入れ替え                                                                  | §14 で決定済み。拾得の受け皿が無いと報酬を置けない   |

## 3. 刻限 10 回の内訳（concept-v3 §12-1 への回答案）

### 3.1 満寸の階層（ノード 10〜12）

1 階層あたりの刻限 10 を、次の配分で組みます。プレイヤーが全部を取れるわけではありません。**踏破に 5、選べる余白に 5** という形です。

| 用途            | 目安   | 内訳の中身                                              |
| --------------- | ------ | ------------------------------------------------------- |
| 通常戦闘        | 3      | 最短ルート上に 2、寄り道に 1                            |
| 精鋭            | 1      | 寄り道側だけに置く。避けて通れる                        |
| 階層ボス        | 1      | 出口。必須                                              |
| 休息 / 習熟訓練 | 2      | 休息ノード 2 つ。各ノードで「休む」か「訓練する」の二択 |
| 情報収集        | 1      | この階層の敵 1 種の開示度を 2 段目へ                    |
| イベント        | 1      | 泉 / 重い宝箱 / 特殊な食事 から 1                       |
| 余白            | 1      | 痕跡の回収、または取りこぼしの拾い直し                  |
| **合計**        | **10** |                                                         |

最短ルート（入口 → 分岐 2 つ → ボス）は 5 刻限です。残り 5 を寄り道へ回すか、瘴気を惜しんで次の階層へ降りるかを選ばせます。**刻限が余っても次の階層へ持ち越しません**。余らせて降りるのが正解になる場面を作るためで、階層が深く瘴気の濃度が高いほど「降りる」が強くなります。

### 3.2 二択を「1 ノード 1 回」の例外にしない

習熟訓練を休息ノードの中の追加行動にすると、1 ノードで刻限を 2 使う例外ができます。そこで**休息ノードでは「休む」か「訓練する」のどちらか 1 つだけを選ぶ**形にします。刻限 1 のまま、回復と習熟の取り合いが生まれます。

### 3.3 最小の階層では刻限 6

ノード 6 の階層に刻限 10 を渡すと、全部踏んでも 4 余ります。圧力が消えるので、**縦切りの間は刻限をその階層のノード数に揃えます**（最小の 1 階層なら 6）。確かめたいのは「刻限が尽きると次の階層へ押し出される」挙動なので、予算はノード数ぴったりで足ります。満寸の階層へ広げるときに 10 へ戻します。

## 4. 最初に通す最小の 1 階層（ノード 6）

### 4.1 形

```text
            [1 入口 / 通常戦闘]           <- 必ず戦闘。操作の導入
               /          \
      [2 休息]              [3 情報収集]  <- 回復か、手記かの二択
               \          /
        [4 通常戦闘]   [5 精鋭]           <- 安全か、厚い報酬かの二択
               \          /
            [6 階層ボス]                  <- 出口
                  |
            （階層間の休憩）-> 階層 2
```

- 接続は縦だけです。横移動は入れません（§2.2）
- 1 行に 2 ノードが並ぶ段が 2 つあり、**プレイヤーが選ぶ分岐は 2 回**です
- 階層間の休憩はノードではありません。刻限を使わず、瘴気もたまりません
- **一度踏んだノードを通り直すのは無料です**（#97 で明文化）。刻限を払うのは新しいノードに入るときだけなので、分岐の片側へ寄ってから戻り、もう片側へ行けます。4 刻限で踏破、6 で両側という §4.2 の数はこの規則から出ます

### 4.2 1 周で何が起きるか

| 刻限 | ノード          | 起きること                                                          |
| ---- | --------------- | ------------------------------------------------------------------- |
| 1    | 入口            | 通常戦闘 1 戦。減った HP とスタミナを持ち越す                       |
| 2    | 休息 / 情報収集 | 休息なら HP 15% とスタミナ全回復。情報収集なら敵の開示度が 2 段目へ |
| 3    | 通常戦闘 / 精鋭 | 精鋭は報酬が厚く、消耗も大きい                                      |
| 4    | 階層ボス        | 撃破で階層 2 へ。倒せずに死ぬとここが死亡地点になる                 |
| 5〜6 | 余白            | 踏まなかった側へ寄り道できる。瘴気は行動ごとにたまる                |

4 刻限で踏破でき、6 まで使うと分岐の両側を取れます。**瘴気が「全部取る」を罰する**構図が、この 6 ノードだけで成立します。

### 4.3 検証の合格条件

- 階層 1 の 6 ノードが生成され、入口が戦闘、最後がボスになる
- ノードを踏むたびに刻限が 1 減り、瘴気が階層の濃度分たまる
- 瘴気 20% ごとに最大スタミナが 1 減り、その値が戦闘へ持ち込まれる
- HP とスタミナがノードをまたいで持ち越される
- 刻限 0 で次の階層へ押し出される
- ボス撃破で階層間の休憩へ移り、HP 30% 回復とスタミナ全回復が起き、瘴気がたまらない

## 5. 残る判断

| #   | 事項                                                       | 本書の案                                             |
| --- | ---------------------------------------------------------- | ---------------------------------------------------- |
| 1   | 刻限が余ったまま降りたときの扱い                           | 持ち越さない（§3.1）。瘴気を惜しむ選択の価値を残す   |
| 2   | 休息ノードを二択にするか、訓練を別ノードに分けるか         | 二択にする（§3.2）。例外の規則を作らないため         |
| 3   | 最小の階層で刻限をノード数に揃えるか、10 のままにするか    | ノード数に揃える（§3.3）。縦切りの間だけ             |
| 4   | 情報収集の対象をプレイヤーが選べるか、階層が決めるか       | 縦切りでは階層が決める。選択制は #100 と合わせて判断 |
| 5   | 死亡地点の痕跡をノードとして置くか、階層の属性として持つか | **ノードとして置く（#97 で決定）**。通常戦闘 1 つと入れ替え、寄り道の側に置く |
