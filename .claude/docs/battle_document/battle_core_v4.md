## 2. 属性と面

### 2.1 属性 5 つ

| 属性     | 盤面への作用                                 | 列で伸びるもの                                  |
| -------- | -------------------------------------------- | ----------------------------------------------- |
| アタック | 相手の HP を減らす                           | 威力、崩し                                      |
| ガード   | 自分に Guard を付ける                        | Guard 量                                        |
| スタンス | 戦闘が終わるまで続く効果を枠に置く           | 効果の強さ                                      |
| スキル   | 状態を付ける、回復する、引く、スタミナを戻す | スタック数、量                                  |
| ムーブ   | 自分の位置を近間 / 遠間へ切り替える          | 付随効果（ムーブだけの札はコスト 1 に固定する） |

- 1 枚は **1〜2 属性**を持ちます。単属性 5 + 二属性 10 = 15 パターンです。
- 属性ごとに **面**を持ちます。カードは列 1〜4 から 1 列を選び、**列番号がコスト、その列の値が効果**です（§3）。二属性のカードは 1 つの列で両方の面の値が決まります。
- 二属性の各面は、単属性の同じ列の **65%** を目安にします（合計 130%）。1 枚で 2 役できる代わりに、それぞれは弱くします。
- 移動は「ムーブ属性」として他と同格に扱います。踏み込み斬りは アタック + ムーブ、足捌きは ガード + ムーブです。
- **単属性ムーブ 6 種は全てコスト 1** です。効果は「近間へ / 遠間へ / 反転」のどれかで、小さな付随効果（Guard 4 / ドロー 1 / スタミナ +1 のどれか 1 つ）を付けます。列で段を上げる梯子は持ちません。
- 位置は 2 値なので、1 回の切り替えで必ず反対側へ移ります。v4.1 の「1 行動 1 段階」の規則は不要になりました。

### 2.2 1 枚の中の解決順

```
特性の判定 → アタック → ムーブ → ガード → スキル → スタンス
```

- **特性は面より前に判定します**（§17.6 F5）。カード表と画面の予測値がこの順を前提にしているためです。
- **位置は必ず「出す前」で読みます。** `moveFirst` の印は置きません。アタック + ムーブの札は、移動前の位置で威力を決め、そのあとに位置が変わります。
- 位置が変わった結果は、次の面と次の行動から効きます。

### 2.3 特性（属性と盤面を条件にした追加効果）

カードは **特性を 1 つまで**持ちます。特性は「条件 → 効果」の 1 組です。

| 条件       | 意味                                        | 例                         |
| ---------- | ------------------------------------------- | -------------------------- |
| 連動       | このターンに <属性> のカードをプレイ済み    | ムーブ連動: スタミナ +1    |
| 位置       | 自分が <近間 / 遠間> にいる（出す前の位置） | 遠間: 威力 +6              |
| 予兆       | 相手の予兆が <種別>                         | 予兆がアタック: Guard +3   |
| 温存       | 使用後の残スタミナ ≥ n                      | 残 6 以上: 次ターン回復 +1 |
| 死力       | 現在スタミナ ≤ 2                            | 威力 +6                    |
| 初手       | このターン最初のプレイ                      | コスト −1                  |
| 締め       | このターン 3 枚目以降のプレイ               | 威力 +3                    |
| 崩し後     | 相手のスタミナ < 3                          | 崩し +1                    |
| 連打       | 直前にプレイしたカードも同じ属性            | アタック連打: 威力 +3      |
| 手薄       | プレイ後の残り手札が 1 枚以下               | ドロー +1                  |
| 相手の状態 | 相手に <語> が付いている                    | 出血中: 威力 +5            |
| 自分の状態 | 自分に <語> が付いている                    | 見切り中: Guard +3         |

- **位置は自分の値だけを読みます。** 相手の位置を条件にする札は作りません（§17.3）。位置(中) は廃止しました。
- 敵側の「相手の Guard が 0」は **無防備**という別の語です（§17.6 F1）。手薄と混ぜません。

効果の語彙は 10 種です。効果は列に依らず一定にします（暗算のため）。

| 効果            | 内容                                                                                   |
| --------------- | -------------------------------------------------------------------------------------- |
| スタミナ +1     | 即時                                                                                   |
| 威力 +n         | この 1 枚のアタック面。n は 4〜8 を目安にする（叩き台）                                |
| Guard +n        | この 1 枚                                                                              |
| ドロー +1       | 即時                                                                                   |
| 状態 +1         | スタックを 1 足す                                                                      |
| **コスト −1**   | この 1 枚のコストが 1 下がる（下限 0）。習熟の「軽さ」と同じ働き                       |
| 次ターン回復 +1 | 次のターン開始のスタミナ回復                                                           |
| **重撃**        | 条件を満たすと威力 +6、**次のターン開始の回復 −1**。今のターンのコストと構えは変えない |
| **転換**        | この 1 枚の Guard の半分を威力に足す                                                   |
| **追撃**        | このターンの次のアタック面に威力 +5                                                    |

- **特性の付け方**: 初期 40 のうち 32 枚、習得 40 の全てが特性を持ちます。同じ「条件 + 効果」の組は 3 枚までです。
- **位置を条件にする札は 16 枚**です（§18 K6）。「攻撃の効果 / 防御の効果 × 近間 / 遠間」の 4 マスに 4 枚ずつ、初期 8 枚・習得 8 枚です。
- **素直な札**: 特性を持たないカード（初期の 8 枚）は各列の威力 +2、Guard +2 を上乗せします。

「このターンにプレイした属性」は state に `playedAttributes`（属性ごとの回数）として持ち、ターン終了で消します。敵も自分のフェーズで同じものを持ちます。

### 2.4 面のスキーマに足す項目（カードと敵で共通）

| 項目      | 意味                                                                | 使う例                 |
| --------- | ------------------------------------------------------------------- | ---------------------- |
| `hits`    | アタック面を n 回に分けて当てる（1 撃ずつ Guard に当たる）          | 双刃の斬撃             |
| `targets` | one / all / self / **ally**（味方に付ける状態。2 体戦の取り巻き用） | 群れの長の遠吠え       |
| `push`    | **敵だけが持つ**。相手の位置を反対側へ変える。Guard で減らない      | 石突きの押し込み、誘い |
| `when`    | スタンスの効果に位置の条件を付ける（例: 遠間にいるターン開始だけ）  | 水の構え、瘴気の帳     |

廃止した項目は `moveFirst`（§2.2）と `shift`（位置が 2 値になり段階の概念が消えた）です。`push` はプレイヤー側のカードには置きません。

## 3. コストと列（§17.2 / §18 K2 / §18 K8）

**旧段表の列が、そのままコストになります。** カードごとに列を 1 つ選び、列番号がコスト、その列の値が効果です。段表はプレイヤーが選ぶ幅ではなく、カードを作るときの目盛りとして残ります。

- **列は 1〜4** です。列 4 のコストは 3 のままで、集中と習熟の「伸び」がコスト 3 の札に掛かったときに使います。
- **列の選び方**: 特性の条件で選びます。満たしにくい条件（死力 / 崩し後 / 相手の状態 / 手薄）を持つ札ほど低い列、つまり安くします。
- **コスト 0** は習熟でだけ生まれます。初期はカードも敵の技もコスト 1 以上です。
- 払えないカードは出せません。敵は払えない予兆が**休み**になります（§6）。

### 3.1 目盛り（叩き台。§18 K2 / K8）

高コストほど 1 スタミナあたり少し得にします。コスト 1 を並べる方針が常に最強になるのを避けるためです。

| 面                     | 列 1 | 列 2 | 列 3        | 列 4            |
| ---------------------- | ---- | ---- | ----------- | --------------- |
| 単属性アタック（威力） | 6    | 13   | 21          | 30              |
| 単属性ガード（Guard）  | 4    | 9    | 15          | 22              |
| 二属性のアタック面     | 4    | 8    | 14          | 20              |
| 二属性のガード面       | 3    | 6    | 10          | 14              |
| 単属性の回復（HP）     | 3    | 8    | 13          | 19              |
| 二属性の回復面         | 2    | 5    | 8           | 12              |
| 出血 / 再生のスタック  | 1    | 2    | 3           | 4               |
| 単属性のスキル（状態） | 1 種 | 2 種 | 3 種        | 3 種 + ドロー 1 |
| 二属性のスキル面       | 1 種 | 2 種 | 2 種 + 1 種 | 3 種 + 1 種     |
| スタンスの上乗せ       | +2   | +3   | +5          | +6              |

- 回復とスキルとスタンスの列は叩き台です。回復は攻撃の約 0.6 倍に置きました。
- **敵の面は、上の目盛りの約 6 割**です。値は `enemy_roster_v4.md` §0 が持ちます。
- 1 回きりだった状態（威圧 / 脆化 / 疲労 / 強化 / 集中 / 見切り / 俊敏 / 鈍足）もスタックで付きます。付与の既定は 2 スタックです。
- 崩し（相手のスタミナ −n）は目盛りを変えません。札の個性として付けます。
- 遠用の低い目盛り（4 / 6 / 9 / 12）と最適間合いの列は廃止しました。アタックの目盛りは 1 本です（§18 K7）。

v4.1 から変えない値は次のとおりです。

| 項目                        | 値                                         |
| --------------------------- | ------------------------------------------ |
| プレイヤー HP               | 50                                         |
| 敵 HP                       | 通常 50〜70 / 精鋭 90〜110 / ボス 160〜200 |
| 敵の 1 ターン出力           | 通常 7〜13 / 精鋭 10〜16 / ボス 13〜20     |
| 構え                        | 残 3 以上で Guard +3                       |
| 出血 / 再生（1 スタック）   | 2                                          |
| 最大スタミナ                | 基準 10（3〜14）                           |
| 階層間の休憩 / 階層内の休息 | 30% / 15%                                  |

## 4. スタンス

- **枠は 1 つ**です。スタンス面を持つカードをプレイすると枠に入ります。別のスタンスを出すと前のものは終わります（同じスタンスなら新しい列で置き直します）。
- 強さは**カードの列**で決まり、戦闘が終わるまで変わりません。戦闘終了で枠は空になります。
- **出したカードは戦闘中は山札に戻りません**（除外置き場へ）。同種を 3 枚入れると死に札になるので、1〜2 枚に抑える理由になります。
- 効果の型は 6 つです。カードはこのどれかを 1 つ持ちます。

| 型             | 例                                              |
| -------------- | ----------------------------------------------- |
| ターン開始付与 | 毎ターン Guard +1 / HP +1 / ドロー +1 / 回復 +1 |
| 条件付き加算   | 近間での攻撃 +1 / 遠間から使うムーブに Guard +1 |
| 被弾時の反応   | Guard が吸収した分の 1/3 を返す                 |
| 移動の補正     | 遠間へ移るとき Guard +1 / 近間へ移るとき威力 +1 |
| コストの割引   | 毎ターン 1 回、<属性> のカードのコスト −1       |
| 敵行動への干渉 | 予兆が咎める側に居ないとき Guard +1             |

- 敵もスタンスを持てます（精鋭・ボス）。表示は同じ枠で対称です。
- `when` の条件は近間 / 遠間で書きます。v4.1 の「遠にいるターン開始だけ」は「遠間にいるターン開始だけ」です。

## 5. 状態（スタック制。§17.5 / §18 K3 / §18 K4）

- 語彙は **10 語**に固定します。カードの文面は「**<状態名> を n 付与する**」で、n がスタック数です。
- **上限**: プレイヤーは状態の**種類**を 6 つまで持てます。敵には上限を置きません。スタック数は数えません。
- 減り方は 2 つの型に分かれます。**使うと減る型**は効果が出るたびに 1 減り、**ターンで減る型**は付いた側のターン開始に 1 減ります。
- 相手に付ける状態の「diff 0 のときだけ発動」という条件は廃止しました。位置に関わらず付きます。

| 語     | 向き   | 効き方                                               | 減り方       |
| ------ | ------ | ---------------------------------------------------- | ------------ |
| 出血   | 相手に | 相手のターン開始に HP −2 × 残りスタック              | ターンで減る |
| 脆化   | 相手に | 次に受ける攻撃の raw ×1.5                            | 使うと減る   |
| 鈍足   | 相手に | 次のターン全体、位置の切り替えができない             | ターンで減る |
| 威圧   | 相手に | 次の行動の値を −3（威力と Guard。旧表のほぼ 1 列分） | 使うと減る   |
| 疲労   | 相手に | 次のターン開始のスタミナ回復 −1                      | ターンで減る |
| 強化   | 自分に | 次のアタック面の威力 **×1.5**                        | 使うと減る   |
| 集中   | 自分に | 次の札を **1 列右**で解決する（列 4 は超えない）     | 使うと減る   |
| 見切り | 自分に | 次の被弾で Guard が吸収した分の半分を相手に返す      | 使うと減る   |
| 俊敏   | 自分に | 有効なターンの開始時に近間 / 遠間を選べる            | ターンで減る |
| 再生   | 自分に | ターン開始に HP +2 × 残りスタック                    | ターンで減る |

- 「俊敏」は v4.1 の「軽足」の改名です。位置が 2 値になり、移動の段階を増やす意味が消えたため、効果をターン開始の選択に変えました。
- 「鈍足」は次のターン全体に効きます。2 回行動の敵なら 2 手とも切り替えを止めます。
- **ボス専用の状態**: ボスは上の 10 語に加えて専用の状態を 2 つ持ちます（`enemy_roster_v4.md`）。例は瘴気纏い（この戦闘中プレイヤーの最大スタミナ −1、重ねて −2 まで）です。最大が下がったときは、現在値を新しい最大まで削ります。専用の状態は予兆で見えて、対処できる形にします。

### 5.1 ダメージ式（§17.6 F4）

足してから掛けます。

```
(面 + 特性 + 追撃 + 転換) × 強化 1.5 × 脆化 1.5 → 丸め（AwayFromZero）→ − Guard
```

- 多段（`hits`）では、追撃は各撃に乗せません。特性の +n と強化は全ての撃に乗ります（F6）。
- 追撃は番の終わりで消えます。プレイヤーはターン終了、敵はフェーズの終わりです（F7）。
- HP が 0 になった瞬間に倒れます。出血の tick・見切りの返し・被弾のどこでも同じです（F9）。

## 6. 予兆と敵 AI

- 予兆は**コミット式**です。敵は次の行動を先に見せ、その通りに実行します。読み合いは予兆に対して行います。
- **予兆に出す情報は「種別 + 咎める側の一字」**です。「攻撃・遠」のように、効果が乗る側を一字で出します（§17.3）。開示度で出る量が変わります（§11.3 の表は `battle_ui_ux_v2.md` が正本）。
- **払えない予兆は休みになります**（§17.2）。技は出ず、そのフェーズは回復だけで終わります。予兆のコミットを崩さないための扱いです。
- **空振り回避は廃止しました。** 距離の差分がなくなり、「外したので間合いを取り直す」という手が成立しないためです。

### 6.1 決定木の枝

| 敵          | 位置     | 決定木の枝                        |
| ----------- | -------- | --------------------------------- |
| 通常敵 6 体 | 持たない | プレイヤーの位置で **2 通り**     |
| 精鋭・ボス  | 持つ     | 自分とプレイヤーの組で **4 通り** |

- **居続け対策**: 敵ごとに「主に咎める側」を持たせ、逆側にいる相手を主な側へ戻す技（押し返し / 誘い）を決定木に置きます。`push` は敵だけが持ちます。
- **精鋭**: 1 フェーズ 2 行動。予兆は 2 段（次と次の次）。スタンスを持ちます。
- **ボス**: 行動履歴で決定木を切り替える適応を持ちます（条件は手記に書ける文にします）。予兆 2 段、1 フェーズ 2 行動、専用の状態 2 つです。
- **2 手目は「予定」として出します。** 1 手目の後に引き直し、変われば「予定変更」と見せます（§17.6 F11）。
- 敵の行動も属性・面・特性・状態を持ちます。`CardDef` と `EnemyAction` は同じ面の表で書けます。

### 6.2 最大スタミナの例外

v3 §3.1「戦闘中に最大値は変わらない」の唯一の例外が、ボス専用の状態「瘴気纏い」です。戦闘中に −1〜−2 し、戦闘終了で戻ります。最大が下がったときは現在値を新しい最大まで削ります。探索側の瘴気ゲージには影響しません。

## 7. 位置と複数体の戦闘

### 7.1 位置（近間 / 遠間）

- **プレイヤーと一部の敵が、常に近間か遠間のどちらかを持ちます。** HP・Guard と同じ常設の値で、状態の枠には数えません。
- **位置を持つのはボスと精鋭だけです**（§17.3）。瘴気の司祭・深淵の釣り人・歪みの根・甲冑の番人・群れの長が持ち、通常敵 6 体と取り巻きは持ちません。
- **素の効果はありません。** 近間 / 遠間そのものは、ダメージ・回復・崩しを変えません。カード・特性・敵の技が、位置を条件として読みます。
- **名前に引かれない配分**: 位置を条件にする効果を、「攻撃の効果 / 防御の効果 × 近間 / 遠間」の 4 マスに同数ずつ配ります。敵の技にも、近間を咎めるものと遠間を咎めるものを両方置きます。
- **切り替え**: ムーブ面を持つカードで切り替えます。位置は 2 値なので、切り替えると必ず反対側へ移ります。敵の押し返し / 誘いは、相手の位置を変える技（`push`）として残します。
- **開始位置**: プレイヤーは毎戦同じ位置から始めます。出立のツールで変更できます。位置を持つ敵は、敵ごとに開始位置を定義します。
- **画面**: 近間の個体は前へ出て、遠間の個体は下がって立ち、足元に「近」「遠」の一字札を置きます（`battle_ui_ux_v2.md` §10.6）。組の名前は画面にもカードの文面にも出しません。

### 7.2 複数体

- 80% では **1 体が基本**で、精鋭「群れの長」だけ取り巻き 1 体を連れて **2 体**で出ます。3 体以上は 100% でも入れません。
- **取り巻きは位置を見ません。** 位置の判断は長にだけ向けます。
- **2 体戦の自分向きの札は、自分の位置だけを読みます。** 基準にする敵を画面に出しません。
- 各敵が自分の予兆を持ち、自分のフェーズを順に実行します（順番は敵定義の並び）。
- カードの相手指定は `targets` = one（受け皿で 1 体）/ all / self です。アタック面は one が既定です。**全体攻撃（all）は規則として残しますが、80% ではカードを作りません**（§17.6 F10）。

## 9. ターン進行

```
[プレイヤーターン開始]
  1. Guard を 0 に
  2. スタミナを 3 回復（固定）。疲労が付いていれば −1
  3. スタンスと状態のターン開始効果（Guard +1 / 再生 / 出血の tick / ドロー補正 / 俊敏の位置選択）
  4. 手札を引く（5 + 補正）。捨てるのはターン終了の手順 8
  5. 敵ごとの予兆を表示（精鋭・ボスは 2 段。2 手目は「予定」）
[プレイヤー行動]（払える限り何枚でも）
  6. カードと相手を決める → 特性を判定 → §2.2 の順で面を解決 → 撃破判定
     コストを払う。「このターンにプレイした属性」を記録する
[ターン終了]
  7. 構え判定（残スタミナ 3 以上 → Guard +3）
  8. 手札を全て捨てる、playedAttributes を消す
[敵フェーズ]（敵ごとに順に）
  9. Guard を 0 に → 敵ごとの回復値でスタミナを回復 → スタンスと状態のターン開始効果
 10. 予兆どおりに実行（コストを払えなければ休み）。精鋭・ボスは 2 行動
 11. 敗北判定
 12. 次の予兆を決める（ボスは適応の条件を見てから）
```

手順 2 の回復を固定 3 にしたのは、コスト 0 の札がなくなり、1 ターンに 2 枚以上出す前提を保つためです（§18 K1）。連動 / 連打 / 締め / 手薄の 25 個の特性が、この前提の上に乗っています。

## 12. 連戦モード（試験運用の最初の形）

実装フェーズは **連戦モードを最初の目標**にします。単発の戦闘を作ってから繋ぐのではなく、最初から「続けて戦う」形で作り、HP とスタミナの持ち越し・デッキの巡り・スタンスの置き直しを一度に確かめます。

- 起動時に戦う順番を渡します。既定は 3 戦（長柄の歪み兵 → 影走りの犬 → 甲冑の番人）で、`-chain a,b,c` で変えられます。**9 戦の並びも選べます**（§17.9）。
- 戦闘の間に探索は挟みません。代わりに「階層間の休憩」相当を**毎回選べます**（HP 30% 回復 + スタミナ全回復、または回復なしで次へ）。この選択が探索側の判断の代役になります。
- HP・スタミナ（現在）・瘴気ゲージ・階層は次の戦闘へ持ち越します。瘴気は戦闘ごとに濃度 × 3% 蓄積します。
- 敗北で連戦は終わり、結果画面に「何戦目、残 HP、使ったカードの属性の内訳、**特性の発動回数**、平均ターン数」を出します。
- **全勝したときは同じ並びをもう一度回します。** 結果はログファイルに書きます（`chain-<日時>.json`）。

### 16.4 間合い（近間 / 遠間）の規則（決定）

- **値**: プレイヤーと敵 1 体ごとに、常に近間か遠間のどちらかを持ちます。HP・Guard と同じ常設の値で、状態の 4 枠（`:189`）には数えません。
- **距離の廃止**: 共有の近 / 中 / 遠、3 段の補正（×1.0 / ×0.5 / ×0.15）、空振り回避をなくします。
- **素の効果なし**: 近間 / 遠間そのものは、ダメージ・回復・崩しを変えません。カード・特性・敵の技が、自分と相手の組（4 通り）を条件として読みます。組の名前は画面にもカードの文面にも出しません。
- **名前に引かれない配分**: 間合いを条件にする効果を、「攻撃の効果 / 防御の効果 × 近間 / 遠間」の 4 マスに同数ずつ配ります。敵の技にも、相手の近間を咎めるものと遠間を咎めるものを両方置きます。
- **切り替え**: ムーブ面を持つカードで切り替えます。旧 詰めは近間へ、旧 退きは遠間へ、向きを選ぶ面は反転です。敵の押し返し / 誘いは、相手の間合いを変える技として残します。
- **画面**: 近間の個体は前へ出て、遠間の個体は下がって立ち、足元に「近」「遠」の一字札を置きます（`battle_ui_ux_v2.md` §10.6）。
- **v4.2 で詰めるもの**: 回復の決め方（いまは距離で +1 / +2 / +3）、予兆に出す情報、決定木を組の 4 枝で書く形、2 体戦で 1 回の切り替えが 2 つの組を同時に変える扱い、戦闘開始時の間合い。2026-09-16 の決定で決着しました（→ §17.3）。
- **最初に測る危険**: 片方の間合いで終え続ける方針が最強になること、両者が遠間のまま膠着すること、手札に切り替えの札が来ないこと（ムーブ面は初期 40 種中 10 種で、5 枚に 1 枚も無い確率は約 24%）。
- **捨てるもの**: v3 で検証した 3 段の勾配と空振り回避（`battle_core_v3.md:58-62`, `:178-180`）です。「実距離と体勢で見せる」（`battle_ui_ux_v2.md:8`）は、立ち位置で見せる形に置き換えます。
- **比べた読み**: 採点（忠実度を 2 倍、30 点満点）は、この形（モデル A）が 23、組から近 / 中 / 遠を導く形（B）が 19、距離を残して足す形（C）が 15 でした。

### 17.2 固定コスト（§16.5 の保留を決着）

**旧段表の列が、そのままコストになります。** カードごとに T0〜T3 から 1 列を選び、列番号がコスト、その列の値が効果です。投入量の廃止（§16.2 決定 3）は変わりません。段表はプレイヤーが選ぶ幅ではなく、カードを作るときの目盛りとして残します。

- **§3 の扱い**: T0〜T3 の値（§3.1）は残します。minInvest と 0 投入の枚数制限は §16.3 のとおり廃止のままです。

### 17.3 近間 / 遠間の詰め（§16.4 の「v4.2 で詰めるもの」を決着）

**位置を持つ敵は、ボスと精鋭だけです。** 瘴気の司祭・甲冑の番人・群れの長の 3 体が近間 / 遠間を持ちます。通常敵 6 体は持ちません。プレイヤーは常に持ちます。

- **カードの位置条件**: 自分の位置だけを読みます。相手の位置を条件にする札は作りません。
- **読む時点**: 常に動く前です。全ての札で、出す前の位置で判定します（旧 moveFirst の印は置きません）。
- **決定木の枝**: 位置を持たない敵はプレイヤーの位置で 2 通り、位置を持つボス・精鋭は 4 通りです。

| 項目               | 決定                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 回復の決め方       | 固定値 + 札の上乗せ。基本は毎ターン同じ量で、上乗せを特性とスタンスに配る（近間と遠間へ同数ずつ） |
| 予兆に出す情報     | 種別と咎める側の一字。「攻撃・遠」のように、効果が乗る側を一字で出す                              |
| 2 体戦の咎め方     | 取り巻きは位置を見ない。位置の判断は長にだけ向ける                                                |
| 2 体戦の自分向き札 | 自分の位置だけ読む。基準の敵は画面に出さない                                                      |

| 自分の開始位置     | 毎戦同じ位置。出立のツールで変更できる                                                            |
| 居続け対策         | 敵ごとに主に咎める側を持たせ、逆側にいる相手を主な側へ戻す技（押し返し / 誘い）を決定木に置く     |

**測ってから決めるもの**は 2 つです。手札に切り替えの札が来ない危険（約 24%、§16.4）と、両者が遠間のままの膠着です。規則もカードの配分も今は変えず、試験台で測ってから判断します。位置を持つ敵がボス・精鋭だけになり、膠着の起きる場面が減ったためです。

### 17.4 背水の陣（§16.7 の保留を決着）

**遠間と死力を重ねる札です。** 自分が遠間のとき攻撃が伸び、スタミナ 2 以下でさらに上乗せします。

- **条件は自分の値だけ**です（自分が遠間 + 自分のスタミナ 2 以下）。位置を持たない通常敵にも効きます。

### 17.5 状態（スタック制へ全面変更。§5 を置き換え）

### 19.1 時間の 4 層（答えの骨格）

| 層  | 長さ            | 何で遊ぶか                                     | 既にある部品                          |
| --- | --------------- | ---------------------------------------------- | ------------------------------------- |
| 1   | 1 枚            | 属性 1〜2 と特性 1                             | §2.1 / §2.3                           |
| 2   | 1 ターン        | 枚数の階段（初手 → 連動 / 連打 → 締め / 手薄） | 特性の条件 30 枚                      |

### 19.2 1 ターンの中の組み合わせ（問い 1）

| 締め / 手薄 | 3 枚目以降         | 放ちのターンだけ                         |

| #   | 決定                                                                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | 回復は **3 のまま**にします。4 には上げません。上げると溜めが要らなくなり、層 3 が消えます                                                                                 |

| S4  | 敵側の語「無防備」（§17.6 F1）は変えません。定義が別物のためです                                                                                                           |

S3 で、締め 3 枚と手薄 3 枚の計 6 枚が、同じ「放ちのターン」の報酬に揃います。狙う場面が 1 つになるので、プレイヤーが覚えることは増えません。

### 19.3 戦闘をまたぐ組み合わせ（問い 2）

**3 型は「その札の何が足を引っ張っているか」で配ります。** 型の意味を 1 語ずつに決めます。伸びは強くなる、軽さは軽くなる、型替えは当たるようになる、です。

| 型     | 配る先                                                              | 直すもの       | 目安の枚数（60 種中） |
| ------ | ------------------------------------------------------------------- | -------------- | --------------------- |
| 伸び   | 列 1〜2 の札                                                        | 出せるが弱い   | 28                    |
| 軽さ   | **列 2〜3 の札だけ**                                                | 強いが出せない | 14                    |
| 型替え | 満たしにくい条件を持つ札（死力 / 崩し後 / 相手の状態 / 自分の状態） | 条件が合わない | 18                    |

| #   | 決定                                                                                                                                                                                                                                              |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S5  | **軽さを列 1 の札に配りません**。列 1 に置くと段 1（刻み 3）でコスト 0 になり、毎ターン 5 枚出せてしまいます。コスト 0（§17.2）は、列 2 の札が段 2（刻み 8）に届いたときか、列 3 の札が段 3（刻み 15、1 つの生で 1 枚）に届いたときだけ生まれます |
| S6  | **型替えは効果を変えず、条件だけを 1 段ずつ緩めます**。数値が動かないので、カード 1 枚ずつの調整（#53）と干渉しません                                                                                                                             |
| S7  | 条件が緩む順を 3 本の道に決めます。枚数の道は 手薄 → 締め → 連打 → 連動 → 初手、資源の道は 死力 → 温存 → 初手、読みの道は 相手の状態 → 崩し後 → 予兆 です                                                                                         |
| S8  | **型替えの札だけ、閾値を 2 / 6 / 12 にします**（ほかは 3 / 8 / 15 のまま）。型替えの札は条件が満たしにくく、刻みの 4 文脈のうち「特性の発火」を最初は取れません。同じ閾値だと、一番育てたい札が一番育ちません                                     |

型替えの例です。観察（#22、手薄: ドロー +1）が、精査（締め: ドロー +1）→ 洞察（連動(Sk): ドロー +1）→ 看破（初手: ドロー +1）と進みます。効果は最後までドロー +1 のままで、発火する場面だけが「放ちのターンだけ」から「毎ターン」へ広がります。

「この札を育てたい」という理由は、この 3 語のどれが欲しいかで決まります。主力を重くしたいなら伸び、決め技を早く出したいなら軽さ、死んでいる特性を生かしたいなら型替えです。才能（開始時に 1 枚、刻み 2 倍）は、型替えの札に置くのが一番効きます。

### 19.4 位置と特性の噛み合い（問い 3）

**片側に居続ける方針は弱くします。** ただし居続けを罰するのではなく、振ると得をする形で弱くします。

居続けが強くなる理由は 2 つです。位置を条件にする 16 枚（K6）が 4 マスに均等なので、片側へ寄せたデッキなら 8 枚が常に発火します。切り替えはムーブ札 1 枚とスタミナ 1 を払います。払わない側が得です。

これを層 3 の往復に重ねて解きます。溜めのターンは守り、放ちのターンは攻めます。守りの札は片側、攻めの札はもう片側で伸びます。**溜めで遠間、放ちで近間**という振り子が、そのまま「守って溜める → 動いて放つ」になります。ムーブ札 1 枚は放ちのターンの 6 スタミナから払うので、溜めのターンの手数を削りません。

| #   | 決定                                                                                                                                                                                                              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S9  | K6 の 4 マス均等（各 4 枚）を変えません。片側へ寄せると振り子が消えます                                                                                                                                           |
| S10 | ムーブ単属性 6 種（K5）の付随効果を向きで分けます。**近間へ 2 枚 = スタミナ +1 / ドロー 1**（放ちを伸ばす）、**遠間へ 2 枚 = Guard 4 / ドロー 1**（溜めを守る）、**反転 2 枚 = Guard 4 / スタミナ +1**            |
| S11 | 敵 9 体すべてに、**近間を咎める技と遠間を咎める技を 1 つずつ以上**持たせます。位置を持たない通常敵 6 体も、プレイヤーの位置で 2 通りに枝分かれします（§17.3）。どちらに居続けても、予兆の約半分が当たりになります |
| S12 | 切り替えの札が手札に来ない危険（約 24%、§16.4）は規則で直しません。ムーブ面を持つ札をデッキへ何枚入れるかを、プレイヤーの判断として残します                                                                       |

止め役は鈍足です。次のターン全体の切り替えを止めるので（§17.5）、振り子は 1 往復を飛ばされます。2 回行動の敵なら 2 手とも止まります。

### 19.5 状態の 2 型の使い分け（問い 4）

**溜めてから一気に使う遊び方は成立させます。** 止め役は「1 撃に乗る倍率は 1 つまで」です。

使うと減る型（強化 / 脆化 / 集中 / 見切り / 威圧。K3）は、使うまで減りません。溜めのターンに積み、放ちのターンに 3〜4 枚のアタックで使い切る形が、そのまま層 3 に乗ります。これは狙いどおりです。

問題は倍率の重ね掛けです。強化 ×1.5 と脆化 ×1.5 が同じ 1 撃に乗ると ×2.25 になり、列 3 のアタック 21 に特性 +6 と追撃 +5 を足した 32 が 72 になります。通常敵の HP は 50〜70 なので、1 撃で落ちます（§18.4-3）。

| #   | 決定                                                                                                                                                                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S13 | **1 撃に乗る倍率状態は 1 つまでにします。乗る順は 脆化 → 強化 です。** 両方付いているときは脆化を 1 消費し、強化は消費せず次の撃へ回ります。§17.6 F4 の式は `(面 + 特性 + 追撃 + 転換) × 倍率 1 つ → 丸め（AwayFromZero）→ − Guard` になります |
| S14 | 上限は置きません。スタック数の上限（§17.5）も、溜められるターン数の上限も置きません。溜めている間は敵の HP が減らないことが、そのまま値段です                                                                                                  |

S13 で、強化 3 と脆化 3 は「3 撃が ×2.25」ではなく「6 撃が ×1.5」になります。1 撃の最大は 32 × 1.5 = 48 に下がり、手数を増やす向きへ働きます。手数が増えると締めと手薄（S3）も発火します。層 2 と層 3 が同じ方向を向きます。

ターンで減る型（出血 / 再生 / 俊敏 / 鈍足 / 疲労）は溜まりません。積み直しが要るので、別の遊び方（血路、§19.8 の 4）になります。

止め役はもう 2 つあります。溜めのターンは出力がほぼ 0 で、敵の 1 ターン出力 7〜13 をそのまま受けます。ボス専用の状態 瘴気纏い（最大スタミナ −1〜−2、§6.3）は、溜められる量そのものを削ります。

### 19.6 スタンス枠 1 の重み（問い 5）

**1 戦に 1〜2 回が良い回数です。**

通常戦は 6〜10 ターン、ボス戦は 12〜18 ターンです（§13）。スタンスは戦闘が終わるまで続くので、置き直すと前の型の残りターンを捨てます。1 ターン目に 1 枚置き、戦いの形が変わる 5〜6 ターン目にもう 1 枚置くのが上限です。3 回以上置けるなら、1 枚が軽すぎるか弱すぎます。

いまのままだと多すぎます。スタンス面を持つ札は 80 種中 15 種です。デッキ 20〜40 枚へ素直に混ぜると 4〜7 枚入り、引くたびに置き直す形になります。

| #   | 決定                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------- |
| S15 | **出立の検証で、スタンス面を持つ札をデッキ 3 枚までに制限します**（`DeckRules.cs`）。同種 3 枚の上限とは別の制限です |
| S16 | スタンスのカード 1 枚ずつの強さは変えません。3 枚制限で回数が決まるので、数値を動かす必要がありません                |

止め役は 2 つです。出したスタンスは除外置き場へ行き、戦闘中は引き直せません（§4）。置いた型が敵の形と噛み合わなくても、1 戦それで通します。§13 の「スタンス無しデッキの勝率が最強 −15 pt 以上」が、必須化の上限を押さえます。

### 19.7 新しい軸（問い 6）

**足しません。**

5 つの軸で足ります。足りなかったのは軸ではなく、層 2 と層 3 の名前でした。本節はその 2 層に規則（S1〜S17）を置いただけで、プレイヤーが覚える語も、画面に出す値も増やしていません。

画面に足すものもありません。枚数の階段はカードの特性の文面がそのまま見せます。溜めと放ちはスタミナの帯が見せます。間合いは足元の一字札が見せます（§16.4）。スタンスは枠が見せます。どれも既に決まっている表示です。

### 19.8 強い組み合わせ 6 型と止め役

「この組み合わせが強い」と言える型です。どれも既にあるカードと規則だけで組めます。

| #   | 型           | 何をするか                                                                                                                                                 | 止め役                                                                                                                                                                                 |
| --- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **溜め放ち** | 1 ターン目に 1 枚だけ出し、残 3 以上で構えを取る。次のターンに 6 スタミナで 3〜4 枚を出す。締め / 手薄 / 連打 / 連動 が同時に発火する                      | 溜めのターンは出力がほぼ 0 で、敵の 7〜13 をそのまま受ける。手札は全捨てなので、溜めのターンに引いた 4 枚を捨てる。精鋭・ボスは 1 フェーズ 2 行動で、溜め 1 ターンに 20〜32 を受けうる |
| 2   | **振り子**   | 溜めで遠間、放ちで近間へ振る。守り × 遠間 の 4 枚と攻め × 近間 の 4 枚が交互に発火する。ムーブ札の付随効果（S10）が往復の両側を支える                      | 鈍足が次のターン全体の切り替えを止める。ムーブ面を持つ札が 5 枚に 1 枚も来ない確率が約 24%。切り替え 1 回につきスタミナ 1 と札 1 枚を払うので、放ちの枚数が 1 枚減る                   |
| 3   | **研ぎ**     | 溜めのターンに強化 / 集中 / 見切りを積み、放ちのターンで使い切る。集中は列を 1 つ右へ動かすので、列 3 の札が列 4（アタック 30）で解決する                  | S13 で 1 撃に乗る倍率が 1 つになり、1 撃の最大が 48 で止まる。溜めている間は敵の HP が減らない。瘴気纏いが最大スタミナを削り、溜められる量が減る                                       |
| 4   | **血路**     | 出血と脆化を積み、相手の状態(出血) を条件にする札（裂き斬り / 棘斬り / 血の舞 / 槍衾）を連鎖させる。ターンで減る型の tick で削り切る                       | 出血はスタックが強さと回数を兼ねるので、積み直さないと 2 ターンで枯れる。ボス（HP 160）では tick が間に合わない。積む札は二属性でアタック面が 65% なので、総火力で溜め放ちに負ける     |
| 5   | **一型**     | 1 ターン目にスタンスを 1 枚置き、毎ターンの上乗せ（ターン開始 Guard / 回復 / 条件付き加算）で押す。残りを列 1 の安い札で固め、溜めずに毎ターン 2〜3 枚出す | スタンスは除外されて引き直せない。置いた型が噛み合わないまま 1 戦続く。S15 の 3 枚制限で重ね置きができない。§13 の「スタンス無しデッキ」の基準が上限を押さえる                         |
| 6   | **背水**     | わざとスタミナを枯らし、遠間 × 死力 で伸びる札（背水の陣 §17.4 / 伸び突き / 覚悟 / 背水の型）を撃つ                                                        | スタミナ 2 以下では構え（残 3 以上）が付かない。回復 3 固定なので、枯らした次のターンは 3 スタミナしかなく放ちができない。威圧（次の値 −3）と疲労（次の回復 −1）が直撃する             |

型どうしの噛み合わせも決まります。1 と 3 は同じターンを狙うので重なります。2 は 1 の往復に乗ります。5 と 6 は溜めない型で、1 や 3 と混ぜると弱くなります。4 はどちらへも寄れます。

- **S17**: §13 の「デッキの型 5 種」（近距離速攻 / 遠距離削り / 受け反撃 / スタンス構築 / 状態異常）を、この 6 型へ置き換えます。試験台の勝率差は 6 型の間で読みます。
