## 2. 属性と面

### 2.1 属性 5 つ

| 属性     | 盤面への作用                                 | 投入量で伸びるもの                         | 間合い補正                         |
| -------- | -------------------------------------------- | ------------------------------------------ | ---------------------------------- |
| アタック | 相手の HP を減らす                           | 威力、崩し                                 | 受ける（×1.0 / ×0.5 / ×0.15）      |
| ガード   | 自分に Guard を付ける                        | Guard 量                                   | 受けない                           |
| スタンス | 戦闘が終わるまで続く効果を枠に置く           | 効果の強さ                                 | 受けない                           |
| スキル   | 状態を付ける、回復する、引く、スタミナを戻す | 段数、持続、量                             | 相手に付ける状態だけ diff 0 で発動 |
| ムーブ   | 間合いを動かす（詰め / 退き）                | 段階数（既定 1、カード個別に 2）、付随効果 | 受けない                           |

- 1 枚は **1〜2 属性**を持つ。単属性 5 + 二属性 10 = 15 パターン。
- 属性ごとに **面**（4 段の表 T0〜T3）を持つ。二属性のカードは 1 回の投入量で両方の面が同時に段を上げる。
- 二属性の各面は、単属性の同じ面の **65%** を目安にする（合計 130%）。1 枚で 2 役できる代わりにそれぞれは弱い。試験台で測って直す。
- 移動は「ムーブ属性」として他と同格に扱う（決定 1）。踏み込み斬りは アタック + ムーブ、足捌きは ガード + ムーブ。
- 単属性ムーブの 4 段は「T0 1 段階（向き固定）/ T1 1 段階（向きを選ぶ）/ T2 2 段階（向き固定）/ T3 2 段階（向きを選ぶ）」を既定の梯子にする（`swordsman_cards_v4.md` §1）。二属性のムーブ面は 1 段階固定で、T2 以上の 2 段階はカード個別に許す。
- minInvest 0 の二属性カードの T0 は アタック面 3 / ガード面 2（単属性の 5 / 3 より下）。

### 2.2 1 枚の中の解決順

```
既定:        アタック → ムーブ → ガード → スキル → スタンス
moveFirst:   ムーブ → アタック → ガード → スキル → スタンス
```

- `moveFirst` はアタック + ムーブのカードだけが持つ。「遠から詰めて斬る」（猪突猛進）は moveFirst で、移動後の距離で威力を計算する。
- 移動後の距離は次の面と次の行動から効く（v3 §2.4 を維持）。
- 崩しと相手に付ける状態は、その面を解決する時点の距離で diff 0 のときだけ発動する。

### 2.3 特性（属性を基準にしたコンボ）

カードは **特性を 1 つまで**持つ。特性は「条件 → 効果」の 1 組で、条件は属性のプレイ履歴などを見る。

| 条件       | 意味                                            | 例                                          |
| ---------- | ----------------------------------------------- | ------------------------------------------- |
| 連動       | このターンに <属性> のカードをプレイ済み        | ムーブ連動: スタミナ +1（こうだいさんの例） |
| 位置       | <間合い> から使う（moveFirst なら移動前の距離） | 遠から: 威力 +6（猪突猛進）                 |
| 予兆       | 相手の予兆が <種別>                             | 予兆がアタック: Guard +3                    |
| 温存       | 使用後の残スタミナ ≥ n                          | 残 6 以上: 次ターン回復 +1（v3 の「冷静」） |
| 死力       | 現在スタミナ ≤ 2                                | 威力 +6（v3 の「×1.5」は使わない）          |
| 初手       | このターン最初のプレイ                          | 投入 −1（段は変えずコストだけ）             |
| 締め       | このターン 3 枚目以降のプレイ                   | 威力 +3                                     |
| 崩し後     | 相手のスタミナ < 3                              | 崩し +1                                     |
| 連打       | 直前にプレイしたカードも同じ属性                | アタック連打: 威力 +3                       |
| 手薄       | このターンの残り手札が 1 枚以下                 | ドロー +1                                   |
| 相手の状態 | 相手に <語> が付いている                        | 出血中: 威力 +5                             |
| 自分の状態 | 自分に <語> が付いている                        | 見切り中: Guard +3                          |

効果の語彙は 10 種。効果は段に依らず一定にする（暗算のため）。

| 効果            | 内容                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| スタミナ +1     | 即時                                                                                       |
| 威力 +n         | この 1 枚のアタック面                                                                      |
| Guard +n        | この 1 枚                                                                                  |
| ドロー +1       | 即時                                                                                       |
| 状態 +1         | 段のある状態は +1 段、1 回きりの状態は 1 つ追加                                            |
| 投入 −1         | この 1 枚のコストだけ下がる。段は変えない                                                  |
| 次ターン回復 +1 | 次のターン開始                                                                             |
| **重撃**        | この 1 枚の投入を +1 払うと威力 +6。段は変えない（「スタミナを多めに払って威力を上げる」） |
| **転換**        | この 1 枚の Guard の半分を威力に足す                                                       |
| **追撃**        | このターンの次のアタック面に威力 +5                                                        |

- **特性の付け方**: 初期 40 のうち 32 枚、習得 40 の全てが特性を持つ。同じ「条件 + 効果」の組は 3 枚まで。
- **素直な札**: 特性を持たないカード（初期の 8 枚）は各段の威力 +2、Guard +2（T0 は +1）を上乗せする。「特性が無いぶん数字で補う」（こうだいさん決定 2026-09-13）。

「このターンにプレイした属性」は state に `playedAttributes`（属性ごとの回数）として持ち、ターン終了で消す。敵も自分のフェーズで同じものを持つ。

### 2.4 面のスキーマに足す項目（カードと敵で共通）

| 項目        | 意味                                                                | 使う例                          |
| ----------- | ------------------------------------------------------------------- | ------------------------------- |
| `moveFirst` | ムーブ面をアタック面より先に解決する                                | 猪突猛進、払いの杖              |
| `push`      | 相手を押す矯正移動（相手との距離を +1）。Guard で減らない           | 石突きの押し込み                |
| `hits`      | アタック面を n 回に分けて当てる（1 撃ずつ Guard に当たる）          | 双刃の斬撃                      |
| `targets`   | one / all / self / **ally**（味方に付ける状態。2 体戦の取り巻き用） | 群れの長の遠吠え                |
| `shift`     | 既定 1。カード個別に T2 以上で 2 を許す                             | 猪突猛進、単属性ムーブの T2〜T3 |
| `when`      | スタンスの効果に間合いの条件を付ける（例: 遠にいるターン開始だけ）  | 水の構え、瘴気の帳              |

## 3. 投入量と 0 投入（決定 3）（2026-09-14 廃止予定 → §16.5）

- 投入量 0〜3、`minInvest` 0 か 1 は v3 のまま。
- **T0 は弱いが効果を残す**。手札は毎ターン固定で 5 枚なので、0 投入が無価値だと「欲しいカードが来ない」だけのターンが増える。

| 面       | T0 の目安                      |
| -------- | ------------------------------ |
| アタック | 威力 5（単属性）/ 3（二属性）  |
| ムーブ   | 1 段階移動                     |
| ガード   | Guard 3（単属性）/ 2（二属性） |
| スキル   | 状態 1 段 1 ターン、回復 2     |
| スタンス | 最弱段                         |

- **minInvest 0 のカードは 80 種のうち 20 種まで**（初期 40 に 12、習得 40 に 8）。5 枚の手札に平均 1.25 枚。
- 0 投入回しの上限は試験台の基準「0 投入だけの方針の勝率 < 10%」で見る（§13）。超えたら T0 の威力を 3 に下げるか、minInvest 0 の枚数を減らす。T0 = 5 は敵の 1 ターン出力（7〜13）の半分近いので、この基準は最初に見る。

## 4. スタンス（決定 4）

- **枠は 1 つ**。スタンス面を持つカードをプレイすると枠に入る。別のスタンスを出すと前のものは終わる（同じスタンスなら新しい投入量で置き直す）。
- 強さは投入量で決まり、戦闘が終わるまで変わらない。戦闘終了で枠は空になる（次の戦闘に持ち越さない）。
- **出したカードは戦闘中は山札に戻らない**（除外置き場へ）。同種を 3 枚入れると死に札になるので、1〜2 枚に抑える理由になる。
- 効果の型は 6 つ。カードはこのどれかを 1 つ持つ。

| 型             | 例                                              |
| -------------- | ----------------------------------------------- |
| ターン開始付与 | 毎ターン Guard +1 / HP +1 / ドロー +1 / 回復 +1 |
| 条件付き加算   | 近での攻撃 +1 / 遠から使うムーブに Guard +1     |
| 被弾時の反応   | Guard が吸収した分の 1/3 を返す                 |
| 移動の補正     | 退きに Guard +1 / 詰めに威力 +1                 |
| 投入の割引     | 毎ターン 1 回、<属性> のカードの投入 −1         |
| 敵行動への干渉 | 予兆の狙い間合いに居るとき Guard +1             |

- 敵もスタンスを持てる（精鋭・ボス）。表示は同じ枠で対称。

## 5. 状態（決定 5）

- 語彙は **10 語**に固定する。カードは語と段数と持続だけを書く。
- 片側に同時に持てる状態は **4 つまで**（5 つ目は付かない）。段数は **3 まで**。
- 相手に付ける状態は **diff 0 のときだけ**発動（v3 §2.3 の追加効果と同じ扱い）。自分に付ける状態は常に発動。

| 語     | 向き   | 効き方                                                          | 持続     | 消え方               |
| ------ | ------ | --------------------------------------------------------------- | -------- | -------------------- |
| 出血   | 相手に | 相手のターン開始に HP −2 × 段数                                 | 3 ターン | 毎ターン 1 段減る    |
| 脆化   | 相手に | 次に受ける攻撃の raw ×1.5                                       | 1 回     | 被弾で消える         |
| 鈍足   | 相手に | 次の行動の移動を 0 にする（空振り回避の間合い取り直しも封じる） | 1 ターン | 行動後に消える       |
| 威圧   | 相手に | 次の行動の投入量 −1                                             | 1 ターン | 行動後に消える       |
| 疲労   | 相手に | 次のターン開始の回復 −1                                         | 1 ターン | 回復後に消える       |
| 強化   | 自分に | 次のアタック面の威力 ×2                                         | 1 回     | アタックで消える     |
| 集中   | 自分に | 次のカードの投入量 +1 を無料で足す（T3 は超えない）             | 1 回     | プレイで消える       |
| 見切り | 自分に | 次の被弾で Guard が吸収した分の半分を相手に返す                 | 1 ターン | 敵フェーズ後に消える |
| 軽足   | 自分に | 次のムーブが 2 段階まで動ける                                   | 1 回     | 移動で消える         |
| 再生   | 自分に | ターン開始に HP +2                                              | 3 ターン | ターンごとに減る     |

- 「軽足」は間合い規則「1 行動 1 段階」の例外、「見切り」は被弾規則の例外である。どちらもカードに明記された 1 回きりの効果として許す。
- **ボス専用の状態**: ボスは上の 10 語に加えて専用の状態を 2 つ持つ（`enemy_roster_v4.md` §4）。例: 瘴気纏い（この戦闘中プレイヤーの最大スタミナ −1、重ねて −2 まで）、呪縛（次のターン、ムーブ属性のカードを使えない）。専用の状態は予兆で見えて、対処できる形にする。

## 6. 予兆と敵 AI

- 通常敵は v3 §6 のまま（コミット式の予兆、空振り回避、距離だけの決定木、投入量は残 3 以上を残す最大）。
- **精鋭**: 1 フェーズ 2 行動。予兆は 2 段（次と次の次）。スタンスを持つ。
- **ボス**: 行動履歴で決定木を切り替える適応（条件は手記に書ける文にする）。予兆 2 段、1 フェーズ 2 行動、専用の状態 2 つ。
- 敵の行動も属性・面・特性・状態を持つ。`CardDef` と `EnemyAction` は同じ面の表で書ける。

### 6.3 最大スタミナの例外

v3 §3.1「戦闘中に最大値は変わらない」の唯一の例外がボス専用の状態「瘴気纏い」である。戦闘中に −1〜−2 し、戦闘終了で戻る。探索側の瘴気ゲージには影響しない。

## 7. 複数体の戦闘（決定 2 / 6）

- 80% では **1 体が基本**、精鋭「群れの長」だけ取り巻き 1 体を連れて **2 体**で出る。3 体以上は 100% でも入れない。
- **間合いは敵ごとに持つ**。プレイヤーは一本の線の上に立ち、敵は全て前方に居る。プレイヤーのムーブは **全ての敵との距離を同じ向きに 1 段階**動かす（端で止まる）。敵のムーブはその敵との距離だけを動かす。
- 各敵が自分の予兆を持ち、自分のフェーズを順に実行する（順番は敵定義の並び）。
- カードの相手指定: `targets` = one（矢印で 1 体）/ all（全ての敵）/ self（自分）。アタック面は one が既定。all のアタック面は敵ごとの距離で補正する。
- 回復（ターン開始）は「最も近い敵との距離」で決める。構えは変わらない。

## 8. 手札とデッキ

## 9. ターン進行（v4）

```

  1. Guard を 0 に
  2. 最も近い敵との間合いで回復（近 +1 / 中 +2 / 遠 +3）。疲労なら −1

  7. 構え判定（残 ≥ 3 → Guard +2）

  9. Guard を 0 に → 間合いで回復 → スタンスと状態のターン開始効果
 10. 予兆どおりに実行（diff 2 なら空振り回避）。精鋭・ボスは 2 行動
 11. 敗北判定
 12. 次の予兆を決める（ボスは適応の条件を見てから）
```

## 12. 連戦モード（試験運用の最初の形、決定 6）

実装フェーズは **連戦モードを最初の目標**にする。単発の戦闘を作ってから繋ぐのではなく、最初から「続けて戦う」形で作り、HP とスタミナの持ち越し・デッキの巡り・スタンスの置き直しを一度に検証する。

- 起動時に戦う順番を渡す（既定 3 戦: 長柄の歪み兵 → 影走りの犬 → 甲冑の番人。`-chain a,b,c` で変更）。
- 戦闘の間に探索は挟まない。代わりに「階層間の休憩」相当を選べる（HP 30% 回復 + スタミナ全回復、または回復なしで次へ）。この選択が探索側の判断の代役になる。
- HP・スタミナ（現在）・瘴気ゲージ・階層は次の戦闘へ持ち越す。瘴気は戦闘ごとに濃度 × 3% 蓄積（探索 3 行動ぶんの代役）。
- 敗北で連戦は終わり、結果画面に「何戦目、残 HP、使ったカードの属性の内訳、0 投入の回数、平均ターン数」を出す。これは試験台の基準 9 項目の人手版になる。
- 連戦の結果はログファイルに書く（`chain-<日時>.json`）。プレイテスト 3 巡の記録票の元にする。

### 16.4 間合い（近間 / 遠間）の規則（決定）

- **値**: プレイヤーと敵 1 体ごとに、常に近間か遠間のどちらかを持ちます。HP・Guard と同じ常設の値で、状態の 4 枠（`:189`）には数えません。
- **距離の廃止**: 共有の近 / 中 / 遠、3 段の補正（×1.0 / ×0.5 / ×0.15）、空振り回避をなくします。
- **素の効果なし**: 近間 / 遠間そのものは、ダメージ・回復・崩しを変えません。カード・特性・敵の技が、自分と相手の組（4 通り）を条件として読みます。組の名前は画面にもカードの文面にも出しません。
- **名前に引かれない配分**: 間合いを条件にする効果を、「攻撃の効果 / 防御の効果 × 近間 / 遠間」の 4 マスに同数ずつ配ります。敵の技にも、相手の近間を咎めるものと遠間を咎めるものを両方置きます。
- **切り替え**: ムーブ面を持つカードで切り替えます。旧 詰めは近間へ、旧 退きは遠間へ、向きを選ぶ面は反転です。敵の押し返し / 誘いは、相手の間合いを変える技として残します。
- **画面**: 近間の個体は前へ出て、遠間の個体は下がって立ち、足元に「近」「遠」の一字札を置きます（`battle_ui_ux_v2.md` §10.6）。
- **v4.2 で詰めるもの**: 回復の決め方（いまは距離で +1 / +2 / +3）、予兆に出す情報、決定木を組の 4 枝で書く形、2 体戦で 1 回の切り替えが 2 つの組を同時に変える扱い、戦闘開始時の間合い。
- **最初に測る危険**: 片方の間合いで終え続ける方針が最強になること、両者が遠間のまま膠着すること、手札に切り替えの札が来ないこと（ムーブ面は初期 40 種中 10 種で、5 枚に 1 枚も無い確率は約 24%）。
- **捨てるもの**: v3 で検証した 3 段の勾配と空振り回避（`battle_core_v3.md:58-62`, `:178-180`）です。「実距離と体勢で見せる」（`battle_ui_ux_v2.md:8`）は、立ち位置で見せる形に置き換えます。
- **比べた読み**: 採点（忠実度を 2 倍、30 点満点）は、この形（モデル A）が 23、組から近 / 中 / 遠を導く形（B）が 19、距離を残して足す形（C）が 15 でした。

### 16.5 固定コスト（投入量の廃止は決定、決め方は保留）

- 1 枚ごとのコストの決め方は保留です。
- 叩き台「役割でコスト 0〜3（軽い技 0 / 補助 1 / 主力 2 / 決め技 3）」は見送りました。理由は「大きさごとに役割を決めるのはつまらない」です。
- 残すもの: 最大スタミナ 10、構え、瘴気、崩し。
- 語の読み替え（投入 −1、集中、威圧、重撃）は、コストの決め方と一緒に決めます。
- 試験台では、固定コストだけを入れた版と、近間 / 遠間を足した版を分けて測ります。2 つを同時に入れると、勝率の変化がどちらによるものか切り分けられないためです。

### 16.6 シナジーの方向（習熟は決定）

- **習熟（決定: 旧段表を上る）**: 使った文脈ごとに刻みを数えます。文脈は、間合いの組・予兆に合った型・特性の発火・構え圏か死力圏の 4 つで、`concept-v3.md:73` の「どのスタミナ量で」を置き換えます。
- **段の上がり方**: 1 枚ごとに次の 3 型から 1 つを持ちます。
  - 伸び: 面が旧表の 1 列右へ進みます。
  - 軽さ: コストが 1 下がります（数値はコストの決め方の後に置きます）。
  - 型替え: 特性が替わります（例: 観察 → 精査 → 洞察 → 看破）。
- **閾値**: 3 / 8 / 15 を仮置きします。段は戦闘の終わりに上がるので、戦闘中の表示は変わりません。
- **戦闘中の判断**: 「いくら払うか」は、「どの順に何枚出し、どちらの間合いで終えるか」に置き換わります。材料は、特性の条件 初手 / 締め / 連打 / 連動 / 手薄（`swordsman_cards_v4.md:36-45`）と、間合いの組です。
- **永続能力**: 高段の永続能力は、情報と選択肢に限ります（`concept-v3.md:75`）。
- **基準**: 試験台の「特性の発動 1 戦 2 回以上」（`swordsman_cards_v4.md:251`）を、主な基準に上げます。§14 の未確定 6（`:356`）は主課題に上がります。
