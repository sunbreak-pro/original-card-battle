## 2. 属性と面

### 2.1 属性 5 つ

| 属性     | 盤面への作用                                 | 列で伸びるもの                                  |
| -------- | -------------------------------------------- | ----------------------------------------------- |
| アタック | 相手の HP を減らす                           | 威力、崩し                                      |
| ガード   | 自分に Guard を付ける                        | Guard 量                                        |
| スタンス | 戦闘が終わるまで続く効果を枠に置く           | 効果の強さ                                      |
| スキル   | 状態を付ける、回復する、引く、スタミナを戻す | スタック数、量                                  |
| ムーブ   | 自分のマスを前へ / 後ろへ動かす（§7.3）      | 付随効果（ムーブだけの札はコスト 1 に固定する） |

- 1 枚は **1〜2 属性**を持ちます。単属性 5 + 二属性 10 = 15 パターンです。
- 属性ごとに **面**を持ちます。カードは列 1〜4 から 1 列を選び、**列番号がコスト、その列の値が効果**です（§3）。二属性のカードは 1 つの列で両方の面の値が決まります。
- 二属性の各面は、単属性の同じ列の **65%** を目安にします（合計 130%）。1 枚で 2 役できる代わりに、それぞれは弱くします。
- 移動は「ムーブ属性」として他と同格に扱います。踏み込み斬りは アタック + ムーブ、足捌きは ガード + ムーブです。
- **単属性ムーブ 6 種は全てコスト 1** です。効果は「前へ 1 / 前へ 2 / 後ろへ 1 / 後ろへ 2」のどれかで、小さな付随効果（Guard 4 / ドロー 1 / スタミナ +1 のどれか 1 つ）を付けます。列で段を上げる梯子は持ちません。6 種の割り当ては cards レーンが決めます。
- **アタック面と相手向きのスキル面は、届く間合い（`reach`）を持ちます**（§2.4）。ガード面・スタンス面・自分向きのスキル面は間合いを見ません。

### 2.2 1 枚の中の解決順

```
特性の判定 → アタック → ムーブ → ガード → スキル → スタンス
```

- **特性は面より前に判定します**（§17.6 F5）。カード表と画面の予測値がこの順を前提にしているためです。
- **間合いは必ず「出す前」で読みます。** 届く間合いも、間合いの境目も同じです。`moveFirst` の印は置きません。アタック + ムーブの札は、動く前の間合いで届くかどうかと威力を決め、そのあとに動きます。踏み込み斬りは「間合い 1〜2 に届き、当ててから前へ 1」と書きます。
- 動いた結果は、次の行動から効きます。同じ 1 枚の中のガード面・スキル面は間合いを見ないので、影響を受けません。

### 2.3 特性（属性と盤面を条件にした追加効果）

カードは **特性を 1 つまで**持ちます。特性は「条件 → 効果」の 1 組です。

| 条件       | 意味                                             | 例                         |
| ---------- | ------------------------------------------------ | -------------------------- |
| 連動       | このターンに <属性> のカードをプレイ済み         | ムーブ連動: スタミナ +1    |
| 間合い     | 相手との間合いが <n 以下 / n 以上>（出す前の N） | 間合い 2 以上: 威力 +6     |
| 予兆       | 相手の予兆が <種別>                              | 予兆がアタック: Guard +3   |
| 温存       | 使用後の残スタミナ ≥ n                           | 残 6 以上: 次ターン回復 +1 |
| 死力       | 現在スタミナ ≤ 2                                 | 威力 +6                    |
| 初手       | このターン最初のプレイ                           | コスト −1                  |
| 締め       | このターン 3 枚目以降のプレイ                    | 威力 +3                    |
| 崩し後     | 相手のスタミナ < 3                               | 崩し +1                    |
| 連打       | 直前にプレイしたカードも同じ属性                 | アタック連打: 威力 +3      |
| 手薄       | プレイ後の残り手札が 2 枚以下（§19.2 S3）        | ドロー +1                  |
| 相手の状態 | 相手に <語> が付いている                         | 出血中: 威力 +5            |
| 自分の状態 | 自分に <語> が付いている                         | 見切り中: Guard +3         |

- **間合いの境目は 1 枚に 1 つまでです。** 相手を選ぶ札は選んだ相手との N を、自分向きの札はいちばん近い敵との N を読みます（§7.4）。v4.2 の「位置は自分の値だけを読む」は、N が 2 人のあいだの値になったので置き換えました。
- 敵側の「相手の Guard が 0」は **無防備**という別の語です（§17.6 F1）。手薄と混ぜません。

効果の語彙は 10 種です。効果は列に依らず一定にします（暗算のため）。

| 効果            | 内容                                                                                   |
| --------------- | -------------------------------------------------------------------------------------- |
| スタミナ +1     | 即時                                                                                   |
| 威力 +n         | この 1 枚のアタック面。n は 4〜8 を目安にする（叩き台）                                |
| Guard +n        | この 1 枚                                                                              |
| ドロー +1       | 即時                                                                                   |
| 状態 +1         | スタックを 1 足す                                                                      |
| **コスト −1**   | この 1 枚のコストが 1 下がる（下限 0）。習熟の「軽さ」と同じ働き                       |
| 次ターン回復 +1 | 次のターン開始のスタミナ回復                                                           |
| **重撃**        | 条件を満たすと威力 +6、**次のターン開始の回復 −1**。今のターンのコストと構えは変えない |
| **転換**        | この 1 枚の Guard の半分を威力に足す                                                   |
| **追撃**        | このターンの次のアタック面に威力 +5                                                    |

- **特性の付け方**: 初期 40 のうち 32 枚、習得 40 の全てが特性を持ちます。同じ「条件 + 効果」の組は 3 枚までです。
- **間合いの境目を条件にする札は 16 枚**です（§18 K6 の読み替え）。「攻撃の効果 / 防御の効果 × 詰めて得（n 以下）/ 離れて得（n 以上）」の 4 マスに 4 枚ずつ、初期 8 枚・習得 8 枚です。
- **素直な札**: 特性を持たないカード（初期の 8 枚）は各列の威力 +2、Guard +2 を上乗せします。

「このターンにプレイした属性」は state に `playedAttributes`（属性ごとの回数）として持ち、ターン終了で消します。敵も自分のフェーズで同じものを持ちます。

### 2.4 面のスキーマに足す項目（カードと敵で共通）

| 項目            | 意味                                                                                                                                                  | 使う例                 |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `hits`          | アタック面を n 回に分けて当てる（1 撃ずつ Guard に当たる）                                                                                            | 双刃の斬撃             |
| `targets`       | one / all（届く間合いの中の全員）/ self / **ally**（同じ戦闘にいるほかの敵に付ける状態）                                                              | 長竜の遠吠え           |
| `reach`         | **届く間合い**（下限〜上限の N）。アタック面と相手向きのスキル面が持つ。既定は 0〜1。カードは外の相手に出せず、敵の行動は外なら空振りになる（§6）     | 長突き（1〜2）         |
| `push` / `pull` | 相手を n マス押す / 引く（§7.3）。Guard で減らない。動けなかったマスの分は壁のダメージ。撃つ側に鈍足が付いていると 1 マス減る（§5）。**両者が持てる** | 石突きの押し込み、誘い |
| `when`          | スタンスの効果に間合いの境目を付ける（例: いちばん近い敵との間合いが 2 以上のターン開始だけ）                                                         | 水の構え、瘴気の帳     |

廃止した項目は `moveFirst`（§2.2）と `shift`（v4.2 で廃止。v4.3 ではムーブ面の「前へ n / 後ろへ n」が同じ役目を持ちます）です。

## 3. コストと列（§17.2 / §18 K2 / §18 K8）

**旧段表の列が、そのままコストになります。** カードごとに列を 1 つ選び、列番号がコスト、その列の値が効果です。段表はプレイヤーが選ぶ幅ではなく、カードを作るときの目盛りとして残ります。

- **列は 1〜4** です。列 4 のコストは 3 のままで、集中と習熟の「伸び」がコスト 3 の札に掛かったときに使います。
- **列の選び方**: 特性の条件で選びます。満たしにくい条件（死力 / 崩し後 / 相手の状態 / 手薄）を持つ札ほど低い列、つまり安くします。
- **コスト 0** は習熟でだけ生まれます。初期はカードも敵の技もコスト 1 以上です。
- 払えないカードは出せません。敵は払えない予兆が**休み**になります（§6）。

### 3.1 目盛り（叩き台。§18 K2 / K8）

高コストほど 1 スタミナあたり少し得にします。コスト 1 を並べる方針が常に最強になるのを避けるためです。

| 面                     | 列 1 | 列 2 | 列 3        | 列 4            |
| ---------------------- | ---- | ---- | ----------- | --------------- |
| 単属性アタック（威力） | 6    | 13   | 21          | 30              |
| 単属性ガード（Guard）  | 4    | 9    | 15          | 22              |
| 二属性のアタック面     | 4    | 8    | 14          | 20              |
| 二属性のガード面       | 3    | 6    | 10          | 14              |
| 単属性の回復（HP）     | 3    | 8    | 13          | 19              |
| 二属性の回復面         | 2    | 5    | 8           | 12              |
| 出血 / 再生のスタック  | 1    | 2    | 3           | 4               |
| 単属性のスキル（状態） | 1 種 | 2 種 | 3 種        | 3 種 + ドロー 1 |
| 二属性のスキル面       | 1 種 | 2 種 | 2 種 + 1 種 | 3 種 + 1 種     |
| スタンスの上乗せ       | +2   | +3   | +5          | +6              |

- 回復とスキルとスタンスの列は叩き台です。回復は攻撃の約 0.6 倍に置きました。
- **敵の面は、上の目盛りの約 6 割**です。値は `enemy_roster_v4.md` §0 が持ちます。
- 1 回きりだった状態（威圧 / 脆化 / 疲労 / 強化 / 集中 / 見切り / 俊敏 / 鈍足）もスタックで付きます。付与の既定は 2 スタックです。
- 崩し（相手のスタミナ −n）は目盛りを変えません。札の個性として付けます。
- 遠用の低い目盛り（4 / 6 / 9 / 12）と最適間合いの列は廃止しました。アタックの目盛りは 1 本です（§18 K7）。
- **届く間合いもコストの一部として数えます**（v4.3）。広く届く札は同じ列でも値を下げ、間合い 0 にしか届かない札は上げます。幅の目安は cards レーンが決めます（#160）。

v4.1 から変えない値は次のとおりです。

| --------------------------- | ------------------------------------------ |
| プレイヤー HP               | 50                                         |
| 敵 HP                       | 通常 50〜70 / 精鋭 90〜110 / ボス 160〜200 |
| 敵の 1 ターン出力           | 通常 7〜13 / 精鋭 10〜16 / ボス 13〜20     |
| 構え                        | 残 3 以上で Guard +3                       |
| 出血 / 再生（1 スタック）   | 2                                          |
| 最大スタミナ                | 基準 10（3〜14）                           |
| 階層間の休憩 / 階層内の休息 | 30% / 15%                                  |

## 4. スタンス

- **枠は 1 つ**です。スタンス面を持つカードをプレイすると枠に入ります。別のスタンスを出すと前のものは終わります（同じスタンスなら新しい列で置き直します）。
- 強さは**カードの列**で決まり、戦闘が終わるまで変わりません。戦闘終了で枠は空になります。
- **出したカードは戦闘中は山札に戻りません**（除外置き場へ）。同種を 3 枚入れると死に札になるので、1〜2 枚に抑える理由になります。
- 効果の型は 6 つです。カードはこのどれかを 1 つ持ちます。

| 型             | 例                                                            |
| -------------- | ------------------------------------------------------------- |
| ターン開始付与 | 毎ターン Guard +1 / HP +1 / ドロー +1 / 回復 +1               |
| 条件付き加算   | 間合い 0 での攻撃 +1 / 間合い 2 以上から使うムーブに Guard +1 |
| 被弾時の反応   | Guard が吸収した分の 1/3 を返す                               |
| 移動の補正     | 後ろへ動くとき Guard +1 / 前へ動くとき威力 +1                 |
| コストの割引   | 毎ターン 1 回、<属性> のカードのコスト −1                     |
| 敵行動への干渉 | 予兆の狙うマスの外に居るとき Guard +1                         |

- 敵もスタンスを持てます（精鋭・ボス）。表示は同じ枠で対称です。
- `when` の条件は間合いの境目で書きます。v4.2 の「遠間にいるターン開始だけ」は「いちばん近い敵との間合いが 2 以上のターン開始だけ」です。

## 5. 状態（スタック制。§17.5 / §18 K3 / §18 K4）

- 語彙は **10 語**に固定します。カードの文面は「**<状態名> を n 付与する**」で、n がスタック数です。
- **上限**: プレイヤーは状態の**種類**を 6 つまで持てます。敵は種類を数えません。ターンで減る型（出血 / 再生 / 俊敏 / 鈍足 / 疲労）は、1 つの語につき 4 スタックまでです（`TURN_DECAY_STACK_MAX`）。この上限はプレイヤーにも敵にも掛かります。使うと減る型のスタック数は数えません（§19.5 S14）。
  - 付けて 4 を超える分は捨てます。4 スタックの語にさらに付けても 4 のままです。付与は拒まれず、語は付いたまま残るので、その語を条件にする特性（自分の状態(再生) など）も成り立ちます。7 種類目は付与そのものが拒まれて語が付かないので、この点が違います。
  - 上限を置くのは、付く速さが減る速さを上回っても溜まらないようにするためです。この型は、付いた側のターン開始に 1 しか減りません。一方で、付与の既定は 2 スタックで、敵は毎フェーズ付け直せます。精鋭とボスは 1 フェーズに 2 回行動します。このため上限が無いと、再生や疲労が戦闘の長さに比例して育ちます（#205）。
  - 4 は、目盛りの列 4 で付く出血 / 再生のスタック数（`swordsman_cards_v4.md`）と同じ値です。既定の 2 を 2 回付けた分も丸ごと入ります。
  - 出血と再生が 1 ターンに動かす HP は 2 × 4 = 8 までです。ボス戦の目安の上限 18 ターン（§13）を通しても 144 です。このため、いちばん HP の低いボス（160）を出血の tick だけで倒すことはできません（§19.8 の 4 の止め役）。
  - この上限は 2026-09-26 の battle レーンの案で、こうだいさんの確認待ちです（§14 の 18、§23）。
- 減り方は 2 つの型に分かれます。**使うと減る型**は効果が出るたびに 1 減り、**ターンで減る型**は付いた側のターン開始に 1 減ります。
- 相手に付ける状態の「diff 0 のときだけ発動」という条件は廃止しました。届く間合いの中なら付きます（§2.4）。

| 語     | 向き   | 効き方                                                                     | 減り方       |
| ------ | ------ | -------------------------------------------------------------------------- | ------------ |
| 出血   | 相手に | 相手のターン開始に HP −2 × 残りスタック                                    | ターンで減る |
| 脆化   | 相手に | 次に受ける攻撃の raw ×1.5                                                  | 使うと減る   |
| 鈍足   | 相手に | 次のターン全体、自分で動くマスと、自分が押す / 引くマスが 1 減る（下限 0） | ターンで減る |
| 威圧   | 相手に | 次の行動の値を −3（威力と Guard。旧表のほぼ 1 列分）                       | 使うと減る   |
| 疲労   | 相手に | 次のターン開始のスタミナ回復 −1                                            | ターンで減る |
| 強化   | 自分に | 次のアタック面の威力 **×1.5**                                              | 使うと減る   |
| 集中   | 自分に | 次の札を **1 列右**で解決する（列 4 は超えない）                           | 使うと減る   |
| 見切り | 自分に | 次の被弾で Guard が吸収した分の半分を相手に返す                            | 使うと減る   |
| 俊敏   | 自分に | 有効なターンの開始時に、1 マスだけ無料で前か後ろへ動ける                   | ターンで減る |
| 再生   | 自分に | ターン開始に HP +2 × 残りスタック                                          | ターンで減る |

- 「俊敏」は v4.1 の「軽足」の改名です。v4.3 で、ターン開始の「近間 / 遠間の選択」を「無料の 1 マス」に読み替えました。
- 「鈍足」は次のターン全体に効きます。2 回行動の敵なら 2 手とも効きます。**減るのは、付いた側が起こすマスの変化です。** 自分のムーブ面と、自分が撃つ押す / 引くの両方が 1 マス減ります（§20.1 の読み替え。§21.3）。
  - 1 マスの移動と 1 マスの押しは 0 になり、v4.2 と同じく止まります。2 マスのものは 1 マスになります。
  - 減るのはマスの数だけです。札も行動も出せて、コストを払い、同じ面の威力・Guard・状態は通常どおり解決します。
  - **相手が撃つ押す / 引くは減りません。** プレイヤーに鈍足が付いていても、敵の押し返しはプレイヤーを動かします。
  - 付与の既定は 2 スタックです。付いた側のターン開始に 1 減って 1 が残るので、次の自分の番のあいだ効き、その次の番の開始で消えます。
- **ボス専用の状態**: ボスは上の 10 語に加えて専用の状態を 2 つ持ちます（`enemy_roster_v4.md`）。例は瘴気纏い（この戦闘中プレイヤーの最大スタミナ −1、重ねて −2 まで）です。最大が下がったときは、現在値を新しい最大まで削ります。専用の状態は予兆で見えて、対処できる形にします。

### 5.1 ダメージ式（§17.6 F4）

足してから掛けます。

```
(面 + 特性 + 追撃 + 転換) × 強化 1.5 × 脆化 1.5 → 丸め（AwayFromZero）→ − Guard
```

- 多段（`hits`）では、追撃は各撃に乗せません。特性の +n と強化は全ての撃に乗ります（F6）。
- 追撃は番の終わりで消えます。プレイヤーはターン終了、敵はフェーズの終わりです（F7）。
- HP が 0 になった瞬間に倒れます。出血の tick・見切りの返し・被弾のどこでも同じです（F9）。

## 6. 予兆と敵 AI

- 予兆は**コミット式**です。敵は次の行動を先に見せ、その通りに実行します。読み合いは予兆に対して行います。
- **予兆に出す情報は「種別 + 狙うマス」です**（v4.3）。狙うマスは、その行動の届く間合い（§2.4 の `reach`）に入るマスで、床に出します。v4.2 の「咎める側の一字（近 / 遠）」はやめました。開示度で出る量が変わります（表は `battle_ui_ux_v2.md` が正本）。
  - **狙うマスは、敵のいまのマスから数えます。** 敵が動いたり押されたりすると、狙うマスも一緒にずれます。
  - **当たるかどうかは、実行の時点の N で決めます。** 予兆を見てから狙うマスの外へ出れば避けられます。敵を押して届かなくしても避けられます。
  - 行動が間合いの境目を読むとき（「間合い 2 以上なら威力 +3」）は、境目を満たすマスを濃く出します。
- **空振り**（v4.3 で復活）: 実行の時点で相手が届く間合いの外にいたら、その行動の**相手向きの面**（アタック、相手に付けるスキル、押す / 引く）は解決しません。コストは払い、自分向きの面（ガード、ムーブ、自分に付けるスキル）は解決します。予兆のコミットは崩さず、行動を替えることもしません。
- **払えない予兆は休みになります**（§17.2）。技は出ず、そのフェーズは回復だけで終わります。予兆のコミットを崩さないための扱いです。
- **プレイヤーの札は空振りしません。** 届く間合いの外の相手には、そもそも出せないためです（§2.4）。

### 6.1 決定木の枝

| 枝            | 見るもの                   |
| ------------- | -------------------------- |
| 間合い 0      | プレイヤーと隣り合っている |
| 間合い 1〜2   | 1〜2 マス空いている        |
| 間合い 3 以上 | 3 マス以上空いている       |

- **全ての敵が、この 3 枝を持ちます。** 枝を決める N は、予兆を決める時点（§9 手順 12）の値です。v4.2 の「位置なし 2 枝 / 位置あり 4 枝」は置き換えました。
- **どの枝にも、その間合いで意味のある行動を 1 つ以上置きます。** 間合い 3 以上の枝には、前へ出る行動か、遠くへ届く行動を必ず置きます。何もできない枝を持つ敵は作りません。
- **通常の敵もムーブ面を持ちます**（2026-09-22 の決定）。敵のムーブ面もカードと同じ「前へ n / 後ろへ n」で、アタックのあとに解決します（§2.2）。
- **居続け対策**: 敵ごとに「得意な間合い」を持たせ、そこから外れた相手を戻す行動（押す / 引く / 自分が動く）を決定木に置きます。詰め続ける相手を咎める行動と、離れ続ける相手を咎める行動を、各敵に 1 つ以上置きます（§19.4 S11 の読み替え）。

### 6.2 最大スタミナの例外

v3 §3.1「戦闘中に最大値は変わらない」の唯一の例外が、ボス専用の状態「瘴気纏い」です。戦闘中に −1〜−2 し、戦闘終了で戻ります。最大が下がったときは現在値を新しい最大まで削ります。探索側の瘴気ゲージには影響しません。

## 7. マスと間合い、複数体の戦闘

### 7.1 場とマス

- **戦闘の場は横 1 列のマスです。** マスは左から 1, 2, 3… と数えます。プレイヤーは左側、敵は右側に立ちます。
- **マスの数は、戦闘の開始時に受け取る値です**（`FIELD_CELLS`、2026-09-23）。既定値は持ちません。範囲は 5〜8 で、層と戦闘ごとの値は探索側が決めます（#168）。大きな敵の戦いは広く取ります。縦切りの試験は 6 マスで戦います。
- **プレイヤーと全ての敵が、立っているマスを持ちます。** HP・Guard と同じ常設の値で、状態の枠には数えません。v4.2 の「位置を持たない敵」はなくしました。
- **1 つのマスに入れるのは、プレイヤー 1 人か、敵 1 体です**（`CELL_CAPACITY`、2026-09-23）。プレイヤーと敵は同じマスに入れません。
- **大きな敵は複数のマスを使います。** 敵の定義が「大きさ」（使うマスの数。1〜3）を持ちます。大きな敵が使うマスには、ほかの敵は入れません。
- **追い越しはできません。** プレイヤーは、いちばん手前の敵が使うマスより右へ行けません。敵は、プレイヤーのマスより左へ行けません。敵どうしは、行き先のマスに空きがあればすれ違えます。

### 7.2 間合い N

- **間合い N は、自分と相手のあいだにある空きマスの数です。** 隣り合っていれば 0 です。プレイヤーがマス 1、敵がマス 6 なら N = 4 です。式は `N = 相手の近い端のマス − 自分のマス − 1` です。
- **大きな敵との間合いは、近い端のマスから数えます。** マス 4〜6 を使う竜と、マス 2 のプレイヤーの間合いは 1 です。大きい敵ほど離れにくくなります。
- **N は敵ごとに別の値です。** 敵は 1 体ずつ別のマスに立つので、2 体の敵が同じ N になることはありません。画面には、いま選んでいる相手との N を 1 つだけ出します（`battle_ui_ux_v2.md` が追従するまでは本節が正です）。
- **素の効果はありません。** N そのものは、ダメージ・回復・崩しを変えません。カード・特性・敵の行動が、N を次の 2 通りで読みます。
  1. **届く間合い**（`reach`、§2.4）: 「間合い 0〜1 に届く」。外なら、その相手には出せません。
  2. **間合いの境目**（§2.3）: 「間合い 2 以上なら威力 +5」。境目は 1 枚に 1 つまでです。
- **「N 1 につき +x」のように N を掛ける効果は、80 種のうち 4 枚までにします。** 暗算できる数の原則（v3 §1.2）を守るためです。
- **よく使う N は 0〜3 です。** 届く間合いの上限が 3 以上のカードは少数にします。N が 4 以上は「届く札がほぼ無い、仕切り直しの距離」として扱います。
- **名前に引かれない配分は引き継ぎます。** 間合いを読む効果を、「攻撃の効果 / 防御の効果 × 詰めて得 / 離れて得」の 4 マスに同数ずつ配ります。敵の行動にも、詰めた相手を咎めるものと離れた相手を咎めるものを両方置きます。

### 7.3 動く、押す、引く

- **自分で動くのはムーブ面です。** 「前へ n」は相手の側へ、「後ろへ n」は自分の側の端へ n マス動きます。n は 1 か 2 です。
- **行けるところまで動きます。** 端や、入れないマスに当たったら、その手前で止まります。1 マスも動けなくても、札は出せて、ほかの面は通常どおり解決します。
- **押す / 引く**（`push` / `pull`）は、相手を n マス動かします。押すは自分から遠ざけ、引くは自分へ近づけます。Guard では減りません。**プレイヤーの札も持てます**（v4.2 の「敵だけ」をやめました）。
- **壁のダメージ**: 押された側が、端や入れないマスに当たって n マスぶん動けなかったとき、動けなかった 1 マスにつき 3 のダメージを受けます（`WALL_DAMAGE`。叩き台）。Guard で減ります。引くには壁のダメージがありません。
- **大きさ 2 以上の敵は、押す / 引くを受けません。** 壁のダメージも受けません。
- **開始のマス**: プレイヤーはマス 2 から始めます（後ろに 1 マスの余裕があります）。敵は、プレイヤーとのあいだに 3 マスをあけて始めます（`START_GAP` = 3、2026-09-23）。6 マスの場なら敵はマス 6 です。出立のツールでプレイヤーの開始のマスを変えられます。
- **場が狭くて入らないとき**は、敵を右端に置き、そのぶん開始の間合いを縮めます。5 マスの場なら間合い 2、6 マスの場の大きさ 3 の敵ならマス 4〜6 で間合い 1 です。プレイヤーのマスと後ろの余裕は動かしません。2 体目からの置き方は §7.4 です。
- **毎ターンの無料の 1 歩は置きません**（2026-09-22 こうだいさんの決定）。敵も自分で間合いを動かすので、まず素の規則で試します（§13、§14）。

### 7.4 複数体

- **同時に出る敵は 3 体までです**（`ENEMIES_MAX`）。1 体ずつ別のマスに立ちます。80% では 1 体が基本です。2〜3 体の戦いは、それぞれが自分の予兆と決定木を持つ敵を、別々のマスに並べて作ります（2026-09-23）。
- **2 体目からの開始のマス**: 敵定義の並びの順に、前の敵の奥（右）の空いたマスへ詰めて置きます。場に入りきらない組み合わせは出せません。組み合わせる側が場を広く取ります。
- **各敵が自分のマス、自分の予兆、自分のフェーズを持ちます。** フェーズの順番は敵定義の並びです。
- **手前の敵が奥の敵をかばいます。** 規則として「かばう」を置くのではなく、届く間合いの結果です。手前の敵と N = 0 のとき、その後ろのマスの敵とは N = 1 で、間合い 0 にしか届かない札は奥へ届きません。
- **相手指定**は `targets` = one（受け皿で 1 体）/ all（届く間合いの中の全員）/ self / ally です。アタック面は one が既定です。all は規則として置き、80% で作る枚数は cards レーンが決めます。v4.3 の cell（1 つのマスにいる全員）は外しました。1 つのマスに敵は 1 体なので、one と同じになるためです。
- **自分向きの札が間合いの境目を読むときは、いちばん近い敵との N を読みます。**
- **all の札の特性は、届く間合いの中でいちばん近い敵の N と Guard を読みます。** 特性は 1 枚に 1 回だけ判定するためです（§2.2）。威力はその値のまま、当たる全員に 1 撃ずつ入ります。
- **押す / 引くが複数の敵に当たるとき**は、押すなら奥の敵から、引くなら手前の敵から動かします。隣の敵が動く前に塞がれることを避けるためです。押された敵がほかの敵のマスに当たって動けなかったときも「入れないマス」として壁のダメージを受けます（§7.3）。
- **敵が 1 体倒れても、ほかの敵が立っていれば戦いは続きます。** 倒れた敵はすぐにマスを空け、予兆も消えます。倒した札の残りの面は、そのまま解決します。全ての敵が倒れたら勝ちです。

## 9. ターン進行

```
[プレイヤーターン開始]
  1. Guard を 0 に
  2. スタミナを 3 回復（固定）。疲労が付いていれば −1
  3. スタンスと状態のターン開始効果（Guard +1 / 再生 / 出血の tick / ドロー補正 / 俊敏の無料の 1 マス）
  4. 手札を引く（5 + 補正）。捨てるのはターン終了の手順 8
  5. 敵ごとの予兆を表示（精鋭・ボスは 2 段。2 手目は「予定」）
[プレイヤー行動]（払える限り何枚でも）
  6. カードと相手を決める（届く間合いの外の相手は選べない）→ 特性を判定 → §2.2 の順で面を解決 → 撃破判定
     コストを払う。「このターンにプレイした属性」を記録する
[ターン終了]
  7. 構え判定（残スタミナ 3 以上 → Guard +3）
  8. 手札を全て捨てる、playedAttributes を消す
[敵フェーズ]（敵ごとに順に）
  9. Guard を 0 に → 敵ごとの回復値でスタミナを回復 → スタンスと状態のターン開始効果
 10. 予兆どおりに実行（コストを払えなければ休み。相手が届く間合いの外なら相手向きの面は空振り）。精鋭・ボスは 2 行動
 11. 敗北判定
 12. 次の予兆を決める（その時点の間合いの帯で枝を選ぶ。ボスは適応の条件を見てから）
```

手順 2 の回復を固定 3 にしたのは、コスト 0 の札がなくなり、1 ターンに 2 枚以上出す前提を保つためです（§18 K1）。連動 / 連打 / 締め / 手薄の 25 個の特性が、この前提の上に乗っています。

## 12. 連戦モード（試験運用の最初の形）

実装フェーズは **連戦モードを最初の目標**にします。単発の戦闘を作ってから繋ぐのではなく、最初から「続けて戦う」形で作り、HP とスタミナの持ち越し・デッキの巡り・スタンスの置き直しを一度に確かめます。

- 起動時に戦う順番を渡します。既定は 3 戦（長柄の歪み兵 → 影走りの犬 → 甲冑の番人）で、`-chain a,b,c` で変えられます。**9 戦の並びも選べます**（§17.9）。
- 戦闘の間に探索は挟みません。代わりに「階層間の休憩」相当を**毎回選べます**（HP 30% 回復 + スタミナ全回復、または回復なしで次へ）。この選択が探索側の判断の代役になります。
- HP・スタミナ（現在）・瘴気ゲージ・階層は次の戦闘へ持ち越します。瘴気は戦闘ごとに濃度 × 3% 蓄積します。
- 敗北で連戦は終わり、結果画面に「何戦目、残 HP、使ったカードの属性の内訳、**特性の発動回数**、平均ターン数」を出します。
- **全勝したときは同じ並びをもう一度回します。** 結果はログファイルに書きます（`chain-<日時>.json`）。

### 16.4 間合い（近間 / 遠間）の規則（決定）

- **値**: プレイヤーと敵 1 体ごとに、常に近間か遠間のどちらかを持ちます。HP・Guard と同じ常設の値で、状態の 4 枠（`:189`）には数えません。
- **距離の廃止**: 共有の近 / 中 / 遠、3 段の補正（×1.0 / ×0.5 / ×0.15）、空振り回避をなくします。
- **素の効果なし**: 近間 / 遠間そのものは、ダメージ・回復・崩しを変えません。カード・特性・敵の技が、自分と相手の組（4 通り）を条件として読みます。組の名前は画面にもカードの文面にも出しません。
- **名前に引かれない配分**: 間合いを条件にする効果を、「攻撃の効果 / 防御の効果 × 近間 / 遠間」の 4 マスに同数ずつ配ります。敵の技にも、相手の近間を咎めるものと遠間を咎めるものを両方置きます。
- **切り替え**: ムーブ面を持つカードで切り替えます。旧 詰めは近間へ、旧 退きは遠間へ、向きを選ぶ面は反転です。敵の押し返し / 誘いは、相手の間合いを変える技として残します。
- **画面**: 近間の個体は前へ出て、遠間の個体は下がって立ち、足元に「近」「遠」の一字札を置きます（`battle_ui_ux_v2.md` §10.6）。
- **v4.2 で詰めるもの**: 回復の決め方（いまは距離で +1 / +2 / +3）、予兆に出す情報、決定木を組の 4 枝で書く形、2 体戦で 1 回の切り替えが 2 つの組を同時に変える扱い、戦闘開始時の間合い。2026-09-16 の決定で決着しました（→ §17.3）。
- **最初に測る危険**: 片方の間合いで終え続ける方針が最強になること、両者が遠間のまま膠着すること、手札に切り替えの札が来ないこと（ムーブ面は初期 40 種中 10 種で、5 枚に 1 枚も無い確率は約 24%）。
- **捨てるもの**: v3 で検証した 3 段の勾配と空振り回避（`battle_core_v3.md:58-62`, `:178-180`）です。「実距離と体勢で見せる」（`battle_ui_ux_v2.md:8`）は、立ち位置で見せる形に置き換えます。
- **比べた読み**: 採点（忠実度を 2 倍、30 点満点）は、この形（モデル A）が 23、組から近 / 中 / 遠を導く形（B）が 19、距離を残して足す形（C）が 15 でした。

### 17.2 固定コスト（§16.5 の保留を決着）

**旧段表の列が、そのままコストになります。** カードごとに T0〜T3 から 1 列を選び、列番号がコスト、その列の値が効果です。投入量の廃止（§16.2 決定 3）は変わりません。段表はプレイヤーが選ぶ幅ではなく、カードを作るときの目盛りとして残します。

- **列の選び方**: 特性の条件で選びます。満たしにくい条件（死力 / 崩し後 / 相手の状態）を持つ札ほど低い列、つまり安くします。
- **コスト 0**: 習熟でだけ 0 になります。初期はカードも敵の技も、コスト 1 以上です。
- **§3 の扱い**: T0〜T3 の値（§3.1）は残します。minInvest と 0 投入の枚数制限は §16.3 のとおり廃止のままです。

語の読み替えは次のとおりです。

| 語              | 旧（投入量の時代）         | 2026-09-16 の決定                                                                                      |
| --------------- | -------------------------- | ------------------------------------------------------------------------------------------------------ |
| 特性「投入 −1」 | この 1 枚の投入を −1       | **コスト −1**（下限 0）。習熟の「軽さ」と同じ働き                                                      |
| 特性「重撃」    | 投入 +1 を払って威力 +6    | **次の回復で払う**。条件を満たすと威力 +6、次のターン開始の回復 −1。今のターンのコストと構えは変えない |
| 状態「集中」    | 次のカードの投入 +1 を無料 | **次の札を 1 列右で解決**。習熟の「伸び」の 1 回きり版                                                 |
| 状態「威圧」    | 次の行動の投入量 −1        | **次の値を −3**。相手の次の行動の威力と Guard を 3 下げる（旧表のほぼ 1 列分）                         |
| 払えない予兆    | 規定なし                   | **休みになる**。予兆の技は出ず、そのフェーズは回復だけで終わる（予兆のコミットを崩さない）             |

### 17.3 近間 / 遠間の詰め（§16.4 の「v4.2 で詰めるもの」を決着）

**位置を持つ敵は、ボスと精鋭だけです。** 瘴気の司祭・甲冑の番人・群れの長の 3 体が近間 / 遠間を持ちます。通常敵 6 体は持ちません。プレイヤーは常に持ちます。

- **カードの位置条件**: 自分の位置だけを読みます。相手の位置を条件にする札は作りません。
- **読む時点**: 常に動く前です。全ての札で、出す前の位置で判定します（旧 moveFirst の印は置きません）。
- **決定木の枝**: 位置を持たない敵はプレイヤーの位置で 2 通り、位置を持つボス・精鋭は 4 通りです。

| 項目               | 決定                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 回復の決め方       | 固定値 + 札の上乗せ。基本は毎ターン同じ量で、上乗せを特性とスタンスに配る（近間と遠間へ同数ずつ） |
| 予兆に出す情報     | 種別と咎める側の一字。「攻撃・遠」のように、効果が乗る側を一字で出す                              |
| 2 体戦の咎め方     | 取り巻きは位置を見ない。位置の判断は長にだけ向ける                                                |
| 2 体戦の自分向き札 | 自分の位置だけ読む。基準の敵は画面に出さない                                                      |
| 敵の開始位置       | 位置を持つ敵だけ、敵ごとに定義する                                                                |
| 自分の開始位置     | 毎戦同じ位置。出立のツールで変更できる                                                            |
| 居続け対策         | 敵ごとに主に咎める側を持たせ、逆側にいる相手を主な側へ戻す技（押し返し / 誘い）を決定木に置く     |

**測ってから決めるもの**は 2 つです。手札に切り替えの札が来ない危険（約 24%、§16.4）と、両者が遠間のままの膠着です。規則もカードの配分も今は変えず、試験台で測ってから判断します。位置を持つ敵がボス・精鋭だけになり、膠着の起きる場面が減ったためです。

### 17.4 背水の陣（§16.7 の保留を決着）

**遠間と死力を重ねる札です。** 自分が遠間のとき攻撃が伸び、スタミナ 2 以下でさらに上乗せします。

- **条件は自分の値だけ**です（自分が遠間 + 自分のスタミナ 2 以下）。位置を持たない通常敵にも効きます。
- **形は単属性のアタック**です。
- **叩き台**: 威力 8、遠間で +5、スタミナ 2 以下でさらに +3。コストは §17.2 の決め方で置きます。

### 17.5 状態（スタック制へ全面変更。§5 を置き換え）

**状態はスタック制に揃えます。** カードの文面は「<状態名> を n 付与する」で、n がスタック数です（例: 俊敏を 3 付与 = 3 ターン続く）。溜まり方と減り方は、状態ごとに変えてよいものとします。

- **既定の減り方**: 付いた側のターン開始に 1 減ります。
- **1 回きりの状態も揃えます**: 威圧・脆化・疲労・強化・集中・見切りを、全てスタックにします。
- **出血・再生**: スタックが強さと回数の両方を兼ねます。出血 3 は毎ターン HP −2 × 残りスタックで、−6 → −4 → −2 と減ります。

| 項目             | 決定                                                                        |
| ---------------- | --------------------------------------------------------------------------- |
| 上限             | プレイヤーは状態の種類 6 つまで。敵には上限を置かない。スタック数は数えない → 2026-09-26（#205）: ターンで減る型だけ 1 語 4 スタックまで。battle レーンの案で、こうだいさんの確認待ち（§5、§23） |
| 「軽足」の改名   | **俊敏**。効果は「有効なターンの開始時に近間 / 遠間を選べる」               |
| 「鈍足」の範囲   | 次のターン全体。2 回行動の敵なら 2 手とも切り替えを止める                   |
| 瘴気纏いの現在値 | 最大スタミナが下がったとき、現在値を新しい最大まで削る                      |

§1 の「片側 4 つまで」（`:39`）と §5 の「片側 4 つまで / 段数は 3 まで」（`:189`）は、上の表で置き換えます。

## 19. 2026-09-21 の決定（投入量の代わりのシナジー）

> **Status**: Issue #62 の 6 つの問いへの回答です。§16 / §17 / §18 の上に載せ、食い違うときは本節が優先します。カード 1 枚ずつの数値と、状態の語 10 / スタンスの型 6 には手を付けていません。
> **数値**: 「叩き台」と書いた数値は仮です。試験台（§13 の基準 10〜14）で測ってから確定します。
> **結論**: 新しい軸は足しません。いまの 5 つの軸を「時間の 4 層」として並べ直し、層ごとに何が起きるかを決めます。

### 19.1 時間の 4 層（答えの骨格）

投入量が無くなって空いたのは「1 枚をどれだけ強く出すか」の判断です。そこへ別の 1 枚ごとの判断を入れ直すのではなく、**判断の置き場を時間の長さで 4 つに分けます**。料理に例えると、1 品ごとの味付けをやめて、切る順・火を入れる順・献立・買い出しへ判断を移したかたちです。

| 層  | 長さ            | 何で遊ぶか                                     | 既にある部品                          |
| --- | --------------- | ---------------------------------------------- | ------------------------------------- |
| 1   | 1 枚            | 属性 1〜2 と特性 1                             | §2.1 / §2.3                           |
| 2   | 1 ターン        | 枚数の階段（初手 → 連動 / 連打 → 締め / 手薄） | 特性の条件 30 枚                      |
| 3   | 2 ターンの往復  | 溜めと放ち、間合いの振り子、状態の貯金         | スタミナ 10 / 回復 3、ムーブ 6 種、K3 |
| 4   | 1 戦と 1 つの生 | スタンス枠 1、習熟の 3 型                      | §4、§17.8                             |

層 2 と層 3 が、これまで名前を持っていませんでした。本節はこの 2 層に規則を置きます。

### 19.2 1 ターンの中の組み合わせ（問い 1）

**回復 3 のままで足ります。** ただし毎ターン 2 枚を平らに出す形ではなく、1 枚のターンと 3〜4 枚のターンを交互に置く形にします。

枚数を条件にする特性は 30 枚です（連動 14 / 初手 5 / 連打 5 / 締め 3 / 手薄 3。§4.2）。#62 の本文と §18.1 の「25」は、初手 5 を数えていません。

スタミナは最大 10、回復は毎ターン 3 です。3 スタミナで列 1 の札を 3 枚出すと残りが 0 になり、構え（残 3 以上で Guard +3）が付きません。3 枚出して構えも取るには 6 スタミナが要ります。つまり **1 ターン 3 枚以上は、前のターンに溜めた分でしか払えません**。ここが層 3 の入口です。

| 条件        | 何枚目で発火するか | 出る頻度                                 |
| ----------- | ------------------ | ---------------------------------------- |
| 初手        | 1 枚目             | 毎ターン                                 |
| 連動 / 連打 | 2 枚目             | 放ちのターンと、列 1 を 2 枚出せたターン |
| 締め / 手薄 | 3 枚目以降         | 放ちのターンだけ                         |

| #   | 決定                                                                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | 回復は **3 のまま**にします。4 には上げません。上げると溜めが要らなくなり、層 3 が消えます                                                                                 |
| S2  | 締めは **「3 枚目以降」のまま**にします。放ちのターンの報酬として残します                                                                                                  |
| S3  | 手薄を **「プレイ後の残り手札 2 枚以下」** に緩めます。5 枚から 3 枚出した時点で、締めと同時に発火します。旧定義（1 枚以下）は 4 枚出す必要があり、1 戦に 1 回も届きません |
| S4  | 敵側の語「無防備」（§17.6 F1）は変えません。定義が別物のためです                                                                                                           |

S3 で、締め 3 枚と手薄 3 枚の計 6 枚が、同じ「放ちのターン」の報酬に揃います。狙う場面が 1 つになるので、プレイヤーが覚えることは増えません。

### 19.3 戦闘をまたぐ組み合わせ（問い 2）

**3 型は「その札の何が足を引っ張っているか」で配ります。** 型の意味を 1 語ずつに決めます。伸びは強くなる、軽さは軽くなる、型替えは当たるようになる、です。

| 型     | 配る先                                                              | 直すもの       | 目安の枚数（60 種中） |
| ------ | ------------------------------------------------------------------- | -------------- | --------------------- |
| 伸び   | 列 1〜2 の札                                                        | 出せるが弱い   | 28                    |
| 軽さ   | **列 2〜3 の札だけ**                                                | 強いが出せない | 14                    |
| 型替え | 満たしにくい条件を持つ札（死力 / 崩し後 / 相手の状態 / 自分の状態） | 条件が合わない | 18                    |

| #   | 決定                                                                                                                                                                                                                                              |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S5  | **軽さを列 1 の札に配りません**。列 1 に置くと段 1（刻み 3）でコスト 0 になり、毎ターン 5 枚出せてしまいます。コスト 0（§17.2）は、列 2 の札が段 2（刻み 8）に届いたときか、列 3 の札が段 3（刻み 15、1 つの生で 1 枚）に届いたときだけ生まれます |
| S6  | **型替えは効果を変えず、条件だけを 1 段ずつ緩めます**。数値が動かないので、カード 1 枚ずつの調整（#53）と干渉しません                                                                                                                             |
| S7  | 条件が緩む順を 3 本の道に決めます。枚数の道は 手薄 → 締め → 連打 → 連動 → 初手、資源の道は 死力 → 温存 → 初手、読みの道は 相手の状態 → 崩し後 → 予兆 です                                                                                         |
| S8  | **型替えの札だけ、閾値を 2 / 6 / 12 にします**（ほかは 3 / 8 / 15 のまま）。型替えの札は条件が満たしにくく、刻みの 4 文脈のうち「特性の発火」を最初は取れません。同じ閾値だと、一番育てたい札が一番育ちません                                     |

型替えの例です。観察（#22、手薄: ドロー +1）が、精査（締め: ドロー +1）→ 洞察（連動(Sk): ドロー +1）→ 看破（初手: ドロー +1）と進みます。効果は最後までドロー +1 のままで、発火する場面だけが「放ちのターンだけ」から「毎ターン」へ広がります。

「この札を育てたい」という理由は、この 3 語のどれが欲しいかで決まります。主力を重くしたいなら伸び、決め技を早く出したいなら軽さ、死んでいる特性を生かしたいなら型替えです。才能（開始時に 1 枚、刻み 2 倍）は、型替えの札に置くのが一番効きます。

### 19.4 位置と特性の噛み合い（問い 3）

**片側に居続ける方針は弱くします。** ただし居続けを罰するのではなく、振ると得をする形で弱くします。

居続けが強くなる理由は 2 つです。位置を条件にする 16 枚（K6）が 4 マスに均等なので、片側へ寄せたデッキなら 8 枚が常に発火します。切り替えはムーブ札 1 枚とスタミナ 1 を払います。払わない側が得です。

これを層 3 の往復に重ねて解きます。溜めのターンは守り、放ちのターンは攻めます。守りの札は片側、攻めの札はもう片側で伸びます。**溜めで遠間、放ちで近間**という振り子が、そのまま「守って溜める → 動いて放つ」になります。ムーブ札 1 枚は放ちのターンの 6 スタミナから払うので、溜めのターンの手数を削りません。

| #   | 決定                                                                                                                                                                                                              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S9  | K6 の 4 マス均等（各 4 枚）を変えません。片側へ寄せると振り子が消えます                                                                                                                                           |
| S10 | ムーブ単属性 6 種（K5）の付随効果を向きで分けます。**近間へ 2 枚 = スタミナ +1 / ドロー 1**（放ちを伸ばす）、**遠間へ 2 枚 = Guard 4 / ドロー 1**（溜めを守る）、**反転 2 枚 = Guard 4 / スタミナ +1**            |
| S11 | 敵 9 体すべてに、**近間を咎める技と遠間を咎める技を 1 つずつ以上**持たせます。位置を持たない通常敵 6 体も、プレイヤーの位置で 2 通りに枝分かれします（§17.3）。どちらに居続けても、予兆の約半分が当たりになります |
| S12 | 切り替えの札が手札に来ない危険（約 24%、§16.4）は規則で直しません。ムーブ面を持つ札をデッキへ何枚入れるかを、プレイヤーの判断として残します                                                                       |

止め役は鈍足です。次のターン全体の切り替えを止めるので（§17.5）、振り子は 1 往復を飛ばされます。2 回行動の敵なら 2 手とも止まります。

### 19.5 状態の 2 型の使い分け（問い 4）

**溜めてから一気に使う遊び方は成立させます。** 止め役は「1 撃に乗る倍率は 1 つまで」です。

使うと減る型（強化 / 脆化 / 集中 / 見切り / 威圧。K3）は、使うまで減りません。溜めのターンに積み、放ちのターンに 3〜4 枚のアタックで使い切る形が、そのまま層 3 に乗ります。これは狙いどおりです。

問題は倍率の重ね掛けです。強化 ×1.5 と脆化 ×1.5 が同じ 1 撃に乗ると ×2.25 になり、列 3 のアタック 21 に特性 +6 と追撃 +5 を足した 32 が 72 になります。通常敵の HP は 50〜70 なので、1 撃で落ちます（§18.4-3）。

| #   | 決定                                                                                                                                                                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S13 | **1 撃に乗る倍率状態は 1 つまでにします。乗る順は 脆化 → 強化 です。** 両方付いているときは脆化を 1 消費し、強化は消費せず次の撃へ回ります。§17.6 F4 の式は `(面 + 特性 + 追撃 + 転換) × 倍率 1 つ → 丸め（AwayFromZero）→ − Guard` になります |
| S14 | 上限は置きません。スタック数の上限（§17.5）も、溜められるターン数の上限も置きません。溜めている間は敵の HP が減らないことが、そのまま値段です                                                                                                  |

S13 で、強化 3 と脆化 3 は「3 撃が ×2.25」ではなく「6 撃が ×1.5」になります。1 撃の最大は 32 × 1.5 = 48 に下がり、手数を増やす向きへ働きます。手数が増えると締めと手薄（S3）も発火します。層 2 と層 3 が同じ方向を向きます。

ターンで減る型（出血 / 再生 / 俊敏 / 鈍足 / 疲労）は溜まりません。積み直しが要るので、別の遊び方（血路、§19.8 の 4）になります。

（2026-09-26、#205）S14 の「スタック数の上限（§17.5）も」は、使うと減る型の話として読みます。ターンで減る型は 1 語 4 スタックまでにする案で、こうだいさんの確認待ちです（§5、§23）。

止め役はもう 2 つあります。溜めのターンは出力がほぼ 0 で、敵の 1 ターン出力 7〜13 をそのまま受けます。ボス専用の状態 瘴気纏い（最大スタミナ −1〜−2、§6.3）は、溜められる量そのものを削ります。

### 19.6 スタンス枠 1 の重み（問い 5）

**1 戦に 1〜2 回が良い回数です。**

通常戦は 6〜10 ターン、ボス戦は 12〜18 ターンです（§13）。スタンスは戦闘が終わるまで続くので、置き直すと前の型の残りターンを捨てます。1 ターン目に 1 枚置き、戦いの形が変わる 5〜6 ターン目にもう 1 枚置くのが上限です。3 回以上置けるなら、1 枚が軽すぎるか弱すぎます。

いまのままだと多すぎます。スタンス面を持つ札は 80 種中 15 種です。デッキ 20〜40 枚へ素直に混ぜると 4〜7 枚入り、引くたびに置き直す形になります。

| #   | 決定                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------- |
| S15 | **出立の検証で、スタンス面を持つ札をデッキ 3 枚までに制限します**（`DeckRules.cs`）。同種 3 枚の上限とは別の制限です |
| S16 | スタンスのカード 1 枚ずつの強さは変えません。3 枚制限で回数が決まるので、数値を動かす必要がありません                |

止め役は 2 つです。出したスタンスは除外置き場へ行き、戦闘中は引き直せません（§4）。置いた型が敵の形と噛み合わなくても、1 戦それで通します。§13 の「スタンス無しデッキの勝率が最強 −15 pt 以上」が、必須化の上限を押さえます。

### 19.7 新しい軸（問い 6）

**足しません。**

5 つの軸で足ります。足りなかったのは軸ではなく、層 2 と層 3 の名前でした。本節はその 2 層に規則（S1〜S17）を置いただけで、プレイヤーが覚える語も、画面に出す値も増やしていません。

画面に足すものもありません。枚数の階段はカードの特性の文面がそのまま見せます。溜めと放ちはスタミナの帯が見せます。間合いは足元の一字札が見せます（§16.4）。スタンスは枠が見せます。どれも既に決まっている表示です。

## 20. 2026-09-21 の決定（#116: 鈍足と予兆の一字）

> **Status**: 縦切りの仕分け（#68）で見つかった `enemy_roster_v4.md` §2.1 との食い違い 2 件の決着です。**本文（§2.3 / §2.4 / §5 / §6）へ入れ込み済みです。本文と食い違うときは本文が正です。** 本節は理由と退けた案の記録です。

### 20.1 鈍足は、付いた側が撃つ `push` も止める

**食い違い**: §5 の鈍足は「位置の切り替えができない」で、止まるのは付いた側の自分の位置でした。長柄の歪み兵（`polearm_warped`。roster の現行の表示名は 錆槍の竜兵）は位置を持たないので、鈍足を付けても何も起きません。一方 roster §2.1 の手記は「押し込みの予兆が出たターンに鈍足を付ける」を弱点に挙げていました。

**決定**: §5 を直しました。鈍足は「付いた側が起こす位置の変化」を止めます。自分の切り替えと、自分が撃つ `push` の両方です。

| 案                                           | 採否 | 理由                                                                                                                                                                                                        |
| -------------------------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **§5 を直す（`push` も止める）**             | ✓    | 位置を持つ敵は 9 体のうち 3 体だけです。直さないと、鈍足は通常敵 6 体に何の効果も持たず、体当たり・足払い・根縛り・翻し足の鈍足の面が通常戦で死にます。§19.4 が鈍足を振り子の止め役に置いた読みとも揃います |
| roster の手記から鈍足を外す                  | ✗    | 鈍足が精鋭・ボス専用の状態になります。プレイヤーの札 4 枚が持つ面としては狭すぎます                                                                                                                         |
| 鈍足が付いた敵は `push` を持つ行動を撃てない | ✗    | 予兆のコミットが崩れるか、払えるのに休みになります。威力まで消えるので、鈍足 2 スタックの値段に対して強すぎます                                                                                             |

止めるのを位置の変化だけにした理由は、プレイヤー側と対称にするためです。鈍足が付いたプレイヤーはムーブ面を持つ札を出せて、威力と Guard は得ますが、位置は変わりません。敵も同じで、石突きの押し込みの威力は当たり、押し出しだけが起きません。

相手が撃つ `push` を止めない理由は、鈍足が「付いた側の足」を縛る状態だからです。プレイヤーに鈍足を付けて押し返しも効かなくなる敵を作ると、居続け対策（§6.1）が自分で自分を消します。

### 20.2 予兆の一字は「その行動が狙っている相手の側」。`push` は押し出される前の側

**食い違い**: §6 は一字を「効果が乗る側」と定義していました。石突きの押し込みの特性は無防備で、位置を読みません。定義どおりに作ると一字は付かず、roster の表の「攻撃・近」と合いません。

**決定**: §6 を直しました。roster の表は直しません。

roster の通常 6 体（20 行動）を読み直すと、一字は一貫した 3 つの出どころで書かれていました。足りなかったのは §6 の定義のほうです。

| 出どころ                       | 当たる行動（通常 6 体）                                                                                        |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 効果に相手の側の条件がある     | 薙ぎ払い（遠）/ 跳びかかり（遠）/ 靄の矢（遠）                                                                 |
| `push`（押し出される前の側）   | 石突きの押し込み（近）/ 跳びかかり（遠）/ 押し込み（遠）/ 退き撃ち（近）/ 靄に溶ける（近）/ 踏み込み斬り（遠） |
| 片側の枝にしか置かれていない   | 噛みつき（近）/ 大振り（近）/ 弩の一射（遠）/ 二段斬り（近）                                                   |
| どれにも当たらない（一字なし） | 穂先の突き / 柄で受ける / 身を低くする / 鉄の身 / 盾を構える / 散り矢 / 退き斬り / 十字受け                    |

`push` の 6 行動は、どれも「主に咎める側の反対」を一字に出しています。押し込み（`rusted_revenant`）と靄に溶ける（`mist_archer`）は両方の枝にあるので、3 つ目の出どころでは説明できません。`push` を独立した出どころに置いたのはこのためです。

| 案                                               | 採否 | 理由                                                                                                                                                    |
| ------------------------------------------------ | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **§6 の定義を広げる（出どころを 3 つにする）**   | ✓    | 通常 6 体の 20 行動がそのまま成り立ちます。プレイヤーが読む意味も通ります。「攻撃・近」は「近間に居ると遠間へ送られて、次に薙ぎ払いを受ける」の予告です |

## 23. 2026-09-26 の案（#205: ターンで減る型の上限。こうだいさんの確認待ち）

> **Status**: battle レーンの案です。こうだいさんはまだ確認していません。本文（§5 / §10）へは入れ込み済みで、コア（`unity-port/BattleCore/`）も従っています。確認が取れるまでは仮の規則として扱います。退けられたら、本文と実装を戻します（§14 の 18）。

### 23.1 見つけた問題

ターンで減る型は、付いた側のターン開始に 1 しか減りません。一方で、付与の既定は 2 スタックで、敵は毎フェーズ付け直せます。精鋭とボスは 1 フェーズに 2 回行動します。このため、付け直しが続くとスタック数が戦闘の長さに比例して育ちます。

- 大黒蛇 セルクは、間合い 3 以上で瘴気の儀と縛りの言葉を毎フェーズ使います。2 つのコストの和 4 は回復 4 と釣り合うので、この組み合わせは止まりません。
- Issue の再現（セルク、seed 21、ランダムなデッキ、手札の左から払える札を出す打ち手）では、12 ターン目にプレイヤーの疲労 13、敵の再生 13 になりました。再生 13 は 1 ターンに HP を 26 戻します。
- セルクを相手に札を出さずにターンを終え続けると、60 ターンでプレイヤー側も敵側も 61 スタックまで育ちました。

再現に出てくるプレイヤーの疲労と鈍足は、実装が置いた代わりの状態です。`enemy_roster_v4.md` では、瘴気の儀は瘴気纏いを 1 付け、縛りの言葉は呪縛を 1 付けます。実装は、その代わりに疲労 2 と鈍足 2 を付けています（`Enemies.cs` の `miasma_rite` と `binding_word`）。瘴気纏いは 2 スタックまでしか重なりません。呪縛は 1 フェーズに 1 回付き、付いた側のターン開始に 1 減るので、育ちません。このため、ロースターのとおりに組んでも際限なく育つのは、敵が自分に付ける再生です。代わりに置いた疲労と鈍足も、実装では再生と同じ速さで育ちます。

### 23.2 案

§5 の上限の箇条と、§10 の `TURN_DECAY_STACK_MAX` です。ターンで減る型は 1 語 4 スタックまでで、プレイヤーにも敵にも掛かります。4 を超える分は付けた時点で捨てます。使うと減る型は S14 のとおり数えません。

- 目盛りの列 4 で付く出血 / 再生の 4 スタックは、付いていない相手に丸ごと入ります。
- 既定の 2 を 2 回付けた分（4）も丸ごと入ります。
- 出血の tick は 1 ターン 8 までなので、ボス戦の目安の上限 18 ターンを通しても 144 です。いちばん HP の低いボス（160）に届かないので、§19.8 の 4（血路）の止め役「ボス（HP 160）では tick が間に合わない」が規則として成り立ちます。

コアのテストは、セルクと 60 ターン戦ってもプレイヤー側と敵側の両方で 4 に止まることを確かめています。Issue と同じ敵と seed の戦いを、固定のデッキで回すテストもあります。そのデッキでは、上限なしで鈍足が 11 まで育ち、上限ありでは 4 で止まりました。

### 23.3 退けた案

- 付け直しを「足す」から「多いほう」に変える案です。特性の「出血 +1 スタック」が、出血 2 の相手には何も起こさなくなります。避けるには 1 枚の中で合算する規則が別に要ります。§19.8 の血路の「出血を積む」も成り立たなくなります。
- 減り方を「半分（端数は切り捨て、最低 1）」に変える案です。暗算が 1 段難しくなります。落ち着く値は 1 ターンに付ける量の 2 倍なので、札を重ねるほど上も大きくなります。
- 1 フェーズに同じ語は 1 回までに絞る案です。セルクは瘴気の儀と縛りの言葉で別の語を付けるので、伸びが止まりません。
- 上限 3 は、目盛りの列 4 の 4 スタックが付かなくなり、`swordsman_cards_v4.md` と食い違います。上限 5 は、出血の tick が 18 ターンで 180 になり、ボスの HP 160 を超えます。

### 23.5 残ること
