# 戦闘コア v3 設計書 — 間合い × スタミナ投入（数値の正本）

> **Status**: DRAFT v1（2026-09-12）。tier1 v6 **R1-2** の成果物。本書の数値が実装（`unity-port/BattleCore/` と TS パリティ元 `src/ui/battle-lab/core/`）の正。
> **入力**: `vision/concept-v3.md` §3 / §7 / §12、検証済み v2 コア（2026-06-27 実機プレイで「ゲーム性はかなり面白い」と評価。数値は `src/ui/battle-lab/core/constants.ts`）、企画書「ゲーム設計(chat GPT)」§3〜§5・§19〜§20。
> **方針**: 検証済みで面白かったもの（間合い相性の勾配、間合い依存の回復、敵の矯正技、決定的 AI、乱数なし）は残す。企画書の新要素（投入量 0〜3、温存の意味、最大スタミナの外部入力、予兆、Guard のみの防御）を載せる。疲労減衰は投入量の仕組みに吸収する。
> **凍結**: アーマー（AP）と体勢ゲージは持たない（§9-4）。

---

## 1. 基礎要素の整理

### 1.1 戦闘中に持つ値（これだけ）

| 値               | 誰が | 範囲               | 一言                                                                   |
| ---------------- | ---- | ------------------ | ---------------------------------------------------------------------- |
| HP               | 両者 | 0〜最大            | 0 で敗北 / 撃破                                                        |
| Guard            | 両者 | 0〜                | ターン内の一時防御。自分のターン開始で 0 に戻る                        |
| スタミナ（現在） | 両者 | 0〜最大            | カードへ投入する主リソース。ターンも戦闘もまたいで持ち越す             |
| スタミナ（最大） | 両者 | 3〜14              | 探索状態（一時変化 + 衰弱）から戦闘へ渡される入力。戦闘中は変わらない  |
| 間合い           | 共有 | 近 0 / 中 1 / 遠 2 | プレイヤーと敵の距離。一つの値を両者が動かす                           |
| 予兆             | 敵   | 行動 1 つ          | 敵が次に取る行動（種別と狙い間合い）。プレイヤーターンの間ずっと見える |

手札・山札・捨札はカードの置き場で、値ではない。これ以外の数値（体勢、AP、エネルギー、速度）は持たない。

### 1.2 原則

1. **乱数を解決に使わない**。乱数はシャッフルだけ。命中・回避は確率ではなく確定の効果量差で表す（v2 で検証済み）。
2. **敵も同じルールで動く**。スタミナ・投入・間合い補正・Guard は対称。違いはカードの中身と AI だけ。
3. **数値は暗算できる大きさ**にする。HP は 30〜40、威力は 1 桁〜11、スタミナは 10 前後。
4. **1 ターンの判断は 3 つ**: どのカードを / いくら投入して / どこへ動くか。それ以外の判断を戦闘に足さない。
5. **読み合いは予兆に対して行う**。敵の次の行動が見えた上で、間合いとスタミナをどう使うかを決める。

### 1.3 v2 検証済みコアからの差分

| v2（検証済み）                           | v3                                                           | 理由                                                      |
| ---------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------- |
| カードごとに固定コスト（1〜5）           | 投入量 0〜3 を毎回選ぶ。カードは最低投入量（0 か 1）だけ持つ | 企画書 §4「消費量で性能が変わる」                         |
| 最大スタミナ 20 固定                     | 基礎 10。探索の一時変化と衰弱で 3〜14 に動く                 | 企画書 §5、コストが 0〜3 に縮んだ分だけ総量も半分にする   |
| 疲労: スタミナ 8 未満で威力が確定減衰    | 廃止。低スタミナでは低投入しか選べないこと自体が減衰になる   | 二重の減衰を避ける。投入量の仕組みで同じ手触りが出る      |
| 敵 AI は敵フェーズに距離を見て行動を選ぶ | 敵は前のフェーズ末に次の行動を宣言（予兆）し、それを実行する | 企画書 §19〜§20「予兆で予測可能に」。読み合いを具体化する |
| 敵に Guard なし                          | 敵も Guard を持つ（構えと防御行動）                          | 対称性。適応 AI の「防御崩し」を敵側にも作れる            |
| 体勢（崩し）は未実装                     | **崩し = 敵スタミナを削る効果**。体勢ゲージは作らない        | 値を増やさず「崩してから叩く」を成立させる                |
| 温存の意味なし                           | **構え**: ターン終了時にスタミナを 3 以上残すと Guard +2     | 企画書 §4.2「使い切る = 正解にしない」                    |

## 2. 間合い

### 2.1 段階と初期値

- 近 = 0 / 中 = 1 / 遠 = 2 の 3 段階。プレイヤーと敵で共有する一つの距離。
- 初期距離は **中**（敵の主力が最も通る帯。開幕から判断を迫る）。戦闘用ツール「開始時の間合い変更」で近か遠に変えられる。

### 2.2 相性補正（攻撃）

カードは最適間合い（`effectiveRange`）を 1 つ持つ。現在距離との差 `diff` で威力に掛ける。

| diff | 補正   | 意味               |
| ---- | ------ | ------------------ |
| 0    | × 1.0  | 最適               |
| 1    | × 0.5  | 不適。撃てるが半減 |
| 2    | × 0.15 | ほぼ空振り         |

- 攻撃は間合い外でも撃てる。手札には現在距離での予測ダメージを表示する（v2 で検証済み。「間合いを外す / 詰める」の勾配を見せる）。
- **回避と命中は個別の値を持たない**。遠にいる相手の近距離攻撃が × 0.15 になること自体が回避である。

### 2.3 間合いが効くその他の項目

| 項目          | 規則                                                             |
| ------------- | ---------------------------------------------------------------- |
| 移動（shift） | カードの移動は間合い補正を受けない。常に適用する                 |
| Guard         | 間合い補正を受けない                                             |
| 追加効果      | 崩し・追加 Guard などの追加効果は **diff 0 のときだけ** 発動する |
| スタミナ回復  | ターン開始時の回復量が間合いで変わる（§3.3）                     |

### 2.4 間合い変更ルール（concept-v3 §12-7 の決定）

1. 距離を動かすのはカードの `shift`（プレイヤー）と敵行動の `shift`（敵）だけ。1 行動につき最大 1 段階。
2. 解決順は「ダメージ → 移動 → 追加効果」。移動後の距離は次の行動から効く。
3. 両者の移動は順番に起きる。同時解決は無い。
4. 0 未満・2 超は端で止まる（clamp）。
5. 敵の矯正技（例: 石突きの押し込み = 近にいる相手を中へ押す）で、プレイヤーの有利な距離は長続きしない。プレイヤー側も同様の矯正技を持てる。

## 3. スタミナ

### 3.1 最大スタミナ

```
最大スタミナ = 基礎 10 + 一時変化（合計を -4〜+4 に clamp） - 衰弱による減少
最終値は 3〜14 に clamp
```

| 衰弱ゲージ | 減少                     |
| ---------- | ------------------------ |
| 0〜19%     | 0                        |
| 20〜39%    | -1                       |
| 40〜59%    | -2                       |
| 60〜79%    | -3                       |
| 80〜99%    | -4                       |
| 100%       | 衰弱死（戦闘に入らない） |

一時変化の例は concept-v3 §7（重い荷物 -2 / 休息 +2 / 食事 +1 / 呪い -3）。戦闘中に最大値は変わらない。

### 3.2 現在スタミナの持ち越し（concept-v3 §12-16 の決定）

- ターンをまたいで持ち越す。
- **戦闘をまたいでも持ち越す**。戦闘終了時の残量がそのまま探索へ戻る。
- 戦闘外の回復: 刻限を 1 消費する非戦闘行動ごとに **+3**（上限は最大値）。休息は全回復に加えて最大値 +2（一時変化）。
- 生の開始時は最大値まで満たす。

「消耗したまま次の戦闘に入るか、刻限を使って回復するか」が探索側の判断になる。これが企画書 §2 の「スタミナを配分する」の探索側の意味である。

### 3.3 ターン開始の回復

| 間合い | 回復 |
| ------ | ---- |
| 近     | +1   |
| 中     | +2   |
| 遠     | +3   |

v2 で検証済み。「攻めると枯れる / 退くと戻る」の押し引きを作る。敵も同じ表で回復する。

### 3.4 投入量

- カードを使うとき、投入量を **0〜3** から選ぶ。投入量がそのままコスト。基礎コストは無い。
- カードは `minInvest`（0 か 1）を持つ。1 のカードは 0 では使えない。重い技（突き・踏み込み斬り・薙ぎ払い）は 1。
- 投入量ごとの性能は 4 段（T0〜T3）の表としてカードが持つ。段ごとに威力・Guard・移動・追加効果が変わる。
- 現在スタミナが投入量に満たない段は選べない。手札には選べる段だけを表示する。

### 3.5 温存の意味

| 規則 | 内容                                                                              | 種類     |
| ---- | --------------------------------------------------------------------------------- | -------- |
| 構え | ターン終了時、残スタミナが **3 以上** なら Guard +2。敵フェーズの被弾で消費される | 共通     |
| 冷静 | カード個別。使用後の残スタミナが閾値以上なら追加効果（例: 次ターン開始の回復 +1） | カード別 |
| 死力 | カード個別。現在スタミナが 2 以下なら威力 × 1.5                                   | カード別 |

「構え」は全カードに共通で働く唯一の温存規則。閾値 3 は「1 枚を T3 で撃てる量」で、次ターンの選択肢を残す意味も兼ねる。

### 3.6 0 投入の扱い（退行対策）

0 投入は「型だけ」で、威力 1〜2 の削りにしかならない。敵の 1 ターンの出力（4〜8）を下回るので、0 投入だけで回すと負ける。構えは残量 3 以上で +2 に固定し、温存だけで守り切れないようにする。プレイテストで 0 投入回しが最適になった場合は、T0 の威力を下げるか敵の出力を上げる（§12-1）。

## 4. 防御

- 防御層は **Guard → HP** の 2 層。AP（装備耐久アーマー）は無い（凍結）。
- Guard は自分のターン開始で 0 に戻る。前のターンの Guard は持ち越さない。
- 被弾: `damage = max(0, raw - guard)`、`guard = max(0, guard - raw)`。
- 敵の Guard も同じ。敵の「防御行動」と「構え」で付く。

---

## 5. 崩し（体勢の代替、concept-v3 §12-18 の決定）

- 体勢ゲージは導入しない。
- **崩し = 相手のスタミナを削る追加効果**（`breakStamina`）。削られた側は次のターンに低投入しか選べず、弱い行動しか取れない。
- 崩しは diff 0 でのみ発動する（§2.3）。「最適間合いで踏み込む → 相手が崩れる → 高投入で叩く」が「崩してから叩く」になる。
- 敵の適応 AI「防御多用 → 防御崩し」は、敵側の崩し行動として表現する。

## 6. 予兆と敵 AI

### 6.1 予兆（コミット式）

- 敵は自分のフェーズの末に、**次の行動（種別と狙い間合い）を決めて宣言する**。プレイヤーターンの間は常に見える。
- 表示: 「攻撃・中」「押し戻し・近」「間合い取り直し」のように種別と間合い。技名・投入量・威力は図鑑の開示度が上がると見える。
- 敵は宣言した行動を実行する。プレイヤーが距離を変えれば相性補正がそのまま効く。**これが間合いを読む報酬**である。
- 投入量は実行時に決める（回復後のスタミナで）。

### 6.2 空振り回避ルール

宣言した攻撃が実行時に diff 2（ほぼ空振り）になっていた場合、敵は攻撃を捨てて **間合い取り直し（自分の主力間合いへ 1 段階移動）** を行う。完全回避の報酬は「その敵フェーズにダメージを受けない」であり、敵は位置を取り戻す。遠で逃げ続ける膠着を防ぐ。

### 6.3 通常敵の AI（決定的）

1. 行動の選択は **距離だけ** で決まる決定木（敵ごとに定義）。同じ距離なら同じ行動。図鑑に「間合いごとの傾向」として記録される内容そのもの。
2. 投入量は「実行後に残スタミナが 3 以上残る最大値」。敵も構えを使う。残りが 3 未満なら最低投入。
3. 最低投入すら払えない場合は間合い取り直しか休み（回復のみ）。

### 6.4 ボス・強敵（Tier 1 R1-15 / Tier 2 R2-3 で拡張）

本書は通常敵までを定義する。ボスは 6.1〜6.3 の上に「行動履歴で決定木を切り替える」「予兆を 2 段階にする」「1 フェーズ 2 行動」を載せる。適応の条件は図鑑に記録できる形で定義する（企画書 §19）。

## 7. カード定義

### 7.1 スキーマ

```
CardDef {
  id, name
  type: attack | move | guard            // 探索効果は探索側の定義に持つ（R1-6）
  effectiveRange: close | mid | far | null // attack のみ
  minInvest: 0 | 1
  tiers: [T0, T1, T2, T3]                 // 投入量ごとの性能
  reserve?: { kind: calm | desperate, threshold, effect }
}
Tier { power, guard, shift, breakStamina, bonusGuardNextTurn? }
```

- `shift` は負で詰める、正で離す。
- `breakStamina` は diff 0 のときだけ発動（§5）。
- T0 は `minInvest: 1` のカードでは使わない（表には「—」）。

### 7.2 剣士 初期 6 種（v2 の 6 種を投入制へ）

| id       | 名前         | type   | 最適 | min | T0           | T1            | T2            | T3                                     |
| -------- | ------------ | ------ | ---- | --- | ------------ | ------------- | ------------- | -------------------------------------- |
| thrust   | 突き         | attack | 近   | 1   | —            | 威力 5        | 威力 8        | 威力 11                                |
| lunge    | 踏み込み斬り | attack | 近   | 1   | —            | 威力 3, 詰め  | 威力 5, 詰め  | 威力 7, 詰め, 崩し 1                   |
| feint    | 牽制         | attack | 中   | 0   | 威力 1, 退き | 威力 3, 退き  | 威力 4, 退き  | 威力 5, 退き, Guard 1                  |
| step_in  | 足捌き・前   | move   | —    | 0   | 詰め         | 詰め, Guard 1 | 詰め, Guard 2 | 詰め, Guard 3                          |
| step_out | 足捌き・後   | move   | —    | 0   | 退き         | 退き, Guard 1 | 退き, Guard 2 | 退き, Guard 3                          |
| brace    | 呼吸を整える | guard  | —    | 0   | Guard 2      | Guard 4       | Guard 6       | Guard 8。冷静(残 ≥ 6): 次ターン回復 +1 |

- 詰め = shift -1、退き = shift +1。
- 初期デッキは 6 種 × 2 = 12 枚（検証台用）。本番の戦闘デッキは 20 枚以上（concept-v3 §4.3）で、習熟段階（R1-5）と探索カード（R1-6）を足す。
- 移動カードが手札に無いターンでも lunge / feint が移動を内蔵しているので詰まない（v2 検証 #4 を維持）。

### 7.3 ダメージ式

```
raw    = tier.power × rangeMult(|distance - effectiveRange|)   // 1.0 / 0.5 / 0.15
raw    = raw × 1.5  （死力が付いていて現在スタミナ ≤ 2 のとき）
raw    = round(raw)
damage = max(0, raw - 相手の Guard)
```

疲労による減衰項は無い。

## 8. 敵定義

### 8.1 スキーマ

```
EnemyDef { id, name, maxHp, actions: EnemyAction[], decisionTree: { close, mid, far }, homeRange }
EnemyAction { id, name, type, effectiveRange, minInvest, tiers, shift | towardHome }
```

`decisionTree` は距離ごとの優先順リスト。`homeRange` は間合い取り直しの目標。

### 8.2 長柄の歪み兵（v2 の検証用敵を投入制へ）

- HP 38。最大スタミナ 10。homeRange = 中。

| id           | 名前             | type   | 最適 | min | T0      | T1      | T2      | T3      | 移動             |
| ------------ | ---------------- | ------ | ---- | --- | ------- | ------- | ------- | ------- | ---------------- |
| sweep        | 薙ぎ払い         | attack | 中   | 1   | —       | 威力 4  | 威力 6  | 威力 8  | —                |
| reach_thrust | 穂先の突き       | attack | 遠   | 0   | 威力 1  | 威力 2  | 威力 3  | 威力 4  | —                |
| shove        | 石突きの押し込み | attack | 近   | 0   | 威力 1  | 威力 2  | 威力 2  | 威力 3  | 相手を中へ（+1） |
| reposition   | 間合い取り直し   | move   | —    | 0   | —       | —       | —       | —       | 中へ 1 段階      |
| guard_up     | 柄で受ける       | guard  | —    | 0   | Guard 2 | Guard 3 | Guard 4 | Guard 5 | —                |

決定木: 近 → shove / reposition。中 → sweep / reach_thrust / guard_up。遠 → reach_thrust / reposition。
「近はプレイヤー有利（敵は弱い shove しかない）→ 敵が中へ押し戻す → 中で薙ぎ払い」の押し引きは v2 と同じ。

## 9. ターン進行

```
[プレイヤーターン開始]
  1. プレイヤーの Guard を 0 に
  2. 現在の間合いで回復（近 +1 / 中 +2 / 遠 +3、上限は最大値）
  3. 手札を 3 枚まで補充（山札切れは捨札を再シャッフル）
  4. 敵の予兆を表示（前フェーズ末に決まっている）
[プレイヤー行動]（何枚でも）
  5. カードと投入量を選ぶ → ダメージ → 移動 → 追加効果（diff 0 のみ）→ 撃破判定
[ターン終了]
  6. 構え判定（残 ≥ 3 → Guard +2）
  7. 手札を捨てる
[敵フェーズ]
  8. 敵の Guard を 0 に → 間合いで回復
  9. 予兆どおりに実行（diff 2 なら空振り回避で間合い取り直し）。投入量は §6.3 の規則
 10. 敗北判定
 11. 次の予兆を決める（現在距離で決定木を引く）
```

## 12. プレイテストで見る点

1. **0 投入回し**が最適にならないか（§3.6）。なっていたら T0 威力を下げる。
2. **遠でのカイト膠着**が起きないか。空振り回避（§6.2）で敵が中へ戻り、プレイヤーが詰めざるを得なくなるか。
3. **崩し 1** に手応えがあるか。敵が翌ターン低投入になることが見えるか。
4. **構え +2** が温存の理由になるか。逆に亀が最適にならないか。
5. **最大スタミナ 6**（衰弱 80% 相当）でも勝ち筋があるか。無ければ衰弱の減少幅（§3.1）を緩める。
6. 予兆が見えることで戦闘が単純になりすぎないか。なっていたらボス以外にも 2 行動の敵を早めに入れる。
