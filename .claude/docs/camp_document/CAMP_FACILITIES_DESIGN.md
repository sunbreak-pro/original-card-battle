## 1. 設計思想

拠点は「次の生を準備する場所」である。旧設計の「休息と準備」「永続成長」「資源管理」のうち、永続成長と資源管理は無くなった。

- **準備**: 遺産と生存者ボーナスを受け取り、ツールと戦闘デッキを決める。
- **記録**: 手記（敵 + ダンジョン + メモ。ほかに用語と状態の頁）を読み、書く。死ぬと死亡地点に残り、選んだ頁だけ次へ。
- 永続成長は無い。キャラクターはこの生の中だけで強くなる。

## 3. 画面詳細

### 3.1 継承の間

**概念**: 前の生から次の生へ渡すものを決める部屋。

```
継承の間
├── 未回収の痕跡（複数残ることがある）
│   ├── 各痕跡の死亡地点（階層 / ノード）を表示
│   ├── 遺産候補: [技術] 洞察 / 受け流し / 後退射撃 ... [手記の頁] 地下水路の近道 / 狼の行動パターン / 走り書き ...
│   └── 候補の一覧を見るだけ。選択と受け取りは「次のキャラクターが死亡地点を訪れたとき」。1 つの生で 1 件（concept-v3 §8.3）
├── 前回生存者（あれば・一人まで）
│   └── 手記は丸ごと引き継ぐ。生存者ボーナスの内容を表示（内容は concept-v3 §12-12 で未確定）
└── 新しいキャラクターを開始
    └── 固定キャラクター。カスタマイズ項目は無い
```

**禁止**: 1 つの生で 2 件目の痕跡から受け取らせない。浅層で死んだ高習熟カードを候補に出さない（閾値は §12-11）。

### 3.2 出立

**概念**: 今回の探索に対する回答を作る部屋。

```
出立
├── ツール選択（枠数は §12-13 で未確定）
│   ├── 探索用: 特定の扉を開ける / 特定の場所へ到達 / 隠しルート解放 / 特殊イベント発生
│   └── 戦闘用: 開始のマスを変える（battle_core_v4 §7.3）/ 初期スタミナ補助 / 一度だけ防御 / 特定の敵への対策
├── 戦闘デッキ構築
│   ├── 所持カード（最大 80 枚程度）から 20〜40 枚を選ぶ
│   └── 探索用カードと戦闘用カードの配分がここでのジレンマ
├── （ダンジョンは一つ。入口の選択は無い。2026-09-12 決定）
└── 出発
```

### 3.3 手記

**概念**: このキャラクターが持ち歩く帳面。知っていることと、自分で書いたこと。死ぬと死亡地点に残る。

```
手記
├── タブ「敵」: 弱点 / 耐性 / 行動パターン / 間合いの帯（0 / 1〜2 / 3 以上）ごとの傾向 / 特殊行動 / 行動条件 / 他の敵との関係 / 適応条件
├── タブ「ダンジョン」: 近道 / 隠し部屋 / 特定地点 / 条件出現の敵 / 特殊イベント / 罠 / 資源 / ショートカット / 特殊な探索条件
├── タブ「メモ」: プレイヤーの自由記述（ゲームは解釈しない）
└── 用語と状態の頁: 間合い・構え・特性・状態の定義の一覧（見た目は art_document/battle-visual-v1.md §7.5）
```

- 手記のタブは、敵・ダンジョン・メモの 3 つです。用語と状態の頁は、3 つのタブとは別に足した 1 頁です（#234、2026-10-03 のこうだいさんの決定）。
- 敵・ダンジョン・メモの 3 つは、このキャラクターが知ったことと書いたことです。観察と遭遇で埋まり、死ぬと死亡地点に残ります。遺産で選んだ頁は、次の生の手記に最初から載ります。
- 用語と状態の頁は規則の説明です。段階開示はせず、最初の生から全項目を読めます。痕跡と遺産の対象にせず、死んでも消えません（tier1 R1-10）。
- 継承の間・出立・探索中・戦闘中のどこでも開けます。戦闘中に開けるのは、今の敵の頁と、用語と状態の頁だけです。用語と状態の頁へは、札の詳細に出る用語から直接飛べます。開いても戦闘の状態は変わりません。
- 所持カードと設定・セーブは、手記に入れません。手記の外の画面に出します（§3.4、§3.5）。死亡地点に残す手記に、カードの一覧や設定が混ざらないようにするためです。

### 3.4 所持カード

**概念**: このキャラクターが今持っているカードを読む画面です。手記の外に置きます。

```
所持カード
├── 1 枚ごとに: 現在の名称 / 習熟度と次の段までの残り / 永続能力の有無と、ある札はその文
└── 今の戦闘デッキに入っている札には印を付ける
```

- 読むだけの画面です。戦闘デッキを組み替えるのは出立だけです（tier1 R1-7）。
- 探索中に開けます。地図の画面の上の帯に、手記のボタンと並べてボタンを置き、階層間の休憩の画面にも同じボタンを置きます。習熟が伸びて名称が変わるのは戦闘の後なので、探索の途中で確かめられるようにします。探索の画面の部品の置き場は `danjeon_document/dungeon_exploration_v4.md` §6.2 が持つので、そちらへの書き足しは dungeon に回します。
- 出立では、デッキを組む画面の所持カードの列がこの画面を兼ねます。同じ中身を別の画面に分けると、デッキを組みながら 2 つの画面を行き来することになるからです。
- 継承の間では開けません。継承の間は前の生から渡すものを見る部屋で、新しいキャラクターのカードを扱うのは出立からだからです。
- 戦闘中は開けません。戦闘で使うのは戦闘デッキだけで、その中身は左の一覧のドロワー（山札・捨札・除外）で読めるからです。
- 見た目は、#244 で作るデッキを組む画面と同じ部品にします。

### 3.5 設定・セーブ

**概念**: 遊び方の設定と、保存してゲームを閉じる操作を置く画面です。手記の外に置きます。

```
設定・セーブ
├── 戦闘の速さ: ×1.0 / ×1.25 / ×1.5（既定は ×1.25。battle_ui_ux_v2 §5.0）
├── 演出短縮: 入れる / 切る（battle_ui_ux_v2 §5.0）
├── 音の大きさ
└── 保存してゲームを閉じる
```

- 継承の間・出立・探索中（地図の画面と階層間の休憩の画面）で開けます。継承の間と出立では右上に、探索中は上の帯に歯車のボタンを置き、Esc でも開けます。ドロワーや確認の札が開いているときの Esc は、そちらを先に閉じます。
- 戦闘中は開けません。戦闘の状態は保存の中身（tier1 R1-16）に入っていないので、戦闘中に「保存してゲームを閉じる」を出すと、何が残るかが決まらないためです。戦闘画面の Esc は、選択の取り消しとドロワーを閉じる役にもう使っています（battle_ui_ux_v2 §3.4）。
- 戦闘の速さは、この画面と戦闘画面の右上のボタン（`art_document/battle-visual-v1.md` §4.1）の 2 か所に置きます。値は 1 つで、どちらで替えても、もう一方にそのまま映ります。戦闘中に替えられる設定は、戦闘画面のボタンの速さだけです。速さは敵の番を見ながら替えるものなので、戦闘画面から外せません。この画面にも置くのは、ほかの設定と一緒に決めておけるようにするためです。演出短縮と並ぶので、演出短縮を入れると速さに関わらず演出が縮むことも同じ画面で分かります。
- 死亡と生の終了は、確定と同時に自動で保存します（tier1 R1-16）。「保存してゲームを閉じる」は、今の状態を保存してゲームを閉じます。生は終わりません。自分で生を終える入口は、探索の画面と階層間の休憩の画面に出す「この生を終える」（生存ルート）で、この操作とは別のものです。
- 次に起動したときは、保存した場面から自動で再開します（tier1 R1-16 の中断・再開）。保存の枠を選んで読み込む操作は置きません。読み込み直して遺産を選び直せないようにするためです。
- 見た目は `art_document/battle-visual-v1.md` の部品（パネル、罫線の枠、本文色）で作ります。

## 4. 導線

```
継承の間 → 出立 → ダンジョン → （生存ルート / 死亡） → 継承の間
```

手記と所持カードと設定・セーブの 3 つの画面は、順路の外から開きます。どこで開けるかは次のとおりです。

| 画面 | 継承の間 | 出立 | 探索中（地図・階層間の休憩） | 戦闘中 |
| --- | --- | --- | --- | --- |
| 手記 | 開けます | 開けます | 上の帯のボタンか J で開けます | 今の敵の頁と、用語と状態の頁だけを開けます |
| 所持カード | 開けません | デッキを組む画面が兼ねます | 上の帯のボタンで開けます | 開けません |
| 設定・セーブ | 右上の歯車か Esc で開けます | 右上の歯車か Esc で開けます | 上の帯の歯車か Esc で開けます | 開けません。戦闘の速さだけは戦闘画面のボタンで替えます |

旧設計の「キャンプ ⇄ 各施設」のハブ構造は無い。順路は一方向。
