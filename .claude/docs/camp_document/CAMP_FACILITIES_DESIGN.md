## 1. 設計思想

拠点は「次の生を準備する場所」である。旧設計の「休息と準備」「永続成長」「資源管理」のうち、永続成長と資源管理は無くなった。

- **準備**: 遺産と生存者ボーナスを受け取り、ツールと戦闘デッキを決める。
- **記録**: 図鑑（敵 + ダンジョン）を読む。死ぬと消える。
- 永続成長は無い。キャラクターはこの生の中だけで強くなる。

## 3. 画面詳細

### 3.1 継承の間

**概念**: 前の生から次の生へ渡すものを決める部屋。

```
継承の間
├── 前回死亡者の痕跡（あれば）
│   ├── 死亡地点（階層 / ノード）を表示
│   ├── 遺産候補: [技術] 洞察 / 受け流し / 後退射撃 ... [知識] 地下水路の近道 / 狼の行動パターン / 隠し部屋 ...
│   └── 候補の一覧を見るだけ。選択と受け取りは「次のキャラクターが死亡地点を訪れたとき」（concept-v3 §8.3）
├── 前回生存者（あれば・一人まで）
│   └── 生存者ボーナスの内容を表示（内容は concept-v3 §12-12 で未確定）
└── 新しいキャラクターを開始
    └── 固定キャラクター。カスタマイズ項目は無い
```

**禁止**: 2 世代前の遺産を出さない。浅層で死んだ高習熟カードを候補に出さない（閾値は §12-11）。

### 3.2 出立

**概念**: 今回の探索に対する回答を作る部屋。

```
出立
├── ツール選択（枠数は §12-13 で未確定）
│   ├── 探索用: 特定の扉を開ける / 特定の場所へ到達 / 隠しルート解放 / 特殊イベント発生
│   └── 戦闘用: 開始時の間合い変更 / 初期スタミナ補助 / 一度だけ防御 / 特定の敵への対策
├── 戦闘デッキ構築
│   ├── 所持カード（最大 80 枚程度）から 20 枚以上を選ぶ（上限は調整対象）
│   └── 探索用カードと戦闘用カードの配分がここでのジレンマ
├── （ダンジョンは一つ。入口の選択は無い。2026-09-12 決定）
└── 出発
```

### 3.3 図鑑

**概念**: このキャラクターが知っていること。死ぬと消える。

```
図鑑
├── 敵図鑑: 弱点 / 耐性 / 行動パターン / 間合いごとの傾向 / 特殊行動 / 行動条件 / 他の敵との関係 / 適応条件
├── ダンジョン図鑑: 近道 / 隠し部屋 / 特定地点 / 条件出現の敵 / 特殊イベント / 罠 / 資源 / ショートカット / 特殊な探索条件
├── 所持カード: 習熟度・現在の名称・永続能力の有無
└── 設定 / セーブ
```

- ダンジョン内でも閲覧できる。戦闘デッキの編集は出立時のみ。
- 遺産で選んだ知識は、次の生の図鑑に最初から載る。

## 4. 導線

```
継承の間 → 出立 → ダンジョン → （生存ルート / 死亡） → 継承の間
                     ↑ 図鑑はどこからでも開ける
```

旧設計の「キャンプ ⇄ 各施設」のハブ構造は無い。順路は一方向。
