## 1. 舞台

**確定**

舞台は一つの坑です。地上に **坑の街** があり、その真下に五つの階層が重なっています。

上のほうは人が掘った坑道です。木の支柱があり、錆びた道具が落ちています。降りるほど人の手が消え、石の回廊になり、最後は掘った跡でないものへ変わります。底に行き着くのは **歪みの根** です。

瘴気はそこから湧いています。根が吐く息です。風のように上へ流れ、浅い階層ほど薄まります。階層ごとに濃度が決まっている規則（`concept-v3.md` §6、濃度 1〜5）は、湧き口からの距離をそのまま数字にしたものです。

坑が塞がらない理由も、根が止まらない理由も、同じ一つです。**根が生きていて、伸び続けているから** です。呪いでも天災でもありません。生き物です。

### 1.1 瘴気が体にすること

瘴気を浴び続けると体に溜まります。溜まると、体が硬くなります。関節が木のようになり、最後は動かなくなって止まります。瘴気の蓄積が 100% で生が終わる規則（`concept-v3.md` §6）は、この現象を数字にしたものです。

固まったものは腐りません。瘴気に侵されたものは腐敗しないからです。だから死亡地点に遺体と手記がそのまま残り、後の代が拾えます（`concept-v3.md` §8.3）。**継承の仕組みが世界の理屈と一致している** ので、説明を足す必要がありません。

### 1.2 「歪み」とは何か

敵の大半は、元は人です。坑道を守っていた衛士、水路を見張っていた猟兵、回廊の門衛長。全員が生前の役目を持っていました。

体が固まりきる前に、**判断する部分が先に止まります**。残るのは、その人がいちばん長く繰り返した動作だけです。門を守る者は門を守り続けます。長柄で押し返す者は押し返し続けます。相手が誰かは分かりません。決まりだけが残っています。

この状態を **歪み** と呼びます。超自然の変異ではなく、**固まる途中の段階** です。敵が人型で、武器を持ち、決まった側からしか咎めないのは、生前の役目が残っているからです。敵が乱数で動かず予兆どおりに実行するのも（`enemy_roster_v4.md` §1.2）、同じ理由で説明できます。**彼らは考えていません。繰り返しているだけです。**

例外は階層 5 の 瘴気の司祭 だけです（→ §5.1）。

## 2. 踏破者

**確定**（`concept-v3.md` §16 の襲名を、世界の側から説明します）

### 2.1 役目としての踏破者

**踏破者** は坑へ潜る役目の名です。個人の名ではありません。装束・面・剣は役に付く支給品で、人が替わるたびに返却と再支給を繰り返します（`concept-v3.md` §16.1）。

継ぐのは役目です。世代ごとに中身は別人で、それぞれ自分の名を持ちます（`concept-v3.md` §14）。**名前は個人のもの、姿は役のもの** なので、世代が変わっても立ち絵は 1 体で足ります。

顔は面で隠れます。街の側から見れば、踏破者はいつも同じ姿で現れて、いつか戻らなくなる一つの役です。

### 2.2 なぜ代々潜るのか

瘴気が上がってきているからです。

坑は昔、ただの鉱山でした。掘り進めた先で根に当たってから、瘴気が出るようになりました。浅い坑道から順に人が退き、いまは階層 1 の入口までが街の領分です。手を打たなければ、次に退く場所は街です。

だから街は役目を出し続けます。踏破者が降りる目的は宝でも名誉でもありません。**根を止めること** です。

### 2.3 何を終わらせたいのか

階層 5 の **歪みの根** を倒すことです。これがクリア条件です（`concept-v3.md` §12-15、`enemy_roster_v4.md` §6）。

一つの生で届くとは限りません。届かなかった生は、技と手記を降りたところに置いて終わります。次の代がそれを拾って、少し先まで行きます。**ゲームの構造（死亡・遺産・継承）が、そのまま物語の構造** になっています。

## 3. 役目を出す主体は街

**確定**（`concept-v3.md` §16.5-1 の回答）

役目を出すのは **坑の街の役所** です。教団でも領主でもありません。

理由は 3 つあります。

1. **既に役所を前提にした決定がある。** 生きて役を返せば手記は役所に納まり、丸ごと次の代へ渡ります（`concept-v3.md` §16.2）。手記の継承が生存と死亡で非対称になる理由が、この時点で役所に寄りかかっています。
2. **教団を選ぶと敵と紛れる。** 階層 5 の 瘴気の司祭 は根を祀る側です（→ §5.1）。地上にも教団を置くと、プレイヤーは「同じ信仰の話か」と読んでしまいます。祀る側は地下だけに置くほうが、司祭の異常さが立ちます。
3. **領主を選ぶと人物が要る。** 領主は顔と台詞を持つ人物です。立ち絵と会話画面の制作費が増えます。街の役所なら制度だけで済み、**人物を 1 人も描かずに** 役目の出どころを説明できます（→ §7 の語る量）。

街の名前は決めません。プレイヤーが街で過ごす場面が無いので、名前を出す場所がありません。

## 4. 継承の間

**確定**

階層 1 の入口の手前、外光が届く最後の場所です。役所が坑の口に置いた小屋で、街ではありません。

| 要素             | 内容                                                                            |
| ---------------- | ------------------------------------------------------------------------------- |
| 壁               | 名札が掛かります。掛かったままの札 = まだ戻っていない代                         |
| 机               | 支給品の受け渡しをします。面・剣・装束の返却と再支給                            |
| 壁の図           | 坑の縦断面が描いてあります。代々の踏破者が自分で線を書き足してきたもの          |
| ここでできること | 痕跡の一覧を見る / 才能を 1 枚選ぶ / 出立の支度（`concept-v3.md` §8.2・§12-13） |

### 4.1 痕跡の一覧を見せているのは誰か

**誰もいません。前の代が自分で書いた線です。**

出立の前に、踏破者は壁の図へ「どこまで降りるつもりか」を書き付けます。戻れば線を消します。戻らなければ、その線が最後の記録として残ります。だから図に残っている線は、**戻らなかった代が最後に目指していた場所** です。

この作りには 3 つの利点があります。

- **案内人が要りません。** 立ち絵も台詞も不要で、「誰も見ていない場所へ一人で降りる」手触りが壊れません。
- **痕跡が正確な点でないことの説明になります。** 線は本人の申告なので、実際の死亡地点はその付近です。だから現地まで行って探す必要があります（`concept-v3.md` §8.3 の「死亡地点で受け取る」と噛み合います）。
- **回収済みが消える理由になります。** 拾った代が線を消すので、未回収だけが残ります（`concept-v3.md` §8.3 の「痕跡は回収まで残る」）。

**継承の間で受け取れるのは情報だけです。** 遺産の受け取りは死亡地点で行います。ここは「どこに何が残っているか」を見せるだけの場所です。

## 5. 五つの階層

**確定**（名前と性格は design レーン。敵の割り当ては `enemy_roster_v4.md` §9 が正で、本書はそれに合わせました）

| 階層 | 名前   | 読み         | 土地の性格                                                     | 光源                    | そこにいるもの                   |
| ---- | ------ | ------------ | -------------------------------------------------------------- | ----------------------- | -------------------------------- |
| 1    | 上坑   | じょうこう   | 人が掘った坑道。木の支柱、錆びた道具、縦坑から届く細い外光     | 縦坑の外光 + 手持ちの灯 | 入口を守っていた衛士と、坑夫の犬 |
| 2    | 沈み階 | しずみかい   | 地下水が溜まった水没区画。膝まで水があり、鉄が全部錆びている   | 手持ちの灯。水面に映る  | 水に浸かったまま止まれない重装兵 |
| 3    | 葬列廊 | そうれつろう | 坑より古い石の回廊。壁龕に死者を納めてある。瘴気の霞が床を這う | 壁の蝋。白く低い        | 門から動かない衛士長と、霞の射手 |
| 4    | 垂根洞 | すいこんどう | 天井と壁を根が貫いている広い洞。足場が根で塞がる。獣が巣を作る | 根の断面が鈍く光る      | 犬の群れと、根に近い歪み兵       |
| 5    | 根底   | ねそこ       | 根の本体がある底。壁も床も根で、瘴気が目に見えるほど濃い       | 根の発光だけ            | ボス 3 体と、底まで来た歪み兵    |

### 5.1 性格の作り方

**人の手が消えていく順に並べます。** 1 は人が掘った坑道、2 は人が使っていた区画、3 は人より古い石造り、4 は人の作ったものが無い洞、5 は根そのものです。階層が進むほど、置いてある人工物が減ります。背景を描くときの指針にもなります。

**光源が階層ごとに替わります。** 外光 → 手持ちの灯 → 蝋 → 根の光 → 根の発光だけ。どこにいるかを光の色だけで判別できます。

**暖色はプレイヤーの側にしか置きません。** 階層 1 から 3 までは手持ちの灯りが居場所を示します。階層 4 以降は根の光のほうが強く、自分の灯りが役に立たなくなります。深く来たことを、明るさではなく「自分の灯りが効かない」で示します。

**濃度が色になります。** 瘴気は濃いほど色が出ます。深いほど画面が紺と菫に寄るのは演出ではなく濃度です。`enemy_roster_v4.md` §9 の濃度 1〜5 が、そのまま背景の彩度になります。

## 6. ボス 3 体と竜

**確定**（設定のみ。数値・行動・決定木は `enemy_roster_v4.md` §4〜§7 が正です）

ボス 3 体は全て階層 5 にいます。根に近い順ではなく、**根との関係の深さ** で並びます。

| 名前         | 位置づけ                                                                   | 出典        |
| ------------ | -------------------------------------------------------------------------- | ----------- |
| 瘴気の司祭   | 根を祀る者。歪みを受け入れた側で、唯一まだ考えている敵                     | `roster` §4 |
| 深淵の釣り人 | 根に養われているもの。元が人ではない。降りてきた者を引きずり込んで根へ運ぶ | `roster` §5 |
| 歪みの根     | 本体。地上へ向かって伸び続けている。瘴気はその息                           | `roster` §6 |
| 竜           | 根より古いもの。因果の外にいる。クリア後にだけ会える（エクストラボス）     | `roster` §7 |

### 6.1 瘴気の司祭 — 唯一考えている敵

元は人で、降りてきた誰かです。ほかの歪み兵と違い、**判断する部分がまだ止まっていません**。固まりかけた体のまま、根を神として祀り、儀式を続けています。

戦闘での役割と設定が一致しています。司祭は行動履歴を見て守りと攻めを切り替えます（`roster` §4.4）。繰り返すだけの通常敵とは、そこが決定的に違います。**プレイヤーが初めて「考える相手」と戦う地点** が階層 5 のこのボスです。

司祭は倒しても根は止まりません。祀る者を除いても、祀られる側は残るからです。

### 6.2 深淵の釣り人 — 根の口

元が人ではない唯一の大物です。底の水に棲み、根に養われています。自分では動かず、相手の位置だけを動かします（`roster` §5）。

役目は運搬です。降りてきたものを引きずり込み、根へ渡します。根が自分で捕らえに来ないのは、**根が動けないから** です。伸びることはできますが、歩けません。だから口の役をするものを飼っています。

### 6.3 歪みの根 — 本体

坑の底で瘴気を生んでいる本体です。撃破がクリア条件になります。

根は地上へ向かって伸びています。人を歪めるのは敵意ではなく、**瘴気が体を固めるという性質の結果** です。根に意図があるかは分かりません。手記にもそう書きます。分からないままにしておきます。

3 段階を持ち、段階ごとに違う問いを出します（`roster` §6.1）。設定の上では、根が本体をせり上げてくる段階です。倒すべきものが最後に姿を現す、という形が段階分けと一致しています。

### 6.4 竜の位置づけ

竜は因果の外にいます。根を祀ってもいませんし、根に養われてもいません。**根が来る前からそこにいたもの** です。

だから瘴気で歪んでいません。判断する部分が止まっていない点では司祭と同じですが、司祭は歪みかけた人、竜は初めから別の生き物です。

竜に会えるのは、根を一度倒してからです。階層 5 の最深ノードの隣に「根の裂け目」が開きます（`concept-v3.md` §15.1）。根が退いて初めて、その下にあったものが見えるという形です。**倒してもクリアにならないのは、竜が瘴気と無関係だから** です。報酬が数値の強化ではなく挑戦の機会と継承の延長だけなのも（`roster` §7.4）、この位置づけと揃っています。

## 7. ゲーム内で語る量

**確定**

**長い導入は置きません。** 冒頭で見せるのは数行だけです。残りは手記の頁に置き、読みたい人だけが読みます。

| 場所             | 量                       | 何を語るか                                                 |
| ---------------- | ------------------------ | ---------------------------------------------------------- |
| 冒頭             | 6 行（→ §7.1）           | 瘴気がどこから来るか。なぜ降りるか。自分は代わりであること |
| 階層に入った瞬間 | 1 行（階層の名前と読み） | それだけ。説明は付けません                                 |
| 手記の敵の頁     | 1 行                     | 生前の役目。弱点と数値は別の欄です                         |
| 手記の階層の頁   | 3 行まで                 | その階層が元は何だったか                                   |
| ボス撃破後       | 2 行まで                 | 祀る者を除いたが根は残る、など                             |
| 最終ボス撃破後   | 未定（#111）             | エンディング。dungeon レーンの担当です                     |

理由は 2 つあります。1 つは、この作品の物語が **死んだ順番で語られる** ことです。前の代が残した手記を拾って読むのが物語の受け取り方で、冒頭の説明はその邪魔になります。もう 1 つは制作費です。台詞と一枚絵が増えるほど、個人開発の 1 人分の時間が削られます。§3 で街を選び、§4 で案内人を置かなかったのは、どちらもこの方針から出ています。

### 7.1 冒頭に見せる文（初稿）

```
瘴気は、坑の底から湧いている。

そこに根がある。
止めに降りた踏破者は、まだ誰も戻っていない。

あなたが次の踏破者だ。
面を付けろ。名札を掛けろ。
```

6 行、53 文字です。読み終わるのに 10 秒かかりません。街の名も年号も人名も出しません。プレイヤーが最初に知る必要があるのは、**下に原因がある / 誰も戻っていない / 自分は代わりである** の 3 つだけです。

3 行目の「まだ誰も戻っていない」は、継承の間の壁（掛かったままの名札、→ §4）と同じことを言っています。文で説明したことを、次の画面で物として見せる形にします。

## 9. 置いた仮定

- 役目を出す主体を街にしました（§3）。`concept-v3.md` §16.5-1 の 3 択からの選択で、根拠は §16.2 の「役所」の記述です。
- 階層 5 つの名前と読みを新しく置きました（§5）。既存の文書に階層の固有名が無かったためです。
- 継承の間に人物を置きませんでした。導入の長さと制作費、それと一人で降りる手触りを優先しました（§4.1）。
- ボス 3 体の関係を「祀る者 / 運ぶもの / 本体」と置きました（§6）。`enemy_roster_v4.md` の行動と決定木から逆算したもので、数値には触れていません。
- 竜を「根より古い、因果の外のもの」と置きました。クリア後にだけ会え、数値のボーナスを与えない扱い（§15.2）と噛み合う説明を選びました。
