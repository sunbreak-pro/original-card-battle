# 世界とデザインの共通規約 v2 — 澱と七層

> **Status**: DRAFT v2（2026-09-21）。design レーンが持つ正本です。**背景・敵・UI に共通する見た目の約束** を持ちます。物語は持ちません。
> **v1 からの差分**: 階層を 5 から **七層** に直し、決定済みの層名を入れました。物語の説明（役目を出す主体・降りる理由・継承の間の由来・冒頭の導入文）を落としました。こうだいさんの指示「ストーリー性を持ち込む気はない。必要なのは背景やデザインに共通したものを見せるだけ」（2026-09-21）によります。
> **役割の切り分け**: 本書は「どう見えるか」と「どう呼ぶか」を決めます。数値は決めません。戦闘の数値は `battle_document/battle_core_v4.md`、敵の数値とロースターは `enemy_document/enemy_roster_v4.md`、仕組みは `vision/concept-v3.md` が正です。
> **入力**: `docs/reports/2026-09-20-dungeon-seven-floors.html`（七層の名前・明るさ・キーアート）、`docs/reports/2026-09-20-world-theme-and-enemy-naming.html`（共通の色・命名規則・言い換え）、`art_document/briefs/player_swordsman.md`。

## 1. 全層に共通する 5 つの規則

背景を 7 枚描いても、敵を 19 体描いても、この 5 つが守られていれば 1 つの世界に見えます。

| #   | 規則                                   | 中身                                                                                                    |
| --- | -------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | **澱は深いほど濃く、紺と菫に寄る**     | 浅い層では薄まって色が出ません。深いほど本来の紺〜菫が出ます。色は濃度であって演出ではありません        |
| 2   | **光源が層ごとに入れ替わる**           | 陽光 → 斜光 → 結晶 → 結晶の全方向 → 散乱光 → 雷の縁 → 澱の発光。どこにいるかを光だけで判別できます      |
| 3   | **明るさの山を 4 層に置く**            | 1・2 は明るく、3 で落とし、4 で最も輝き、5 から抜いていきます。暗い層を 1 つ挟まないと 4 層が効きません |
| 4   | **暖色はプレイヤーの側にしか置かない** | 琥珀の灯りがプレイヤーの居場所です。4 層以降は結晶のほうが明るく、灯りが役に立たなくなります            |
| 5   | **結晶は 4 層を境に増える**            | 2 層で芽を出し、3 層で大蛇の背に育ち、4 層で壁と天井を覆います。1 層には 1 つも置きません               |

## 2. 七層

| 層  | 名前         | 読み                 | 見えるもの                                                                   | 光源                 | 明るさ     | 主な色    |
| --- | ------------ | -------------------- | ---------------------------------------------------------------------------- | -------------------- | ---------- | --------- |
| 1   | 燦光の樹海   | さんこうのじゅかい   | 沈んだ森。崩れた天井の大穴から陽が落ちる。彩度の高い緑と強い光条             | 天井の大穴からの陽光 | 明るい     | 若草 + 陽 |
| 2   | 沈んだ都     | —                    | 1 層より古い時代の地表。石の柱列と砂。柱の根元に菫色の結晶が芽を出す         | 崩れた天井からの斜光 | 明るい     | 砂と白石  |
| 3   | 大黒蛇の住処 | だいこくじゃのすみか | 壁からうねり出た黒い大蛇がとぐろを巻く。背の結晶がこの層の唯一の光           | 大蛇の背の結晶       | 薄暗い     | 藍紫      |
| 4   | 輝晶の間     | きしょうのま         | 結晶の柱が林立する大広間。影が下でなく横と上から差す。人影は逆光で黒く抜ける | 結晶そのもの。全方向 | 最も明るい | 白と淡菫  |
| 5   | 血染めの死海 | —                    | 干上がった赤い海床。巨大な肋骨が門のように立ち、塩が白く析出している         | 赤い靄の散乱光       | 中         | 緋と塩白  |
| 6   | 獄雷峡       | ごくらいきょう       | 切り立った谷。黒い雷が崖を走る。谷幅を竜が占める                             | 獄雷の縁の光だけ     | 暗い       | 黒紫      |
| 7   | 果てなき世界 | —                    | 床も天井も壁も無い。澱そのものでできた空洞。中央に湧き口がある               | 澱そのものの発光     | 最も暗い   | 紺と菫    |

### 2.1 各層で絵にすること

- **1 層 燦光の樹海**: 唯一、地上の光で歩ける層です。探索者のランタンはほとんど役に立ちません。
- **2 層 沈んだ都**: 明るい画面の中で紫が浮くので、**結晶の初出がはっきり読めます**。石と砂を明るく起こし、斜めの強い光を入れます。
- **3 層 大黒蛇の住処**: 七層で唯一の「暗い上層」です。ここを暗くしておくことで次の輝晶の間が効きます。
- **4 層 輝晶の間**: 灯りが完全に無意味になります。探索の難しさが「暗くて見えない」から **「眩しくて先が見えない」** へ反転します。
- **5 層 血染めの死海**: 輝晶の間の白からここで一気に赤へ振ります。落差が効きます。明るさはここから抜けていきます。
- **6 層 獄雷峡**: 獄雷は「黒い雷」なので背景より暗く抜け、縁だけが菫に光ります。加算合成では出ません（→ §7）。
- **7 層 果てなき世界**: 上下が分からないこと自体が最終層の異常さです。探索者は浮いています。

## 3. 共通の色

**背景だけ層で差し替え、UI の色は変えません。** 実装が楽で、プレイヤーも読み方を覚え直さずに済みます。

| 色名 | 値        | 使う場所                                      |
| ---- | --------- | --------------------------------------------- |
| 鈍鋼 | `#6d7787` | UI の枠線、鎧と武器の金属                     |
| 菫澱 | `#8b6fd0` | 澱ゲージ、危険の予兆                          |
| 燐光 | `#b9a3ff` | 結晶の発光、予兆バナーのハイライト            |
| 琥珀 | `#e8a84c` | プレイヤー、灯り、選択中、継承の間            |
| 灯芯 | `#ffd89a` | 最も重要な強調を 1 点だけ（習得・遺産・決着） |
| 緋   | `#c2483f` | HP、致命、取り返しのつかない選択              |

手当てが 3 か所要ります。

- **4 層**: 背景が最も明るいので、UI の地を暗く反転しないと読めません。
- **5 層**: 背景の赤と HP の緋 `#c2483f` が混ざります。この層だけ HP の色を変えるか、縁を付けます。
- **6・7 層**: 地の色（黒紫・紺）と澱ゲージの菫澱が同系になります。ゲージの縁を燐光 `#b9a3ff` に上げて浮かせます。

## 4. 敵の意匠

### 4.1 命名

```
通常敵 = [澱の浸かり具合] + の + [生前の役目]   例: 錆槍の衛士
精鋭   = [象徴する構え]   + の + [役職名]       例: 鉄壁の門衛長
大物   = [肩書き]         + カタカナの固有名     例: 大黒蛇 セルク
```

| 前に置く語 | 意味                                         | 主に出る層 |
| ---------- | -------------------------------------------- | ---------- |
| 錆         | 澱が金属を侵している。まだ体は固まっていない | 1〜2       |
| 澱         | 澱を帯びている。体の中に溜まり始めている     | 1〜4       |
| 灰         | 澱が抜けて脆くなった。崩れかけ               | 2〜3       |
| 晶         | 結晶が育った                                 | 3〜4       |
| 燐         | 結晶が発光している                           | 4〜7       |

### 4.2 規則

- **固有名は大物だけ**。通常敵と精鋭は一般名詞の組み合わせにします。出し惜しむと大物の登場が事件になります。
- **漢字 2 + 漢字 2**。読みを 6〜8 音に収めます。戦闘画面の敵名枠に収まり、手記の頁でも折り返しません。
- **上位種は後ろの語を変えない**。深い層の強化版は役目の語を据え置き、前の語だけ変えます（澱走りの供犬 → 燐光の供犬）。同じ系統だと一目で分かります。
- **層名を敵名に入れない**。敵は層をまたいで出るためです。
- **和の武術語を使わない**。錫杖・兜割り・薙ぎ払い・長柄は置き換えます。架空の地下文化に実在の日本の武術語が混ざるのを避けます。
- **腐敗語を使わない**。腐肉・白骨・亡者・這うもの・吊るし首は使いません。ホラー感はほぼこの 5 語から出ます。

## 5. プレイヤーの意匠

仕様の正本は `art_document/briefs/player_swordsman.md` です。共通規約として持つのは次の 3 つだけです。

- **顔は面で隠す**。目を光らせません（敵と読み違えるため）。輪郭は 面 + フード + マント で固定し、世代が変わっても変えません。
- **暖色はプレイヤーだけ**。灯り・選択中・継承の間は琥珀 `#e8a84c` です。
- **装甲を描かない**。アーマーは凍結中です（`concept-v3.md` §3.4）。板金と肩当ては置きません。

## 8. 次に判断が要る点

- **「瘴気」を「澱」に統一するか。** 本書と層名・敵名は「澱」で書いています。`concept-v3.md` §6 と `battle_core_v4.md` と実装は「瘴気」のままです。統一するなら全レーンを 1 回で通す Issue が要ります。
- **五層から七層への変更の波及。** ノードマップと澱の濃度（1〜5 を 1〜7 へ）は dungeon レーン、敵の層の割り当ては cards レーンです。Issue を 2 本切るのが早いです。
- **ComfyUI の導入。** 済めば 7 層ぶんの背景を実際に生成できます。プロンプトは七層レポート §6 に 7 本置いてあります。
