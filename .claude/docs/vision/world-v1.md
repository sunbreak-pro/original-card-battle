## 1. 舞台は竜の住処

**確定**

**竜が世界を侵略しようとしています。** このゲームのダンジョンは、その **竜の住処** です。

地上から掘って潜るのではありません。住処の口が地上へ開いていて、そこから降ります。層を降りるほど住処の奥になり、竜のものが増えていきます。一層の森も二層の秘跡も、元は人の側にあったものが呑み込まれた跡です。

**瘴気は住処に満ちているものです。** 竜がもたらし、奥ほど濃くなります。浴び続けると体に溜まり、最後は固まって動けなくなります（`concept-v3.md` §6）。設定としてはこれだけで足ります。

この設定が持つのは次の 3 つだけです。**これ以上の物語は作りません。**

| 設定             | 絵と画面に効くこと                                                     |
| ---------------- | ---------------------------------------------------------------------- |
| 竜の住処である   | 人工物が層を降りるほど減り、竜のもの（鱗・骨・爪痕・彫りもの）が増える |
| 竜が侵略している | 人の側の建物が壊れた形で残る。直された跡は無い                         |
| 瘴気が満ちている | 奥ほど画面が紺と菫に寄る。色は濃度であって演出ではない                 |

## 2. 全層に共通する 5 つの規則

背景を 7 枚描いても、敵を 19 体描いても、この 5 つが守られていれば 1 つの世界に見えます。

| #   | 規則                                   | 中身                                                                                                    |
| --- | -------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | **瘴気は深いほど濃く、紺と菫に寄る**   | 浅い層では薄まって色が出ません。深いほど本来の紺〜菫が出ます                                            |
| 2   | **光源が層ごとに入れ替わる**           | 陽光 → 斜光 → 結晶 → 結晶の全方向 → 散乱光 → 雷の縁 → 瘴気の発光。どこにいるかを光だけで判別できます    |
| 3   | **明るさの山を四層に置く**             | 1・2 は明るく、3 で落とし、4 で最も輝き、5 から抜いていきます。暗い層を 1 つ挟まないと 4 層が効きません |
| 4   | **暖色はプレイヤーの側にしか置かない** | 琥珀の灯りがプレイヤーの居場所です。4 層以降は結晶のほうが明るく、灯りが役に立たなくなります            |
| 5   | **結晶は四層を境に増える**             | 二層で芽を出し、三層で大蛇の背に育ち、四層で壁と天井を覆います。一層には 1 つも置きません               |

## 3. 七層

| 層  | 名前         | 読み                 | 見えるもの                                                                         | 光源                 | 明るさ     | 主な色    |
| --- | ------------ | -------------------- | ---------------------------------------------------------------------------------- | -------------------- | ---------- | --------- |
| 1   | 燦光の樹海   | さんこうのじゅかい   | 沈んだ森。崩れた天井の大穴から陽が落ちる。彩度の高い緑と強い光条                   | 天井の大穴からの陽光 | 明るい     | 若草 + 陽 |
| 2   | ■■の秘跡     | —                    | 竜神を祀った古い聖域。石の柱列と砂。柱に竜を象った彫り。根元に菫色の結晶が芽を出す | 崩れた天井からの斜光 | 明るい     | 砂と白石  |
| 3   | 大黒蛇の住処 | だいこくじゃのすみか | 壁からうねり出た黒い大蛇がとぐろを巻く                                             | 大蛇の背の結晶       | 薄暗い     | 藍紫      |

| 5   | 血染めの死海 | —                    | 干上がった赤い海床。巨大な肋骨が門のように立ち、塩が白く析出している               | 赤い靄の散乱光       | 中         | 緋と塩白  |
| 6   | 獄雷峡       | ごくらいきょう       | 切り立った谷。黒い雷が崖を走る。谷幅を竜が占める                                   | 獄雷の縁の光だけ     | 暗い       | 黒紫      |
| 7   | 果てなき世界 | —                    | 床も天井も壁も無い。瘴気そのものでできた空洞。中央に湧き口がある                   | 瘴気そのものの発光   | 最も暗い   | 紺と菫    |

### 3.1 各層で絵にすること

- **一層 燦光の樹海**: 唯一、地上の光で歩ける層です。探索者のランタンはほとんど役に立ちません。
- **二層 ■■の秘跡**: 明るい画面の中で紫が浮くので、**結晶の初出がはっきり読めます**。柱の彫りが竜の形をしていることが、**この層だけ画面から読み取れる手掛かり** です（→ §4）。
- **三層 大黒蛇の住処**: 七層で唯一の「暗い上層」です。ここを暗くしておくことで次の輝晶の間が効きます。
- **四層 輝晶の間**: 灯りが完全に無意味になります。探索の難しさが「暗くて見えない」から **「眩しくて先が見えない」** へ反転します。
- **五層 血染めの死海**: 輝晶の間の白からここで一気に赤へ振ります。明るさはここから抜けていきます。
- **六層 獄雷峡**: 獄雷は「黒い雷」なので背景より暗く抜け、縁だけが菫に光ります。加算合成では出ません（→ §8）。
- **七層 果てなき世界**: 上下が分からないこと自体が最終層の異常さです。探索者は浮いています。

## 4. 二層 ■■の秘跡 と 竜神

**確定**（層の扱いと見せ方）／ **提案**（戦闘の中身は cards レーンの担当）

### 4.1 名前の伏せ方

この層の正式名称は **竜神の秘跡** です。ゲーム内では最初 **■■の秘跡** と表示します。

| 状態                     | 層の名前の表示 |
| ------------------------ | -------------- |
| 手掛かりのアイテム未取得 | ■■の秘跡       |
| 取得後                   | 竜神の秘跡     |

伏せるのは 2 文字だけです。**層に入った瞬間の 1 行**、手記の層の頁、ノードマップの見出しの 3 か所で同じ表示を使います。伏字は塗り潰しの四角 2 つで、フォントは変えません。

**この形にする理由**: 何が伏せられているかがプレイヤーに見えるので、「この層には名前がある」と分かります。名前ごと隠すと、伏せられていること自体に気付けません。

### 4.2 この層の役目

**エンドコンテンツ「竜神」への手掛かりを手に入れる層** です。

- 竜神は住処の主で、**クリア後にだけ会えます**。枠は `enemy_roster_v4.md` §7（エクストラボス、Issue #39）がそのまま竜神になります
- 手掛かりは二層で拾うアイテムです。拾うと層の名前が「竜神の秘跡」に変わります
- **手掛かりを拾うこと自体に戦闘上の効果を付けません。** `roster` §7.2 の「解禁が与えるのは挑戦の機会だけ」を守ります

### 4.3 六層の獄竜との関係

獄竜 ガルドは住処の番をしている竜です。竜神とは別の個体で、**本編の途中で戦う竜** です。竜神は本編では姿を見せません。

2 体を分けることで、「竜と戦う」経験を本編で 1 回与えたうえで、クリア後にその上位を置けます。

## 5. 共通の色

**背景だけ層で差し替え、UI の色は変えません。** 実装が楽で、プレイヤーも読み方を覚え直さずに済みます。

| 色名 | 値        | 使う場所                                      |
| ---- | --------- | --------------------------------------------- |
| 鈍鋼 | `#6d7787` | UI の枠線、鎧と武器の金属                     |
| 菫   | `#8b6fd0` | 瘴気ゲージ、危険の予兆                        |
| 燐光 | `#b9a3ff` | 結晶の発光、予兆バナーのハイライト            |
| 琥珀 | `#e8a84c` | プレイヤー、灯り、選択中、継承の間            |
| 灯芯 | `#ffd89a` | 最も重要な強調を 1 点だけ（習得・遺産・決着） |
| 緋   | `#c2483f` | HP、致命、取り返しのつかない選択              |

手当てが 3 か所要ります。

- **四層**: 背景が最も明るいので、UI の地を暗く反転しないと読めません。
- **五層**: 背景の赤と HP の緋 `#c2483f` が混ざります。この層だけ HP の色を変えるか、縁を付けます。
- **六・七層**: 地の色（黒紫・紺）と瘴気ゲージの菫が同系になります。ゲージの縁を燐光 `#b9a3ff` に上げて浮かせます。

## 6. 敵の意匠

### 6.1 命名

```
通常敵 = [瘴気の浸かり具合] + の + [生前の役目]   例: 錆槍の衛士
精鋭   = [象徴する構え]     + の + [役職名]       例: 鉄壁の門衛長
大物   = [肩書き]           + カタカナの固有名     例: 大黒蛇 セルク
```

| 前に置く語 | 意味                                           | 主に出る層 |
| ---------- | ---------------------------------------------- | ---------- |
| 錆         | 瘴気が金属を侵している。まだ体は固まっていない | 1〜2       |
| 瘴         | 瘴気を帯びている。体の中に溜まり始めている     | 1〜4       |
| 灰         | 瘴気が抜けて脆くなった。崩れかけ               | 2〜3       |
| 晶         | 結晶が育った                                   | 3〜4       |
| 燐         | 結晶が発光している                             | 4〜7       |

### 6.2 規則

- **固有名は大物だけ**。通常敵と精鋭は一般名詞の組み合わせにします。出し惜しむと大物の登場が事件になります。
- **漢字 2 + 漢字 2**。読みを 6〜8 音に収めます。戦闘画面の敵名枠に収まり、手記の頁でも折り返しません。
- **上位種は後ろの語を変えない**。深い層の強化版は役目の語を据え置き、前の語だけ変えます（瘴走りの供犬 → 燐光の供犬）。同じ系統だと一目で分かります。
- **層名を敵名に入れない**。敵は層をまたいで出るためです。
- **和の武術語を使わない**。錫杖・兜割り・薙ぎ払い・長柄は置き換えます。
- **腐敗語を使わない**。腐肉・白骨・亡者・這うもの・吊るし首は使いません。ホラー感はほぼこの 5 語から出ます。

### 6.3 言い換え（提案・cards レーンの判断）

`enemy_roster_v4.md` は cards レーンの持ち物なので、案を出すだけです。資源の語が「瘴気」で確定したので、`瘴気の帳` `瘴気の矢` などはそのまま残ります。

| 分類 | 現行              | 案                    | 理由                                   |
| ---- | ----------------- | --------------------- | -------------------------------------- |
| 状態 | 瘴気纏い          | 晶蝕                  | 体の中で結晶が育って動きが鈍る         |
| 状態 | 呪縛              | 縛言（ばくげん）      | 「呪」は魔術の語。この世界に魔術は無い |
| 技   | 錫杖の打ち込み    | 晶杖の打ち込み        | 錫杖は実在の仏具                       |
| 技   | 薙ぎ払い / 兜割り | 払い斬り / 打ち下ろし | どちらも実在の武術語                   |
| 技   | 石突きの押し込み  | 柄尻の押し込み        | 石突きは日本語の部位名                 |

敵 9 体 + 10 体の改名案の一覧は `docs/reports/2026-09-20-world-theme-and-enemy-naming.html` §7・§9 にあります。本書は重複して持ちません。

## 7. 大物

姿だけを持ちます。数値と行動表は `enemy_roster_v4.md` が正です。

| 名前          | 層       | 姿                                                                         | 絵としての狙い                                                 |
| ------------- | -------- | -------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 大黒蛇 セルク | 3        | 壁からうねり出た黒い巨躯。とぐろを巻き、鎌首だけを下ろす。背に結晶         | 動かない。結晶の発生源で、この層の唯一の光源                   |
| 獄竜 ガルド   | 6        | 四足・二対の翼の欧州型。黒い雷を纏う。後ろへ反る二本の角、細長い頭、重い顎 | 暗い谷で「黒より黒いもの」が動く。灯りを当てても照らし返さない |
| 歪みの根      | 7        | 住処の最奥で瘴気を生んでいるもの。撃破がクリア条件（`roster` §6）          | 上下の無い空間の、唯一の中心                                   |
