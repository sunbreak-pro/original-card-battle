## 1. 一文コンセプト

> 死者の技を継ぎ、失われた知識を自らの記憶で補いながら、限られた生の中でダンジョンの深奥を目指す、高難度ダンジョン探索 × カード戦略ゲーム。

短縮形: **「死ぬたびに人は変わる。だが、技と記憶は次の生へ。」**

- プレイヤーは一人の固定キャラクターを操作する。キャラクター自体のカスタマイズはしない。
- キャラクターは永続成長しない。「生」を繰り返し、前の生の技術・知識・遺産を次のキャラクターへ限定的に継承する。
- キャラクターは死ぬ。手記は死亡地点に置き去りになる。しかしプレイヤー自身の知識と、死者が残した一部の技術と頁は次の生へつながる。

## 2. 中核の 5 要素と循環

| #   | 要素        | 一言                                                                         |
| --- | ----------- | ---------------------------------------------------------------------------- |
| 1   | 習熟度      | カードを「どう使ったか」で育ち、名称・性能・役割が変わる                     |
| 2   | 間合い      | 近 / 中 / 遠。双方が有利な距離を奪い合う                                     |
| 3   | スタミナ    | カード使用の主リソース。温存にも意味がある                                   |
| 4   | 手記 / 知識 | 敵とダンジョンの攻略情報と自分のメモ。死ぬと置き去りになり、選んだ頁だけ継ぐ |
| 5   | 瘴気        | 階層ごとの濃度で蓄積し、一つの生で探索できる回数を制御する                   |

独立したシステムとしてではなく、次の一つの循環として設計する。

> 探索する → 情報を得る → 敵を読む → 間合いを作る → スタミナを配分する → 習熟したカードで戦う → 生き残る / 死ぬ → 次の生へ継承する

## 3. 戦闘

### 3.1 間合い

- プレイヤーと敵には間合い（近 / 中 / 遠）がある。カードや敵の行動で変化する。
- カードには間合いによる補正がある。攻撃力・防御力・追加効果・命中と回避・特殊効果が変わる。
- 敵も間合いを戦術的に変える。戦闘は「強いカードを出す」ゲームではなく、**敵と自分の双方にとって有利な距離を奪い合うゲーム**である。
- 段階数・初期距離・移動ルールなどの細部と数値は `battle_document/battle_core_v3.md`（2026-09-12）を正とする。

### 3.2 スタミナ

- ターンをまたいで持ち越す。ターン開始時に少量回復する。
- カード使用時に任意量を消費する。**1 枚のカードに投入できるスタミナは最大 3**。消費量で性能が変わる（0 = 低 / 1 = 中 / 2 = 高 / 3 = 最大）。
- 「今ターンに最大火力を出すか、温存して次ターンに備えるか」を毎ターン判断させる。
- スタミナを残す意味を設ける。例: 現在スタミナが一定以上なら追加効果 / 少ないほど強い / ターン終了時に一定量残すと防御効果 / 温存で次ターンの選択肢が増える。**「使い切る = 正解」にしない。**

### 3.3 最大スタミナ

二つの軸で決まる。

1. **一時的な変化**（この生の中で発生）: 重い荷物 -2 / 特定の食事 +1 / 特殊な休息 +2 / 呪い -3 など。探索中の選択・イベント・状態で発生する。
2. **瘴気による変化**（この生で浴びた瘴気の蓄積、§6）: 恒久的に減少する。

### 3.4 防御（アーマー凍結後）

- 防御層は **Guard（ターン内の一時防御）のみ**。Guard → HP の 2 層で調整する。
- AP（装備耐久由来のアーマー）・装備破損・修理は凍結。設計書は残すが実装対象から外す（`ap-equipment-system.md` に FROZEN 表示）。
- 解除条件: アーマー無しの戦闘で難易度と調整が一巡し、ユーザーが解除を指示したとき。

### 3.5 適応型 AI と予兆（ハードモード設計）

- ボスと一部の強敵は固定パターンではなく、プレイヤーの行動で方針を変える。例: 近距離攻撃を繰り返す → 接近対策 / 防御多用 → 防御崩し / 同じカードを繰り返す → そのカードへの対策 / 遠距離維持 → 接近優先。
- 完全なブラックボックスにしない。**敵の予兆 + 手記の頁 + 戦闘中の観察** で予測可能にする。
- 難易度思想: 「敵を知らなければ難しい。しかし知れば必ず勝てるとは限らない」。死亡は失敗ではなく、次回の攻略に必要な情報を得る機会である。

## 4. カード

### 4.1 習熟度

- カードごとに習熟度がある。使用回数だけでなく **どの間合いで / どのスタミナ量で / 敵のどの行動に対して / どの条件下で** 使ったかで進む。「何回使ったか」ではなく「どう使ったか」が成長に反映される。
- 一定の習熟度で名称・性能・役割が変わる（例: 観察 → 精査 → 洞察 → 看破）。名称変化そのものを成長の実感として扱う。
- 一部のカードは高習熟で **カードを使わなくても効く永続能力** を得る（例: 洞察眼 = 戦闘開始時に敵の行動候補を一つ確認。デッキから外していても発動）。永続能力は数値強化ではなく、情報・選択肢・探索上の利便性・条件付きの小さな補助を中心にする。
- 既存の「使用回数 → 派生カード解放」（masteryManager）は、この文脈ベース習熟へ置き換える。

### 4.2 探索用カードと二面性

- 探索に特化したカードを設ける（観察 / 探知 / 聴覚 / 地図作成 / 解体 / 応急処置 / 交渉 / 採取）。戦闘性能は低くてよい。
- 可能なら 1 枚に **探索時の効果 + 戦闘時の効果** の二面性を持たせる（例: 観察。探索 = 周辺の隠された情報を発見 / 戦闘 = 敵の次行動候補を確認）。
- デッキ構築に「戦闘力を取るか、探索能力を取るか」のジレンマを作る。

### 4.3 所持と戦闘デッキ

- 所持カードは最大 80 枚程度。戦闘デッキは 20 枚以上を基本とし、上限は調整対象。
- 所持カードと戦闘デッキを分離する。デッキ構築は「今回のダンジョン / 敵に対する回答を作る行為」になる。

## 5. 手記

「図鑑」ではなく **手記** と呼ぶ。図鑑は探索に持ち出せない百科事典だが、手記は探索者が持ち歩き、自分で書き込む帳面である（2026-09-12 決定）。

- **敵の頁**: 弱点 / 耐性 / 行動パターン / 間合いごとの傾向 / 特殊行動 / 行動条件 / 他の敵との関係 / プレイヤーへの適応条件（例: 「同一カテゴリの攻撃を 3 回受けると防御行動を優先する」）。観察・遭遇で段階的に埋まる。
- **ダンジョンの頁**: 近道 / 隠し部屋 / 特定地点 / 条件出現の敵 / 特殊イベント / 罠 / 資源 / ショートカット / 特殊な探索条件。
- **メモ**: プレイヤー自身が自由に書き込める頁。ゲームは内容を解釈しない。
- **どこで読めるか**: 拠点・探索中・戦闘中のどこでも読める。**戦闘中は現在の敵の頁を読めるだけ**で、読むことが戦闘に直接の効果（バフ・予兆の精度上昇など）を与えることはない。予兆の表示精度は手記の開示度で決まるが、それは「知っていること」の反映であり、読む操作の効果ではない。
- **死んだら**: 手記はそのキャラクターの死亡地点に痕跡として残る（§8.3）。次のキャラクターは遺産の枠で **手記の一部の頁だけ** を選んで継ぐ。選ばなかった頁と資源は失われる。手記を丸ごと継ぐことはできない。
- 「キャラクターは知らない。しかしプレイヤーは知っている」は保つ。プレイヤーの記憶は消えず、キャラクターが持つ知識は選んだ頁だけになる。
- concept-v2 A1「手記は死を越える」は **一部復活**: 死を越えるのは遺産で選んだ頁だけ。

## 6. 刻限と瘴気

「衰弱」は **瘴気** に改名した（2026-09-12）。身体の疲弊ではなく、ダンジョンに満ちる毒気を浴び続けることで生が削られる。

| リソース | 役割                         | 単位                                     | 尽きると               |
| -------- | ---------------------------- | ---------------------------------------- | ---------------------- |
| 刻限     | この階層で何をするか         | 一つの階層に約 10 回                     | その階層の行動が終わる |
| 瘴気     | この生をどこまで続けられるか | 蓄積ゲージ 0〜100%（例: ■■■■■■□□□□ 60%） | 瘴気死（生の終了）     |

- **刻限**を消費して、探索 / 情報収集 / イベント / 戦闘 / 習熟訓練 / 休息 / 近道の発見 / 特殊地点の調査を行う。「次の階層へ進むか、この階層をもっと調べるか、習熟を上げるか」を選ばせる。刻限は単なるターン数ではなく「限られた時間で何を優先するか」のリソースである。
- **瘴気の濃度**は階層ごとに決まり、深いほど濃い。刻限を 1 消費する行動ごとに、濃度の分だけ蓄積が増える。濃い階層ほど探索の難度も上がる（敵プールと難易度カーブは R2-8）。
- **瘴気の蓄積**が進むほど最大スタミナが減る（20% ごとに -1。数値は `battle_core_v3.md` §3.1）。100% で瘴気死。「もっと調査したい / しかし身体が限界に近い」のジレンマを作る。
- **和らげる手段**を用意する。探索用ツール（例: 防瘴の面 = この生の間、濃度 -1）、資源（例: 浄化の香 = 蓄積 -10%、消耗）、階層間の休憩（蓄積しない安全地帯）、一部の探索カード。ツールの枠は §12-13、資源の入手は §12-17。
- 二つを別リソースにする意味を明確に保つ。刻限 = 階層内の優先順位、瘴気 = 生の長さ。競合させない。

## 7. 探索と戦闘の相互作用

探索中の選択が最大スタミナ・HP・瘴気を変え、その後の戦闘難易度に直接効く。

| 選択                   | 効果                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| 重い宝箱を運ぶ         | 貴重なアイテム獲得 / 最大スタミナ -2                                        |
| 休息する（階層内）     | HP 15% 回復 / スタミナ全回復 / 最大スタミナ +2 / 刻限 -1 / 瘴気は濃度分蓄積 |
| 休憩する（階層間）     | HP 30% 回復 / スタミナ全回復 / 瘴気は蓄積しない                             |
| 特殊な食事             | 最大スタミナ +1 / 別の代償が発生                                            |
| 泉・薬草などのイベント | HP 回復（量はイベントごと）。R2-4 で定義                                    |

### 7.3 探索のランダム性（2026-09-12 決定）

- 探索の報酬とイベントはランダムに出す。生存ルートが「手記を丸ごと持ち越す安全な選択」になりすぎないよう、深く潜るほど期待値の高い報酬（カード / 資源 / 手記の希少な頁）が出る。
- ランダムの範囲: 報酬の種類と量、イベントの発生。敵の行動と戦闘の解決は乱数を使わない（`battle_core_v3.md` §1.2）。
- 内容は R2-4 で定義する。手記のダンジョンの頁に「条件出現」として記録できる形にする。

### 7.1 HP と回復（2026-09-12 決定）

- HP はスタミナと同じく **戦闘をまたいで持ち越す**。
- 回復手段は 3 系統: **戦闘中のカード**（応急処置など。投入量で回復量が変わる。`battle_core_v3.md` §4）、**階層間の休憩**（上表）、**探索中のイベント**（泉・薬草・階層内の休息）。
- 無償の全回復は無い。瘴気が「生の長さ」を、HP が「次の戦闘に耐えられるか」を担う。

### 7.2 ツール（探索前ロードアウト）

- 探索開始時に限られた数のツールを選ぶ。カードとは役割を分ける。
- 探索用: 特定の扉を開ける / 特定の場所へ到達する / 隠しルートを解放する / 特殊イベントを発生させる / **瘴気の濃度を和らげる**。
- 戦闘用: 開始時の間合いを変更 / 初期スタミナ補助 / 一度だけ防御 / 特定の敵への対策。

## 8. 生・死・継承

### 8.1 二つの終わり方

```
探索者 A
 ↓ 瘴気が進行
 ↓ まだ死亡していない
 ├─ 生存ルート: 「この生はここまで」と判断し、A は生存したまま次のキャラクターへ
 └─ 死亡: 死亡地点に A の痕跡（遺産）が残る
```

- 瘴気死まで探索する必要はない。プレイヤー自身が生の終了を選べる（生存ルート）。
- 旧ライフ制（Hard 2 / Normal 3、0 でゲームオーバー全リセット）は **廃止**。死は次の生への移行であり、全リセットは存在しない。

### 8.2 生存者の継承

- 生存ルートを選んだ場合、次のキャラクターは (1) 前回死亡したキャラクターの遺産 と (2) 前回生存したキャラクター の両方からボーナスを受け取れる。
- 生存キャラクターは **一人まで** しか次の生に登場できない。前世代の生存者を蓄積できない。
- **生存ルートでは手記を丸ごと受け継ぐ**（2026-09-12 決定）。死亡（選んだ頁だけ）より見返りを大きくするのが自然だからである。生存ルートのボーナスは「手記の全頁 + 生存者ボーナス（§12-12）」で構成する。
- ただし生存ルートが常に得にならないよう、探索には **ランダムな報酬とイベント** を持たせる（§7.3）。死亡地点の遺産は「深い地点まで行った証」として、生存ルートでは得られない技術を含む。

### 8.3 死亡者の遺産

- 死亡地点に前キャラクターの痕跡が残る。次のキャラクターがその場所を訪れると遺産を受け継げる。**選択は死亡地点で行う**。継承の間では死亡地点と候補の一覧を見るだけで、受け取りは訪問時（2026-09-12 に文書間の不一致を統一）。
- 遺産の内容: 技術 / 習熟したカードの成果 / 一部の敵知識 / 探索知識 / 特殊な能力。
- **痕跡は回収されるまで残る**（次の死亡で上書きしない。2026-09-12 決定、企画書 §16「前回死亡者だけ」からの変更）。深い地点で死んだ探索者の遺産は、後の世代が届いたときに受け取れる。
- ただし **1 つの生で受け取れる遺産は 1 件**（最初に訪れた痕跡）。世代を跨いだ蓄積はこれで防ぐ。継承の間では未回収の痕跡が全て見える。
- **選択制**: 限られた枠（例: 3 つまで）から数個だけ選ぶ。「何を次の人生へ残すか」が戦略になる。

### 8.4 浅層での意図的な死亡への対策

- 一定以上の習熟度を持つカードは、浅い階層・弱い敵との戦闘で死亡した場合、遺産として残らない。
- 強い技を育てることと、その技を遺産として残す資格を得ることを分離する。資格 = その技に見合った危険な地点まで到達していること。

## 9. 成長の構造とゲームループ

| 成長                 | 持続                         | 死亡時                                         |
| -------------------- | ---------------------------- | ---------------------------------------------- |
| キャラクターの成長   | この生の中だけ               | 失われる                                       |
| カードの習熟         | この生の中で成長             | 遺産として一部だけ継承                         |
| 手記                 | そのキャラクターの知識とメモ | 死亡地点に残る。選んだ頁だけ継承、他は失われる |
| 遺産                 | 死亡地点 → 次のキャラクター  | 一部継承                                       |
| プレイヤー自身の知識 | ゲーム外                     | 失われない                                     |

「キャラクターは死んでも、プレイヤーは少しずつ上手くなる」を成立させる。

```
探索開始 → ツール選択 → 所持カードから戦闘デッキ構築 → ダンジョンへ
 → 刻限を消費しながら探索（情報収集 / 戦闘 / 習熟 / イベント / 近道発見 / 休息）
 → 手記に敵・ダンジョンの知識を書く → カード習熟 → 次の階層へ → 瘴気が濃くなる
 → 「さらに進む」or「この生を終える」
    ├─ 生存ルート: 次のキャラクター + 生存者のボーナス
    └─ 死亡: 死亡地点に遺産 → 次のキャラクターが一部継承
```

## 10. 既存ルールとの対応（上書き表）

| 既存ルール（concept-v2 / 設計書）                                              | 本改定                                                                                | 扱い               |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- | ------------------ |
| ライフ制（Hard 2 / Normal 3、0 で全リセット）                                  | 生の繰り返し + 瘴気 + 生存ルート。全リセット無し                                      | 置換               |
| 手記は死を越える（A1）                                                         | 手記は死亡地点に残り、遺産の枠で選んだ頁だけ継ぐ                                      | 一部復活           |
| ソウル（経験値）100% 獲得 → サンクチュアリ永続スキルツリー                     | キャラクターの永続成長は無い                                                          | 凍結               |
