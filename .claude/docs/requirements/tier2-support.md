# Tier 2 — 補助要件（コアが回った後に体験を厚くする）

> **Status**: DRAFT v3（2026-09-12: concept-v3 準拠で全面改稿）
> **入力**: `docs/vision/concept-v3.md` / `tier1-core.md` v6
> 位置づけ: Tier 1 の「2 つの生」通しプレイが成立してから着手する。

---

## R2-1: ダンジョン構造の設計書化（単一ダンジョン・ノード式）

- **由来**: concept-v3 §12-14（2026-09-12 決定: 一つのダンジョンを深く潜る。マップはノード式のまま、後で変更の可能性あり）
- **内容**: 単一ダンジョンの階層数・階層ごとの敵プール・ノードの種類（戦闘 / 情報収集 / イベント / 休息 / 近道 / 特殊地点）・刻限との対応を `danjeon_document/` に書く。マップ生成はノード式を継続し、マップ方式を差し替えられるよう「ノード = 刻限を消費する行動の置き場」として抽象化する。死亡地点の遺産（R1-12）が階層 + ノードで一意に指せること
- **依存**: R1-12
- **受け入れ基準**:
  - [ ] 遺産の痕跡が階層・ノードで一意に指せる
  - [ ] マップ方式（ノード式）を差し替えても刻限・遺産のデータが壊れない境界がある

## R2-2: 剣士カードの再定義（習熟段階付き）

- **由来**: concept-v3 §4 / 旧 R1-10
- **内容**: 剣士カードを新ルール（間合い補正表 / 投入量 0〜3 / 習熟段階と名称変化 / 一部の永続能力 / 探索効果）で再定義。枚数は所持上限 80 に対して十分な選択肢が出る規模
- **依存**: R1-5, R1-6
- **受け入れ基準**:
  - [ ] 全カードに習熟段階の定義がある
  - [ ] `card_document/` と実装データの差分ゼロ

## R2-3: 敵ロースターの新ルール対応

- **由来**: concept-v3 §3.1 / §3.5 / §5
- **内容**: 敵定義に得意間合い・間合い変更行動・予兆・手記項目（弱点 / 耐性 / 条件 / 関係 / 適応条件）を付与。ボスに適応ルールを持たせる
- **依存**: R1-4, R1-15
- **受け入れ基準**:
  - [ ] 全敵が手記の全項目を埋められる

## R2-4: 探索イベントとツールの拡充

- **由来**: concept-v3 §7
- **内容**: 最大スタミナ・HP・瘴気を変えるイベント（重い宝箱 / 休息 / 食事 / 呪い / 泉 / 薬草）と、探索用・戦闘用ツールの実データ（防瘴の面を含む）。資源（浄化の香など）とアイテム（§12-17）の扱いをここで決める
- **依存**: R1-9, R1-14
- **受け入れ基準**:
  - [ ] 1 階層あたり最大スタミナが動くイベントが 2 つ以上出る
  - [ ] 瘴気を和らげる手段がツール・資源に 1 つずつ以上ある

## R2-5: 戦闘 HUD と演出

- **由来**: concept-v3 §3 / §6
- **内容**: 間合い・スタミナ（投入量選択 UI）・Guard・HP・瘴気（蓄積と階層の濃度）・刻限の常時表示。予兆の表示。戦闘中に手記（敵の頁）を開く導線。アート / Live2D は `plans/2026-06-28-unity-migration-character-art.md`
- **依存**: R1-9, R1-15
- **受け入れ基準**:
  - [ ] 投入量 0〜3 を 1 操作で選べる

## R2-6: 学習手段

- **由来**: 旧 R1-19 / R2-4
- **内容**: 間合い・スタミナ・習熟・手記・瘴気・継承の 6 ルールを日本語で伝える tips と初回導線
- **依存**: R1-17
- **受け入れ基準**:
  - [ ] 新規プレイ導線で 6 ルールを操作しながら学べる

## R2-7: 魔術師の新コア再適合

- **由来**: concept-v2 §4「魔術師は後追い」（継続）
- **内容**: 属性共鳴を投入量スタミナと習熟段階に再設計。剣士で新コアが安定してから
- **依存**: R2-2
- **受け入れ基準**:
  - [ ] 魔術師で「2 つの生」通しプレイが可能

## R2-8: 難易度帯とバランス

- **由来**: 旧 R1-21〜R1-24
- **内容**: 階層ごとの敵強度・瘴気の濃度・刻限の難易度カーブを設計書化。アーマー無しでの調整が一巡した時点で、アーマー凍結解除の判断材料（§12-19）をまとめる
- **依存**: R2-1, R2-3
- **受け入れ基準**:
  - [ ] 難易度カーブが設計書に数値で載っている
  - [ ] アーマー解除を判断するための計測項目が列挙されている
