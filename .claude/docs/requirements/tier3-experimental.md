## 実験候補（コンセプトと整合するが今回見送った軸）

### R3-1: 身体リアリティの拡張

- **由来**: concept-v2 §1 見送り軸の残り。衰弱（R1-9）が「疲労」の後継として入った
- **内容**: 負傷部位 / 出血の恒常化 / 空腹 / 治療に時間がかかる。衰弱の内訳として拡張する案が最有力
- **着手条件**: Tier 1-2 完了後、通しプレイで「もっと身体が欲しい」と感じた場合

### R3-2: 世界・生活リアリティ

- **由来**: concept-v2 §1 見送り軸
- **内容**: 時間経過 / 天候 / NPC の生活。刻限（R1-8）に天候を絡める小さな入口がある
- **着手条件**: ステージ構造（R2-1）が定着した後

### R3-3: 演出・質感

- **由来**: PixiJS Phase 2-4 の演出案（Unity 移行で置き換え）
- **内容**: 間合い移動の演出、習熟による名称変化の演出、遺産の痕跡の演出
- **着手条件**: R2-5 完了後
