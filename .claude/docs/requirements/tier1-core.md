## R1-3 [Phase 1]: スタミナ v3 の C# 実装

- **由来**: concept-v3 §3.2 / §3.3
- **内容**: `BattleCore` のスタミナを「投入量 0〜3 の可変コスト + ターン持ち越し + 開始時回復 + 最大値の外部入力（探索状態から）」へ改める。温存効果（スタミナ閾値で追加効果 / 低スタミナで強化 / ターン終了時残量で防御）をカード効果の型として追加
- **依存**: R1-2
- **受け入れ基準**:
  - [ ] 同じカードを投入量 0 / 1 / 2 / 3 で使い分けられる
  - [ ] 最大スタミナを外から -2 / +2 と変えたときに戦闘が追随する
  - [ ] `dotnet test` で投入量 0〜3 の各段・最大スタミナの外部入力・構えをカバーする（TS パリティは打ち切り。fixture と `parity:*` スクリプトは履歴として残す）

## R1-4 [Phase 1]: 間合い補正と敵の間合い戦術

- **由来**: concept-v3 §3.1
- **内容**: カードの間合い補正を「有効間合いか否か」の二値から、補正表（攻撃 / 防御 / 追加効果 / 命中回避）へ拡張。敵行動に間合い変更と得意間合いを持たせ、AI が距離を取りに行く
- **依存**: R1-2
- **受け入れ基準**:
  - [ ] 同じカードが間合いで少なくとも 2 種類の性能を持つ
  - [ ] 敵が自分の得意間合いへ移動する行動を選ぶ

## R1-5 [Phase 2]: 文脈ベース習熟とカード変化

- **由来**: concept-v3 §4.1
- **内容**: 習熟度をカードごとに持ち、「どの間合いで / どのスタミナ量で / 敵のどの行動に対して / どの条件で」使ったかで加算する。閾値で名称・性能・役割が変わる段階（例: 観察 → 精査 → 洞察 → 看破）。高習熟の一部カードに永続能力（デッキ外でも発動。情報・選択肢・利便性・小さな補助に限定）。既存 masteryManager の「使用回数 → 派生」を置き換える
- **依存**: R1-3, R1-4
- **受け入れ基準**:
  - [ ] 使用回数が同じでも使い方で習熟が違う
  - [ ] 名称が変わったカードが UI と手記に反映される
  - [ ] 永続能力がデッキに入れていないカードから発動する

## R1-6 [Phase 2]: 探索用カードと二面性

- **由来**: concept-v3 §4.2
- **内容**: 探索効果を持つカード型を追加（観察 / 探知 / 聴覚 / 地図作成 / 解体 / 応急処置 / 交渉 / 採取）。1 枚に探索効果 + 戦闘効果を持てるデータ構造。探索ノードでカードを「使う」導線
- **依存**: R1-5, R1-9
- **受け入れ基準**:
  - [ ] 戦闘で弱く探索で強いカードが少なくとも 4 枚ある
  - [ ] 観察が探索と戦闘の両方で効く

## R1-7 [Phase 2]: 所持カードと戦闘デッキの分離

- **由来**: concept-v3 §4.3
- **内容**: 所持上限 80 枚程度、戦闘デッキ 20 枚以上（上限は調整対象）。出立時に所持から戦闘デッキを組む画面
- **依存**: R1-5
- **受け入れ基準**:
  - [ ] 所持とデッキが別データで、デッキだけが戦闘に入る
  - [ ] 出立時にデッキを組み替えられる

## R1-8 [Phase 3]: 刻限

- **由来**: concept-v3 §6
- **内容**: 階層ごとに約 10 回の行動回数。探索 / 情報収集 / イベント / 戦闘 / 習熟訓練 / 休息 / 近道発見 / 特殊地点調査が刻限を消費する。次の階層へ進むと刻限が更新される。§12-1 の「10 回の具体的な行動」を設計書に落とす
- **依存**: R1-1
- **受け入れ基準**:
  - [ ] 階層内で 10 回前後の選択が発生し、使い切ると先へ進むしかない
  - [ ] 休息が刻限 -1 と最大スタミナ +2 を同時に起こす

## R1-9 [Phase 3]: 瘴気・最大スタミナ・HP の持ち越しと回復

- **由来**: concept-v3 §6 / §7 / §7.1
- **内容**: 瘴気の蓄積ゲージ（0〜100%）。階層ごとの濃度を持ち、刻限 1 行動ごとに濃度分だけ蓄積。20% ごとに最大スタミナ -1、100% で瘴気死。探索イベントによる一時的な最大スタミナ変化（重い荷物 -2 / 食事 +1 / 休息 +2 / 呪い -3）と合算して戦闘へ渡す。HP とスタミナは戦闘をまたいで持ち越し、階層間の休憩（HP 30% / スタミナ全回復 / 瘴気は蓄積しない）と階層内の休息（HP 15% / 刻限 -1）で回復。和らげる手段（防瘴の面 = 濃度 -1、浄化の香 = 蓄積 -10%）を最低 1 つずつ
- **依存**: R1-3, R1-8
- **受け入れ基準**:
  - [ ] 瘴気ゲージと階層の濃度が HUD に常時表示される
  - [ ] 瘴気 60% で最大スタミナが下がった状態で戦闘が始まる
  - [ ] 100% で生が終了し、次の生へ移る
  - [ ] 戦闘後の HP・スタミナが次の戦闘に持ち越され、階層間の休憩で回復する
  - [ ] 防瘴の面を持つと同じ階層で蓄積が遅くなる

## R1-10 [Phase 3]: 手記（敵 / ダンジョン / メモ）と死亡時の置き去り

- **由来**: concept-v3 §5
- **内容**: 手記は敵の頁（弱点 / 耐性 / 行動 / 間合い傾向 / 特殊行動 / 条件 / 関係 / 適応条件）、ダンジョンの頁（近道 / 隠し部屋 / 条件出現 / イベント / 罠 / 資源 / ショートカット）、自由記述のメモを持つ。段階開示（観察・遭遇で埋まる）。拠点・探索中・戦闘中のどこでも読めるが、戦闘中は現在の敵の頁を表示するだけで戦闘に効果を与えない。**死亡時、手記は痕跡に含めて死亡地点に残す**。次の生は遺産の枠で選んだ頁だけを受け取る。§12-9 の開示量を設計書に落とす
- **依存**: R1-8
- **受け入れ基準**:
  - [ ] 死亡後に開始した次の生の手記は、遺産で選んだ頁以外が空である
  - [ ] メモに書いた文字列が保存・表示され、遺産候補「走り書き」として選べる
  - [ ] 戦闘中に手記を開いても戦闘状態が変わらない

## R1-11 [Phase 4]: 生の終了（生存ルート / 死亡）

- **由来**: concept-v3 §8.1
- **内容**: 探索中いつでも「この生を終える」を選べる生存ルート。死亡（HP 0 / 瘴気死）は死亡地点を記録し、手記を痕跡に含める。ライフ制・ゲームオーバー全リセット・テレポートストーン・帰還ルートは実装しない
- **依存**: R1-9, R1-16
- **受け入れ基準**:
  - [ ] 生存ルートと死亡の両方から次のキャラクター作成へ遷移する
  - [ ] 死亡地点（階層・ノード）が保存される

## R1-12 [Phase 4]: 遺産（死亡者からの継承）

- **由来**: concept-v3 §8.3 / §8.4
- **内容**: 死亡地点に痕跡を置き、次のキャラクターが訪れると（継承の間では候補を見るだけ）遺産一覧（技術 / 習熟カードの成果 / 手記の頁 / 走り書き / 特殊能力）から限られた枠（仮 3）を選んで継承する。痕跡は回収まで残り、1 つの生で受け取れるのは 1 件（最初に訪れた痕跡）。**浅層対策**: 一定以上の習熟度を持つカードは、その習熟に見合わない浅い階層・弱い敵での死亡では遺産に載らない（閾値は §12-11）
- **依存**: R1-10, R1-11
- **受け入れ基準**:
  - [ ] 遺産の候補が死亡時の状態から生成され、3 つまで選べる
  - [ ] 浅層で死んだ高習熟カードが候補に出ない
  - [ ] 1 つの生で 2 件目の痕跡を訪れても受け取れない
  - [ ] 未回収の痕跡が次の死亡で消えない

## R1-13 [Phase 4]: 生存者の継承

- **由来**: concept-v3 §8.2
- **内容**: 生存ルートを選んだキャラクターは次の生にボーナスを与える。生存者は一人まで（新しい生存者が前の生存者を置き換える）。前回死亡者の遺産と併用できる。ボーナス内容は §12-12
- **依存**: R1-11
- **受け入れ基準**:
  - [ ] 生存者を 2 回続けて出しても次の生に効くのは直近 1 人だけ
  - [ ] 遺産と生存者ボーナスが同時に適用される

## R1-14 [Phase 5]: 出立（ツール選択 + デッキ構築）と継承の間

- **由来**: concept-v3 §7.1 / §10 施設再解釈
- **内容**: 旧キャンプの導線を 2 画面に置き換える。**継承の間**（遺産選択 / 生存者ボーナス確認 / 新キャラクター開始）→ **出立**（ツール選択 / 戦闘デッキ構築 / 出発）。ツールは探索用・戦闘用を分け、枠数は §12-13。ショップ / 鍛冶屋 / サンクチュアリは表示しない（凍結）
- **依存**: R1-7, R1-12, R1-13
- **受け入れ基準**:
  - [ ] 新しい生の開始から出発まで 2 画面で完結する
  - [ ] 凍結施設への導線が UI に無い

## R1-15 [Phase 5]: 予兆と適応型 AI（ボス・強敵）

- **由来**: concept-v3 §3.5
- **内容**: 敵行動に予兆（次行動の種別または候補）を付け、手記の開示度と観察で精度が上がる。ボス・強敵はプレイヤーの行動履歴（近距離連打 / 防御多用 / 同一カード反復 / 遠距離維持）で方針を切り替える。切り替え条件は手記で判明可能にする
- **依存**: R1-4, R1-10
- **受け入れ基準**:
  - [ ] 同じボスに同じ手を繰り返すと対策行動が出る
  - [ ] 対策の条件が手記に記録される

## R1-16 [Phase 4]: セーブと「生」の記録（前倒し・2026-09-12）

- **由来**: 実装上の必要 / 三者評価（セーブが遺産より後だと R1-11〜13 を検証できない）
- **内容**: 現在の生（キャラクター・所持カード・習熟・手記・瘴気・刻限・位置・HP・スタミナ）と世代の記録（未回収の痕跡一覧・直近の生存者）を保存する。**死亡と生の終了は確定と同時に保存**し、リロードで遺産を選び直せないようにする（セーブスカム防止、旧 R1-14 の配慮を継承）。旧セーブ（ライフ / 装備 / ソウル）は読まない
- **依存**: R1-8, R1-9, R1-10
- **受け入れ基準**:
  - [ ] 中断・再開で生の状態が復元される
  - [ ] 死亡直後にプロセスを落として再開しても、死亡が確定し痕跡が残っている
  - [ ] 遺産を選んだ直後に再開しても選び直せない

## R1-17 [Phase 6]: 合格基準の監査

- **依存**: R1-1〜R1-16
- **受け入れ基準**:

  - [ ] 通しプレイでクラッシュ・詰み・バランス崩壊なし
