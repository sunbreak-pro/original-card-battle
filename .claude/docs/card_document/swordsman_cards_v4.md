## 1. 記法

### 1.1 属性と面

| 略  | 属性     | 面が持つもの                                                                        | 列で伸びるもの                     |
| --- | -------- | ----------------------------------------------------------------------------------- | ---------------------------------- |
| A   | アタック | 威力、崩し                                                                          | 威力、崩し                         |
| G   | ガード   | Guard                                                                               | Guard 量                           |
| St  | スタンス | 戦闘中ずっと続く効果（枠 1、置き換え式。出したカードは戦闘中は山札に戻らない）      | 効果の強さ                         |
| Sk  | スキル   | 状態の付与、回復、ドロー、スタミナ                                                  | スタック数、付く状態の種類、回復量 |
| M   | ムーブ   | 自分のマスを前へ n / 後ろへ n 動かす。または相手を n マス押す / 引く（押す / 引く） | 付随効果の有無                     |

- **コストは列番号**です。1 枚は列 1〜4 のどれか 1 つを持ち、その列の値だけが効果になります。列 4 のコストは 3 です（K8）。コスト 0 は習熟の「軽さ」と特性「コスト −1」でだけ生まれ、初期値は 1 以上です（§17.2）。
- 二属性のカードは効果の欄に「威力 8 ／ 前へ 1」のように 2 つの面を「／」で並べます。二属性の各面は単属性の同じ面の 65% を目安にします。
- **目盛り（列 1 / 列 2 / 列 3 / 列 4）**

| 面                     | 列 1 | 列 2 | 列 3        | 列 4            |
| ---------------------- | ---- | ---- | ----------- | --------------- |
| 単属性アタック（威力） | 6    | 13   | 21          | 30              |
| 単属性ガード（Guard）  | 4    | 9    | 15          | 22              |
| 二属性のアタック面     | 4    | 8    | 14          | 20              |
| 二属性のガード面       | 3    | 6    | 10          | 14              |
| 単属性の回復（HP）     | 3    | 8    | 13          | 19              |
| 二属性の回復面         | 2    | 5    | 8           | 12              |
| 出血 / 再生のスタック  | 1    | 2    | 3           | 4               |
| 単属性のスキル（状態） | 1 種 | 2 種 | 3 種        | 3 種 + ドロー 1 |
| 二属性のスキル面       | 1 種 | 2 種 | 2 種 + 1 種 | 3 種 + 1 種     |
| スタンスの上乗せ       | +2   | +3   | +5          | +6              |

- アタックの目盛りは 1 本です。遠用の低い目盛り（4 / 6 / 9 / 12）と最適間合いの列は廃止しました（K7）。届く間合いが既定と違う札は、この目盛りから §1.4 の式で威力を動かします。
- 1-shot だった状態（威圧 / 脆化 / 疲労 / 強化 / 集中 / 見切り / 俊敏 / 鈍足）はスタック制です（§17.5）。付与の既定は 2 スタックで、表には「威圧 2」のように書きます。出血 / 再生は上の表のスタック数です。
- 崩し（相手のスタミナ −n）は目盛りを変えません。札の個性として付けます。
- **ムーブ**の面は「前へ n」「後ろへ n」の 2 つで、n は 1 か 2 です。前へは敵の側へ、後ろへは自分の側の端へ動きます。端や入れないマスに当たったら、その手前で止まります。1 マスも動けなくても札は出せて、ほかの面は通常どおり解決します。v4.2 の「反転」はなくしました。**単属性ムーブ 6 種は全てコスト 1** で、面に小さな付随効果（Guard 4 / ドロー 1 / スタミナ +1 のどれか）を 1 つ持ちます（K5）。
- **押す / 引く**は、ムーブ面が自分の代わりに相手を n マス動かすものです。押すは自分から遠ざけ、引くは自分へ近づけます。Guard では減りません。押された相手が端や入れないマスに当たって動けなかったときは、動けなかった 1 マスにつき 3 のダメージが入ります（壁のダメージ。Guard で減ります）。大きさ 2 以上の敵は押す / 引くを受けません（`battle_core_v4.md` §7.3）。本書で押す / 引くを持つのは、盾押し（押す 1）と手繰りの歩み（引く 1）の 2 枚です。
- **解決順は A → M → G → Sk → St** で固定です。`moveFirst` は廃止しました。届く間合いも間合いの境目も「出す前の間合い」で読むためです。アタック + ムーブの札は、動く前の間合いで届くかどうかと威力を決め、当ててから動きます。
- **素直な札**: 特性を持たない 8 枚（初期のみ）。その列の威力・Guard・回復に **+2** を上乗せします。列によって上乗せを変えません。特性欄は「なし（素直: +2）」です。
- 構え（ターン終了時に残 3 以上で Guard +3）とスタミナの回復（毎ターン 3。K1）は全カード共通の規則で、表には書きません。

### 1.2 特性（1 枚に最大 1 つ）

書き方は「条件: 効果」です。条件 12 種と効果 10 種の組み合わせだけを使います。同じ「条件 + 効果」の組は 3 枚までしか重ねません（条件は括弧の中身と境目の数まで含めて同じもの、効果は種類が同じものを数えます）。

| 条件                     | 意味                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 連動(X)                  | このターンに属性 X のカードをプレイ済み                                                                           |
| 間合い(n 以下 / n 以上)  | 出す前の間合い N が n 以下 / n 以上。相手を選ぶ札は選んだ相手との N を、自分向きの札はいちばん近い敵との N を読む |
| 予兆(攻撃 / 移動 / 防御) | 敵の予兆がその種別                                                                                                |
| 温存(残 ≥ n)             | 使用後の残スタミナが n 以上                                                                                       |
| 死力                     | 現在スタミナが 2 以下                                                                                             |
| 初手                     | このターン最初のプレイ                                                                                            |
| 締め                     | このターン 3 枚目以降のプレイ                                                                                     |
| 崩し後                   | 敵のスタミナが 3 未満                                                                                             |
| 連打                     | 直前にプレイしたカードと同じ属性を 1 つ以上持つ                                                                   |
| 手薄                     | プレイ後のこのターンの残り手札が 1 枚以下                                                                         |
| 相手の状態(語)           | 相手にその状態が付いている                                                                                        |
| 自分の状態(語)           | 自分にその状態が付いている                                                                                        |

v4.2 の 位置(近間 / 遠間) は、v4.3 で間合いの境目に置き換えました。表には「間合い 0: 威力 +5」「間合い 2 以上: ドロー +1」のように書きます。「間合い 0」は「間合い 0 以下」と同じです。境目は 1 枚に 1 つまでです。「N 1 につき +x」のように N を掛ける効果は、本書では使っていません（上限は 80 種で 4 枚。`battle_core_v4.md` §7.2）。

| 効果            | 意味                                                                               |
| --------------- | ---------------------------------------------------------------------------------- |
| スタミナ +1     | 即時                                                                               |
| 威力 +n         | この 1 枚のアタック面。目安は +3 / +5 / +6                                         |
| Guard +n        | この 1 枚のガード面（無ければ Guard として付く）。目安は +3                        |
| ドロー +1       | 即時                                                                               |
| 状態            | 「<語> +n スタック」（出血 / 再生）か「<語> を n 付与」（ほかの状態）              |
| コスト −1       | この 1 枚のコストが 1 下がる（下限 0）。習熟の「軽さ」と同じ働き                   |
| 次ターン回復 +1 | 次のターン開始のスタミナ回復に +1                                                  |
| 重撃            | 条件を満たすと威力 +6、次のターン開始の回復 −1。今のターンのコストと構えは変えない |
| 転換            | この 1 枚の Guard の半分（切り上げ）を威力に足す                                   |
| 追撃            | このターンの次のアタック面の威力 +5                                                |

- 効果は、間合いの 4 マスを数えるときに **攻撃の効果** と **防御の効果** に二分します。攻撃は 威力 +n / 重撃 / 転換 / 追撃 / 相手へ付ける状態、防御は Guard +n / スタミナ +1 / ドロー +1 / コスト −1 / 次ターン回復 +1 / 自分へ付ける状態です。
- スタンスの特性はプレイした瞬間に 1 回だけ判定します（枠に置いた後は判定しません）。
- 条件と効果は、面を解決する前に判定します（§17.6 F5）。「連打」「初手」「締め」「手薄」はプレイ順の情報、「間合い」は出す前の N、「相手の状態」「自分の状態」はプレイ時点の状態を見ます。

### 1.3 列の意味

- **コスト**: その札が持つ列の番号です。列 1 = コスト 1、列 2 = 2、列 3 と列 4 = 3 です。列は次の順で決めました。
  1. 条件の満たしにくさで基準の列を置きます。満たしにくい 死力 / 崩し後 / 相手の状態 / 手薄 は列 1、中ほどの 予兆 / 温存 / 締め / 連打 は列 2、満たしやすい 初手 / 連動 / 自分の状態 と素直な札は列 3 です（§17.2）。
  2. 間合いの境目を条件にする 16 枚は、4 マスそれぞれの 4 枚を 列 1 / 列 2 / 列 2 / 列 3 に散らします。詰めて戦う型も離れて戦う型も、どのコスト帯でも組めるようにするためです。
  3. 単属性ムーブ 6 種は K5 により列 1 に固定します。
  4. 基準が列 3 の札のうち、1 枚で大きく跳ねる特性（重撃 / 転換 / 追撃 / コスト −1）を持つものは列 2 へ下げます。
  5. 届く間合いは列を動かしません。値だけを §1.4 の式で動かします。
- **列 4 を初期値に使った札はありません。** 列 4 は、集中（次の札を 1 列右で解決）と習熟の「伸び」がコスト 3 の札に掛かったときの行き先です（K8）。
- **届く**: 届く間合い（§1.4）。「—」は間合いを見ない札です。
- **習熟**: 習熟で名称が変わるか。初期 40 は全て「あり」。習得 40 は半分です。
- **探索**: 探索の面を持たせる候補。80 種のうち 12 種です。
- **入手先**: 習得 40 だけ。ボス固有 9 / 精鋭 8 / 探索の発見 23 です。

### 1.4 届く間合い（v4.3）

アタック面と相手向きのスキル面、押す / 引くは、**届く間合い**を持ちます（`battle_core_v4.md` §2.4 の `reach`）。表の「届く」の欄に、届く N の下限〜上限を書きます。「0」は隣り合った相手にだけ届く札です。

- **既定は 0〜1** です。ガード面・スタンス面・自分向きのスキル面と、自分を動かすムーブ面は間合いを見ないので「—」と書きます。
- 1 枚の相手向きの面は、1 つの届く間合いを共有します。二属性の札で、アタック面とスキル面が別の間合いを持つことはありません。
- **届く間合いの外の相手には、その札を出せません。** 相手向きの面を持つ札は、Guard などの自分向きの面が付いていても、届く相手がいなければ出せません。出せないので、敵の行動のような空振りもありません（`battle_core_v4.md` §6）。
- **幅で値を動かします。** 幅は届く N の数です。0〜1 なら 2、0 だけなら 1、1〜3 なら 3 です。**間合い 3 に届く札は、幅を 1 多く数えます。** 開始の間合いが 3 なので、1 ターン目から動かずに当てられる分の値段を払わせるためです。
  - アタック面の威力を **列番号 × (2 − 幅)** だけ動かします。幅 1 なら列番号ぶん足し、幅 3 なら列番号ぶん引き、幅 4 なら列番号の 2 倍を引きます。
  - 例: 列 2 の単属性アタック 13 は、0 だけなら 15、0〜2 なら 11、1〜3 なら 9 です。
  - 素直な札の +2 と、特性の威力 +n は、この補正とは別に足します。
  - アタック面の無い相手向きの札（状態だけ、押す / 引くだけ）は値を動かさず、幅を 3 までに抑えます。スタック数は 1 刻みなので、式の補正を当てられないためです。
- **間合いの境目は、届く間合いの一部でだけ満たせるように置きます。** 「0 だけに届く札に 間合い 0 の特性」のように、出せば必ず満たす組や、決して満たさない組は作りません。
- **スタンスの条件**（水の構え、根渡り、霞み足、浄化の一閃、深淵の構え）は、`battle_core_v4.md` §4 の `when` と同じく、いちばん近い敵との N を読みます。深淵の構えの「間合い 0 の相手へのアタック」だけは、選んだ相手との N を読みます。
- **間合い 3 以上で出せない札を置きます**（`battle_core_v4.md` §21.1 の 4）。相手向きの札 47 枚のうち、上限が 3 に届くのは 4 枚だけです。残る 43 枚は、間合い 3 以上では出せません。自分向きの 33 枚は、どの間合いでも出せます（§4.5）。
- 敵の行動の届く間合いと値の決め方は `enemy_roster_v4.md` §1.2 が持ちます。

## 5. 試験台で見る点

前提の数: プレイヤー HP 50、スタミナの回復 毎ターン 3、開始の間合い 3。敵の HP・1 ターン出力・回復は `enemy_roster_v4.md` の目盛りに従います（v4.4 で試験台の結果から HP を上げました。#204）。

1. **コスト 1 だけのデッキ**: コスト 1 の 25 種だけで組んだデッキの勝率が、型 5 種の平均を 10 pt 以上上回らないこと。上回ったら列 1 の目盛りを下げます（K2 の確認、§18.4）。
2. **1 ターンのプレイ枚数**: 中央値が 2 以上であること。下回ったら回復を 3 から 4 に上げます（K1 の確認、§18.4）。
3. **重撃の期待値**: 重撃は威力 +6 と引き換えに次のターンの回復 −1 です。回復 3 のうち 1 を前借りする形なので、連発すると手数が落ちます。1 戦で重撃が 3 回以上発動する型の勝率が他より 25 pt 以上高ければ、+6 を +5 に下げます。
4. **二属性 65%**: 「受け流し斬り × 3 + 柄当て × 3」を軸にしたデッキが、「突き × 3 + 鉄の受け × 3」の素直なデッキに 25 pt 以上勝ち越さないか。超えたら 65% を 60% に下げます。
5. **素直な札の +2**: 素直な札だけの 8 種 × 3 = 24 枚のデッキが、特性入りの平均に 15 pt 以上負けないか。負けたら +2 を +3 にし、勝ち越すなら +1 にします。
6. **離れたままの膠着**: 両者が間合い 3 以上で止まる方針が最強にならないか。v4.3 では全ての敵がマスを持って動き、3 以上の枝に前へ出る行動か遠くへ届く行動を必ず置くので（`enemy_roster_v4.md` §1.2）、敵の全てで見ます。膠着したら、その敵の 3 以上の枝の並びを直します。
7. **スタンス必須化**: スタンス無しのデッキがスタンス入りに 15 pt 以上負けないか。負けたら岩の構え / 鉄壁の構えのターン開始 Guard を 1 ずつ下げます。
8. **特性の発動率**: 連動 / 連打 / 初手 / 締め / 手薄 / 間合い の特性が 1 戦で平均 2 回以上発動するか。1 回未満なら条件を緩めます（締め = 2 枚目以降、手薄 = 2 枚以下 など）。間合いは、手札にムーブ面の札が来ない危険（約 24%、`battle_core_v4.md` §14）と合わせて見ます。
9. **届く間合いの値段**: 幅で威力を動かす式（§1.4）が釣り合うか。3 に届く 4 枚を 3 枚ずつ入れたデッキの勝率が、型の平均を 15 pt 以上上回ったら、3 に届く札の数え方を「幅 +1」から「幅 +2」へ重くします。0 にだけ届く 4 枚の採用率が平均の半分を切ったら、幅 1 の上乗せを列番号の 2 倍にします。
10. **1 ターン目に何も当てられない率**: 開始の間合い 3 で、初期 40 から組んだデッキが 1 ターン目に相手へ届く札を 1 枚も出せない率を数えます。`battle_core_v4.md` §13 の「届く札が無くて何も当てられないターン」が外れたら、前へ 2 の札か 1〜2 に届く札を初期 40 に 1〜2 枚足します。
