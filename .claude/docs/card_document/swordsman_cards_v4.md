# 剣士カード v4 — 80 種の案（属性 5 種 × 投入量 0〜3 × 特性）

> **Status**: DRAFT v4.1（2026-09-13。目盛りを T0 = 5 に合わせ、特性を 72 枚に拡張）。戦闘 100% の棚卸（`docs/reports/2026-09-13-battle-100-inventory.html`）とこうだいさんの決定を受けた叩き台。数値は `battle_core_v4.md` が正になり、本書はカードの一覧を持つ。
> **入力**: `battle_core_v3.md` §7（剣士 7 種）、concept-v3 §4（習熟 / 探索カード / 所持とデッキ）、棚卸レポート §2〜§5、2026-09-13 の差し戻し 2 点（目盛り / 特性）。
> **v3 からの差分**: タイプ 1 種（attack / move / guard / heal）を属性 5 種（アタック / ガード / スタンス / スキル / ムーブ）に改め、1 枚に 1〜2 属性を持たせた。カードごとの「特性」（属性と状態を基準にしたコンボ）を新設し、80 種のうち 72 種が持つ。手札は毎ターン全捨てして 5 枚引く。同種は 3 枚まで。目盛りは T0 のアタックが威力 5 になるように v3 の約 1.6 倍（HP はプレイヤー 50、敵は通常 50〜70 / 精鋭 90〜110 / ボス 160）。v3 の 7 種は全て初期 40 に含め、形を直した。旧 `SWORDSMAN_CARDS_40.md`（剣気 / 貫通 / 会心）は流用しない。

## 1. 記法

### 1.1 属性と面

| 略 | 属性 | 面が持つもの | 投入量で伸びるもの | 間合い補正 |
| --- | --- | --- | --- | --- |
| A | アタック | 威力、最適間合い、崩し | 威力、崩し | 受ける（diff 0 / 1 / 2 = ×1.0 / ×0.5 / ×0.15）。崩しは diff 0 のみ |
| G | ガード | Guard | Guard 量 | 受けない |
| St | スタンス | 戦闘中ずっと続く効果（枠 1、置き換え式。出したカードは戦闘中は山札に戻らない） | 効果の強さ | 受けない |
| Sk | スキル | 状態の付与、回復、ドロー、スタミナ | 段数、付く状態の数、回復量 | 相手に付ける状態は最適間合いで diff 0 のときだけ。自分に付けるものは受けない |
| M | ムーブ | 詰め（−1）/ 退き（+1） | 段階数（1 か 2）、向きを選べるか | 受けない |

- 二属性のカードは T の欄に「威力 5 ／ 詰め 1」のように 2 つの面を「／」で並べる。1 回の投入量で両方の面が同時に段を上げる。二属性の各面は単属性の同じ面の 65% を目安にする。
- **目盛り（T0 / T1 / T2 / T3）**: 単属性アタック 近 / 中 = 5 / 8 / 12 / 16、遠 = 4 / 6 / 9 / 12。二属性のアタック面 = 3 / 5 / 8 / 10、遠 = 3 / 4 / 6 / 8。単属性ガード = 3 / 6 / 9 / 12。二属性のガード面 = 2 / 4 / 6 / 8。回復 = 2 / 5 / 8 / 11。出血は相手のターン開始に HP −2 × 段、再生は自分のターン開始に HP +2。崩し（相手のスタミナ −n）は目盛りを変えない。
- **min** は最低投入量。1 のカードは T0 が「—」。0 のカードの T0 は弱いが効果を残す（上の目盛りの T0 の列。ムーブ面 1 段階、スキル面 状態 1 段 1 ターン、スタンス面 最弱段）。
- **ムーブ単属性**の 4 段: T0 1 段（向き固定）/ T1 1 段（向きを選ぶ）/ T2 2 段（向き固定）/ T3 2 段（向きを選ぶ）。
- **moveFirst** を持つ A+M カードは移動してから攻撃する（M → A → G → Sk → St）。それ以外は A → M → G → Sk → St。
- **1-shot の状態**（脆化 / 威圧 / 鈍足 / 疲労 / 強化 / 集中 / 見切り / 軽足）は段が無いので、投入量は「付く状態の数」で伸ばす。**段のある状態**（出血 / 再生）は段数で伸ばす。片側の状態は 4 つまで、段は 3 まで。
- **素直な札**: 特性を持たない 8 枚（初期のみ）。各段の威力と Guard に +2（T0 は +1、回復は HP +2）を上乗せした値を表に書く。特性欄は「なし（素直: +2）」。特性を持つカードは目盛りどおりで上乗せ無し。
- 構え（ターン終了時に残 3 以上で Guard +3）は全カード共通の規則で、表には書かない。

### 1.2 特性（1 枚に最大 1 つ）

書き方は「条件: 効果」。条件 12 種と効果 10 種の組み合わせだけを使う。同じ「条件 + 効果」の組は 3 枚までしか重ねない（条件は括弧の中身まで含めて同じもの、効果は種類が同じものを数える）。

| 条件 | 意味 |
| --- | --- |
| 連動(X) | このターンに属性 X のカードをプレイ済み |
| 位置(近 / 中 / 遠) | その間合いから使う |
| 予兆(攻撃 / 移動 / 防御) | 敵の予兆がその種別 |
| 温存(残 ≥ n) | 使用後の残スタミナが n 以上（旧「冷静」） |
| 死力 | 現在スタミナが 2 以下 |
| 初手 | このターン最初のプレイ |
| 締め | このターン 3 枚目以降のプレイ |
| 崩し後 | 敵のスタミナが 3 未満 |
| 連打 | 直前にプレイしたカードと同じ属性を 1 つ以上持つ |
| 手薄 | プレイ後のこのターンの残り手札が 1 枚以下 |
| 相手の状態(語) | 相手にその状態が付いている |
| 自分の状態(語) | 自分にその状態が付いている |

| 効果 | 意味 |
| --- | --- |
| スタミナ +1 | 即時 |
| 威力 +n | この 1 枚のアタック面。目安は +3 / +5 / +6 |
| Guard +n | この 1 枚のガード面（無ければ Guard として付く）。目安は +3 |
| ドロー +1 | 即時 |
| 状態 | 「<語> +1 段」（段のある状態）か「<語> を 1 つ追加」（1-shot の状態）。相手向けは diff 0 のときだけ |
| この 1 枚の投入 −1 | 段は変えずコストだけ下がる（T0 では意味が無い） |
| 次ターン回復 +1 | 次のターン開始の回復に +1 |
| 重撃 | この 1 枚に投入 +1 を払うと威力 +6。段は変えない。スタミナを多めに消費する代わりに威力を上げる |
| 転換 | この 1 枚の Guard の半分（切り上げ）を威力に足す |
| 追撃 | このターンの次のアタック面の威力 +5 |

- スタンスの特性はプレイした瞬間に 1 回だけ判定する（枠に置いた後は判定しない）。
- 条件と効果は解決順の最初（面の解決より前）に判定する。「連打」「初手」「締め」「手薄」はプレイ順の情報、「相手の状態」「自分の状態」はプレイ時点の状態を見る。

### 1.3 列の意味

- **習熟**: 習熟で名称が変わるか（R1-5）。初期 40 は全て「あり」。習得 40 は半分。
- **探索**: 探索の面（R1-6）を持たせる候補。80 種のうち 12 種。
- **入手先**: 習得 40 だけ。ボス固有 9 / 精鋭 8 / 探索の発見 23。80% の時点で確定しているのは瘴気の司祭・甲冑の番人・群れの長の分。

## 5. 試験台で見る点

前提の数: プレイヤー HP 50、敵 HP 通常 50〜70 / 精鋭 90〜110 / ボス 160、敵の 1 ターン出力 通常 7〜13。

1. **0 投入回し（威力 5 × 5 枚）**: 最低投入 0 のアタック面は小手打ち / 探り突き / 投げ刃 / 柄頭打ち / 影踏み の 5 種。同種 3 枚 × 5 種 = 15 枚のデッキで毎ターン 5 枚が全て 0 投入アタックなら、間合いが合えば 5 + 4 + 4 + 3 + 3 = 19 点が無料で出て、通常敵の出力 7〜13 を上回る。この方針の勝率が 10% を超えたら、(a) 0 投入アタックの T0 を 4 に下げる、(b) 1 ターンの 0 投入プレイを 2 枚までにする、(c) 構えの閾値を「残 3 以上」から「残 3 以上かつ 0 投入 2 枚以下」にする、の順に試す。
2. **重撃の期待値**: 重撃は投入 +1 で威力 +6。T1 → T2 の伸びが単属性で +4、二属性で +3 なので、重撃の +6 は「段を上げるより 1 スタミナあたり強い」。条件付きなので常には使えないが、崩し後の貫き / 急所突きと連打の覇者の一振りが T3 + 重撃 = 4 投入で 22〜26 点を出す。1 戦で重撃が 3 回以上発動する型の勝率が他より 25 pt 以上高ければ、+6 を +5 に下げる。
3. **二属性 65%**: 「受け流し斬り × 3 + 柄当て × 3」を軸にしたデッキが、「突き × 3 + 鉄の受け × 3」の素直なデッキに 25 pt 以上勝ち越さないか。超えたら 65% を 60% に下げる。
4. **素直な札の +2**: 素直な札だけの 8 種 × 3 = 24 枚のデッキが、特性入りの平均に 15 pt 以上負けないか。負けたら +2 を +3 にする。勝ち越すなら +2 を +1 にする。
5. **遠の膠着**: 遠カード（投げ刃 / 探り突き / 伸び突き / 石礫 / 虚空の突き）だけのデッキで、敵の空振り回避が間合いを戻すか。戻らない敵がいたら敵側の決定木を直す。
6. **スタンス必須化**: スタンス無しのデッキがスタンス入りに 15 pt 以上負けないか。負けたら岩の構え / 鉄壁の構えのターン開始 Guard を 1 ずつ下げる。
7. **特性の発動率**: 連動 / 連打 / 初手 / 締め / 手薄 の特性が 1 戦で平均 2 回以上発動するか。1 回未満なら条件を緩める（締め = 2 枚目以降、手薄 = 2 枚以下 など）。相手の状態 / 自分の状態は、状態を付けるカードが同じデッキに入っているときだけ発動するので、デッキ構築で「組」を作る動機になっているかを見る。
8. **moveFirst の強さ**: 猪突猛進を遠から使う（T3 で威力 10 + 6 = 16、2 段詰め）が、突き T3（18）を常に上回らないか。上回るなら位置(遠)の +6 を +5 にする。
9. **ムーブ単属性の投入**: T1（向きを選ぶ）と T3 が実際に選ばれるか。選ばれなければ T1 に「Guard +2」を足すか、T の表を T0 / T2 の 2 段だけにする。
