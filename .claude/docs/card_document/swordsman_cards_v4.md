# 剣士カード v4 — 80 種の案（属性 5 種 × 投入量 0〜3）

> **Status**: DRAFT v4.0（2026-09-13）。戦闘 100% の棚卸（`docs/reports/2026-09-13-battle-100-inventory.html`）とこうだいさんの 7 決定を受けた叩き台。規則と数値の正本は `battle_core_v4.md`、本書はカードの一覧を持つ。
> **入力**: `battle_core_v3.md` §7（剣士 7 種）、concept-v3 §4（習熟 / 探索カード / 所持とデッキ）、棚卸レポート §2〜§5。
> **v3 からの差分**: タイプ 1 種（attack / move / guard / heal）を属性 5 種（アタック / ガード / スタンス / スキル / ムーブ）に改め、1 枚に 1〜2 属性を持たせた。カードごとの「特性」（属性を基準にしたコンボ）を新設した。手札は毎ターン全捨てして 5 枚引く。同種は 3 枚まで。v3 の 7 種は全て初期 40 に含め、形を直した。旧 `SWORDSMAN_CARDS_40.md`（剣気 / 貫通 / 会心）は流用しない。

## 1. 記法

### 1.1 属性と面

| 略  | 属性     | 面が持つもの                                                                   | 投入量で伸びるもの               | 間合い補正                                                                   |
| --- | -------- | ------------------------------------------------------------------------------ | -------------------------------- | ---------------------------------------------------------------------------- |
| A   | アタック | 威力、最適間合い、崩し                                                         | 威力、崩し                       | 受ける（diff 0 / 1 / 2 = ×1.0 / ×0.5 / ×0.15）。崩しは diff 0 のみ           |
| G   | ガード   | Guard                                                                          | Guard 量                         | 受けない                                                                     |
| St  | スタンス | 戦闘中ずっと続く効果（枠 1、置き換え式。出したカードは戦闘中は山札に戻らない） | 効果の強さ                       | 受けない                                                                     |
| Sk  | スキル   | 状態の付与、回復、ドロー、スタミナ                                             | 段数、付く状態の数、回復量       | 相手に付ける状態は最適間合いで diff 0 のときだけ。自分に付けるものは受けない |
| M   | ムーブ   | 詰め（−1）/ 退き（+1）                                                         | 段階数（1 か 2）、向きを選べるか | 受けない                                                                     |

- 二属性のカードは T の欄に「威力 3 ／ 詰め 1」のように 2 つの面を「／」で並べる。1 回の投入量で両方の面が同時に段を上げる。二属性の各面は単属性の同じ面の 65% を目安にする。
- 単属性の目安: アタック 近 / 中 = T1 5 / T2 8 / T3 11、遠 = 4 / 6 / 8。ガード = T0 2 / T1 4 / T2 6 / T3 8。二属性のアタック面 = 3 / 5 / 7（遠 3 / 4 / 5）、ガード面 = 1 / 3 / 4 / 5。
- **min** は最低投入量。1 のカードは T0 が「—」。0 のカードの T0 は弱いが効果を残す（アタック面 威力 3、二属性のアタック面 威力 2、ムーブ面 1 段階、ガード面 Guard 2、二属性のガード面 Guard 1、スキル面 状態 1 段 1 ターン、スタンス面 最弱段）。
- **ムーブ単属性**の 4 段: T0 1 段（向き固定）/ T1 1 段（向きを選ぶ）/ T2 2 段（向き固定）/ T3 2 段（向きを選ぶ）。
- **moveFirst** を持つ A+M カードは移動してから攻撃する（M → A → G → Sk → St）。それ以外は A → M → G → Sk → St。
- **1-shot の状態**（脆化 / 威圧 / 鈍足 / 疲労 / 強化 / 集中 / 見切り / 軽足）は段が無いので、投入量は「付く状態の数」で伸ばす。**段のある状態**（出血 / 再生）は段数で伸ばす。片側の状態は 4 つまで、段は 3 まで。
- 構え（ターン終了時に残 3 以上で Guard +2）は全カード共通の規則で、表には書かない。

### 1.2 特性（1 枚に最大 1 つ）

書き方は「条件: 効果」。条件 8 種と効果 6 種の組み合わせだけを使う。

| 条件                     | 意味                                          |
| ------------------------ | --------------------------------------------- |
| 連動(X)                  | このターンに属性 X のカードをプレイ済み       |
| 位置(近 / 中 / 遠)       | その間合いから使う                            |
| 予兆(攻撃 / 移動 / 防御) | 敵の予兆がその種別                            |
| 温存(残 ≥ n)             | 使用後の残スタミナが n 以上（旧「冷静」）     |
| 死力                     | 現在スタミナが 2 以下。効果は威力 ×1.5 で固定 |
| 初手                     | このターン最初のプレイ                        |
| 締め                     | このターン 3 枚目以降のプレイ                 |
| 崩し後                   | 敵のスタミナが 3 未満                         |

効果: スタミナ +1 / 威力 +n / Guard +n / ドロー +1 / 状態 +1 段 / この 1 枚の投入 −1（段は変えずコストだけ下がる。本書では未使用）。

### 1.3 列の意味

- **習熟**: 習熟で名称が変わるか（R1-5）。初期 40 は全て「あり」。習得 40 は半分。
- **探索**: 探索の面（R1-6）を持たせる候補。80 種のうち 12 種。
- **入手先**: 習得 40 だけ。ボス固有 9 / 精鋭 8 / 探索の発見 23。80% の時点で確定しているのは瘴気の司祭・甲冑の番人・群れの長の分。

## 5. 試験台で見る点

1. **0 投入回し**: 最低投入 0 の 20 種だけで組んだデッキ（同種 3 枚 × 5〜7 種）の勝率が 10% を超えないか。超えたら T0 の威力 3 を 2 に、二属性の T0 を 1 に下げる。
2. **二属性 65%**: 「受け流し斬り × 3 + 柄当て × 3」を軸にしたデッキが、「突き × 3 + 呼吸を整える × 3」の単属性デッキに 25 pt 以上勝ち越さないか。超えたら 65% を 60% に下げる。
3. **遠の膠着**: 遠カード（投げ刃 / 探り突き / 伸び突き / 石礫 / 虚空の突き）だけのデッキで、敵の空振り回避が間合いを戻すか。戻らない敵がいたら敵側の決定木を直す。
4. **スタンス必須化**: スタンス無しのデッキがスタンス入りに 15 pt 以上負けないか。負けたら岩の構え / 鉄壁の構えのターン開始 Guard を 1 ずつ下げる。
5. **特性の発動率**: 連動 / 初手 / 締め の特性が 1 戦で平均 2 回以上発動するか。1 回未満なら条件を緩める（締め = 2 枚目以降 など）。
6. **moveFirst の強さ**: 猪突猛進を遠から使う（威力 7 + 4 = 11 で 2 段詰め）が、突き T3（11）を常に上回らないか。上回るなら位置(遠)の +4 を +3 にする。
7. **ムーブ単属性の投入**: T1（向きを選ぶ）と T3 が実際に選ばれるか。選ばれなければ T1 に「Guard +1」を足すか、T の表を T0 / T2 の 2 段だけにする。
