## 1. 記法

### 1.1 属性と面

| 略 | 属性 | 面が持つもの | 列で伸びるもの |
| --- | --- | --- | --- |
| A | 攻撃 | 威力、崩し | 威力、崩し |
| G | 防御 | Guard | Guard 量 |
| Sk | スキル | 状態の付与（ターンで減るものと使うと減るものだけ）、回復、ドロー、スタミナ | スタック数、付く状態の種類、回復量 |
| St | スタンス | 戦闘が終わるまで続く永続の効果だけ | 効果の強さ |

- **1 枚が持つ属性は 1 つだけです。** 札は面（攻撃面・防御面・スキル面）を 1〜2 個持てます。属性は、持つ面のうち 攻撃 ＞ 防御 ＞ スキル の順でいちばん上のものです（`battle_core_v4.md` §2.1）。攻撃しながら防御する札は攻撃の札、防御しながら状態を付ける札は防御の札です。表の「属性」の列は寄せた後の属性で、面の内訳は「効果」の列に「威力 10 ／ Guard 6」のように「／」で並べます。連動・連打・締めは、寄せた後の属性で数えます。
- **スタンスは独立した属性です。** 永続の効果だけを持ち、ほかの属性の面も移動も持ちません（`battle_core_v4.md` §4）。置くと永続の効果の一覧に加わり、数の上限も置き換えもなく、重ね掛けできます（同じスタンスを 2 回置くと 2 回ぶん効きます）。出した 1 枚はその戦闘で手札・山札・捨札に戻りません。デッキに残る同じ札の写しは残り、引けばまた出せます。デッキに入れるスタンスの札の枚数に制限はなく、同種 3 枚の上限だけが掛かります。永続はスタンスだけが持ち、スキルが付ける効果はターンで減るものと使うと減るもの（スタック）だけです。特性の効果（スタミナ +1 / ドロー +1 / Guard +n / コスト −1 / 次ターン回復 +1 / 追撃）は、スタンスの札にも付きます。
- **コストは列番号**です。1 枚は列 1〜4 のどれか 1 つを持ち、その列の値だけが効果になります。列 4 のコストは 3 です（K8）。コスト 0 は習熟の「軽さ」と特性「コスト −1」でだけ生まれ、初期値は 1 以上です（§17.2）。
- 面を 2 つ持つ札（移動の効果を付けた攻撃・防御の札を含む）の各面は、単独の同じ面の 65% を目安にします。攻撃面は、列 1〜3 では同じ幅・同じ列の単独の値の 65% です。例外の 1 マスと列 4 の決め方は §1.4 に書きます。防御面と回復面の目盛りは v4.3 のままです。v4.5 で #22 観察と #72 覚悟に足した Guard 3 は、面を 2 つ持つ札の防御面の列 1 の値です。
- **目盛り（列 1 / 列 2 / 列 3 / 列 4）**

| 面 | 列 1 | 列 2 | 列 3 | 列 4 |
| --- | --- | --- | --- | --- |
| 単独の攻撃面（威力） | 6 | 13 | 21 | 30 |
| 単独の防御面（Guard） | 4 | 9 | 15 | 22 |
| 面を 2 つ持つ札の攻撃面 | 4 | 8 | 14 | 20 |
| 面を 2 つ持つ札の防御面 | 3 | 6 | 10 | 14 |
| 単独の回復（HP） | 3 | 8 | 13 | 19 |
| 面を 2 つ持つ札の回復面 | 2 | 5 | 8 | 12 |
| 出血 / 再生のスタック | 1 | 2 | 3 | 4 |
| 単独のスキル面（状態） | 1 種 | 2 種 | 3 種 | 3 種 + ドロー 1 |
| 面を 2 つ持つ札のスキル面 | 1 種 | 2 種 | 2 種 + 1 種 | 3 種 + 1 種 |
| スタンスの上乗せ | +2 | +3 | +5 | +6 |


- **攻撃の 2 行は幅 3 の値です。** 「単独の攻撃面」と「面を 2 つ持つ札の攻撃面」の行は、届く間合いが 0〜2 か 2〜3（幅 3）の札の威力です。ほかの幅の値は §1.4 の帯の表から読みます。
- 攻撃の目盛りは 1 本です。遠用の低い目盛り（4 / 6 / 9 / 12）と最適間合いの列は廃止しました（K7）。届く間合いの違いは、§1.4 の帯の表で表します。
- 1-shot だった状態（威圧 / 脆化 / 疲労 / 強化 / 集中 / 見切り / 俊敏 / 鈍足）はスタック制です（§17.5）。付与の既定は 2 スタックで、表には「威圧 2」のように書きます。出血 / 再生は上の表のスタック数です。
- 崩し（相手のスタミナ −n）は目盛りを変えません。札の個性として付けます。
- **移動**は属性ではなく、どの札にも付けられる効果です。「前へ n」「後ろへ n」の n は 1 か 2 で、前へは敵の側へ、後ろへは自分の側の端へ動きます。端や入れないマスに当たったら、その手前で止まります。1 マスも動けなくても札は出せて、ほかの面は通常どおり解決します。**移動が中心の札 6 種は全てコスト 1** で、小さな付随効果（Guard 4 / ドロー 1 / スタミナ +1 のどれか 1 つ）を持ちます（K5）。Guard を持つ 3 枚（#26 後ろ跳び・#27 摺り足・#28 間合い切り）は防御、ドローとスタミナの 3 枚（#25 足運び・#60 跳び退り・#63 駆け込み）はスキルの札です（§4.1）。`battle_core_v4.md` §2.1 の枚数（Guard の 2 枚 / ドローとスタミナの 4 枚）との食い違いは #364 で扱います。
- **押す / 引く**は、移動の効果のうち、自分の代わりに相手を n マス動かすものです。押すは自分から遠ざけ、引くは自分へ近づけます。Guard では減りません。押された相手が端や入れないマスに当たって動けなかったときは、動けなかった 1 マスにつき 3 のダメージが入ります（壁のダメージ。Guard で減ります）。大きさ 2 以上の敵は押す / 引くを受けません（`battle_core_v4.md` §7.3）。本書で押す / 引くを持つのは、盾押し（押す 1）と手繰りの歩み（引く 1）の 2 枚です。
- **解決順は 特性の判定 → 攻撃 → 移動 → 防御 → スキル → スタンス** で固定です。これは効果の解決順で、属性の優先（攻撃 ＞ 防御 ＞ スキル）とは別です。`moveFirst` は廃止しました。届く間合いも間合いの境目も「出す前の間合い」で読むためです。攻撃 + 移動の札は、動く前の間合いで届くかどうかと威力を決め、当ててから動きます。
- **素直な札**: 特性を持たない 8 枚（初期のみ）。その列の威力（§1.4 の帯の値）・Guard・回復に **+2** を上乗せします。列によって上乗せを変えません。特性欄は「なし（素直: +2）」です。
- 構え（ターン終了時に残 3 以上で Guard +3）とスタミナの回復（毎ターン 3。K1）は全カード共通の規則で、表には書きません。

### 1.2 特性（1 枚に最大 1 つ）

書き方は「条件: 効果」です。条件 13 種と効果 10 種の組み合わせだけを使います。同じ「条件 + 効果」の組は 3 枚までしか重ねません（条件は括弧の中身と境目の数まで含めて同じもの、効果は種類が同じものを数えます）。

| 条件 | 意味 |
| --- | --- |
| 連動(X) | このターンに属性 X（攻撃 / 防御 / スキル / スタンス）のカードをプレイ済み。寄せた後の属性で数える |
| 移動後 | このターンに自分のマスが動いた（自分の移動の効果と俊敏の無料の 1 マス。押された・引かれた動きと、同じ札の移動は数えない） |
| 間合い(n 以下 / n 以上) | 出す前の間合い N が n 以下 / n 以上。相手を選ぶ札は選んだ相手との N を、自分向きの札はいちばん近い敵との N を読む |
| 予兆(攻撃 / 移動 / 防御) | 敵の予兆がその種別 |
| 温存(残 ≥ n) | 使用後の残スタミナが n 以上 |
| 死力 | 現在スタミナが 2 以下 |
| 初手 | このターン最初のプレイ |
| 締め | このターン 3 枚目以降のプレイ |
| 崩し後 | 敵のスタミナが 3 未満 |
| 連打 | 直前にプレイしたカードと同じ属性（寄せた後） |
| 手薄 | プレイ後のこのターンの残り手札が 2 枚以下 |
| 相手の状態(語) | 相手にその状態が付いている |
| 自分の状態(語) | 自分にその状態が付いている |

v4.2 の 位置(近間 / 遠間) は、v4.3 で間合いの境目に置き換えました。表には「間合い 0: 威力 +5」「間合い 2 以上: ドロー +1」のように書きます。「間合い 0」は「間合い 0 以下」と同じです。境目は 1 枚に 1 つまでです。「N 1 につき +x」のように N を掛ける効果は、本書では使っていません（上限は 80 種で 4 枚。`battle_core_v4.md` §7.2）。

| 効果 | 意味 |
| --- | --- |
| スタミナ +1 | 即時 |
| 威力 +n | この 1 枚の攻撃面。目安は +3 / +5 / +6 |
| Guard +n | この 1 枚のガード面（無ければ Guard として付く）。目安は +3 |
| ドロー +1 | 即時 |
| 状態 | 「<語> +n スタック」（出血 / 再生）か「<語> を n 付与」（ほかの状態） |
| コスト −1 | この 1 枚のコストが 1 下がる（下限 0）。習熟の「軽さ」と同じ働き |
| 次ターン回復 +1 | 次のターン開始のスタミナ回復に +1 |
| 重撃 | 条件を満たすと威力 +6、次のターン開始の回復 −1。今のターンのコストと構えは変えない |
| 転換 | この 1 枚の Guard の半分（切り上げ）を威力に足す |
| 追撃 | このターンの次の攻撃面の威力 +5 |

- 効果は、間合いの 4 マスを数えるときに **攻撃の効果** と **防御の効果** に二分します。攻撃は 威力 +n / 重撃 / 転換 / 追撃 / 相手へ付ける状態、防御は Guard +n / スタミナ +1 / ドロー +1 / コスト −1 / 次ターン回復 +1 / 自分へ付ける状態です。
- スタンスの特性はプレイした瞬間に 1 回だけ判定します（永続の効果の一覧に置いた後は判定しません）。
- **予兆の種別は、出る回数が大きく違います。** 2026-09-26 の実測（#208）では、札を出す場面の予兆は 攻撃 が約 76%、移動 が約 8%、防御 が約 5% でした。移動の予兆は敵が寄ってくる間合い 3 以上でほとんど出ます。予兆(攻撃) 以外を条件にする札は、発動が稀な分を値で補います（#79 影踏み）。
- **崩し後は、崩しの札と組んで初めて届く条件です。** 崩し 1 は敵の毎ターンの回復 2〜4 に消されるので、崩しの源（#6 / #44 / #75 / #49）を持たないデッキではほとんど発動しません。#44 と #75 の崩しは 2 にしています（#208）。
- 移動後は、同じ札の移動が面より後に解決されるので、その札自身の移動には効きません。連動(ムーブ) を置き換えたものです（`battle_core_v4.md` §2.3）。連動(スタンス) は「連動 スタンス」のまま残ります。
- 条件と効果は、面を解決する前に判定します（§17.6 F5）。「連打」「初手」「締め」「手薄」はプレイ順の情報、「間合い」は出す前の N、「相手の状態」「自分の状態」はプレイ時点の状態を見ます。

### 1.3 列の意味

- **コスト**: その札が持つ列の番号です。列 1 = コスト 1、列 2 = 2、列 3 と列 4 = 3 です。列は次の順で決めました。
  1. 条件の満たしにくさで基準の列を置きます。満たしにくい 死力 / 崩し後 / 相手の状態 / 手薄 は列 1、中ほどの 予兆 / 温存 / 締め / 連打 は列 2、満たしやすい 初手 / 連動 / 自分の状態 と素直な札は列 3 です（§17.2）。
  2. 間合いの境目を条件にする 16 枚は、4 マスそれぞれの 4 枚を 列 1 / 列 2 / 列 2 / 列 3 に散らします。詰めて戦う型も離れて戦う型も、どのコスト帯でも組めるようにするためです。
  3. 移動が中心の札 6 種は K5 により列 1 に固定します。
  4. 基準が列 3 の札のうち、1 枚で大きく跳ねる特性（重撃 / 転換 / 追撃 / コスト −1）を持つものは列 2 へ下げます。
  5. 届く間合いは列を動かしません。攻撃面の威力は、列と届く間合いの幅から §1.4 の帯の表で決まります。
- **列 4 を初期値に使った札はありません。** 列 4 は、集中（次の札を 1 列右で解決）と習熟の「伸び」がコスト 3 の札に掛かったときの行き先です（K8）。
- **届く**: 届く間合い（§1.4）。「—」は間合いを見ない札です。
- **習熟**: 習熟で名称が変わるか。初期 40 は全て「あり」。習得 40 は半分です。
- **探索**: 探索の面を持たせる候補。80 種のうち 12 種です。
- **入手先**: 習得 40 だけ。ボス固有 9 / 精鋭 8 / 探索の発見 23 です。

### 1.4 届く間合い（v4.3。帯の表は v4.5）

攻撃面と相手向きのスキル面、押す / 引くは、**届く間合い**を持ちます（`battle_core_v4.md` §2.4 の `reach`）。表の「届く」の欄に、届く N の下限〜上限を書きます。「0」は隣り合った相手にだけ届く札です。

- **既定は 0〜1** です。防御面・スタンス・自分向きのスキル面と、自分を動かす移動は間合いを見ないので「—」と書きます。
- 1 枚の相手向きの面は、1 つの届く間合いを共有します。面を 2 つ持つ札で、攻撃面とスキル面が別の間合いを持つことはありません。
- **届く間合いの外の相手には、その札を出せません。** 相手向きの面を持つ札は、Guard などの自分向きの面が付いていても、届く相手がいなければ出せません。出せないので、敵の行動のような空振りもありません（`battle_core_v4.md` §6）。
- **幅は届く N の数です。** 0〜1 なら 2、0 だけなら 1 です。**間合い 3 に届く札は、幅を 1 多く数えます。** 開始の間合いが 3 なので、1 ターン目から動かずに当てられる分の値段を払わせるためです。1〜3 は届く N が 3 つで、3 に届くので幅 4 と数えます。下の表の「幅」は、この 1 を足した後の数です。
- **攻撃面の威力は、列と幅から下の帯の表で決まります**（v4.5、#352）。幅ごとの行を、本書では「帯」と呼びます。v4.4 までの式（列番号 × (2 − 幅)）は使いません。

**単独の攻撃面**

| 幅 | 届く | 倍率 | 列 1 | 列 2 | 列 3 | 列 4 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | ×1.3 | 8 | 17 | 27 | 36 |
| 2 | 0〜1 / 1〜2 | ×1.15 | 7 | 15 | 24 | 33 |
| 3 | 0〜2 / 2〜3 | ×1.0 | 6 | 13 | 21 | 30 |
| 4 | 1〜3 | ×0.8 | 5 | 10 | 17 | 26 |
| 5 | 0〜3 | ×0.6 | 4 | 8 | 13 | 22 |

**面を 2 つ持つ札の攻撃面**（列 1〜3 は同じ幅・同じ列の単独の値の 65% で、列 4 は列 3 に 6 を足した値です）

| 幅 | 届く | 列 1 | 列 2 | 列 3 | 列 4 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 5 | 11 | 18 | 24 |
| 2 | 0〜1 / 1〜2 | 5 | 10 | 16 | 22 |
| 3 | 0〜2 / 2〜3 | 4 | 8 | 14 | 20 |
| 4 | 1〜3 | 3 | 7 | 11 | 17 |
| 5 | 0〜3 | 2（例外） | 5 | 8 | 14 |

- **目安は列 2 の単独の攻撃面に置きました。** #352 のこうだいさんの目安は、0〜1 に限られる札が 15 くらい、0〜3 の札が 8 くらいです。幅 2 の 15 と幅 5 の 8 を直線で結ぶと、幅 3 は 12.67 です。丸めると `battle_core_v4.md` §3.1 の 13 と一致します。そこで §3.1 の攻撃の目盛りを、幅 3 の行と読み直しました（§1.1）。
- **列 1〜3 の単独の攻撃面**は、幅 3 の値に幅ごとの倍率（幅 1 から順に ×1.3 / ×1.15 / ×1.0 / ×0.8 / ×0.6）を掛けて出します。丸めは四捨五入で、0.5 はゼロから遠いほうへ寄せます（`battle_core_v4.md` §5.1）。列 2 の行（17 / 15 / 13 / 10 / 8）は、目安の 2 点を結んだ直線の値（17.33 / 15 / 12.67 / 10.33 / 8）を丸めた値と、どの幅でも一致します。
- **列 1〜3 の面を 2 つ持つ札の攻撃面**は、同じ幅・同じ列の単独の値（丸めた後）の 65% を、同じ丸めで出します。例えば幅 2・列 2 は 15 × 0.65 = 9.75 で 10 です。幅 3 の行は §3.1 の 4 / 8 / 14 / 20 に戻ります。
- **例外は幅 5・列 1 の面を 2 つ持つ札の 1 マスだけです。** 65% では 3 ですが、2 に下げました。3 のままだと 1 スタミナあたり列 2（2.5）を上回り、K2 の「高いコストほど 1 スタミナあたり少し得」が逆になるためです。このマスを使う札はありません。列 1 の札は、単独も面を 2 つ持つ札も幅 3 までにします。
- **列 4 の欄は、列 3 の値に `battle_core_v4.md` §3.1 の差を足した値です**（単独 +9、面を 2 つ持つ札 +6）。列 4 から始まる札は無く、この欄は集中と習熟の「伸び」が列 3 の札に掛かったときの行き先です。集中は `battle_core_v4.md` §5 のとおり §3.1 の差を足すので、列 4 の欄と同じ値になります。列 1・2 の札に集中が掛かったときも、§3.1 の差（単独 +7 / +8、面を 2 つ持つ札 +4 / +6）を足します。このため、幅 2・列 2 の単独 15 に集中が掛かると 23 になり、表の列 3（24）とは 1 ずれます。
- 1 スタミナあたりの値は、表の全てのマスで 列 1 ≤ 列 2 ≤ 列 3 です（K2）。どの列でも、狭い幅ほど値は大きいか同じです。
- **表の外の値**は次のとおりです。
  - 素直な札は +2 を足します（§1.1）。
  - 特性の威力 +n は、表の値に足します（§1.2）。
  - #79 影踏みは +2 を足します。予兆(移動) の発動が稀な分を埋めるためです（#208）。
  - #80 背水の陣は、表の 7 ではなく 8 を使います。§17.4 の叩き台の値です（§3 の後の段落）。
- **攻撃面の無い相手向きの札**（状態だけ、押す / 引くだけ）は、今までどおり値を動かさず、幅を 3 までに抑えます。スタック数は 1 刻みなので、帯の倍率を当てられないためです。Guard・回復・スタックの値も、届く間合いでは動かしません。
- **§3.1 の読み方は #364 で扱います。** `battle_core_v4.md` §3.1 の最後の箇条は、既定の 0〜1 の札が目盛りどおりの値だと読める書き方です。本書は §3.1 の攻撃の行を幅 3 の値と読み、#352 の決定に従います。v4.4 までの式は、既定の 0〜1 を目盛りどおりの値としていました。v4.5 では幅 3 を目盛りどおりの値としたので、既定の札の威力は目盛りの約 1.15 倍になりました。
- **間合いの境目は、届く間合いの一部でだけ満たせるように置きます。** 「0 だけに届く札に 間合い 0 の特性」のように、出せば必ず満たす組や、決して満たさない組は作りません。
- **スタンスの条件**（水の構え、根渡り、霞み足、浄化の一閃、深淵の構え）は、`battle_core_v4.md` §4 の `when` と同じく、いちばん近い敵との N を読みます。深淵の構えの「間合い 0 の相手への攻撃」だけは、選んだ相手との N を読みます。
- **間合い 3 以上で出せない札を置きます**（`battle_core_v4.md` §21.1 の 4）。相手向きの札 43 枚のうち、上限が 3 に届くのは 5 枚（#9 / #31 / #34 / #48 / #73）だけです。残る 38 枚は、間合い 3 以上では出せません。自分向きの 37 枚は、どの間合いでも出せます（§4.5）。
- 敵の行動の届く間合いと値の決め方は `enemy_roster_v4.md` §1.2 が持ちます。

## 5. 試験台で見る点

前提の数: プレイヤー HP 50、スタミナの回復 毎ターン 3、開始の間合い 3。敵の HP・1 ターン出力・回復は `enemy_roster_v4.md` の目盛りに従います（v4.4 で試験台の結果から HP を上げました。#204）。

1. **コスト 1 だけのデッキ**: コスト 1 の 25 種だけで組んだデッキの勝率が、型 5 種の平均を 10 pt 以上上回らないこと。上回ったら帯の表（§1.4）の列 1 を下げます（K2 の確認、§18.4）。v4.5 では、コスト 1 の 25 種にコスト 1 の防御が 6 枚入ります（v4.4 は 3 枚）。列 1 の攻撃の札 11 枚のうち 8 枚が 1 ずつ上がったので（幅 2 の単独 6 → 7、面を 2 つ持つ札 4 → 5）、v4.4 より強く出るおそれがあります。
2. **1 ターンのプレイ枚数**: 中央値が 2 以上であること。下回ったら回復を 3 から 4 に上げます（K1 の確認、§18.4）。
3. **重撃の期待値**: 重撃は威力 +6 と引き換えに次のターンの回復 −1 です。回復 3 のうち 1 を前借りする形なので、連発すると手数が落ちます。1 戦で重撃が 3 回以上発動する型の勝率が他より 25 pt 以上高ければ、+6 を +5 に下げます。
4. **面を 2 つ持つ札 65%**: 「受け流し斬り × 3 + 柄当て × 3」を軸にしたデッキが、「突き × 3 + 鉄の受け × 3」の素直なデッキに 25 pt 以上勝ち越さないか。超えたら 65% を 60% に下げます。
5. **素直な札の +2**: 素直な札だけの 8 種 × 3 = 24 枚のデッキが、特性入りの平均に 15 pt 以上負けないか。負けたら +2 を +3 にし、勝ち越すなら +1 にします。
