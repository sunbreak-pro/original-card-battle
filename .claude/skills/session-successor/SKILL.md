# session-successor — セッションを引き継ぐ人

前のセッションの続きを、同じ前提のまま再開するためのスキルです。引っ越しの引き継ぎメモと現地確認をひとまとめにした手順書です。**書いてあることを信じて進めるのではなく、書いてある前提を測り直してから進めます。** 前提（インストールの状態、サーバーの起動、ファイルの有無）は、セッションの外で人が触るため、書いた時点より古くなります。

## モード

`args` の先頭語で決めます。省略時は `read` です。

| args           | すること                                                        |
| -------------- | --------------------------------------------------------------- |
| `read [slug]`  | 引き継ぎ書を読んで前提を実測し、次の一手を出して作業を続ける    |
| `write <slug>` | いまのセッションの状態を引き継ぎ書に書き出す                    |
| `list`         | `.claude/docs/handover/` の一覧を新しい順に出す（読み取りのみ） |

## read（引き継いで再開する）

1. **選ぶ**: `slug` があれば `.claude/docs/handover/*<slug>*.md`、無ければ更新日が最新の 1 件を読みます。候補が複数あって決められないときだけ、一覧を出して聞きます。
2. **並べて読む**: 引き継ぎ書と `.claude/MEMORY.md` の「進行中 / 直近の完了」を同じメッセージで読みます。引き継ぎ書が参照する正本（レポート、スキルの references、設計書）も必要な範囲だけ読みます。
3. **実測する**: 引き継ぎ書の「確認コマンド」を全部実行します。1 つでも食い違ったら、その行を実測値で書き換えてから進みます。**実測せずに「前回どおり動いているはず」と書かない。**
4. **報告する**: 作業を始める前に、次の 3 つだけを出します。
   - 前回どこまで進んだか（1〜3 行）
   - いま実測して分かった食い違い（無ければ「食い違いなし」と書く）
   - 次の一手（1 つだけ。人の手が要るなら、その 1 手を具体的な操作で書く）
5. **続ける**: 「次の一手」から作業に入ります。引き継ぎ書が別のスキル（`visual-production-pipeline` など）を指していれば、そちらを起動します。
6. **閉じる**: 区切りがついたら `write` で引き継ぎ書を更新します。

## write（引き継ぎ書を作る・更新する）

置き場は `.claude/docs/handover/YYYY-MM-DD-<slug>.md` です。同じ作業の続きなら、日付を今日に変えたファイル名で新しく作らず、**既存のファイルを上書き**して「更新日」を書き換えます（引き継ぎ書は履歴ではなく現状の 1 枚です。履歴は HISTORY が持ちます）。

章は次の 6 つだけです。増やさないでください。

```markdown
# <作業の名前>（引き継ぎ書）

- 更新日: YYYY-MM-DD / 対象ブランチ: <branch>
- 正本: <レポートや設計書のパス。3 件まで>

## いまどこ

3 行以内。完了したこと、動いている状態、止まっている点。

## 確認コマンド

引き継いだ側が最初に実行する読み取り専用のコマンドと、期待する結果。
| 目的 | コマンド | 期待 |

## 次の一手

1 つだけ。人の操作なら画面の名前とボタン名まで書く。

## 決まっていること

判断済みで蒸し返さない前提。理由を 1 行ずつ。

## 判断待ち

人に聞く必要がある項目。推奨とその理由を添える。

## 落とし穴

この作業で実際に踏んだ失敗と回避方法。
```

## 規約

- 引き継ぎ書に秘密情報（API キー、トークン、パス付きの個人情報）を書かない。
- 環境の値（版・空き容量・VRAM・起動の有無）は「確認コマンド」で取り直す前提で書き、本文に断定で埋め込まない。
- タスクの状態（進行中 / 完了 / 予定）の正本は `MEMORY.md` です。引き継ぎ書はその作業 1 件の作業台で、二重管理しません。重なる内容は MEMORY 側を指すだけにします。
- 引き継ぎ書は 150 行以内に収めます。超えたら、中身を正本（レポートやスキルの references）へ移してリンクにします。
