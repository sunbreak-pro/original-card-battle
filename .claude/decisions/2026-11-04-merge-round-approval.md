# merge-round の起動を、その回の merge の承認にする

決めた日は 2026-11-04 で、こうだいさんの依頼です。life-editor の決まりを、このリポジトリへ移しました。
元の文があった場所は、`.claude/CLAUDE.md` の「課題追跡は GitHub Issues が正」の節の、「1 Issue = 1 ブランチ = 1 PR」の項目です。

## 何を決めたか

- merge は、常に人が決めます。
- こうだいさんが chat-main で `merge-round` スキルを起動したら、それがその回の承認です。事前確認を通った PR は、`.claude/hooks/merge-gate.mjs` が確認なしで通します。
- ほかのチャットから打つ merge のコマンドは、同じ hook が止めます。回の外の merge には、確認を出します。
