# カードバトル RPG「生と継承」— 現状ブリーフ（2026-09-16）

> 外部の AI（ChatGPT / Gemini など）に相談するための資料です。これ 1 つで現状の設計が分かるように書いています。
> 開発は個人 1 人。Unity（C#）で実装中。戦闘コアは実装済みの版があり、いまは設計を v4.2 へ改訂している段階です。

---

## 1. どんなゲームか

一人の探索者が単一のダンジョンを潜り、死ぬたびに次の世代へ技と記憶を継いでいくシングルプレイのカードバトル RPG です。和風の暗い世界観で、瘴気（しょうき）に侵された地下を降りていきます。

- **ジャンル**: ターン制カードバトル + ローグライト（死亡で成長リセット、限定的な継承あり）
- **中核**: 「知らなければ難しい」。敵の行動は乱数ではなく予兆（次の手の予告）で示され、プレイヤーは読み合いで勝つ
- **設計原則 5 つ**: 乱数に頼らない / プレイヤーと敵は対称の規則 / 暗算できる数字 / 1 ターンの判断は 3 つまで / 読み合いは予兆に対して行う
- **クリア条件**: 最深部の最終ボス「歪みの根」を倒す

## 2. ゲームループ

```
継承の間（遺産を選ぶ / 才能を選ぶ）
  → 出立（ツール 3 枠と戦闘デッキ 20〜40 枚を決める）
  → ダンジョン（5 階層 × 刻限 10 回 × 瘴気）
  → 戦闘（近間 / 遠間 × スタミナ × カード）
  → 死亡（死亡地点に遺産と手記が残る）または 生存ルート（次の代へ交代）
  → 継承の間へ戻る
```

- **死亡**: 成長は消える。死亡地点に手記と遺産候補が残り、次の代がそこを訪れて 3 つ選ぶ。痕跡は回収まで残り、1 つの生で受け取れるのは 1 件
- **生存ルート**: 生きたまま次の代へ交代する。手記を丸ごと継ぎ、次の 1 生だけツール枠 +1・デッキ上限 +5
- **浅い階層でわざと死ぬ抜け道の対策**: 2 段目以上に育てたカードは、階層 3 以上で死んだときだけ遺産になる

## 3. 戦闘システム（v4.2 の確定仕様）

### 3.1 持つ値

| 値          | 内容                                                        |
| ----------- | ----------------------------------------------------------- |
| HP          | プレイヤー 50。敵は通常 50〜70 / 精鋭 90〜110 / ボス 160    |
| Guard       | 毎ターン 0 にリセットされる一時的な防御。ダメージから引く   |
| スタミナ    | 最大 10。カードのコストとして払い、ターン開始に回復する     |
| 近間 / 遠間 | 位置。**ボスと精鋭だけが持つ**。プレイヤーは常に持つ        |
| 状態        | スタック制（後述）。プレイヤーは種類 6 つまで、敵は上限なし |
| 瘴気        | 探索で蓄積し、最大スタミナを下げる                          |

### 3.2 1 ターンの流れ

1. Guard を 0 にする
2. スタミナを回復（固定値 + 札による上乗せ）
3. スタンスと状態のターン開始効果（再生・出血などの tick、スタックを 1 減らす）
4. 手札を 5 枚（± 補正）引く
5. 敵ごとの予兆を表示（精鋭・ボスは 2 手分）
6. プレイヤーが好きな枚数カードを出す（コストを払う）
7. ターン終了。スタミナが 3 以上残っていれば「構え」で Guard +3、手札を捨てる
8. 敵フェーズ（予兆どおりに実行。精鋭・ボスは 2 行動）

### 3.3 カード

- **属性 5 つ**: アタック（A）/ ガード（G）/ ムーブ（M）/ スキル（Sk）/ スタンス（St）。1 枚は 1〜2 属性
- **コスト**: 旧「段表」の列番号（0〜3）。列の値がそのカードの効果量になる。列は特性の条件の重さで選ぶ（満たしにくい条件を持つ札ほど安い）
- **コスト 0**: 最初は無し。習熟の「軽さ」でだけ 0 に下がる
- **数値の目安**: 単属性アタックは列ごとに 5 / 8 / 12 / 16（遠距離向けは 4 / 6 / 9 / 12）、単属性ガードは 3 / 6 / 9 / 12、回復は 2 / 5 / 8 / 11。二属性は各面が単属性の 65%
- **特性**: 1 枚に最大 1 つ。「条件 → 効果」の組で、条件 12 種 × 効果 10 種の語彙から作る
  - 条件の例: 連動（このターンに属性 X を出した）/ 初手 / 締め（3 枚目以降）/ 連打（直前と同じ属性）/ 手薄（残り手札 1 枚以下）/ 死力（スタミナ 2 以下）/ 崩し後（敵のスタミナ 3 未満）/ 相手の状態 / 自分の状態 / 位置（自分が近間 / 遠間）/ 予兆（敵の次の手の種別）/ 温存（使用後の残スタミナ）
  - 効果の例: 威力 +n / Guard +n / スタミナ +1 / ドロー +1 / 状態 +1 / コスト −1 / 次ターン回復 +1 / 重撃（威力 +6、次の回復 −1）/ 転換（Guard の半分を威力に足す）/ 追撃（次のアタックの威力 +5）
- **特性の判定**: カードの効果を適用する**前**に条件を見る
- **枚数**: 所持 80 種（初期 40 / 探索で習得 40）。戦闘デッキは 20〜40 枚、同じカードは 3 枚まで

### 3.4 ダメージ式

```
（面の威力 + 特性 +n + 追撃 + 転換）× 強化 ×2 × 脆化 ×1.5 → 丸め（四捨五入・0 から遠い側）→ − Guard
```

多段攻撃（1 撃ずつ Guard に当たる）では、特性 +n と強化は全ての撃に乗り、追撃だけ 1 回。

### 3.5 近間 / 遠間

- プレイヤーは常にどちらかにいる。**敵はボスと精鋭だけが持つ**（通常敵は位置を持たない）
- 位置そのものに素の効果は無い（ダメージ倍率などは付けない）。カードと敵の技が「自分が遠間なら威力 +5」のように条件として読む
- カードは**自分の位置だけ**を条件にする（相手の位置は見ない）
- 切り替えはムーブ面を持つカードで行う。条件は常に「動く前の位置」で判定する
- 敵の決定木は、通常敵はプレイヤーの位置で 2 通り、ボス・精鋭は自分と相手の組 4 通り
- 「ずっと同じ位置で終える」が最強にならないよう、敵ごとに主に咎める側を持たせ、逆側にいる相手を押し戻す / 誘う技を決定木に置く

### 3.6 状態（スタック制）

- カードは「<状態名> を n 付与する」と書く。例: 俊敏を 3 付与 = 3 ターン有効
- 既定では付いた側のターン開始に 1 減る。溜まり方・減り方は特性ごとに変えてよい
- 出血・再生は「スタック = 強さと回数の両方」。出血 3 なら毎ターン HP −2 ×残りスタック（−6 → −4 → −2）
- 語彙 10 種: 出血 / 再生 / 鈍足 / 威圧 / 集中 / 俊敏 / 脆化 / 疲労 / 強化 / 見切り（+ ボス専用 2 種: 瘴気纏い / 呪縛）
  - 威圧 = 相手の次の行動の威力と Guard を −3 / 集中 = 次に出す札を 1 列右（1 段強く）で解決 / 俊敏 = 有効なターンの開始時に近間 / 遠間を選べる / 鈍足 = 次のターン全体の切り替えを止める

### 3.7 敵と予兆

- 敵は乱数で動かない。決定木で次の手を決め、予兆として画面に出してからそのとおりに実行する（コミット式）
- 崩し（相手のスタミナを削る）で予兆の技のコストを払えなくなった敵は、そのフェーズを休みにする
- 開示度 3 段: 0 = 何も見えない / 1 = 種別 + 咎める側の一字 / 2 = 技名と値。1 段目は 1 度遭遇すれば上がり、2 段目は観察カードか探索の情報収集で埋める
- 80% の段階の敵は 9 体（通常 6 / 精鋭 2 / ボス 1）。最終的に 19 体

### 3.8 操作（UI）

- ドラッグ主体。単体の攻撃・デバフは相手の人型に出る「受け皿」で離す。全体攻撃や自分向きの札は、手札の上の線より上で離す（投げ上げ線）
- 画面の情報量は削る方向。上帯を廃止し、左上にターン・階層・連戦・瘴気、右上に手記だけ
- 近間 / 遠間は、立ち位置と足元の一字札（「近」「遠」）で見せる
- 演出の強弱は、その一撃の確定値（威力・Guard・回復）で 4 段に分ける。1 行動 2.0 秒以内

## 4. 習熟と継承

- **習熟の刻み**: カードを使った文脈ごとに数える。文脈は 4 つ（間合い / 予兆に合った型 / 特性の発火 / 構え圏か死力圏）。1 回のプレイで 0〜4 刻み
- **段**: 刻み 3 / 8 / 15 で 1 / 2 / 3 段目（閾値は仮置き）。段が上がると「伸び（値が 1 列右へ）」「軽さ（コスト −1）」「型替え（特性が変わる。観察 → 精査 → 洞察 → 看破 のように名前も変わる）」のいずれか 1 つが起きる。型は 60 種に 1 枚ずつ設計で割り当てる
- **1 つの生で 3 段目にできるのは 1 枚だけ**。ほかは 2 段目まで
- **才能**: 生のはじめに 1 枚選ぶと、その札だけ刻みが 2 倍で溜まる
- **遺産**: 死亡地点に、習熟 1 段以上のカードと埋まった手記の頁を全て並べ、次の代が 3 つ選ぶ。手記を選べば全ての頁を受け取れる（手記をコンパクトで整然とした設計にすることが前提）
- **継いだカードは段をそのまま保つ**

## 5. 探索

- 5 階層。1 階層あたり刻限 10 回。1 ノードを選ぶたびに刻限 1 と瘴気を消費する
- 刻限を使う行動: 戦闘 / 情報収集 / 休息 / 習熟訓練（1 回で指定した 1 枚に刻み 1）など
- 瘴気は階層の濃度（1〜5）ぶん溜まり、最大スタミナを下げる。ツールや休息で和らげる
- 出立でツール 3 枠（探索用・戦闘用の区別なし）と戦闘デッキを決める。消耗品は 3 枠で、拠点へは持ち帰らない
- 装備・Gold・ショップ・倉庫は凍結中（防御は Guard のみ）

## 7. いま測ろうとしていること（未確定）

1. **コストの釣り合い**: 固定コストだけの版と、近間 / 遠間を足した版を分けて自動対戦で測る
2. **切り替えの札が来ないターン**: 手札 5 枚に移動の面が 1 枚も無い確率が約 24%。痛いかどうかを測ってから対策を決める
3. **ボス・精鋭との膠着**: 両者が遠間のままにらみ合う頻度
4. **特性の発動率**: 1 戦で平均 2 回以上発動するか（少なければ条件を緩める）
5. **習熟の閾値 3 / 8 / 15**: 刻みが 1 プレイ 0〜4 になったので測り直す

## 8. 相談したいこと

外部の視点で見てほしい点です。

1. **面白さの核**: 「投入量（1 枚にいくら払うか）」を廃止し、「どの順に何枚出すか」「どちらの位置で終えるか」「特性のシナジー」に判断を寄せました。この 3 つで 1 ターンの判断は十分に濃いでしょうか。単調になる危険はどこにありますか
2. **位置（近間 / 遠間）をボスと精鋭だけに持たせる判断**: 通常敵との戦いでは、位置は「自分がどちらで終えるか」だけの選択になります。格上の敵だけが位置を読むという非対称は、面白さと分かりやすさの両面で成立しますか
3. **状態のスタック制**: 全ての状態を「n 付与」に統一しました。出血のように「スタック = 強さと回数の両方」にすると暗算が重くならないか、種類 6 つの上限は妥当か
4. **習熟と継承のバランス**: 1 つの生で 3 段目にできるのは 1 枚、才能で 1 枚だけ刻み 2 倍。死んで成長が消える設計の中で、これで「育てた実感」と「次の代への期待」が両立しますか
5. **ローグライトとしての周回動機**: クリア条件が最終ボス撃破 1 つで、装備や通貨が無い（カードの習熟と手記だけが積み上がる）構成です。1 周 30〜60 分想定として、何周も遊ぶ動機は足りますか
6. **個人開発として削るべきもの**: 敵 19 体 / カード 80 種 / Live2D / 5 階層という規模で、最初に遊べる形（縦の 1 本）を出すために削るなら何から削るべきですか
