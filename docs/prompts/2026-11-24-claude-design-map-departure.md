## 先に考えたこと — 何が足りないと「簡素」に見えるか

今の画面をコードで読み、ゲームらしく見える画面に共通する点と比べました。足りないのは次の 7 つです。案はどれも、このうち幾つかを強く出す形で作りました。

| 足りないもの | 今の画面 | 足すときの考え方 |
| --- | --- | --- |
| 場所 | ノードは同じ大きさの四角で、等間隔の格子に並びます。線は直線です | 地図を「いる場所の絵」にします。層ごとの光と形を、地図の中に入れます |
| 自分 | 地図には歩く駒がありますが、出立の画面には探索者の姿がありません | 探索者と灯りを画面の中心に置きます。琥珀の灯りが自分の居場所だという世界の決まりを、そのまま使います |
| 素材 | どの箱も、同じ色の地と 1 px の枠です | 紙・札・卓・岩のような、触れる物として描きます。手記は和紙、という決まりが既にあります |
| 迫るもの | 崩壊の暦は「残り N 日」の文字と粒です。出立の画面には暦が出ません | 暦を、減っていく物として見せます。次の 1 歩で何日減るかを、押す前に見せます |
| 選ぶ重み | 行き先の中身は、右の板の文字で読みます | 行き先を選ぶ前に、何が待っているかを絵で見せます。知らない相手は「？」のまま見せます |
| 反応 | ホバーで 6 px 浮きます | 選べる所だけが浮く、灯りが届く、札がめくれる、のように、選べることを動きで見せます |
| 積み重ね | 何度目の出立か、どこまで降りたかが、支度のときに見えません | 同じ探索者が潜り直す形になったので、これまでの深さと回数を、降りる前に見せます |

## プロンプト本文

### 共通の前置き（どの依頼にも先に貼る）

```
Unity で作っている日本語の 2D カードバトルの、戦闘の外の画面を作り直します。今の画面は情報は足りていますが、簡素で、ゲームらしい面白みに欠けます。規則と、画面に出す情報と、操作は変えません。見せ方だけを変えた案を、切り口の違う 3 つずつ作ってください。

# 1. ゲームの概要

- PC 向け、16:9、横画面です。基準は 1920×1080 です。画面の文言は全て日本語です。絵文字は使いません。
- 1 人の探索者が、地下の 7 つの層を降ります。層ごとに地図があり、部屋をつないだ道を、入口からボスまで進みます。部屋の種類は、通常戦闘・精鋭・階層ボス・休息・情報収集・イベント・死亡地点の痕跡・秘跡の彫り です。
- 世界は「崩壊の暦」で 100 日後に終わります。まだ踏んでいない部屋に入ると 1 日進みます。踏んだ部屋へ戻るのは 0 日です。
- 死ぬと拠点に戻り、同じ探索者がまた降ります。札の習熟と手記は持ち越します。
- 出立の前に決めるのは、束（デッキ。73 種から 20〜40 枚、1 種 3 枚まで）、道具 3 枠（8 種から）、消耗品 3 枠（5 種から）です。
- 層は、1 層が「燦光の樹海」（沈んだ森。天井の大穴から陽が落ちる。若草と陽の明るい層）、2 層が「■■の秘跡」（砂と白い石の柱）です。3 層からは竜・寄生・亡霊の 3 つの領域に分かれます。暗い層は最後の星空の層だけです。

# 2. 見た目の決まり（戦闘画面と同じ）

色は役割で固定します。
- 地 #10141d / パネル rgba(16,20,30,.88) / 不透明パネル #141925 / カードの地 #171c28
- 本文 #ecebf2（24 px 未満の文字は必ずこの色）/ 補足 #a9adbd / 罫線 rgba(157,166,186,.26) / 鈍鋼 #6d7787（線だけ）
- 琥珀 #e8a84c（自分・灯り・選択中・ボタンの枠）/ 灯芯 #ffd89a（最も重要な強調を 1 点だけ）
- 緋 #c2483f（HP のバー）/ HP の文字 #e36a5e / 菫 #8b6fd0（敵・危険）/ 燐光 #b9a3ff（威力の数字）/ Guard #8fc4d8 / ボス #d08cf0（必ず二重枠と組にする）
- 和紙 #f0e6d0 と、その上の文字 #1d1a16（手記の頁）
- 暖色（琥珀・灯芯）は、プレイヤーの側にだけ置きます。琥珀の灯りがプレイヤーの居場所だ、という世界の決まりです。

文字は、見出しが Shippori Mincho、本文が Zen Kaku Gothic New、数字が IBM Plex Mono です。最小の文字は 16 px です。役割の色で書く文字は 24 px 以上だけにします。角丸は 6 px、線は罫線 1 px・枠 2 px です。破線は「まだ・空き・外れ」を表します。ぼかしは使いません。アイコンは 24×24 の枠の線画で、線の太さは 2.2 px です。

# 3. 作れる範囲

- 最後は Unity の uGUI に写します。単色とグラデーションの画像、9 スライスの枠、位置・大きさ・透明度・回転の動きで作れる形にしてください。背景のぼかしと、複雑なマスク合成は避けます。
- 絵は、あとで Krita で描いて差し込めます。絵が要る所は、単色の影絵か、枠と名前の仮置きにしてください。下手な絵を描くより、仮置きのほうが役に立ちます。
- 数値は全てゲームの計算側から来ます。画面は計算しません。

# 4. 足さないもの

- 新しい規則・新しい用語・世界観の理由づけ。今ある情報を、別の見せ方で出すだけにします。
- お金・装備・経験値・点数の評価。今のゲームにありません。
- ほかのゲームの画面の写し。切り口は借りても、形は作り直します。

# 5. 出力の形

- 1 案を 1920×1080 の 1 枚で作ってください。3 案は、切り口が名前で言えるくらい違うものにします。
- 各案に「何を優先して、何を捨てたか」を 3 行で添えてください。
- 今の画面に無い情報を足したときは、足したと書いてください。
```

### 依頼 1: 探索の地図

```
# 依頼: 探索の地図の画面を、3 つの切り口で作り直す

## 今の画面

- 上に高さ 96 px の帯があり、層の名前、暦（「残り N 日」と粒 30 個）、HP とスタミナ（文字だけ）、手記・所持カード・設定のボタンが並びます。
- 左の 1060×680 の範囲に地図があります。ノードは 88×88 の角丸の四角で、塗りは単色、中に 44 px の線画のアイコンが 1 つです。行は上から下へ並び、入口が上、ボスが下です。1 層は 11 個（行の幅 1・3・3・3・1）です。線は直線の破線です。
- ノードの状態は 5 つです。今いる所（琥珀の太い枠と光）、進める所（琥珀の枠が明滅）、戻れる所、踏んだ所（薄くなる）、遠い所（破線の枠）です。遠い所も種類の名前は見えていて、中身の行だけが伏せられます。
- 右に、選んだノードの詳細の板（種類・敵・脅威・「暦 残り 87 → 86 日」・「進む」のボタン）と、持ち物の板（道具の札、消耗品の枠 3 つ）があります。
- 1 回目のクリックで選び、同じノードをもう一度押すと進みます。

## 見本の場面（3 案とも同じ場面で作る）

1 層「燦光の樹海」、残り 87 日、HP 38 / 50、スタミナ 8 / 10。入口と 2 行目の通常戦闘を踏み、今は 2 行目にいます。進めるのは 3 行目の休息と精鋭で、精鋭を選んでいます。精鋭は「錆槍の竜兵」と、まだ知らない相手（？）の 2 連戦です。道具は 日読みの砂・息継ぎの笛・灯芯の欠片、消耗品は 薬草・早駆けの丸薬・空き です。

## 作ってほしい 3 案

1. 手記に描く地図。地図を、探索者の手記の見開きにします。左の頁に墨で描いた地図、右の頁に選んだ場所の書きつけと「進む」を置きます。踏んだ所は墨が濃く、遠い所は鉛筆の下書きです。頁の上を、探索者の灯りが照らします。手記のほかの頁（敵・ダンジョン・メモ）は、本の端の見出しから開きます。
2. 層の断面を降りる地図。層を岩の断面として描き、部屋を岩に開いた空洞にします。空洞の中には、その層の光が見えます（1 層なら若草と陽）。踏んだ道と、今いる所から進める道だけが明るく、遠い空洞は暗いままです。上から下へ降りる向きを保ち、7 層のうちどこにいるかを左の端に出します。
3. 卓に並べる場の札。部屋を、卓に並べた札にします。戦闘の向きに合わせて、左から右へ進みます。進める札だけが卓から浮き、探索者の駒が今の札の上に立ちます。暦は「残る日の束」と「過ぎた日の束」の 2 つの山にします。

## 見てほしい点

- ノード式の地図は、部屋ごとにイベントと敵を持つ洞窟の形に作り直すと決まっています（部屋のつながりは今と同じ、点と線です）。どの案も、部屋と通路に読み替えられる形にしてください。
- 次の 1 歩で暦が何日減るかを、押す前に見せてください。
- HP とスタミナは、戦闘画面と同じ記号（ハートとバー、琥珀の粒）で出してください。
```

### 依頼 2: 出立の画面

# 依頼: 出立の画面を、3 つの切り口で作り直す

## 今の画面

- 流れは、拠点 → 出立の 1 段目「デッキを組む」→ 2 段目「出立の支度」→ 探索 です。
- 1 段目は、左に札の一覧（156×219 の札が 6 列 × 3 行、札の下に「− ×n ＋」）、上に絞り込み（属性とコスト）、右に札の詳細・枚数の箱・今のデッキの一覧・「出立の支度へ」のボタンです。
- 2 段目は、左に道具の枠 3 つと品の札 8 個、消耗品の枠 3 つと品の札 5 個、右に開始の位置の図と「出立する」のボタンです。品の札は名前と説明の文字だけで、絵がありません。
- 背景は、灯りの部屋のグラデーションと、光の円 2 つ、粒 26 個です。探索者の姿と、崩壊の暦は出ません。
- 拠点の画面は別にあります。同じ探索者が潜り直す形になってからは、拠点で決められるのは「出立する」と「タイトルへ」だけです。

## 見本の場面（3 案とも同じ場面で作る）

探索者はケイト。残り 87 日。束は 24 枚（攻撃 11・防御 6・スキル 3・スタンス 2・移動 2）、道具は 日読みの砂・息継ぎの笛・空き、消耗品は 早駆けの丸薬・薬草・空き です。

## 作ってほしい 3 案

1. 支度の卓。2 段を 1 画面にまとめます。左の卓に持ち札を並べ、下の棚に道具と消耗品を物として並べ、右の「荷」に詰めます。束は、厚みが枚数になる札の山で見せます。
2. 探索者と装い。探索者の立ち姿を中心に置き、束は腰、道具は帯、消耗品は袋、と体の 3 か所から開きます。開いた物の選び直しは、右の板で行います。名前と、これまでの出立の回数といちばん深い層を出します。
3. 降り口の前。拠点と出立を 1 つの場面にまとめます。降り口の向こうに 1 層の光が見え、その上に崩壊の暦、右に 7 つの層と前の生が終わった深さを出します。支度は足元の 3 つの箱（束・道具・消耗品）から開き、最後に「降りる」を押し続けて出立します。

## 見てほしい点

- 一覧の札は小さくなるので、小さい札で読ませるのは、コスト・属性・届く間合い・名前・主な値 1 つだけにしてください。全文は詳細で読ませます。
- 道具と消耗品は、文字の行ではなく、物として並べてください。絵は仮置きでかまいません。
- 支度が整ったことと、出立のボタンが押せることを、1 か所で分かるようにしてください。
