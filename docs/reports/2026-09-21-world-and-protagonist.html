明るさの山は四層。そこから光が抜けていく

背景 7 枚・敵 19 体・UI が 1 つの世界に見えるための約束です。物語は持ちません。正本は .claude/docs/vision/world-v1.md。

  • 規則 1

    澱は深いほど濃い

    浅い層では薄まって色が出ません。深いほど紺と菫が出ます。色は濃度であって演出ではありません。

  • 規則 2

    光源が層ごとに替わる

    陽光 → 斜光 → 結晶 → 全方向 → 散乱光 → 雷の縁 → 澱の発光。どこにいるかを光だけで判別できます。

  • 規則 3

    暖色はプレイヤーだけ

    琥珀の灯りがプレイヤーの居場所です。四層以降は結晶のほうが明るく、灯りが役に立たなくなります。

あと 2 つ。明るさの山を四層に置きます（三層を暗くしておかないと四層の輝きが効きません）。結晶は四層を境に増えます（二層で芽を出し、三層で大蛇の背に育ち、四層で壁と天井を覆う。一層には 1 つも置きません）。

明るさの配列

1 燦光の樹海2 沈んだ都3 大黒蛇の住処4 輝晶の間5 血染めの死海6 獄雷峡7 果てなき世界

一層と二層は明るく鮮やかです。三層でいったん落とすのは、四層を輝かせるための溜めです。暗いところを 1 つ挟まないと、輝晶の間の光が「明るいものの続き」になります。五層から下は 赤 → 黒紫 → 紺 の順に光を抜いていきます。

七層

層名前読み見えるもの光源主な色
1燦光の樹海さんこうのじゅかい沈んだ森。天井の大穴から陽が落ちる。彩度の高い緑と強い光条天井の大穴からの陽光若草 + 陽
2沈んだ都—一層より古い時代の地表。石の柱列と砂。柱の根元に菫色の結晶が芽を出す崩れた天井からの斜光砂と白石
3大黒蛇の住処だいこくじゃのすみか壁からうねり出た黒い大蛇がとぐろを巻く大蛇の背の結晶藍紫
4輝晶の間きしょうのま結晶の柱が林立する大広間。影が横と上から差し、人影は逆光で黒く抜ける結晶そのもの。全方向白と淡菫
5血染めの死海—干上がった赤い海床。巨大な肋骨が門のように立ち、塩が白く析出している赤い靄の散乱光緋と塩白
6獄雷峡ごくらいきょう切り立った谷。黒い雷が崖を走る。谷幅を竜が占める獄雷の縁の光だけ黒紫
7果てなき世界—床も天井も壁も無い。澱そのものでできた空洞。中央に湧き口がある澱そのものの発光紺と菫

各層で絵にすること

  • 一層: 唯一、地上の光で歩ける層です。探索者のランタンはほとんど役に立ちません。
  • 二層: 明るい画面の中で紫が浮くので、結晶の初出がはっきり読めます。
  • 三層: 七層で唯一の「暗い上層」です。ここを暗くしておくことで次の輝晶の間が効きます。
  • 四層: 灯りが完全に無意味になります。探索の難しさが「暗くて見えない」から 「眩しくて先が見えない」 へ反転します。
  • 五層: 輝晶の間の白からここで一気に赤へ振ります。明るさはここから抜けていきます。
  • 六層: 獄雷は「黒い雷」なので背景より暗く抜け、縁だけが菫に光ります。
  • 七層: 上下が分からないこと自体が最終層の異常さです。探索者は浮いています。

共通の色

背景だけ層で差し替え、UI の色は変えません。 実装が楽で、プレイヤーも読み方を覚え直さずに済みます。

敵の命名

通常敵 = [澱の浸かり具合] + の + [生前の役目]   例: 錆槍の衛士
精鋭   = [象徴する構え]   + の + [役職名]       例: 鉄壁の門衛長
大物   = [肩書き]         + カタカナの固有名     例: 大黒蛇 セルク
前に置く語意味主に出る層
錆澱が金属を侵している。まだ体は固まっていない1〜2
澱澱を帯びている。体の中に溜まり始めている1〜4
灰澱が抜けて脆くなった。崩れかけ2〜3
晶結晶が育った3〜4
燐結晶が発光している4〜7
  • 固有名は大物だけ。出し惜しむと大物の登場が事件になります。
  • 漢字 2 + 漢字 2、読みは 6〜8 音。敵名枠に収まり、手記でも折り返しません。
  • 上位種は後ろの語を変えない。澱走りの供犬 → 燐光の供犬。同じ系統だと一目で分かります。
  • 和の武術語を使わない。錫杖・兜割り・薙ぎ払い・長柄は置き換えます。
  • 腐敗語を使わない。腐肉・白骨・亡者・這うもの・吊るし首は使いません。ホラー感はほぼこの 5 語から出ます。

プレイヤーの意匠

仕様の正本は art_document/briefs/player_swordsman.md です。共通規約として持つのは 3 つだけです。

  • 顔は面で隠す。目を光らせません（敵と読み違えるため）。輪郭は 面 + フード + マント で固定し、世代が変わっても変えません。
  • 暖色はプレイヤーだけ。灯り・選択中・継承の間は琥珀 #e8a84c です。
  • 装甲を描かない。アーマーは凍結中なので、板金と肩当ては置きません。

大物 3 体

名前層姿絵としての狙い
大黒蛇 セルク3壁からうねり出た黒い巨躯。とぐろを巻き、鎌首だけを下ろす。背に結晶動かない。結晶の発生源で、この層の唯一の光源
獄竜 ガルド6四足・二対の翼の欧州型。黒い雷を纏う。後ろへ反る二本の角、細長い頭、重い顎暗い谷で「黒より黒いもの」が動く。灯りを当てても照らし返さない
澱の胎 オルド7湧き口そのもの。空洞の中央に穴として開く上下の無い空間の、唯一の中心

崖と谷底の人影が定規の役をします。ガルドは翼の先が両側の崖に食い込む構図で描き、大きさを伝えます。
