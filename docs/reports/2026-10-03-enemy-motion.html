攻撃と倒れは、まず絵 1 枚を画面の側で動かし、要所の 2 枚だけ絵を足すのがおすすめです

3 枚の絵は、それぞれ別の敵の見た目にしました。動きの作り方は 3 段階あり、下の段ほど手間がかかります。いちばん軽い段は新しい絵が要らないので、戦闘の担当がすぐに作れます。

  • すぐ始める

    絵 1 枚を画面の側で動かす

    踏み込み・被弾の揺れ・倒れて消える動きを、Unity の側で付けます。新しい絵は要らず、戦闘の担当の作業（#288）です。

  • 次に足す

    攻撃と倒れの絵を 1 枚ずつ足す

    こうだいさんが Krita で 1 体につき 2 枚作ります。画面の側の動きと組み合わせると、要所だけ絵が切り替わります。

  • 必要になったら

    ボーンを入れて動かす

    絵を部品に分けて骨を入れる方法です。手触りの確認（#79・#60）で動きが硬いと感じたときに考えます。

3 枚とも左向きのまま使います。絵は画面で向く向きのまま描く決まりに変えました（2026-10-03）。敵は左向き、プレイヤーは右向きで描き、Unity では反転しません。前の決まり（全員右向きで描き、敵だけ Unity で反転する）では、敵が行動するたびに反転が外れて後ろを向く不具合も見つかったので、反転ごとやめます（#288）。上級の 2 枚は幅が 800 と 900 で、決まりの 640 より広いので、穂先を切るか表示枠を広げるかを見た目の担当が決めます。

動きの作り方は 3 段階あります

紙人形にたとえると分かりやすいです。1 段目は、1 枚の紙人形を手で前後に滑らせたり傾けたりします。2 段目は、構えの違う紙人形を何枚か用意して、要所で差し替えます。3 段目は、紙人形を腕・脚・槍に切り分けて割りピンで留め、関節ごとに動かします。

2 段目の絵を Krita で作る手順

攻撃の絵（槍を振り抜いた構え）

今の待機の絵を見本にして、同じ竜兵が別の構えをとった絵を作ります。1 体につき 30〜60 分の見込みです。

  1. 待機の絵の .kra を「名前を付けて保存」で複製します（例: 竜の槍兵2_攻撃.kra）。大きさは同じ 640 × 1536 のままにします。
  2. 新しいレイヤーに、攻撃の構えを棒人間でざっくり描きます。足の位置は待機の絵と同じ下端の中央にし、待機の絵と同じく左（プレイヤーの側）を向かせて、槍は水平に振り抜いた向きにします。線は黒で、太めで大丈夫です。
  3. AI 生成のパネルで「Control layer」を追加し、種類を Scribble にして、いま描いた棒人間のレイヤーを選びます。「From image」のボタンは押しません。自動で線を取り出す部品の使用条件が確かめられていないためです。
  4. もう 1 つ Control layer を追加し、種類を Reference にして、待機の絵のレイヤーを選びます。顔つき・鱗の色・甲の形を、待機の絵に寄せるためです。
  5. 指示文は待機の絵と同じものの末尾に , attacking, swinging polearm, dynamic pose を足します。負の指示文は同じです。
  6. Batches を 4 にして Generate を押し、出た絵から待機の絵にいちばん近い 1 枚を選びます。
  7. 細部（甲の形、角の本数、槍の飾り）が待機の絵とずれていたら、手で描き足して合わせます。この描き足しのレイヤーは結合せずに残します。人の手を入れた証拠になるためです。

倒れの絵（膝をついて槍を落とした構え）

攻撃と同じ手順で、棒人間を「膝をつき、上体が前へ崩れ、槍が手から離れて床に落ちる」形にします。指示文の末尾には , kneeling, defeated, dropped polearm を足します。

守ること

  • 名前が noob で始まる Pose と Reference のモデルは使いません。生成物の商用化を禁じる条件があるためです。Scribble と Reference は、製品に使える側のモデル（xinsir の union と h94 の IP-Adapter）で動きます。
  • 一部だけ描き直すときは、選択範囲に Refine を強度 80% 以下で使います。80% を超えると、条文を確かめられない部品が動くためです。
  • できた絵は、見た目の担当が背景を抜いて（向きは左向きのまま）、chr_<敵の id>_act_sweep.png（攻撃）と chr_<敵の id>_react_down.png（倒れ）として取り込みます。

  • Scribble と Reference を組み合わせて、待機の絵とどこまで同じ竜兵に見える絵が出るかは、まだ試していません。絵柄の決まり（style-guide）にも「同じ体の差分をどう揃えるかは未調査」とあります。揃わなければ、Flux 2 Klein 4B の編集で「槍を振り抜かせる」形を試します。
