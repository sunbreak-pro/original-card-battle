3. 積んだ PR は、取り込み先を main に付け替えてから merge する

今日から下の PR を merge したら、上の PR の取り込み先を main に付け替えます

引っ越しの段ボールを積んだまま下の箱だけ運び出すと、上の箱が宙に浮くのと同じです。付け替えないまま上の PR を merge すると、中身は消えた下のブランチに入り、main には届きません。前回の #255 はこれで main に入りませんでした。

いま積んであるのは #272 → #275 です。戦闘の担当も、このあとコアの PR と敵 AI の PR を #274 の上に積みます。どれも PR 本文に「merge 後に取り込み先を main に付け替える」と書かせています。

  1. いちばん下の PR（取り込み先が main のもの）を merge します。
  2. その上に積まれた PR を開き、題の右の「Edit」を押します。
  3. 題の下に出る取り込み先（base）のボタンを押し、main を選びます。「Change base」の確認が出たら押します。
  4. 差分が、その PR で足した分だけになっていることを「Files changed」で確かめてから merge します。
  5. さらに上の PR があれば、2〜4 を繰り返します。

merge した後のブランチに担当がコミットを足すと、その分は main に入りません。足したいことが出たら、新しい PR にするよう担当のチャットに伝えてください。
