もの正本理由

2. 効きが大きい取り込み設定

項目値効き
Pixels Per Unit100画面の大きさには影響しません。UGUI の Image では RectTransform が決めます。SetNativeSize() を揃えるためだけの値です
Mesh TypeFull Rect（既定は Tight）Tight はアルファからメッシュを作るので、瘴気のにじみと低アルファの縁が切られます。1 体が同じ sprite を 3 枚の Image で共有するので、完全一致が要ります
PivotCustom (0.5, 0)（既定は Center）Bottom は「テクスチャ矩形の下辺中央」であって「足の中心」ではありません。書き出し規約を守れば一致しますが、破れたとき Custom なら実測値を書けます
Generate Mipmapon（既定は off。要実測）1536 の絵を実画素 450〜900 で出すので 1.7〜3.4 倍の縮小です。容量 +33%（20 枚で 18.8 → 25 MiB）
Filter ModeTrilinear（既定は Bilinear）ミップを入れるなら段の切り替わりを混ぜないと、姿勢の scaleY で見えます
Standalone の Overrideon + BC7ここが 0 だと上書きが丸ごと効きません。 最も静かに失敗する箇所です
Max Size2048（既定のまま。1024 にしない）1024 を保険に置くと、大きく書き出した絵を 683 × 1024 に落として 4 の倍数を割り、圧縮を壊します。保険が事故を作ります
Alpha Is Transparency / sRGB / Wrap / Aniso既定のままSprite では既に正しい値です。「off の既定を直す」と書くと .meta の diff を読み違えます

3. 自動で当てる 3 つの手

手既存のファイルにも効く値をテキストで見られる手で直した値を守る採否
A. Preset + Preset Managerいいえ（初回だけ）はいはい採る
B. AssetPostprocessor版番号を上げればいいえガード次第見送り
C. フォルダ単位の preset（Unity の見本）はいはいいいえ見送り

A を採ります。値が .preset というレビューできるテキストに残り、Inspector で手直しした 1 枚を潰さないからです。C は約 190 行の Editor コードで、手で直した値が次の再取り込みで黙って戻ります。立ち絵は Pivot を 1 枚ずつ詰める可能性があるので、その手は採りません。

登録は PNG を入れる前に済ませます。 既定 preset は初回の取り込みにしか当たりません。既存に当て直せるのは Inspector の Reset と、C# の preset.ApplyTo() + WriteImportSettingsIfDirty() の 2 つだけです。Reimport も ForceUpdate も効きません。

5. 権利の整理

論点結論
OpenRAIL++-M は生成物に権利を主張するかしません。「Licensor claims no rights in the Output You generate using the Model」。義務は重みの再配布に掛かり、PNG の同梱は再配布ではありません
使用制限は生成物にも及ぶか及びます。同じ節の 3 文目「No use of the output can contravene any provision as stated in the License」。竜と亜竜の絵はどの制限にも触れません
Apache-2.0（FLUX.2 klein 4B）の NOTICE要りません。生成物は Work の再配布ではありません。9B 版は商用不可なので入れません
台帳は法の要求か違います。米国は登録申請時の開示、日本は登録も届出も不要です。台帳は自分で説明するための任意の記録です
画像検索（similarity_check）の位置づけ文化庁のチェックリストが「利用に先立って類似していないか確認することが必要」とし、手段として画像検索を名指しします。異常検知ではなく、資料が挙げる確認手段そのものです
指示文を残す意味同資料が、指示文に固有名詞を入れると依拠性が認められやすいと述べます。全文を辿れることが、固有名詞を使っていない証拠になります
Steam の開示Pre-Generated として申告し、ストアページに公開されます。 実装を詳しく述べるよう求められ、審査でマーケティング素材と照合されます。日本語の文面も要ります
