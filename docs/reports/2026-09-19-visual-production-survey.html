キャラ・動き・背景を、できるだけ 0 円で作る

問い: 絵を作るためにこうだいさんは何をすればよいか。予定している出費を 0 円に近づけられるか。

結論: 0 円で全工程を回せます。代わりに増えるのは、こうだいさんの手の時間（選ぶ・直す・骨を入れる）です。

画像生成は API（Gemini は無料枠なし）をやめてローカルの ComfyUI に、描画は CSP の購入をやめて Krita に、動きは敵を Unity 2D Animation・主人公を Live2D FREE にします。

ただし 8 GB の GPU で「自動パーツ分け」と「同じ顔を保つ学習」が通るかは未実測です。最初に 1 晩かけて測り、そこで 0 円案を確定させるのが次の一手です。

こうだいさんがすること / Claude がすること

1 体を通す順番です。人 がこうだいさんの手の作業、Claude が Claude の作業です。

  1. 初回準備と実測（1 回だけ、1〜4 時間）

    人Krita と ComfyUI ポータブルを C:/ai/ に入れ、モデル 2 つを置いて起動する。Unity と Chrome を閉じた状態で実測を回す。 Claude導入手順書と起動 .bat、台帳、スタイルガイド案、実測の手順と記録表を作る。ComfyUI を公式 MCP / API で動かす。

  2. 仕様と影絵

    人影絵 3〜5 案から 1 つ選び、直したい点を 1〜2 行返す。主人公の見た目（性別・年齢・装束）を決める。 Claude仕様カードと SVG の影絵を作って撮る。

  3. 候補の生成

    人8 枚から 1〜2 枚を選び、理由を 1 行書く。 Claudeプロンプトとワークフローを書き、一括生成して seed とモデル版を台帳に残す。

  4. 背景除去と加筆（1 体数時間）

    人Krita で顔・手・武器の崩れを描き直す。人の創作的な寄与（著作権の根拠）はここに集まる。 Claudeisnet-anime（Apache-2.0）で背景を抜き、直す箇所を切り抜いて指示書にする。

  5. パーツ分けと動かす

    人自動分けの結果（前髪・武器・袖の重なり）を直す。2D Animation で骨とウェイトを付ける。主人公は Live2D FREE。 ClaudeSee-through で層つき PSD の下書きを作る。Unity の取り込み設定、プレハブ、配線を MCP で組む。

  6. 演出・UI・背景・確認

    人実画面で手触りに良い / だめを返す。 ClaudeParticle・シェーダー・UGUI をコードで書き、1080p / 720p で撮って読みやすさと時間を測る。

いま一番重いのは「人」の欄です。Claude は絵そのものを描けないので、選ぶ・直す・骨を入れるの 3 つは代われません。

今回わかった大事な点

  • Gemini の画像生成に無料枠はありません。Flash Image / Flash Lite Image / Pro Image すべて Free Tier が「Not available」です。API で 0 円にする道はありません。
  • ComfyUI ポータブルが新しい GPU にそのまま対応しました。Python 3.13 と PyTorch CUDA 13.0 を同梱しており、RTX 50 系向けの torch を自分で入れる手間がなくなりました（公式）。
  • パーツ分けを自動化する道具が出ました。See-through は 1 枚絵を最大 23 層の PSD に分けます。ただし公式のピークは約 8 GB で、いまの空き（約 4.3〜6.2 GB）では既定の設定では載らない見込みです。
  • いまの差し替え口は静止画専用です。FigureView.cs:37-43 の SetSprite は Image.sprite を替えるだけなので、2D Animation や Live2D の動く絵は受けられません。動かす前に受け口の追加が要ります。
  • 塗った絵では被弾の白い点滅が見えません。SetSprite が色を白に戻し（FigureView.cs:41）、DepictionFx.Flash は色の乗算だけで点滅させる（DepictionFx.cs:113-119）ためです。白を足すシェーダーで直せます。
  • ヒットストップと揺れの値が設計書とずれています。コードは 0/40/70/110 ms と 6〜24 px（DepictionFx.cs:15-16）、v2 §5.3 は 60/80/110 ms と 2/4/6 px です。

置いた仮定と未確認

  • 1 ドル 150 円、導入 1〜4 時間、加筆 1 体数時間は推定です。電気代は 0 円に含めていません。
  • RTX 5060 Ti 8 GB での SDXL の生成秒数、See-through を低解像度にしたときのピーク、LoRA 学習が 8 GB で回るかは未実測です。
  • Krita の PSD を Live2D と Unity の PSD Importer が層のまま読めるかは未確認です（コミュニティの体験談だけ）。
  • CSP の無料期間の解約期限と、ボスが Live2D FREE のパーツ 30 に収まるかは未確認です。
  • AI Studio のブラウザ画面での無料生成は、日次上限と商用利用の可否が未確認なので案から外しました。
  • 外部の主張はワークフローの反証役が一次情報で照合し、Gemini の無料枠・Live2D FREE の上限・CSP の価格・両モデルのライセンス・ComfyUI の同梱内容は Claude が公式ページを直接開いて確かめました。

次に判断が要る点

1. CSP PRO はもう買いましたか。API キーは設定済みですか。

まだなら買わずに 0 円プランで始めるのを推します。買っていれば低コストプランの買い切り側の合計になります。

2. 生成の主経路を「クラウド主（#14）」から「ローカル主・API は保険」に差し戻しますか。

推奨は差し戻しです。API に無料枠がなく、ローカルの導入の手間も減ったためです。

3. 「ローカルは条件が来たら測る（#23）」をやめて、最初に実測しますか。

推奨は最初に測ることです。自動パーツ分けと LoRA 学習が 8 GB で通るかで、0 円プランが成り立つかが決まります。

4. ボスを Live2D から 2D Animation に変えますか。

推奨は 2D Animation で始め、パーツ 30 以内に収まれば Live2D FREE にすることです。v2 の決定からの変更になります。
