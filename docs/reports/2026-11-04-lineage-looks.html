01なぜこの結論か

色だけに頼らず、影絵の形でも系統が分かるようにしました

正典 v5 の §3 の規則 5 は「系統の色を混ぜない」で、竜は鱗の藍紫、寄生は爛れの色、亡霊は燐光の色を芯にすると決めています[1]。寄生の色だけは、見た目の担当が決めることになっていました。色だけで分けると、画面で小さく映ったときや色が読みにくい人には見分けにくくなります。そこで影絵の形でも分かるように、体に何が付いているかを決めました。付けた物は、竜は角と翼、寄生は外から刺さる芽と根、亡霊は薄れる下半身です。王と龍神には、「どの竜よりも大きい」「本編で姿を見せない」などの約束が正典にあります。そこで約束を守る見せ方を 3 案ずつ出しました[1]。

02描き分け

竜は藍紫、寄生は爛れの桃と灰緑、亡霊は燐光で、影絵でも見分けます

3 つの系統は、芯の色と影絵の印の 2 つで見分けます。
系統芯の色影絵で分かる印描かないもの
竜藍紫（H 235〜275、彩度 15〜40%）。例 #4e4a8c角・爪・尻尾、段が上がるほど翼と長い首特になし。今の決まりのまま（style-guide.md の §16.1、§16.2）
寄生宿主の獣は灰と土色。食い込む芽・根・蔓は爛れの桃 #9a6876（H 335〜355）と灰緑 #7f8f78（H 90〜130）獣の外周から芽か蔓が 1 か所以上はみ出し、体の中へ消える線で刺さります。宿主の目を根が覆います。竜の角と鱗（系統を混ぜないため）
亡霊燐光 #b9a3ff 付近の半透明（不透明度 40〜70%）人の影絵で、下半身ほど薄れます。生前の持ち物（剣・盾・灯）で格を分けます。琥珀（プレイヤーの色）、腐敗の描写

数は色の差（人の見た目の違いを表す指標 CIEDE2000 の ΔE、計算）です。2 前後で見分けがつき、10 を超えると別の色に見えます。どれも 10 を超えます。

寄生の桃は、正典 §4 の蔓絡みの獣窟の「濁った桃」と血染めの腐林の「桃紫」に合わせました[1]。赤い斜線は「敵の行動が届くマス」だけの意味なので、それに近い赤は寄生の体にも使いません[3]。

03三体の王

三体の王は、画面からはみ出す大きさで 1 体ずつ違う見せ方にします

2026-11-03 にこうだいさんが、大型の敵を枠や画面からはみ出す大きさで見せると決めました[3]（battle-visual-v1.md §4.3、#840）。王はその最初の使い手です。

竜王は、首と片翼だけで大きさを見せる案を推します。
案姿良い所気になる所
推奨 A 首と片翼だけ画面に入るのは頭・長い首・片方の翼だけです。藍紫の鱗に燐光の結晶の筋があり、息の前に喉が光ります。「どの竜よりも大きい」が一目で伝わります。描く面積も少なくて済みます。全身の形は見えません。
B 翼を広げた全身翼を画面の横幅いっぱいに広げた全身で、体は小さめです。竜の形がそのまま分かります。獄竜（翼の竜）と大きさで差が付きにくいです。
C 首だけが闇から首から先だけが背景の奥から伸びます。不気味で印象が強いです。竜王らしい翼と四足が見えません。
世界樹は、根が床を這う案を推します。
案姿良い所気になる所
推奨 A 脈打つ幹幹の割れ目が桃紫に脈打つ芯になります。根が床のマスを這い、枝に宿主の獣の殻が吊られます。画面の上へはみ出します。寄生の王だと形で分かります。根が床を這うので、マスの戦いとつながります。描く物が多いです。
B 巨獣を呑んだ木幹に呑まれかけた巨きな獣の頭が浮かびます。「宿主と寄生」が 1 枚で伝わります。歪みの根（中ボス）と形が近いです。
C 実が戦う樹そのものは背景になり、幹から垂れた巨大な繭の実と戦います。動く敵として描きやすいです。王の姿が背景に沈みます。
死霊王は、冠と霧と骨片の案を推します。
案姿良い所気になる所
推奨 A 冠の人影冠を戴く背の高い半透明の人影です。外套の裾が霧になり、周りに燐光の骨片が浮かびます。亡霊の後ろの語（魂・霧・骨）がそのまま絵になります。普通の亡霊と大きさ以外の差を冠に頼ります。
B 寄り集まった影多くの亡霊の輪郭が重なって、1 つの人影をなします。「呑まれた人の王」が伝わります。顔を描かないように気を付けます（腐敗の描写を避ける決まりがあるため）。
C 玉座ごと半透明の玉座に座ったまま動かない姿です。王らしく見えます。跳ぶ・押せないなどの亡霊の動きが伝わりにくいです。

04龍神と中ボス

龍神は星の欠けた形だけで見せ、還らずの英雄は顔の無い騎士にします

龍神は竜の系統に入らず、本編で姿を見せない決まりです[1]。還らずの英雄は、暗き死海に出る亡霊の中ボスです。名前の残らなかった英雄で、戦い方はターンごとに別のマスへ跳びます。

龍神は、星が欠けた形で見せる案を推します。
案姿良い所気になる所
推奨 A 無い星第 8 層の星空で、星が欠けた形が翼の無い長い龍に見えます。体は描きません。「姿を見せない」を守りながら形が残ります。今の星空の背景を使えます。気付かない人もいます。
B 閉じた瞼封印の中心に、閉じた巨大な瞼だけがあります。「眠っている」が一目で分かります。竜でも龍でもない形に見えます。
C 光の環燐光の環が龍の形に巻きます。綺麗で分かりやすいです。姿を見せていることに近くなります。
還らずの英雄は、顔の無い騎士の案を推します。
案姿良い所気になる所
推奨 A 顔の無い騎士顔の無い甲冑の騎士で、折れた剣と名の削れた盾を持ちます。跳んだ後のマスに燐光の残像が 1 ターン残ります。名前が残らなかったことを、顔と盾で見せられます。跳ぶ戦い方が残像で読めます。残像は画面の演出（battle）の仕事になります。
B 外套の旅人外套の旅人の姿で、先代の探索者に似せます。探索者の行く末を思わせます。継承の間の「帰らず」と混ざります（字を分けた理由が薄れます）。
C 大きな影だけ人の形をした大きな影で、輪郭だけが燐光です。描くのが軽く済みます。普通の亡霊との差が大きさだけになります。

05層の見た目

寄生の 2 層は暗くしすぎず、第 7 層は秘跡の柱を描き直して使います

2026-11-04 にこうだいさんが、暗い層を星空の果てなき世界だけにすると決めました（正典 §3 の規則 3）[1]。そこで新しい層の明るさも、空の平均の明るさ（画面の明るさを 0〜1 で表す相対輝度）で 0.003 の星空より明るく置きます。今の層は、明るい 1・2・4 層が約 0.66、3 層が 0.534、5 層が 0.488、6 層が 0.456 です[5]。

寄生の 2 層は、星空より明るく置く案を推します。
層案空の平均の明るさ光と色
蔓絡みの獣窟推奨 A0.40 前後根の隙間に滲む菫の瘴気と、芽の鈍い白緑の光。灰緑と濁った桃です。
蔓絡みの獣窟B0.30 前後同じ色で、根の影を濃くします。
血染めの腐林推奨 A0.30〜0.35幹の割れ目で脈打つ桃紫の光です。桃紫と灰緑。星空よりは明るく、5・6 層より暗くなります。
血染めの腐林B0.05 未満（暗い層）同じ色です。正典の規則 3 に「腐林も暗い層」の例外を足す必要があります。

注: 正典 §4 は血染めの腐林の色を「暗い桃紫」（提案）と書いています[1]。規則 3 と並べると、暗い色相を明るさ 0.30 以上で描く読み方になります。どちらにするかで、正典の書き方が変わります。

こうだいさんの指示で、今の 7 枚の背景から使い回せるものも選択肢にしました[4]。

第 7 層は、秘跡の柱を描き直す案を推します。
案姿良い所気になる所
推奨 A 秘跡を描き直す■■の秘跡の柱の列を、白石と濃い菫で描き直します。柱に三体の王の印を刻みます。明るさは 0.45〜0.50 で、名前の案は「三王の座」（さんおうのざ）です。第 2 層の手掛かり（龍神の彫り）とつながります。コードの遠景（柱）を使い回せます。第 2 層と見分けるために、色を大きく変える必要があります。
B 輝晶の間の奥結晶の柱の大広間で、上端だけに星空がのぞきます。名前の案は「封の際」（ふうのきわ）です。第 8 層の星空への入口に見えます。輝晶の間（亡霊の領域）と近すぎます。
C 3 色の広間左が竜の藍紫、中が寄生の桃、右が亡霊の燐光の大広間です。名前の案は「三界の境」（さんかいのさかい）です。三体の王が並ぶ層だと一目で分かります。新しく描く物が最も多いです。

層の名前を決めるのはメインのチャットです（正典の持ち主）。ここに書いたのは見た目の担当からの案です。

06骨と日数の色

暗き死海の骨は海獣のものにし、残りの日数は本文の色で出して残り少なくなると色を変えます

正典 §10 は、骨と赤の出どころを見た目の担当に決めるよう頼んでいます[1]。

暗き死海の骨は、海獣の骨と鉄の錆の案を推します。
案姿良い所気になる所
推奨 A 海獣の骨と鉄の赤骨は、干上がった海にいた巨きな海獣のものです。赤は血ではなく、海床に溜まった鉄の錆の色です。どの系統の印にもならず、亡霊の領域に置いても食い違いません。「血」の字の名残（旧名の血染め）が説明から消えます。
B 英雄が倒したもの還らずの英雄が倒した巨きなものの骨です。中ボスの伝説とつながります。英雄の強さの話が増えます。
C 龍神の抜け殻龍神の古い抜け殻の骨です。龍神への手掛かりになります。第 2 層の手掛かりと役が重なります。本編で姿を見せない決まりに近づきます。

瘴気のゲージが無くなり、崩壊までの日数を出すようになりました。色は正典 §6 で見た目の担当が決めます[1]。

残りの日数は、本文の色を残りに応じて変える案を推します。
案姿良い所気になる所
推奨 A 本文の色から段階で数字は本文の色 #ecebf2、枠は菫にします。残り 30 日で注意の色 #e6c35c と「△」、残り 7 日で緋 #c2483f にします。探索の画面の四隅の暗さと菫の滲みを、瘴気の % から残りの日数に付け替えます。色が変わる所が 2 つだけで覚えやすいです。今の暗さの仕組みを使い回せます。30 日と 7 日の境目は仮の値です。
B 燐光から菫へ旧いゲージの塗りと同じく、残りが減るほど燐光から菫へ寄せます。瘴気の色の流れを引き継ぎます。日数と瘴気が別物になった今は、意味がずれます。
C 色を変えない数字は本文の色のままにします。迫ってくる感じは四隅の暗さだけで出します。最も静かです。残り少ないことに気付きにくいです。

菫は、予兆の枠と灯り、瘴気の景色の色として残します[1]。

07今の竜の絵

Unity に入っている竜の待機の絵 3 枚は、銅色から赤茶で、藍紫の決まりと合いません

3 枚とも、明るい画素の色相の中央値は 17.7° から 22.6° で、藍紫（240〜280° の見当）から大きく外れています。
絵明るい画素の色相の中央値暖色の高彩度に入る画素
錆槍の竜兵 polearm_warped22.6°11.5%
晶槍の竜兵 polearm_crystal17.8°83%
不退の槍竜 polearm_unyielding17.7°10.9%

測り方は、Unity リポ（RPG-by-card）の次の画像から数えました。

Assets/Art/Characters/<id>/chr_<id>_idle_stand.png

不透明な画素のうち、明るさ（HSV の V）が 0.2 以上の画素の色相を数えました（2026-11-04、計算）。「暖色の高彩度」は、style-guide.md の §14.1 が敵に置かない色（色相 15〜65°、彩度 35% 超）です[2]。藍紫は色相 240〜280° の見当です。

直し方は 3 つあります。

  • A 塗り直す。 3 枚を Krita で藍紫へ塗り直します。色相の調整レイヤーで回し、錆は穂先と金属だけに残します。
  • B 決まりを変える。 正典の竜の芯の色を「錆びた銅と赤茶」に変えます。寄生の桃や HP の緋と近づくので、赤の扱いを見直す必要があります。
  • C 眷属だけ許す。 竜人と小竜だけは銅色を許し、亜竜・竜・竜王で藍紫に寄せます。

申し送り（2026-11-04-design-891-dragon-body-colour.md）で、メインのチャットに回しました。

08仮定と未確認

案はどれも絵を描く前の段階で、画面ではまだ確かめていません

  • 色の数値はすべて計算です。実際の絵と Unity の画面では確かめていません。
  • 亡霊の半透明（不透明度 40〜70%）は、影絵の関門の測り方（不透明度 50% 以上を影絵とする scripts/silhouette.py）と合いません。亡霊を測るときは閾値を下げるか、輪郭の燐光で測るかを決める必要があります。
  • 寄生の宿主の獣は、竜の小竜と混ざらないように、角と鱗を持たない獣（狼・猪・鹿など）を仮に置きました。種を決めるのはカードの担当です。
  • 第 7 層と寄生の 2 層の明るさは、今の層の値から置いた見当です。
  • 層の名前（第 7 層）を決めるのはメインのチャットです。
