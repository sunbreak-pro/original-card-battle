01なぜこの結論か

値を動かさず、今ある札だけで束を組めます

いまの初期の札は 32 種で、そのうちスタンスは 2 種です。全 64 種のうち、移動が中心のスキルは 3 種です。攻撃と防御は、コスト 1・2・3 を 1 種ずつ選べば、スタミナ（札を出すときに使う値。毎ターン 3 回復します）の使い分けを最初の束だけで覚えられます。どれも今ある札なので、値を動かさずに束を作れました。特性の語のほうは、設計書を直しても画面には出続けます。画面の文を作るプログラムが、語を自分で持っているためです。

02束の中身

11 種は、いまある札の値をそのまま使っています

11 種のうち 9 種は初期の 32 種から、2 種は探索で見つける札から選びました。値は札の設計書の今の表と同じです[1]。選び方は次のとおりです。

  • 攻撃と防御は、コスト 1・2・3 を 1 種ずつ選びました。スタミナは毎ターン 3 回復するので、3 の札を 1 枚出すか、1 と 2 の札を出すかを最初の束だけで選べます。
  • スキルは移動が中心の 3 種です。戦闘は間合い（相手との距離の目盛り）3 から始まり、最初期の攻撃は間合い 0〜1 と 0〜2 にしか届きません。詰める札が要るため、跳び退りと駆け込みを、探索の一層と二層で見つける札から最初の束へ移します。
  • スタンスの 2 種は、いまの初期の札にあるスタンスの全部です。デッキ（戦闘に持ち込む札の束）には、このうち 1 種だけを入れます。

デッキは 20〜30 枚になります。9 種を 3 枚ずつと、スタンス 1 種を 3 枚で 30 枚です。デッキの下限 20 枚と、同じ札 3 枚までの決まりは変えていません。最初期の 11 種は、特性を持たない形で書きました。

特性をなくす範囲を、語だけにするか効果ごとにするか

何が起きているか
2026-11-22 の指示は「特性の語をすべて消し、割り振られている特性は札の説明文に入れる」でした。2026-11-23 の指示は「既存の特性はすべて削除する」です。語だけをなくすのか、条件つきの効果ごとなくすのか、2 通りに読めます。
なぜ決める必要があるか
決めないと、札の説明文を書き直す Issue #1022 と、その後ろの 5 件（#1023・#1039〜#1042）に着手できません。効果ごとなくす場合、先に書いた文がすべて無駄になるためです。
選ぶと何が起きるか
  • 最初期の 11 種だけ効果も外し、ほかの札は説明文で残す: PR #1037 はそのまま使えます。Issue #1022 は残りの札を文に書き直します。戦法の柱（1 つの狙いにそろえた札の組）10 本と、習熟の仕組みは変わりません。
  • 語だけをなくし、11 種も効果を説明文で残す: PR #1037 の 11 種に、いまの効果を文で書き足します。例えば袈裟斬りには「間合い 0 なら威力 +5」と書きます。最初の束の札にも条件つきの文が付きます。
  • 条件つきの効果ごと、全部の札からなくす: 64 種が効果の列だけの札になります。Issue #1022 を書き直します。戦闘のプログラムの特性の仕組みを作り直す Issue が要ります。習熟で条件を緩める段を持つ 14 枚と、戦法の柱の「得をする札」の役も、作り直す Issue が新しく要ります。
推奨と根拠

最初期の 11 種だけ効果も外し、ほかの札は説明文で残す

最初の束は単純になり、2026-11-22 の決定と戦法の柱もそのまま使えるためです。
